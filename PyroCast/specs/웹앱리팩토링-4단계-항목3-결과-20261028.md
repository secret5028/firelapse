# 4단계 항목 3 — 결과 탭

사용자 ‘계속해’에 따라 확정된 순서의 결과 탭만 구현했다. 탐색·건물 탭, 엔진, 서버, 캐시 키, 결과 포맷, 셰이더, render_order는 변경하지 않았다. 시뮬레이션 실행 0회.

## 화면과 상태

- 저장 사례 선택과 목록 새로고침은 기존 경계 컨트롤러를 유지한다. 완료 여부와 저장된 종료 시간을 표시하며, 없는 실행 시간/엔진 버전은 만들지 않는다.
- 선택 실 카드에 FO·FGI·백드래프트·롤오버 지수 바와 현재 임계선(기본 100/70), 저장된 병목 요인을 표시한다. 지수는 어댑터의 degree×100 값을 그대로 사용한다. 반올림은 텍스트 표시에서만 한다.
- 바의 공통 축은 최소 200이며 더 큰 값/임계값이 있으면 확장한다. 지수 원값을 100으로 자르지 않는다. 미평가는 0점과 구분한다.
- 다중 셀 방은 ‘셀 목록 · 방 평균 없음’을 펼쳐 보여준다. 셀 버튼은 selection/set만 호출한다. 새 평균·최대 시계열을 만들지 않는다.
- 기존 온도·산소·발열 상세는 카드 안의 ‘계산값’에 유지한다. UI에서 bulk 대신 ‘상층 연소’를 사용한다.
- 본문 설명은 선택 카드의 ⓘ 또는 하단 접힌 ‘가정과 한계’로 정리한다. 기존 패널은 호환 핸들러/조회용으로 숨겨 두고, 필요한 DOM 입력만 새 카드로 이동한다. 실감보기·층/건물 맞춤·전체 메뉴 검토 기능을 보존한다.

## MC 집계 의미와 읽기 비용

서버 목록은 무작위 완주 표본의 조건 충족 수와 지수 최대를 이미 제공하지만, 현상별 최대 실 수는 제공하지 않는다. 그래서 ‘저장 표본 집계 읽기’ 버튼을 추가했다. 클릭하면 기존 결과 API로 완주 표본을 한 개씩 읽어 원래 방 ID로 셀을 중복 제거한다. 계산 엔진 실행이 아니라 저장된 점수의 집계다. 초기 로드에서 10개 대용량 파일을 자동으로 읽지 않는다.

- **≥100 표본 / 지수 최대:** 기존 목록의 무작위 완주 8표본 기준. 지수 최대는 저장 maximum_score×100.
- **최대 실:** 필수 2건을 포함한 전체 완주 10표본에서, 해당 현상을 전체 시간 중 한 번 이상 충족한 원래 방 수의 표본 간 최대. 동시 충족 실 수와는 다르다. 기준 차이를 표 하단과 ⓘ에 표시한다.
- 미완료 표본은 제외한다. 읽기 실패는 집계 미완료로 표시한다. null이 있으면 확인된 최대 실 수를 `≥n` 하한으로 표시하고 원인을 툴팁에 남긴다.
- 목록 갱신/종료 시 진행 중 읽기를 취소한다. MC 읽기는 현재 활성 사례·시각·카메라를 바꾸지 않는다. 원 playback은 집계 후 보유하지 않는다.

| 현상 | ≥100 무작위 표본 | 최대 실(전체 완주) | 지수 최대(무작위, 원값) |
|---|---:|---:|---:|
| FO | 6/8 | 1 | 161.4253435 |
| FGI | 0/8 | 0 | 94.5927456 |
| 백드래프트 | 7/8 | 2 | 193.0297217 |
| 롤오버 | 1/8 | 1 | 107.4377068 |

별도 저장 표본 검사에서 목록의 분자·지수 최대와 실제 degree 시계열이 일치함을 확인했다. UI는 161/95/193/107로 반올림한다.
