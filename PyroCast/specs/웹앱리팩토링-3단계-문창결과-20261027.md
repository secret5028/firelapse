# 3단계 openings 레이어 완료 — 2026-10-27

`Claude검토-3단계기준-기존화면코드-20261026.md` 2절과 사용자의 매 프레임 판정 지시를 적용했다. 이번 범위는 **문·창 레이어만**이다. 코어 및 나머지 레이어는 진행하지 않고 멈춘다.

## 구현

- `app/web/adapters/legacy_openings.js`: 원본 CAD 층·개구부와 층 그룹을 읽는 명시적 어댑터. 건물 SHA 확인, 원본 수정 없음.
- `app/web/layers/openings_geometry.js`: 기존 `exteriorWindowFace()`를 그대로 분리. 규격 외부 창, 테라스·난간 제외, 최소 외접 상자와 외부 면 선택을 보존했다.
- `app/web/layers/openings.js`: 외부 창 사각형과 실내 문 사각형을 독립 그룹으로 생성한다. 외부 창은 #62dcb0, opacity .65, depthTest true, renderOrder 30. 실내 문은 #e6bd68, opacity .9, depthTest false, renderOrder 46이다. 모두 transparent, depthWrite false이며 정책은 실제 LineLoop와 material에 적용한다.
- 창 카메라 방향은 **tick마다 모든 창**에 법선·카메라 방향 내적 `> 0`으로 판정한다. OrbitControls 이벤트에 의존하지 않는다. 뒤편 강조는 숨기고 현재 보는 외부 면만 강조한다.
- 층 가시성과 위치를 원본 CAD 그룹에서 매 프레임 반영한다. 문과 창 각각의 표시 토글을 제공하되 이번 단계에 패널을 새로 연결하지 않았다.
- building/resultMeta 동일성을 확인한다. 카메라·시간·선택·층 변경 또는 결과 메타만 변경할 때 기하를 재생성하지 않는다. 새로 소유한 선 기하·재질만 dispose한다.
