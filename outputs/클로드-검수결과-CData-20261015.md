## 2. 질문별 답

### Q1. CData로 구현 가능한가 — 역할 분담

CData가 담당 [문서]:
- `-P` 생성
  - MHDR: 표본 수, **SEEDS 고정** 필수
  - MRND: CONSTANT/UNIFORM/TRIANGLE/(TRUNCATED_)NORMAL/LOGNORMAL/BETA/GAMMA/USER_DEFINED_DISCRETE·CONTINUOUS, MINIMUM_FIELD/MAXIMUM_FIELD 기하 제약, ADD_FIELD
  - MFLD: VALUE/SCALING/INDEX/LABEL. **같은 RAND_ID를 여러 INDEX 필드에 연결하면 물성 묶음·문 상태 묶음을 일관되게 바꿀 수 있다.**
  - MFIR: HRR·시간 스케일, 거듭제곱 화재, 초기 훈소·유염 단계, 화재실 무작위 선택
- `&OUTP`: 실행별 스칼라 요약(MIN/MAX/TRIGGER_*/INTEGRATE). 7.7.7 엔진이 `&OUTP`/`&DUMP`를 모두 읽는다. [소스] read_dump
  - 실별 "첫 초과 시각"(TRIGGER_GREATER/LESSER)은 OUTP로도 뽑을 수 있다.
- `-A` 누적(parameters.csv + calculations), `-S` MSTT(히스토그램, 경험적 PDF, 평균 수렴, 결정트리)

앱이 담당:
- 실행: CData 배치 스크립트는 Windows에서 `background.exe`, Linux에서 `qfds.sh`가 필요하다. `work/.../cfast7` 폴더에 background.exe가 **없음**. [측정] 앱의 `cfast_runtime.run_native` 대기열로 실행하는 편이 낫다.
- 관찰 높이 기준 지표: 상·하부층 전환 조건이라 OUTP로는 표현할 수 없다.
- 실별·시간별 초과 비율 지도, 노출시간, 대표 사례 선정
- 유효성 검사·실패 분류(M5, 엔진 abort, 시간 초과)
- 병합 구획 제약: 병합은 F=1 일반문을 기준으로 하므로, 병합 내부 문은 변동 변수가 될 수 없다
- LLM 변수 화이트리스트와 실 ID 매핑

[미확인] — 소규모 시험으로 확인할 항목:
- 384줄 TABL을 가진 기준 입력을 CData가 그대로 보존하는지
- 생성 파일에 `&MISC MAX_TIME_STEP`가 유지되는지
- MFLD로 VENT `F` 배열을 지정할 수 있는지(지침 예시는 WIDTH/TOP INDEX 방식)
- `-k -o:CD` 실행에서도 calculations.csv가 생성되는지(OUTP FILE이 WALLS/MASSES이면 실패 예상)

### Q2. 일관성 검사와 현재 입력의 필수 수정

필수 수정은 §1 M1~M4. 검사 항목(앱 전처리, 표본마다):
- **에너지**: ∫HRR dt = 연소 질량 × ΔHc가 용도별 화재하중 범위 안. MFIR HRR 스케일은 피크와 총열량을 함께 바꾸고, 시간 스케일은 총열량만 바꾼다. 가연물량 변수는 시간 스케일, 화원 규모 변수는 HRR 스케일로 의미를 고정한다.
- **HRRPUA·화원 체적**: 면적을 고정한 채 HRR만 키우면 엔진의 화염 체적당 HRR 검사에 걸려 abort될 수 있다. [소스] read_chem `hrrpm3>4e6 → cfastexit`. 이 경우 "실패"로 분류하고, 면적 공동 스케일 또는 `MODIFY_FIRE_AREA_TO_MATCH_HRR` 검토.
- **기하**: 화원 반폭 < 구획 경계(현 runner assert 유지), VENT TOP ≤ COMP HEIGHT(M1 변경 시 재검), 착화 표면이 실 다각형 안에 있을 것.
- **묶음**: 재료(k, ρ, c, 두께, 방사율)와 착화 기준(369°C 등)은 하나의 이산 생성기 인덱스로 함께 변경한다(독립 표본 금지). 연료군(ΔHc, χr, soot, CO, HRR 곡선군)도 같은 방식.
- **문 상태**: 0/50/100%는 USER_DEFINED_DISCRETE + INDEX. 닫힘은 지침 예시처럼 언더컷 높이 또는 1% 누설로 정의를 고정. 병합 그룹 내부 문은 변수에서 제외하고 UI에 표시.
- **출력 검사**: 정상 종료, 시간 끝값, IGN·로그·HRR 일치(M5), NaN, 층 높이 범위(현 assert 유지).

### Q3. 최선·중앙·최악과 반복 비율의 정의

- 관찰 높이 지표(Q5)로 실 r, 시각 t, 표본 i의 초과 여부 H_i(r,t)를 정의한다. 샤프트 40개는 단일 구역이라 HGT 열이 없으므로 항상 상부층 값을 쓴다. [측정] 하부층 열은 60개 구획만 있음.
- 초과 비율 p(r,t) = Σ w_i·H_i / Σ w_i. **분모는 유효 표본만** 넣고, 유효 n과 실패 n을 함께 표시한다.
- 표본 수 불확도를 같이 보인다. Wilson 95%: 95/100 → 0.89~0.98, 50/100 → 0.40~0.60, 0/100 → 0~0.037. [측정] 계산값. "현실 확률"이 아니라 "설정한 분포에서의 초과 비율"로 표기한다.
- 대표 사례는 스칼라 심각도 S_i(예: 대상 공간의 첫 초과 시각, 초과 면적×시간)로 정한다. 5/50/95 백분위에 **가장 가까운 실제 계산 1건**을 재생하고 "표본 내 n번째 백분위"로 표기한다. S의 정의를 화면에 노출한다.
- 표시 구분: 통계 지도(비율)와 단일 재생(실제 값)은 별도 모드로 둔다. 병합 구획은 빗금과 "묶음 계산", 미계산 구획은 회색과 "미계산(안전 아님)", 실패 표본은 별도 수로 표시한다.
- 드문 고심각도 사례는 최악 백분위 재생과 "최대 심각도 사례"로 따로 노출한다. Codex 권고와 동일하게 유지한다.

### Q4. 369°C 조건부 착화의 범위·근거

- 공식 기능 범위: FIRE `IGNITION_CRITERION='TEMPERATURE'` + PLATE DEVC는 7.7.7 공식 입력이다. 착화 후 TABL 시간 원점이 착화 시각이 되는 것도 진단 HRR(착화 3 s 후 0.53 kW)과 맞는다. [측정]
- 근거 적합성: 369°C와 열물성은 NCSTAR 1-5C 종이 적층 시험의 적합값이다(후면 단열, 수평). CFAST PLATE는 양면 노출이고 수직 배치다. Codex가 이 차이를 명시해 둔 점은 적절하다.
- 핵심 한계는 M4의 근접장이다. 착화 판단보다 배치 가정의 영향이 크다.
- 대칭 진단이 MC에 주는 영향(M5): 표본마다 착화 대상이 많아질수록 무효율이 올라갈 수 있다. 무효율을 집계해 보고하고, 무효가 특정 변수 영역에 몰리면 해당 영역 결과의 대표성이 떨어진다는 점을 표시한다.

### Q5. 0.25 s와 하부층 OD 예외의 해석

[측정] 3F_R9의 HGT가 **정확히 0.100 m**에 고정된 구간: 150~300 s, 585~670 s, 1440~1800 s (361 샘플 중 122). PH_R5도 890 s 이후 같은 상태다.
- 솔버의 `radiation_fix` 하한 처리 결과로 보인다. [소스] update_data. radiation_fix 기본값은 [미확인]이지만 0.100 고정으로 보아 활성 상태다.
- 이 상태의 하부층(0.1 m × 바닥면적)은 실질적으로 단일 구역이다. 하부층 농도는 질량/미소체적이어서 수치 민감도가 크다. **-14.56% 예외는 이 구간(1590 s)에서 발생했다.**
- 관찰 높이 1.5 m 또는 1.8 m 기준으로 다시 비교하면(HGT < 관찰 높이 → 상부층 값) 전 구획·전 시간 최대차는 **OD 0.00512/m, 온도 0.853°C**다. 예외가 지표에서 사라진다. [측정]
- 권고: HGT ≤ 0.1 m일 때 하부층 값은 표시·집계에 쓰지 않는다. 지표는 관찰 높이 기준으로 고정한다.
- 시나리오 전반 적용 전 비교: 극단 조합 5~10개(최대 HRR, 최대 soot, 문 닫힘/열림, 착화 다수)를 1.0 s(엔진 기본 강제값)와 0.25 s로 각각 실행한다. 원시 층값이 아니라 **위험 지표**(실별 첫 초과 시각, 노출시간, 대표 선정 결과)의 차이를 본다. 정확도의 1차 제어는 허용오차이고, 시간간격 상한은 스텝 경로를 바꿀 뿐이다.

### Q6. 병목 계측과 행렬 최적화 제안의 근거

[측정] `multifloor-progress.json` 분석:

### Q7. 사전 계산·추가 계산·캐시·병렬 구조

- **사전 계산 라이브러리**: (화재실 × 핵심 이산 상태) 단위로 SEEDS를 고정한 CData 표본을 만든다. 각 실행은 독립 폴더에서 `run_native`로 돌리고, 입력 해시 캐시를 유지한다.
- **병렬**: 단일 실행은 단일 스레드(CPU 800 s ≈ wall 809 s [측정])라 독립 실행 병렬화가 처리량을 키운다. 동시 실행 수는 물리 코어 수 이하로, 메모리·디스크 I/O를 같이 측정해서 정한다. 응답시간 수치는 약속하지 않는다.
- **저장량**: 실행당 compartments 12 MB + zone 35 MB → 100개면 약 4.7 GB. 실행 직후 필요한 실별 시계열(관찰 높이 지표, T, OD, CO, O2)만 압축 저장하고, 원시 파일은 대표 사례만 보존한다.
- **자연어 질의**: LLM은 화이트리스트 변수의 조건 패치만 생성한다.
  - 기존 분포 지지 범위 안이고 조건부 표본이 충분하면 → 기존 표본 필터 결과를 보여주되 "기존 표본 n=…, 신규 계산 아님"을 표기
  - 범위 밖이거나 표본이 부족하면 → 신규 계산을 대기열에 넣고 진행 상태를 표시
  - 가까운 사례를 새 계산 결과로 표시하지 않는다(Codex 권고 유지)
- **중간 결과 표시(B안)**: CSV가 출력 시각마다 디스크에 반영되는지(버퍼링) 1회 시험한 뒤 적용 여부를 결정한다. [미확인]

### Q8. 최소 구현 순서와 필수 검증

0. **사용자 결정**: M1 구획 높이, M2 연기 수율 범위, 첫 변수 3~5개(제안: soot 수율, 주요 문 상태, 화원 규모 스케일, 착화 간격, 외기온).
1. **기준 입력 정리**(물리 동일성 회귀 포함): M2-a 수율을 CHEM으로 이동, M3 화원별 CHEM/TABL 분리. 정리 전후 결과가 같아야 한다.
2. **CData 연동 시험 — 1구획 진단 모델, 10개 표본**: `-P` 생성 파일과 기준 파일 diff, parameters.csv·seeds 재현성, OUTP→calculations.csv(`-k -o:CD` 포함), `-A`, `-S` 히스토그램. §Q1의 [미확인] 4가지 확인.
3. **전층 모델 3~5개 × 10분**: 실행, 유효성·실패 분류, IGN 검사.
4. **통계 파이프라인**: 관찰 높이 지표, p(r,t)+Wilson 구간, 첫 초과 시각·노출시간, 대표 사례 선정.
5. **UI**: 기존 UI는 그대로 두고 통계 레이어와 범례(병합/미계산/실패)만 추가.
6. **확대 계산**: 수렴 확인(MSTT CONVERGENCE_OF_MEAN 또는 앱), 1.0 s/0.25 s 회귀(Q5).
7. **성능 계측**(Q6 a→b)은 2~3단계와 병행 가능.
