# C-5 최악 급기 상태 — 구현·검증 결과

2026-11-02. C-5와 추가 두 항목만 구현. 다음 단계·push 없음.

## 구현

- 결과 MC 카드: 최악 표본 적용. 순위는 연소 실 수↓ → 주의 이상(원래 방의 최대 지수 ≥70) 실 수↓ → 최초 FO 시각↑. 완주·평가 가능한 표본만 사용, 동률은 표본 ID.
- 저장 파일: `simulation/config/lite-door-overrides.json`의 `fixed_state`. 기존 문 분류 정정은 보존. 건물 탭에 표본·문별 개방률·해제 버튼.
- 이후 ② 자동/수동 화점 입력과 MC에서 확정 상태가 극단/추첨보다 우선. 현재 playback·장면은 교체하지 않음. 입력 변경 후 저장 결과 동등성 라벨 재검사.
- R11 등 자동 제외 실도 C-2 사용자 수동 지정인 경우 MC 허용. 양의 연료·화원 상한 검증 유지, 자동 순위 제외 유지.
- 경로 표 지수 <70: 현상 —, 지수 숫자 유지. 원래 경로 색·평가값은 유지.
- 해제 직후 재적용 시 저장 완료 전에 버튼이 활성화되는 경합을 수정하고 UI 재검증.

## 코드 검사·한계

- Python 19개 테스트, Node 4개 테스트 파일 통과. 단위 검사에는 실제 적분 호출 없음. 자동/수동 ②가 계산 직전에 받는 4개 입력에서 확정 개방률 우선 적용을 검사.
- 엔진·셰이더·렌더 정책 등 기존 동결 대상 **56파일 SHA 동일**. 서버 동결은 C-5 범위에서 해제.
- 서버 `tools/serve_cfbt_building.py`: **+18 / −3줄**. 읽기/저장 경계와 POST `/cfbt/lite/fixed-openings` 추가. 기존 직렬 실행·예산 유지.
- 문 상태를 고정하는 기능이며 추가 시뮬레이션 없이 기존 결과를 새 설정 결과로 바꾸지 않음. 고정 설정 적용 후 옛 입력의 결과는 현재 설정과 동등하다고 표시하지 않음.
- 최악은 이번 두 표본 중의 최악이며 전역 최악/화재 발생 확률을 뜻하지 않음. 미완료/미평가 표본은 안전으로 간주하지 않음.
- 고정값을 우선하므로 이후 두 극단 입력이 같아질 수 있음. 기존 ② 실행 횟수 자체는 변경하지 않음.
