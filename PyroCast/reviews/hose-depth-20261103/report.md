# 외부 호스 깊이 가림 수정

외부 경로(room=null)의 본선·어두운 외곽선에만 depthTest를 켰다. 불투명한 소방차가 기록한 깊이에 의해 지면 호스가 차체 뒤에서 가려진다. 건물 내부 위험 경로는 기존 depthTest=false 표시를 유지한다. 차량 재질·경로 좌표·거리·호스 본 수·시뮬레이션은 변경하지 않았다.

설치된 Edge에서 비스듬히/위에서 전후 캡처 확인. 차량 위를 가로지르던 선이 사라지고 지면 선은 유지됨. 외부/내부 경로의 깊이 검사 분리 확인. 브라우저 오류 0, dispose 후 구독 0.

캡처: before 및 after의 initial.png/top.png. 운영 모듈 버전 쿼리를 갱신했다.
