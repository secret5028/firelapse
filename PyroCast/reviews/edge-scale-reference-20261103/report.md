# Edge 크기 비교 모형 표시 확인

사용자가 알려준 동일 주소(8832/data/wando-coldstore/model.html)를 설치된 Edge의 별도 시험 세션으로 확인했다. 사용자의 기존 Edge 세션 내부 상태는 직접 확인하지 못했다.

재현: 초기 자동 맞춤 시점에서 차량 일부가 캔버스 하단에 잘리고 사람은 화면 밖이었다. 모형 생성은 정상이며 Edge 자체 렌더 호환 오류는 재현되지 않았다.

수정: R5 및 경로 차량/사람의 실제 경계 상자를 포함해 초기 카메라를 맞춘다. 우상단 '소방차·사람 보기'는 경로·차량 표시를 켜고 같은 시점으로 이동한다. model.html의 운영 모듈과 운영 모듈의 번들 import에 버전 쿼리를 추가했다. 계산·치수·모형·엔진·서버는 변경하지 않았다.

검증: 설치된 msedge.exe, 별도 headless 세션, 1280×720. initial.png에서 차량과 사람 모두 확인. 1325/1400/2100초 공동 발광 0, 분출 화염 유지. 차량 길이8m·사람 높이1.75m, 표시 토글 왕복 통과, 오류0·dispose 후 구독0.

사용자 기존 세션의 캐시 또는 화면 상태까지 동일한 원인이었다고 확정하지 않는다. 최신 링크로 재접속하면 변경된 시점과 버튼을 사용할 수 있다.
