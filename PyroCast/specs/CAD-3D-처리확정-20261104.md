# CAD → 3D 처리 확정 (2026-11-04)

사용자 지시: CAD → 3D → 미흡한 곳 AI 공리 검토·보정 → 남은 미완은 도면에 표시. 도면 모델링 작업은 이 범위로 마무리한다.

## 공통 처리

- 층 좌표 정렬 후 반복 위치·형상을 비교해 계단·승강기·기둥을 판별한다. 기둥은 실이나 통로가 아니다.
- 기둥 자동 분류는 원본 기둥 검출점, 구조 표기, 여러 층의 동일 위치·형상이 함께 지지할 때 적용한다. 원래 실 레코드는 구조물에 보관한다.
- 본 프로젝트의 수직 이동·유동 연결은 계단·승강기로 한정한다. 램프 형상은 보존하되 수직 연결에는 넣지 않는다. 이는 모델의 범위 설정이다.
- 실내 호는 문 존재의 근거로 사용한다. 연결할 두 실은 호·문틀·실 경계로 확인하며, 단지 고립 실이라는 이유로 가까운 실에 문을 만들지 않는다.
- 복도 안에 계단 표기가 있다는 이유로 복도 전체를 계단실로 취급하지 않는다. 대응 영역이나 층 정렬이 불명확하면 표시로 남긴다.
- AI 검토 결정은 원본 CAD 해시, 대상 실, 형상 근거를 보관한다. 해시·형상이 맞지 않는 결정은 적용하지 않고 미확인으로 표시한다.

## 실행과 표시

공통 입력은 기존 CAD 로더가 만든 building JSON이다. `tools/finalize_cad_model.py`가 공통 공리와 검토 결정을 적용하고, 도면의 보정/추정/미연결/로더 오류 목록을 생성한다. `--publish`는 검증된 모델 입력과 보고서를 배치한다. 원본 CAD와 저장 시뮬레이션 결과는 변경하지 않는다.

AI 보정은 이번 작업에서 실제 도면을 시각 검토하여 기록한 결정을 사용한다. 새 CAD 업로드마다 외부 LLM을 자동 호출하는 서비스는 구현된 것으로 간주하지 않는다. 검토 기록이 없으면 AI 검토 미실시로 표시한다.

미완이 남아도 3D 열람과 위치 확인은 가능하게 한다. 입력 로더 실패를 계산 성공으로 표시하지 않는다. 시뮬레이션은 별도 실행이다.

## 호텔 적용 결과

- 14개 층, 257개 실 후보 → 251개 공간 + 기둥 중복 6개 분리.
- 미연결: 최초 71 → 문 인식·AI 검토 후 47 → 기둥 분리 후 41.
- 수직 연결: 6 → 20개, 계단·승강기만 포함.
- 남은 미연결 41개와 B1 R9 로더 오류는 숨기지 않고 도면에 표시한다.
- 결과 맞추기를 위한 문 추가, 미확인 공간 삭제, 계산 재실행은 하지 않는다.
