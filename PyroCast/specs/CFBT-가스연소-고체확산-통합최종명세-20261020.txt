1. 목적과 결과의 의미

사용자가 설정한 임계조건과 연료·개방 가정 아래에서 위험 가능성이 있는 공간, 시점, 원인을 탐색한다. 연기·미연소 연료·산소가 이동하고 추가 연소가 발생할 때 온도·복사열·층 높이·압력·유동이 어떻게 달라지는지 계산하고 3D에 표시한다.

정확한 사건 시각이나 화재 이상현상의 세부 형상을 재현하는 것을 첫 목적에 두지 않는다. 임계값과 대표 연료 설정은 탐색 가정으로 허용한다. 범용 임계값이나 실물 재현 정확도를 먼저 확보해야 개발할 수 있다는 전제도 두지 않는다.

대신 다음 일관성은 유지한다.
- 조건을 넘으면 해당 연소 경로가 실제 작동하고 이후 열·유동 상태에 영향을 준다.
- 같은 연료·산소·발열을 두 번 사용하지 않는다.
- 조건 형성, 추가 연소, 급격한 열환경 변화, 현상 이름을 구분한다.
- 사용한 가정과 계산 경로를 결과에서 확인할 수 있다.

하나의 시나리오는 최초 화점, 고체 연료 재고, 초기 가스 상태, 문·창·배연 일정, 벽 재료, 점화원 가정, 반응 프로파일, 임계값 묶음으로 정의한다. 모든 화점과 독립 문 상태의 전수 조합은 기본 범위에 포함하지 않는다.

2. 두 연소 경로와 전체 구조

2.1 G 경로: 미연소 가스의 추가연소

대상은 이미 기체로 존재하거나 열분해로 공급된 미연소 연료다.
- G-VENT: 개구부를 통과한 연료가 공기와 혼합하며 타는 경로.
- G-PLUME: 기존 화원 플룸과 연계된 내장 연소 경로.
- G-ROOM: 같은 구획에 머무는 축적 가스가 조건을 충족해 재착화하는 추가 경로.

연료가스와 산소를 소모하고 생성물·발열을 CFAST 상태방정식에 반영한다. 이 계산은 CFAST의 시간 진행 안에서 수행한다. 가스 재연소를 새 고체 TIME 화원으로 대신하지 않는다.

2.2 S 경로: 고체 가연물의 착화·연소 참여 확대

대상은 아직 열분해 공급에 참여하지 않은 고체 연료군이다.
- 대표 판정면의 표면온도로 착화 조건을 평가한다.
- 가장 이른 조건 도달을 추가 고체 화원 활성화 이벤트로 선택한다.
- 해당 화원을 포함한 CFAST 입력으로 다시 실행한다.
- 새 고체 화원은 설정 성장곡선에 따라 고체를 열분해가스로 공급한다. 실제 연소는 산소·혼합 조건의 제한을 받는다.

추가 화원에 따라 바뀐 환경에서 다음 고체 착화를 다시 평가한다. 이 과정은 외부 이벤트 루프가 관리한다. 가스연소는 모든 회차에서 계속 계산된다.

2.3 계산 흐름

CAD 실·문 연결망 + 좌표 대응 + 재료·연료·개방 일정·설정
  → CFAST 입력 및 고정된 수동 판정면 후보 생성
  → CFAST 실행
       내부: 질량·성분·에너지·유동 + G 경로 연소 + 벽·복사·대류
  → 문 너머 보충 노출 + 판 열응답
  → 가장 이른 미참여 고체 연료군의 착화 조건 평가
  → 추가 화원을 포함한 입력으로 재실행·검사·이벤트 확정
  → 새 이벤트가 없거나 실행 예산에 도달할 때까지 반복
  → 마지막 유효 실행의 시계열·반응 기록으로 CFBT 현상·원인 분류
  → 3D·시계열·이벤트 표시

현상 이름은 계산 결과에 붙이는 분류다. BD·RO·FO라는 이름 자체가 별도 열원을 만들지 않는다. 한 반응에 여러 현상 태그가 붙어도 발열은 한 번만 계산한다.

4. 공통 상태와 연료·산소·에너지 예산

4.1 연료군과 상태 전이

실별 총 고체 연료를 사전에 배분한다.
  초기 화원 배정분 + 추가 참여용 잔여 연료군 = 총 고체 연료 재고

각 연료군은 ‘미참여 → 활성화 → 열분해 공급 중 → 고체 소진’ 상태를 가진다. 열분해로 나온 연료는 ‘기체 저장·이동 → 연소 또는 외부 배출’로 이어진다.

연료 보존 관계는 질량 및 연료별 잠재에너지로 추적한다.
  초기 고체 + 초기 미연소 가스 + 외부 유입 연료
  = 잔여 고체 + 내부 미연소 가스 + 누적 연소 연료 + 외부 배출 연료
단, 화학종 표현·질량 기준은 선택한 유효 연료 모델에 맞춰 기록한다. 산소가 포함된 생성물 전체 질량과 연료 자체 질량을 혼용하지 않는다.

CFAST 설계 HRR은 열분해 공급량과 연결되고 실제 HRR은 산소 부족으로 작아질 수 있다. 고체 예산은 실제 발생 열의 적분만으로 차감하지 않는다. 이미 기체로 나온 연료는 고체 재고에서 차감한다.

4.2 연소 경로 간 공유

- 내장 경로와 확장 경로가 동일 상태의 가용 연료·산소를 공유한다.
- 구획 또는 경로별 소비율을 합한 뒤 음의 성분 재고가 생기지 않도록 적분한다.
- 확장 반응의 생성물·유효연소열은 그 반응이 소모하는 유효 연료 조성과 일치시킨다.
- 적응형 솔버의 반복적인 미분항 평가에서 영구 재고를 매번 차감하는 부작용을 만들지 않는다. 재고는 상태 적분으로 갱신한다.
- 실별 DJET를 새 고체 화원이나 별도 가스 열원으로 다시 더하지 않는다.
- 그을음 질량, 광학밀도, 연기층 체적을 연료가스 질량으로 대신하지 않는다.

4.3 복사의 두 수준

기체·벽·화원의 기본 열수지는 CFAST가 계산한다. G 경로의 추가 발열은 이 수지에 반영한다.

첫 구현의 문 너머 보충 복사는 수동 판정면에 대한 단방향 노출 근사다. 보충 노출만으로 CFAST 기체온도를 직접 올리지 않는다. 이를 공간 전체의 양방향 복사 에너지 교환으로 주장하지 않는다. 표면의 추가 착화가 발생한 뒤 그 화원에서 공급되는 열은 이후 CFAST 실행에 반영된다.

기체 연소 수지의 일관성과 외부 노출 근사의 에너지 연결 수준을 결과에 각각 기록한다.

5. 공간·유동·사용자 설정

5.1 기본 관측량

실/유효층: 온도, 질량·체적, 층 경계, 압력, 산소 질량·농도, 미연소 연료 질량·농도·잠재에너지, 그을음·광학밀도, 경로별 발열, 벽온도.
관찰점/판정면: 높이·법선, 기체온도, 입사복사·대류 노출, 표면온도.
개구부/방향/유동구간: 질량유량[kg/s], 체적유량[m3/s], 평균 유속[m/s], 산소·연료・그을음 전달률[kg/s]와 상류 상태.

양방향 유동의 각 성분을 보관한다. 순유량 하나로 산소와 연료 이동을 설명하지 않는다. 누설도 성분 수지에 포함한다. 단일층 구획에는 존재하지 않는 하층 값을 생성하지 않는다.

5.2 중성대

같은 절대높이의 압력차가 0인 높이를 층·개구부 구간별로 찾는다. 여러 근은 모두 보관한다. 단방향·무유동·근 계산 불가를 구분한다. 층 경계와 중성대는 별도 값이다.

흐름 방향은 압력차와 실제 유동 결과를 사용한다. 항상 상부 유출로 고정하지 않는다. 중성대 높이 하나로 연료지배/환기지배를 결정하지 않는다.

5.3 지배 상태

활성 반응 경로별로 연료 공급으로 가능한 Q_f와 혼합·가용 산소로 가능한 Q_o를 비교한다.
- Q_f 제한: 연료지배.
- Q_o 제한: 산소/환기지배.
- 설정한 전환 범위: 혼합/전환.
- 점화 대기·무공급·비활성은 별도 상태.

Q_actual/Q_input은 입력 정의와 함께 보조 지표로 사용한다. 같은 실에서도 고체 화원과 문 가스연소의 지배 상태가 다를 수 있다.

5.4 초기 탐색 설정

다음은 사용자 제안의 시작값이며 사용자 조절·저장·불러오기·초기화를 지원한다.
- T_FO_warn=500℃, T_FO=600℃, q_FO=20kW/m2.
- T_AI=520℃, T_HOT=300℃.
- O2_DEF=10vol%, O2_SUF=12vol%.
- 연료 농도 지수 Y_f/Y_LFL 기준=1.0, 과농 기준 Y_RICH=0.10.
- 층 두께 지표 dz_min=0.3m.
- 급격한 온도 상승 기준=5℃/s, 평가창=30s.
- 관찰 높이=1.5m.

임계조건은 지표와 반응 경로별로 적용한다. dz_min은 표시·위험조건 필터의 선택값이며 얇은 층의 모든 연소를 자동 중단시키는 공통 스위치로 쓰지 않는다. 연료 농도 지수는 선택한 유효 연료와 질량분율 기준을 사용하고, 농도 모델의 적용 범위를 벗어나면 자료 없음으로 표시한다.

5.5 설정 데이터

각 값에 value, unit, role, basis_type, note, source, profile_version을 둔다. basis_type은 사용자 가정/프로젝트 근사/문헌 모델/엔진 기본값을 구분하며 문헌 출처가 없는 사용자 설정도 허용한다.

반응 게이트·연료·문 일정·노출 모델·착화 기준을 바꾸면 물리 계산을 다시 한다. 표시 색, 표시 전용 경고, 저장 결과의 평가창만 바꾸면 후처리만 수행할 수 있다. 같은 온도값이라도 반응 제어와 표시 중 어디에 쓰였는지 role로 구분한다.

산소 vol%와 엔진 질량분율은 조성·분자량에 따라 변환하고 변환 가정을 저장한다. 15mass%와 15vol%를 같은 값으로 취급하지 않는다. 실제 반응을 막거나 허용하는 엔진 설정은 모두 기록한다. UI 값만 바뀌고 내부 게이트는 숨겨진 채 남는 상태를 허용하지 않는다.

6. G 경로: 가스 추가연소

6.1 기존 유량 기반 연소 우선

개구부와 기존 화원 플룸의 공급·혼합·산소 제한 모델을 재사용한다.
  Q_actual = min(연료 공급률 × 유효연소열,
                 혼합유량 × 산소 질량분율 × 저산소 보정 × 산소소모당 발열량)

CFAST 기본 산소소모당 발열량은 13.1MJ/kg-O2다. 저장량[kg]을 공급률[kg/s] 위치에 넣지 않는다. 사용자가 ‘모든 가스를 몇 초에 태움’을 반드시 지정해야 하는 구조로 만들지 않는다.

7.7.7 기본 개구부 경로에는 초기 실내온도+200K인 내부 온도 조건이 있다. 확장 모드에서는 사용자 온도·산소·연료·점화 조건을 어느 경로에 적용하고 기존 조건을 대체/유지하는지 명시한다. 산소 제한 보정과 점화 허용 조건은 의미를 구분해 저장한다. 적용 대상 외의 기존 연소를 일괄 차단하지 않는다.

6.2 구획내 축적 가스 재착화

G-ROOM은 기존 개구부 경로나 주어진 화원 플룸에 연결되지 않은 축적 가스의 추가 반응을 담당한다.
- 가용 연료 농도, 산소, 온도, 점화원 가정으로 반응 허용을 평가한다.
- 고온 자발반응과 지정/가정한 파일럿 점화를 구분한다.
- 활성화 후 속도는 단일 유한 반응 프로파일로 계산한다.
- 연료·산소 소진, 온도 저하 등 정지 조건과 재활성화·히스테리시스를 프로파일에 둔다.
- 반응이 허용되었다는 사실만으로 저장량을 즉시 모두 소모하지 않는다.

모델 방향은 2006년 연구의 온도·연료·산소 농도 기반 유한 반응 구조를 참고한다. 프로파일에는 정확한 반응식, 계수·단위, 유효 연료, 혼합 가정, 작동 온도 범위, 적분 방식이 있어야 한다. 이 통합본은 아직 대조하지 않은 논문 표의 계수나 범용 기본 상수를 새로 확정하지 않는다.

첫 구현에는 프로파일 한 종류만 연결한다. 계수 확정은 구현 전 기술 결정으로 수행하며 사용자에게 프로젝트 목적이나 임계값 채택 여부를 다시 승인받는 절차로 삼지 않는다. 프로파일 미정 상태는 model_not_configured로 표시하고, 추가 연소를 계산한 결과로 반환하지 않는다.

NIST FDS 혼합시간·유한 반응 모델은 참고 근거다. 격자·난류량을 방 크기로 치환한 것을 공식 FDS 계산으로 부르지 않는다. 새로운 전층 열·유동 솔버는 만들지 않는다.

6.3 상태·원인 기록

경로별로 허용 조건, 활성화·정지·재개 시각, 연료·산소 소비율, 생성물, 대류/복사 발열, 공급 제한 이유를 기록한다. 같은 구획에 고체 화원이 이미 있다는 이유로 G 경로를 제외하지 않는다.

7. S 경로: 대표 고체와 열노출

7.1 후보와 연료군의 연결

실행 전 후보 위치와 대표 재료를 선언한다. 여러 후보는 같은 연료군의 다른 관측면일 수 있다. 후보마다 방 전체 연료를 새로 배정하지 않는다.

초기 기본 배치:
- 개구부 수신측 0.5m, 1.5m × 높이 0.75m, 1.5m의 4개 면, 법선은 문 방향.
- 실 바닥 중앙 또는 실제 내부 대표점의 상향 면 1개.
- 문 높이·실 내부 형상에 맞지 않는 후보는 이동/제외 사유를 기록한다.
- 시간에 따라 열릴 문은 처음부터 후보를 생성한다. 처음 닫혀 있다는 이유로 영구 제외하지 않는다.

후보는 수동 PLATE 타깃으로 넣어 기본 복사와 기체온도를 얻는다. 후보 집합은 회차마다 동일하게 유지한다. 착화 후보가 기존 내장 조건부 화원을 별도로 자동 점화하지 않도록 관리자 경로를 통일한다.

첫 범위에서는 신규 실당 잔여 대표 고체 연료군 1개를 둔다. 최초 발화실은 초기 화원 배정분과 잔여 대표군을 분리한다. 동일 군의 가장 이른 유효 후보가 그 군을 활성화하며 다른 면은 중복 화원을 만들지 않는다.

이 규칙은 대표 고체의 모델 활성화 조건이다. 판 하나의 도달을 실 안 모든 가구의 착화로 확대하지 않는다. 추후 소수 재료군으로 확장할 수 있으나 상세 가구 배치는 요구하지 않는다.

7.2 좌표·구획·재료 입력

CAD 문 ID, 양쪽 실의 실제 문 위치·높이·법선, 좌표변환, CFAST 등가 COMP 대응을 보관한다. 현행 덱의 i*60 ORIGIN, FRONT/OFFSET=0만으로 실제 문 기하를 복원하지 않는다. 병합 COMP는 원래 실과의 매핑을 유지하고, 같은 COMP 안의 두 실을 독립적인 기체 상태로 표시하지 않는다.

벽·천장·바닥은 알려진 구성 또는 설정한 대표 구성과 assumed 표시를 사용한다. 운영 콘크리트 모델과 v43 단열 가정은 별도 입력으로 보존한다. 다른 재료를 선택한다고 모든 모델을 덮어쓰지 않는다.

대형 실 분할은 선택 사항이다. 한 변/높이 비 3, 면적 100m2 등은 검토 안내 설정으로 사용할 수 있으나 자동 분할 의무로 삼지 않는다. 가상 개구부의 유량·혼합 가정과 원래 실·표시의 대응을 기록한다.

7.3 판정면 입사복사

단위: kW/m2.
  q_inc = q_native_inc
        + Δq_aperture
        + Σq_direct_fire
        + Σq_djet

q_native_inc는 해당 바이너리의 타깃 출력 정의를 확인한 뒤 변환한다. 기존 방식의 TRGFLXI/ε_native를 무조건 다른 출력 정의에 적용하지 않는다. CFAST 발열 출력의 W와 설계 입력의 kW도 명시적으로 변환한다.

(a) 문 너머 연기·벽: v41 회색기체 전달과 개구부 적분을 재사용하는 방향으로 일반화한다. Δq는 수신측 가상 배경 방향을 실제 개구부 노출로 교체하는 부호 있는 보정이다. 수신실 자체 가스 방출을 재추가하지 않는다.
- 임의 방향 문, 층 기준 높이, 면 법선, 바닥 하한을 지원한다.
- 부분 개방은 유효 개구 영역을 정해 적분한다. F>0이면 전체 문 면적이라는 처리는 사용하지 않는다.
- 흡수계수는 적합한 엔진 계수에서 얻는다. 광학밀도를 그대로 복사 흡수계수로 대체하지 않는다.
- 적분점 n=24는 초기 설정이며 오차가 보장된 보편값으로 표시하지 않는다.
- 벽 radiosity 근사 εσTw^4+(1−ε)σTamb^4는 근사 프로파일로 유지할 수 있다.

(b) 문 너머 화원: 실제 HRR−HRRC의 비음수 복사분을 사용한다. 점광원·개구부 가시성·양쪽 층 경로 감쇠를 적용한다. 화원 위치와 화염높이 기반 복사 중심을 현재 계산과 대응시킨다. 동일 화원의 같은 방향 경로를 여러 문으로 중복 계산하지 않는다.

(c) 문 분출 연소: 문별·방향별 연소 기여를 사용한다. 실별 DJET 합계를 문마다 반복 배치하지 않는다. 문별 값을 확보하지 못하면 가중치 합이 1인 배분 근사를 명시한다. 유입 방향이 없는 문에 임의로 기여를 부여하지 않는다.
  Q_rad,v = χ_r × Q_djet,v
  q_djet,v = Q_rad,v × max(0,cosθ)/(4π max(r,r_min)^2)
초기 설정 χ_r=0.30, r_min=0.5m, 근접 표시 거리=1.0m.
합산 Q_djet,v는 실별 DJET와 맞춰 검사한다. 배치 위치는 수신측 문 상단 대표점이라는 근사다. near_flame은 거리 기반 가능성 표시이며 화염 접촉 열은 계산하지 않는다.

7.4 대류 노출 가정

- local: CFAST의 해당 위치 유효층 기체온도. 첫 구현의 기본값.
- exit_assumed: 설정 거리 내 후보에 실제 유출 구간의 온도를 적용하는 선택 노출 가정. 초기 적용 거리=1m. 단방향 유출도 실제 유동으로 판별한다.

‘유출온도가 항상 더 뜨거움’ 또는 ‘항상 보수적’이라고 가정하지 않는다. 기본 루프는 노출 가정 하나로 진행한다. 다른 가정은 이벤트 직전까지의 동일 환경에 대한 참고 민감도로 둘 수 있다.

독립적인 확산 결과 두 개가 필요하면 전체 루프도 각각 실행해야 한다. exit로 먼저 화원을 만든 실행의 이후 노출을 사용해 얻은 local 도달 시각을 독립적인 늦은 예측으로 취급하지 않는다. 두 시각은 노출 가정별 결과이며 예측 신뢰구간으로 명명하지 않는다.

7.5 판 열응답·물성·점화원

material_exposure_v40.solve의 1D 판 전도와 앞뒤 대류·복사 구조를 재사용한다. 입력은 앞뒤 입사복사, 앞뒤 기체온도, 초기온도, 두께, k, ρ, c, 흡수율 α_abs, 방사율 ε_emit이다.

앞면 열수지:
  q_net,front = α_abs q_inc,front − ε_emit σ Ts,front^4
                + h_front (Tgas,front−Ts,front)
뒷면에도 해당 노출을 별도로 적용한다. 식 내부 온도와 단위를 통일한다. q_inc가 kW/m2이면 계산 시 W/m2로 변환한다.

흡수율과 방사율은 개별 필드다. 유효물성 가정으로 α_abs=1을 사용할 수 있다. native 재현 시험은 native와 동일한 흡수·방사 조건에서 수행하고 α_abs=1 시나리오와 구분한다.

시작 프로파일 예: 서류 묶음 k=0.04184W/(m·K), ρ=500kg/m3, c=2.092kJ/(kg·K), 두께=0.025m, 파일럿 착화 표면온도=369℃. 주거·창고 등에 대체할 경우 proxy=true를 둔다. 기존 수치를 모든 재료의 확정 착화점으로 사용하지 않는다. 사용자는 대표 재료와 임계온도를 조절할 수 있다.

초기 노드=49, 판 적분 dt=0.05s. 재료별 전도 및 표면 열수지의 안정 조건으로 조정한다. 모든 재료에 같은 간격의 안정성을 보장하지 않는다. 저장 시점 사이의 도달 시각은 보간할 수 있으나 출력보다 세밀한 실제 사건 해상도를 확보했다고 주장하지 않는다.

점화원 모드: 없음 / 존재 가정 / 지정 일정. 파일럿이 필요한 프로파일에서 없음은 자동 가정으로 바꾸지 않는다. 표면온도 도달 상태는 별도 표시한다.
- 같은 실의 기존 화원·DJET는 점화원 대리 지표로 저장한다.
- 근거 시간창은 [t−30s,t]를 초기값으로 사용한다. 미래 DJET를 과거 점화 근거로 사용하지 않는다.
- proxy 지표가 있다고 후보에 실제 화염이 도달했다고 표시하지 않는다.
- 표면 자연발화는 별도 재료 프로파일이 지정된 경우에만 사용한다. 기체 T_AI를 고체 표면 자연발화 온도로 전용하지 않는다.

8. 고체 추가 화원 정의

고체 조건을 충족한 후보의 바닥 투영점을 시작 위치로 사용하되 실제 내부 형상과 CFAST 좌표 대응을 확인한다. 벽 이격 초기값은 0.3m다. 이격할 공간이 없는 경우 조정 가정을 기록한다.

τ = t−t_ign, τ≥0.
  Q_design(τ) = min(α_growth τ^2, Q_peak)
  A_fire(τ) = max(A_min, Q_design(τ)/HRRPUA)
위 식은 성장·정상 구간이며 이후 감쇠와 고갈을 포함한 전체 곡선을 생성한다.

α_growth[kW/s2], Q_peak[kW], HRRPUA[kW/m2], A_min[m2], 연소열, 화학 조성, 생성물 수율은 용도·연료 프로파일에 둔다. A_min 초기값은 0.1m2다. 면적은 배정된 가연물/구획의 가용 면적을 넘지 않으며, 면적과 HRRPUA 조건이 충돌하면 Q_peak 또는 곡선을 함께 조정해 기록한다.

감쇠 시작 70%는 초기 설정으로 선택할 수 있다. 총 곡선 적분은 감쇠 꼬리까지 배정 잠재에너지 이내로 맞춘다. 소진 판단은 고체 열분해 공급 기준이다. 실제 HRR만 적분해 미연소 가스 공급을 누락하지 않는다.

CFAST TIME 화원은 고체 연료군의 활성화를 표현한다. 기존 휴면 화원을 같은 ID/연료군으로 재설정하거나 대체하여 별도의 내장 점화와 중복되지 않게 한다. 이미 생성된 미연소 가스를 태우기 위한 가짜 고체 화원을 만들지 않는다.

9. 외부 고체 확산 루프

9.1 실행 예산과 기본 정의

max_added_ignitions: 실제 반영 가능한 추가 고체 연료군 수.
max_runs: 기준 실행을 포함한 전체 엔진 실행 수.
wall_time_budget: 경과 시간 예산. 시간 제한으로 중단한 실행은 미완료로 취급한다.

첫 소형 구현의 제안 기본값은 추가 이벤트 3건, 전체 실행 4회다. 사용자가 늘릴 수 있다. 원안의 10은 범용 필수값으로 고정하지 않는다. 추가 이벤트 10건을 실제 반영하려면 기준 실행 포함 최대 11회가 필요하다.

9.2 이벤트 확정 절차

fixed_candidates = 실행 전에 정한 후보 집합
committed = []
run = execute_and_validate(deck(initial_fires, committed, fixed_candidates))
if 기준 실행 실패: 실패 반환

반복:
    현 run에서 보충 노출·고체 판 응답·미참여군 후보 평가
    이전 확정 시각보다 이른 후보가 생겼는지 먼저 검사
    event_id와 시간 허용오차로 이미 확정한 후보를 제외
    후보 없음: no_new_ignition으로 종료
    예산 소진: 후보를 pending에 남기고 예산 종료
    가장 이른 후보 1건 선택
    proposed = committed + [후보]
    next_run = execute_and_validate(deck(initial_fires, proposed, fixed_candidates))
    다음 실행 실패/인과 검사 실패: 현 run을 마지막 유효 결과로 보존하고 종료
    committed = proposed
    run = next_run

final = run
반환 ignitions = final 입력에 실제 포함된 committed

추가한 화원으로 실행하기 전에 ignited 목록을 확정하지 않는다. 마지막 반복의 미실행 화원을 최종 결과에 포함하지 않는다. 실패한 시도는 attempts로 따로 기록하고 성공 runs와 구분한다.

9.3 시간 순서와 동시 사건

이전 후보를 ‘t>t_last’로 먼저 버리지 않는다. 시간 역전 검사를 먼저 수행한다. 같은 시각의 다른 연료군은 event_id로 구분해 재평가 대상에 남긴다.

첫 구현은 한 건씩 처리하며, 시간 허용오차 내 동시 후보는 안정적인 ID 순서로 선택한다. 이후 재실행에서 남은 후보를 다시 평가한다. 시간 허용오차는 출력·이벤트 해상도에 맞춰 설정한다. 선택 순서가 결과에 영향을 줄 수 있는 동시 사건은 tie 정보를 보관한다. 동시 일괄 활성화는 별도 정책으로 후순위에 둔다.

9.4 유효성·인과 검사

- 정상 종료, 요청 종료 시각 도달, 필수 파일·필드, 유한 수치, 입력·엔진 일치.
- 새 이벤트가 작동하기 전 시계열을 동일 시각에 정렬해 이전 유효 실행과 비교.
- ULT/LLT[℃], HGT[m], HRR/DJET[W 또는 kW] 및 핵심 성분을 물리량별 절대·상대 허용오차로 검사.
- 이벤트 도달 시각 주변은 해당 해상도·활성화 정의에 맞춰 비교 구간을 정한다.
- 후보 집합·재료·기하·게이트가 회차 사이에 몰래 변하지 않게 한다.

예산 종료는 계산 깊이 제한이다. no_new_ignition과 구분한다. 마지막 유효 실행의 요청 시간 완료 여부와 외부 확산 루프의 완료 여부도 각각 기록한다. 미래에 더 번지지 않는다는 의미로 해석하지 않는다.

9.5 회차별 판 시계열

활성화가 확정된 군의 미착화 판 온도는 해당 시각까지 유효하다. 이후 값은 null/valid_until로 처리한다. 전체 건물 재생은 마지막 유효 CFAST 실행에 통일한다. 이전 실행의 늦은 후보 시각은 확정 이벤트로 재사용하지 않는다.

10. CFBT 조건·연소·급변·원인 분류

모든 현상은 조건 상태, 반응 상태, 열환경 급변 상태를 분리한다. 조건 형성만으로 현상 발열을 생성하지 않는다. 복수 현상 태그를 허용한다.

10.1 백드래프트형(BD)
- 이력: 저산소/환기 제한 + 연료가스 축적 + 설정 고온 조건.
- 전이: 산소 공급·혼합의 회복 또는 누적으로 점화 조건 충족.
- 반응: 축적 가스 소비와 추가 발열이 발생.
- 분류: 위 이력·공급 전이·가스 반응에 설정한 급격한 온도 상승이 동반되면 백드래프트형 급격 연소.
- 유입 산소가 바로 소비될 수 있으므로 산소 농도 상승만을 필수 증거로 삼지 않는다. 유입·소모량을 함께 사용한다.
- 완전 밀폐실에만 적용하지 않는다.

10.2 롤오버형(RO)
- 상층 연료·온도·산소·점화 조건과 상층/연결 개구부 가스 반응으로 분류.
- 급변이 있으면 ‘급격한 온도 상승 동반’을 추가.
- BD와의 구분은 저산소 축적 이력, 반응 위치·경로, 산소 공급 전이를 함께 사용.
- 존 평균으로 계산한 상층 연소를 표시하며 해상되지 않은 화염전면 애니메이션을 생성하지 않는다.

10.3 이동·축적 연기 착화(FGI)
- 이동 또는 축적된 연료가스가 산소·점화 조건을 충족해 해당 공간에서 반응.
- 고온 자발반응과 파일럿 점화를 구분하고 초기 온도가 T_AI 미만인 파일럿 사례도 기록.
- BD·RO와 중첩 가능. 폭압·압력파를 계산한 결과로 표시하지 않는다.

10.4 플래시오버형(FO)
- T_FO_warn, T_FO, q_FO는 각각 열환경 접근/도달 지표.
- 미참여 대표 고체군의 추가 착화와 그 발열·급변을 기록.
- 설정한 대표 고체군의 참여 범위 또는 참여율, 추가 발열, 급변이 충족되면 플래시오버형 전이로 분류.
- 실당 잔여군 1개인 첫 범위에서는 ‘대표 고체군 확대 연소’라는 분류 근거를 함께 표기.
- 온도·열유속만 도달하면 ‘플래시오버 열환경 조건’으로 기록.
- 가구 전체 착화를 확인하지 않은 상태에서 ‘모든 가연물 착화’라고 표시하지 않는다.

10.5 급변과 일반 열위험

상층·하층·관찰높이의 온도 상승률과 복사열 급증을 구분한다. 기본 상승률은 현재까지의 평가창 변화율로 계산하고 사용한 차분·평가식을 저장한다. 미래 자료로 평활하여 시점을 앞당기지 않는다.

유입 고온가스·외부 복사·대류가 원인인 상승과 실내 가스/고체 추가연소를 구분한다. 급변이 없더라도 위험 조건·상층 연소·열환경 초과는 계속 표시한다.

10.6 원인 기록의 수준

필수 기록: 연료·산소 유입/소모/잔량, 반응 허용 조건, 기존/신규 고체 발열, 구획내/개구부 가스 발열, 고온가스 엔탈피 이동, 노출 항별 시계열, 착화 전 누적 흡수 노출.

착화 순간 가장 큰 입사 항은 ‘그 순간 최대 입사 항’이다. 이것만으로 전체 착화 원인을 확정하지 않는다. 필요할 때 동일 착화 전 환경에서 특정 노출 항을 뺀 판 열응답 민감도를 추가할 수 있다. 독립적인 문 개방 효과 등은 선택 시나리오 짝 비교로 확인한다.

비선형 피드백이 있으므로 각 열원에 독립적인 온도 상승분을 강제로 배분하지 않는다. 모델 반응 경로의 근거와 개입 비교의 근거를 구분한다.

11. 결과 계약·캐시·3D

11.1 메타데이터

spec_version, scenario_id, engine_mode/version/hash, input_hash, config_hash,
gas_model_id/version, material_profile/version, geometry_mapping_version,
radiation_model/version, plate_solver/version, code_hashes, assumptions.

실별·문별·후보별 원시 시계열은 단위와 source_method를 가진다. 미확보 값을 0으로 채우지 않는다. 직접 출력/계산 파생/배분 근사/미지원 상태를 구분한다.

11.2 실행과 이벤트

- attempted_runs_count, successful_runs_count, committed_ignitions_count.
- terminated: no_new_ignition / max_added_ignitions / max_runs / time_budget /
  solver_failed / invalid_output / causality_failed / invalid_configuration.
- simulation_complete_to_requested_horizon와 spread_search_complete를 분리.
- final_input_hash, committed_ignitions, pending_candidates, failed_attempts.
- 이벤트별 room/COMP, fuel_group, candidate, t_ign, exposure_case,
  threshold/profile, pilot_assumption, pilot_proxy_evidence, proxy_material,
  event_source, terms_at_event, cumulative_absorbed_exposure, near_flame.
- exposure_case별 crossing_time 또는 미도달/미계산. 예측 신뢰구간 필드는 만들지 않는다.
- 보충 복사는 passive_one_way, DJET 배분은 measured_per_vent 또는 allocated 등으로 명시.

11.3 상태

조건: 미충족/접근/충족/이전 충족/자료 없음.
반응: 비활성/점화 대기/산소·혼합 대기/진행/공급 제한/소진/중지/미구현.
모델 적용 불가, 설정 미완료, 계산 실패를 정상 미충족과 구분한다.

11.4 시간과 캐시

엔진 내부 적분, 상태 저장, 판 적분, UI 재생 간격을 각각 기록한다. 급변을 기존 5초 출력의 보간만으로 만들어내지 않는다. 필요한 이벤트 주변 원시값과 반응 로그를 보관한다. 전건물 test.out을 항상 1초 간격으로 대량 출력하는 것을 고정 전제로 삼지 않는다.

엔진 캐시에는 엔진·입력·확장 반응 설정을 포함한다. 노출·판 캐시에는 기하·개방 일정·재료·노출 배열·모델·솔버 소스 버전을 포함한다. 정상 완료 및 검사를 통과한 결과만 완료 캐시로 사용한다. 개구부 기하·가시성·형태계수는 기하/개방 상태별로 재사용한다.

11.5 기존 앱과 화면

기존 해석 흐름은 유지하고 확장 계산 옵션과 별도 결과 메타데이터를 추가한다. /api/run?spread=1은 호환 가능한 연결 제안이며 실제 기존 API를 확인한 뒤 구현한다. 가스 확장과 고체 확산의 활성화 상태를 각각 표시하고, 고체 루프만 작동한 결과를 전체 CFBT 계산 완료로 표시하지 않는다.

- 온도/산소/미연소 연료 모드, 상층·하층·관찰높이 구분.
- 문별 중성대·방향·산소 및 연료 이동.
- 조건 형성, 계산된 반응, 급변, 모델 현상 분류의 구분.
- ‘모델 추가 착화 조건 도달 t=…’, ‘모델 분류: 백드래프트형 급격 연소’ 등 일관된 명칭.
- 선택 시 설정값, 반응 경로, 연료·산소·발열·노출 그래프와 가정 확인.
- 미완료/예산 종료/자료 없음의 명확한 표시.
- PPE 기준은 선택 높이·방향의 열환경 지표로 연결하고 개인 방호시간으로 자동 환산하지 않는다.
- 여러 시나리오의 실별 최대값을 하나의 실제 화재 시간 재생으로 합성하지 않는다.

12. 가볍게 구현할 첫 범위

12.1 반드시 포함할 기능

검증용 첫 연결망은 발화실–홀/인접실–계단 등 약 3~5개 구획으로 구성한다. 하나의 최초 화점·개방 일정·대표 재료 설정으로 시작한다. 이후 같은 구조를 선택 건물 시나리오에 적용한다.

- 열·유동 엔진은 CFAST 하나를 사용한다. 기존 v44/v45를 동시에 확대하지 않는다.
- 내장 가스 반응을 재사용하고 사용자 게이트를 연결한다.
- G-ROOM은 단일 유한 반응 프로파일을 연결해 실제 추가 발열·성분 소모·온도/유동 피드백을 구현한다.
- 첫 G-ROOM 활성 대상은 실별 상층 또는 단일층으로 제한한다. 하층 성분 수송은 유지하되 별도 하층 재착화가 미지원임을 기록한다. 기본 내장 경로의 유효층 처리를 임의로 삭제하지 않는다.
- 고체는 신규 실당 대표 잔여군 1개, 최초 발화실의 초기/잔여 예산 구분을 사용한다.
- 문 주변 대표 면과 실 대표 상향 면, 단일 판 열응답 프로파일을 사용한다.
- 보충 복사는 단방향 수동 노출 근사로 구현하고 기하·열원 중복을 제거한다.
- 기본 대류 노출은 local 하나, 추가 고체 이벤트는 제안 기본 3건/전체 실행 4회.
- 시계열·원인 이벤트·기본 3D 레이어를 제공한다.

이는 기능을 조건 배지로만 축소하는 범위가 아니다. 제한된 공간·프로파일·이벤트 수 안에서 가스 추가연소와 고체 추가 착화가 모두 상태 변화에 연결되는 최소 범위다. 각 기능이 단계적으로 완성되면 구현 상태를 개별 표시하고, 둘 다 연결되기 전에는 통합 계산 완료로 취급하지 않는다.

12.2 선택 기능과 후순위

- local/exit 두 가지 전체 확산 루프 비교.
- 실별 소수 재료군 확대 및 하층 G-ROOM 반응.
- 선택한 대형 실의 분할과 가상 개구부.
- 주요 문 개방·배연 변경 몇 가지의 짝 비교.
- 전건물의 대표 시나리오 적용과 선택적 정밀화.

자동 대공간 분할, 모든 화점·독립 문 상태 탐색, 모든 재료 라이브러리 완성, 상세 가구 열분해·탄화, 화염 접촉 열·실내 화염전면, 창 통한 상층 확산, 문·벽 파괴, 폭압·압력파, FDS 전환, 볼륨 렌더링은 첫 범위에서 제외한다.

12.3 계산량 관리

주요 비용은 전체 CFAST 재실행 횟수다. 두 구획의 실행시간을 전건물 회차 시간으로 사용하지 않는다. 실행 횟수·추가 이벤트·시간 예산을 별도로 관리한다.

판 노출의 다른 항을 뺀 민감도는 가능한 경우 판만 재계산한다. 저장 기하·형태계수를 재사용하고 필요한 시계열·진단량만 출력한다. 임계값 근처가 아닌 후보를 제거하는 경우에는 제거 규칙과 그에 따른 탐색 한계를 명시한다. 무누락 보장이 없는 점수 필터를 물리적 불가능 판정으로 사용하지 않는다.

16. 통합 결정 요약

가스 추가연소는 CFAST 시간 적분 안의 반응 경로로 계산한다. 고체 착화·확산은 대표 표면의 조건 도달을 외부 이벤트 루프로 CFAST 화원에 반영한다. 두 경로는 동일한 고체→가스→연소 재고를 공유한다.

첫 범위는 소형 연결망·단일 반응 프로파일·소수 대표 고체군·노출 가정 하나·제한된 추가 이벤트다. 이 안에서 실제 추가 발열과 온도·유동 피드백, 원인 분류까지 구현한다. 공간·프로파일·시나리오·반복 횟수를 제한해 가볍게 만들며, 사용자 설정 조건을 넘었을 때의 상태 계산이라는 목적은 유지한다.
