# 완도 창고 — 사진 기준 외형·투시

사용자 정정: 처마 아래 FGI를 계산하거나 새 외부 연소를 표시하는 작업이 아니다. **기존 계산 범위를 유지하고 사진처럼 지붕·처마를 포함한 건물 외형을 표시**한다. 기본은 투시다.

- `specs/wando/aerial.png`를 직접 확인해 파란색 긴 지붕, 흰색 외벽, 전면 연속 처마, 왼쪽 앞 2층 외형을 추가했다.
- 표시면 불투명도 0.28, 보조선 0.30. 지붕 너머 내부 연기·불꽃·위험 테두리·경로가 보인다. 표시 탭의 **사진 기준 외형 · 투시**로 외형만 끌 수 있다.
- 운영 `model.html`과 기존 `preview.html`에 같은 외형 모듈을 사용한다. 창·외장 줄눈·처마 기둥은 장식 기하이며 문 목록·연결 그래프에 넣지 않는다.
- **계산 체적·연료·산소·개구부·P1 시계열·경로 결과 불변**, 재계산 0회. 외부 연기·FGI 효과 추가 없음. 차량 기호도 없다.

## 치수 근거

사진에서 형상·색상·상대 배치를 확인했으며 실측 외형을 완전히 복원한 것은 아니다. 원래 내부 치수는 유지하고 미제공 치수만 표시용으로 가정했다.

| 항목 | 적용 | 구분 |
|---|---|---|
| 기본 평면 | 72×18.4 m | 명세 수치 |
| 지붕 처마선 | z=6.405 m | 실 높이를 외형에 적용한 가정 |
| 파란 지붕 | 낮은 맞배, 용마루 +1.2 m | 사진 기반 단순화·경사 가정 |
| 전면 처마 | x=9~72 m, 돌출 3 m, 벽측 3.6 m → 끝 3.3 m | 사진 추정·치수 가정 |
| 왼쪽 2층 외형 | x=0~27 m, y=0~6 m, 높이 +3 m | 사진 추정·치수 가정, 계산 제외 |

위 구분은 `exterior.json`과 화면의 **외형 치수 근거 · 가정**에 기록했다. 원래 방 JSON·CFAST 입력을 수정하지 않고 별도 외형 레이어로 구성했다. 연기 다음·불꽃 이전에 투시 외형을 그려 지붕이 연기 때문에 사라져 보이지 않게 했다. 공통 `render_order.js`·셰이더는 변경하지 않았다.
