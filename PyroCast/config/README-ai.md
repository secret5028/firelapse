# FireLapse · AI 연결 안내

AI는 선택 기능입니다. 포함된 건물과 저장 결과를 보는 데 AI 연결은 필요하지 않습니다.

## 앱에서 연결하기

1. `설정·탐색 → AI 연결`을 엽니다.
2. OpenAI 호환 API의 기본 주소, 실제 사용 가능한 모델명, 인증 키를 입력합니다.
3. **연결**을 누르고 상태를 확인합니다.

주소는 원격 HTTPS 또는 같은 PC의 로컬 HTTP를 사용합니다. 서버는 기본 주소에 `/chat/completions`를 붙여 요청합니다. 제공자가 안내한 API 경로를 사용하세요.

연결 확인은 작은 텍스트 요청으로 진행합니다. **연결됨은 이미지 판독·CAD 자동 보정의 검증 완료를 뜻하지 않습니다.** CAD 이미지 판독에는 이미지 입력을 실제 비전 모델까지 전달하는 API와 이미지 지원 모델이 필요합니다.

## 키와 데이터

- 화면에서 연결한 키는 서버 메모리에 보관합니다. 앱을 재시작하면 다시 연결해야 합니다.
- 키를 Git 저장소·README·채팅에 적지 않습니다. 배포본에 제작자의 키는 포함하지 않습니다.
- AI 요청에 포함된 도면·실 정보·질문은 사용자가 설정한 서버로 전달됩니다.
- 외부 AI가 연결되지 않았을 때 용도별 기본 기준을 사용한 배치를 실제 AI 검토 완료로 표시하지 않습니다.

## 가연물과 도면 검토

가연물 제안은 등록된 기준과 연결해 해석합니다. AI가 임의로 만든 물성값을 검증 자료처럼 사용하지 않습니다. 실별 설정을 바꾸면 저장 상태와 화점 후보·재계산 필요 여부를 확인하세요.

새 CAD의 기하·공리 보정과 검토 결과는 확실한 자동 보정, 추정, 미확인으로 구분합니다. API AI로 새 도면을 보정하고 검증하는 전체 과정은 첫 배포에서 통합 검증 미완료입니다.

## 개발용 파일 설정

화면 연결과 별도로 개발용 설정은 `ai.example.json`의 형식을 참고합니다. `base_url`, `model`, `api_key_env`를 지정하고 키는 지정한 환경변수로 제공합니다. `ai.json`에 실제 키 값을 쓰지 않습니다.

서버 메모리 연결과 파일·환경변수 설정은 서로 다른 경로입니다. 사용 중인 경로와 서버 상태를 확인하세요. 단독 내보내기 HTML은 보기용이며 AI 연결을 지원하지 않습니다.
