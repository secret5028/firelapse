전층 연기 확산 재생 보완 — 2026-10-22

사용자: 층의 전층 연기 확산이 빠져 보임. 구현 요청.

확인한 원인
- 직전 작업에서 기본 사례가 이전 R25 국부 시연에서 R9/전체 31실 검증 사례로 변경됐다.
- 첫 화면은 10분 시점이고 저장 시점도 복원되어, 0초부터 퍼지는 과정을 바로 볼 수 없었다.
- 연기층은 위험 조건과 무관하게 표시됐지만, 문을 통과하는 흐름은 주로 화살표로만 표시됐다.
- '31실 계산'과 '현재 연기가 존재하는 실 수'가 구별되지 않았다.

구현
- '층 전체 연기 확산 재생': 선택 층을 전체 구도로 맞추고 0초부터 실감보기로 재생한다.
- 회색 연기층: 기존 CFAST OD/층 높이를 그대로 사용하고 위험 조건으로 숨기지 않는다.
- 문 통과 회색 연기: native 방향별 soot/mass/평균 유속이 있는 개구부에만 가벼운 Points 1회 그리기로 표시한다.
  깨끗한 공기나 0 유량에 연기를 만들지 않는다. 점 무늬·꼬리 길이·표시 불투명도는 시각 효과다.
  실제 실내 연기 전면이나 세부 속도장을 새로 계산하지 않는다. 가스 화염은 계속 OFF.
- 실별 첫 관측 순서와 해당 시점으로 이동하는 버튼을 추가했다.
- 전체 계산 실 수 / 현재 연기 표시 실 수 / 연결 미확인 공간을 구분해 표시한다.
- 기본 모드의 OD=0인 공간에 남던 고정 .02 불투명도도 제거했다.
- CFAST/착화/창 파괴 계산 및 원본 결과 파일을 바꾸거나 재실행하지 않았다.

현재 R9 사례의 표시 기준 첫 관측 (5초 출력)
R9 00:05 → R2 01:15 → R1/R8/R11/R12/R23 04:00 → R4 09:15
→ R0/R3/R15 10:45 → R25 11:45 → R21 12:10 → R18 12:15.
0초 0실, 10분 8실, 전체 기간 중 14실에 연기가 관측된다.
31실 모두를 연기로 강제 채우지 않는다. 닫힌 경로·연결 미확인 공간은 구별하며,
미관측을 안전이나 실제 무연기 보장으로 해석하지 않는다. 첫 관측은 시각화 기준이며 발화/위험 임계값이 아니다.
