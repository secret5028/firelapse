# 3단계 core 레이어 완료 — 2026-10-27

`Claude검토-3단계기준-기존화면코드-20261026.md` 2절에 따라 **core 레이어만** 구현했다. 연기·화염·위험·선택 등 다음 레이어는 진행하지 않고 멈춘다.

## 구현

- `app/web/adapters/legacy_core.js`: 도면 transport·층 그룹·원래 CAD shape 변환 함수를 읽는다. 건물 hash가 일치해야 하며 원본을 변경하지 않는다.
- `app/web/layers/core.js`: `stair`/`elev`만 대상. `connected`, `to_floor`, 비어 있지 않은 `meshes` 중 하나도 없으면 제외한다. region이 없으면 원래 anchor를 사용하고, 둘 다 없으면 제외한다. 도면에 없는 층간 연결이나 승강로를 새로 만들지 않는다.
- 계단 색 #ffc342, 승강기 색 #55baff. shell .10/r70, 디딤판 .86/r72, 모서리 .95/r73. 모두 transparent, depthTest false, depthWrite false다. 정책은 실제 Mesh/Line과 material에 적용한다. shell은 DoubleSide, 디딤판은 기존 FrontSide를 유지한다.
- **전체 보기 AND 수직 공간 체크박스 ON**일 때만 표시한다. 기존 store의 layers.core와 floor_id=null을 사용한다. 층 선택 시 체크박스가 켜져 있어도 숨긴다.
- 층 그룹의 위치·가시성을 tick에서 따라간다. 시간·선택·층·표시 변경과 결과 메타 단독 교체는 기하 재생성을 유발하지 않는다.
- 셰이더·계산 엔진·서버·캐시 변경 없음. 운영 중인 웹 화면은 새 호스트로 전환하지 않았다.

Chrome 156, Three.js r160, 1000×700, clock=180000 ms. 실제 CAD 건물과 기존 `lite_viewer.js` 66~83행 코어 생성 블록을 그대로 실행한 기준 장면을 새 레이어와 비교했다.
