# 설정·탐색 AI API 연결 — 2026-11-05

- 설정·탐색 탭에 `AI 연결` 버튼과 연결 상태. API 주소·모델 ID·password 키 입력 → 짧은 실제 API 요청 1회 성공 후 사용. 실패하면 기존 연결 보존. 연결 해제 지원.
- 키는 8841 연결 서버 메모리에만 보관. 파일·환경변수·localStorage·sessionStorage·상태 응답에 기록하지 않음. 입력란은 제출 직후 비움. 새로고침/건물 전환 후 유지, 서버 종료 시 소멸.
- 서버의 공통 연결을 기존 연료 AI·AI 도구 대화·새 건물 스캔 판독 호출 경로에서 재사용. 다른 서버 프로세스에는 키를 보내지 않고 로컬 연결 서버가 API 호출을 중계.
- 연결 확인은 모델의 텍스트 응답 검사. 이미지 입력 지원 여부는 실제 도면 판독 시 별도 확인 필요.
- 호텔의 기존 결과 AI 도구 서비스는 아직 `assistant:false`이며, 이번 키 설정 기능이 그 미연결 도구를 임의 활성화하지 않음. 현재 Codex 대화는 웹앱 API와 별개의 연결이며 자동 공유되지 않음.
- 기존 config/ai.json + 환경변수 방식도 호환. UI 연결을 해제하면 기존 파일/환경 설정이 있는 환경에서는 그 설정으로 복귀. 현재 운영에는 해당 설정이 없음.
