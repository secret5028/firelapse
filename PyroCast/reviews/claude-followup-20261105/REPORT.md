# Claude 기능 검수 후속 수정 · 2026-11-05

실제 Claude 데스크톱의 기존 PyroCast 중계 대화 검수(B-1/B-2, R-3~6, I-1~9)에 대한 수정이다. 계산식·기준·입력과 기존 결과는 변경하지 않았다.

## 수정

- 건물 목록 연결 실패에도 현재 건물 이름을 유지한다. 다른 건물에서 강화 공장으로 잘못 표시하던 기본값을 제거했다.
- 강화 active.json에서 불필요한 전체 결과 목록/MC 스캔을 분리했다. 초기 로딩과 실패를 화면에 표시한다.
- 결과 목록에 계산 기간·저장 시각·실행 식별자를 표시한다. 현재 결과 강조와 동시 3행 노출은 유지한다.
- MC 저장 표본을 자동으로 읽어 최대 충족 실을 집계하고 같은 배치에서는 캐시한다. 필수 2표본과 무작위 표본을 구분한다.
- 후보 순위는 CAD 실명을 우선하고 용도는 괄호로 보완한다. 겹치는 3D 실명은 선택 실 우선으로 숨긴다.
- 하층 두께 0.05 m 미만일 때 하층 온도·산소는 표시만 —로 처리하고 이유를 툴팁에 남긴다.
- 내보내기 목록 불일치는 명시적 오류로 응답한다. 모델 GET 내보내기도 Origin을 검사한다. 단독 HTML의 계산·연료 편집 입력은 보기 전용으로 잠근다.
- 공개 결과 목록의 로컬 파일 path 제거, 완도 정적 문서 제목 FireLapse 반영.

## 수치 회귀 및 한계

호텔10F 추가 회귀는 완료했다: 3600s, 적분904.0708초, 전체906.9183초, 연소2실, 최초FO230s. 이 층의 긴 적분 시간 원인 분석은 이번 UI 수정 범위 밖이다. 앞선 수치 Jacobian 수정은 수치 출력에 작은 차이를 만들며 옛 결과를 새 엔진 검증 결과로 간주하지 않는다. execution_evidence.engine_hashes()는 simulation/pyrocast_lite/*.py를 포함하므로 jacobian.py가 엔진 증거에 포함된다.

전체 app 시험 중 호텔 입력 점검에서 B1의 CAD_B1_R9 개구 폭 제한은 계속 보고된다. 입력을 임의로 축소하거나 계산 완료로 표시하지 않는다. 실제 AI API는 키 없는 환경에서 미검증이며 모의 호출 시험과 구분한다.

미감 검수와 수정 후 재검수는 같은 실제 Claude 대화에 요청했다. 판정은 완료 후 별도 기록한다.
