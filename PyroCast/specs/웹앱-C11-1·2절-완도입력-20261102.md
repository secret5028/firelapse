# C11 1·2절 — 완도 저온창고 건물·연료·재료 준비

범위: `Claude지시-C11-완도저온창고사례-20261102.md` 1·2절. 3절 실행 및 4절 운영 건물 선택기 연결은 하지 않았다. BDF 적분 0회, CFAST 실행 0회, 점수·MC 계산 0회.

## 산출물

- `data/wando-coldstore/building.json`: 기존 `pyrocast.building/1`, 1층 8실, 외기문 8개. 창·실내 연결문 없음.
- `fuel-inputs.json`: 실별 내장재 면적·총 에너지·바닥면적당 하중·HRRPUA·피복률·분류 근거.
- `materials.json`, `thermal-input.json`, `materials.cfast.inc`: PU 벽·천장, 콘크리트 바닥. 기존 간략 엔진이 읽는 CFAST 재료 입력으로 단위 통일. 입력 조각이며 실행 시나리오가 아니다.
- `provenance.json`: 사실의 출처·가정·면적 불일치·미실행 범위.
- `preview.html`/`preview.js`: 기존 `createSceneHost`와 `BuildingLayer`를 가져와 치수 JSON 기하를 표시하는 계산 전 미리보기. 운영 패널·서버·셰이더는 변경하지 않음.
- 재생성: `tools/build_wando_c11.py`. 미리보기: `tools/serve_wando_c11.py --port 8832` → `http://127.0.0.1:8832/data/wando-coldstore/preview.html`.

`fire_load_table.json`의 `coldstore_pu_lining`에 두께·밀도·발열량·HRRPUA를 한 출처로 저장한다. 각 실 하중은 `(둘레×높이 + 바닥면적)×두께×밀도×발열량 / 바닥면적`으로 계산한다. 278을 모든 실에 일괄 대입하지 않는다. 개구부 면적을 빼지 않는 지시서 식을 그대로 썼다. 피복률 0.3/0.5/1.0 민감도는 미실행이다.

## 명시한 가정과 차이

1. HWP 보고서 원문은 이번에 직접 확인하지 않았다. 사실 표기는 제공된 C11 지시서의 보고서 수치에 근거한다.
2. R8이 R1 내부에 있으므로 R1에서 R8 영역을 빼 L자 폴리곤을 만들었다. R1/R8의 합은 원래 R1 외곽 면적과 같다. R1 외기문은 남은 전면 x=9~18의 중앙 x=13.5로 배치했다. 원래 전체 폭 중앙 x=9는 R8 모서리와 겹치므로 외기문을 온전히 둘 수 없다.
3. R9 기계실 문은 북측 y=23.9 중앙, R8 문은 남측 중앙으로 가정. 다른 실 높이도 R5의 6.405 m로 확장한 가정이다. 문 초기 닫힘은 표시용 기본이며 A/B/C 실행 상태는 미작성이다.
4. 모델 면적은 1,366.2 m²로, 보고서 1층 면적 1,701.3 m²와 335.1 m² 차이가 있다. 제시된 좌표·치수만 사용하고 누락 공간을 만들어 맞추지 않았다. R2 돌출부는 지시대로 제외했다.
5. 기계실 `equipment`의 수치가 명세·기존 표에 없다. 기존 `default` 500 MJ/m²·250 kW/m²·t_alpha 300 s를 임시값으로 명시했다. 기존 기본 클래스/분류 정규식은 변경하지 않았다.
6. 다른 저온실은 명세대로 공실 PU 내장재 등가이며 생선·배추·미역 저장물 연료를 더하지 않았다. 기계실 PU 마감도 가정이다.
7. PU 방사율 .9는 프로젝트 가정. 바닥은 기존 콘크리트 프록시(k=1.75, ρ=2200, c=1000, 두께 .15, 방사율 .94). 실제 콘크리트 바닥 두께는 미제공이다. 시각화 벽 .4 m는 RC .3+PU .1 가정이며 내부 치수는 바꾸지 않는다.
8. 단일 열재료 경계다. 강판·RC 복합층, 강판 뒤 산소 제한, 에폭시 제거, 배풍기, 절단 개구는 미모델. 2층은 상부 슬래브 표시만 제공한다.
