## 0. 목적 (사용자 정의)
건축물 화재진압대원에게 **화재 특이현상(FO·FGI·백드래프트·롤오버) 위험 공간 정보**를 준다.
① 소방차 위치 → 화점 최단 경로, 거리는 **소방호스 본 수**(15 m/본) ② 경로상 특이현상 위험 구간 가시화.
절차: CAD→3D → 가연물 배치(자동 + AI 보조) → 화점 특정(자동 순위 또는 사용자 지정) → 최악 급기량(MC) 확정 → 시뮬레이션 → 조건 달성 색상·이력 → 경로 표시 → 단독 HTML 결과.

### 1.1 ① 점수 (v7/v8 확정)
- 지표 5개 균등합: log10 연료 에너지 · `Q_origin,peak/(1500ΣA√H)`(clip 3) · 연결도(확정 방화문만 차단) · 통과 공간 인접 · 방화 격리(추정 0.5).

- 화점 화원(①②MC 공통): `Q_origin,peak = min(coverage·A·HRRPUA, k·1500·ΣA√H_ext)`, 내부 실은 `750·max 내부 A√H`. 시연 peak 미사용.
- HRRPUA·연료 하중은 `fire_load_table.json` 단일 출처(불꽃 표시도 같은 파일).

### 1.2 ② 상위 N 실행 (확정)
- N 사용자 지정, **기본 8**.
- 실마다 극단 2상태: (가) 확정 방화문만 닫힘·나머지 열림 (나) 전부 닫힘. 나쁜 쪽 채택.
- **급기 확정 상태(5.2)가 있으면 2극단 대신 확정 상태 1회**, 라벨 "확정 급기".
- 정렬: 연소 실 수 ↓ → **주의 이상 실 수(현상 지수 최대 ≥70) ↓** → 최초 FO ↑ → 화점 최고 상층 T ↓.
- 3F 결과 [사실]: R3 → R2 → R1 → R9 → R8 → R23 → R0 → R4.

## 2. 전이 규칙 (동결, v8과 동일)
실간: 부모 실 상층 ≥ `temperature_C`(600) + 경로 지연(열린 문 60 s / 닫힌 일반문 600 s / 방화문 전이 없음·MC 열림 표본은 열린 간선 / 수직 위층 60 s). 셀간: `cell_temperature_C`(300) + 거리/0.05 m/s. Dijkstra 단일 부모. 통과 공간(<50 MJ/m²)은 센서만. 셀 분할: >150 m² 또는 종횡비 >3, 8~12 m 격자(`cell_mode: legacy`). 설정 범위·프리셋은 v8 2.1절 그대로.

## 3. 간략 엔진 (동결)
- 유지: 2존, BDF, 슬랩 유동, Heskestad, 층별 산소(LOL tanh, Cd .70), 미연 연료 이월 + 상층 ξ_u + **문 분출 연소 ON(채택)**, 유한 두께 1노드 벽, 덱 MATL/CHEM/INIT/LEAK 공유.
- OFF 보관: 창 파괴, 실 단위 산소 재고, 복사 되먹임, 판 센서.
- 속도: 누적 상태 E 제거 + 희소성 정정 **채택**(441→107 열 묶음, 3.3×). 야코비안 재사용 등 추가 최적화 미적용.
- 실패 시 Radau 1회. 표본당 적분 예산 1,200 s.
- 채택 관문 [사실]: 3F 표준 `CFAST 표준 ⊆ 간략 ⊆ CFAST 공격` 통과(legacy 셀 분할). 알려진 편차: 후반 상층 T −14~−20 %.
- **미결 [사실]**: 11실 연소 케이스 680~820 s. 다실 연소 프로파일링은 제출 후.

## 4. 조건표와 위험 지수 (확정, 10-27 결정)
### 4.1 요인 지수 (v8 그대로)
현상별 `r_T·r_F·r_O` = 현재값/기준값. FO 산소 12 vol%, FGI·BD 10 vol% 유지(통일 안 함).
FO 연료 항은 모든 실·사례에 `r_F = Q_actual/Q_FO`, `Q_actual = 자체 HRR(기존 화원+상층 추가연소) + 수신 door jet HRR(수신 실 합계 1회)`로 적용하며, 온도·산소 항과 `min(r_T,r_F,r_O)×100`은 유지하고 온도 단독 방식은 사용하지 않는다.
### 4.2 **현상 지수 통일**
- `현상 지수 = min(r_T, r_F, r_O) × 100`. 100 = 세 조건 충족. 새 계산 없음(`degree×100`).
- 명칭 수식어(가능/잠재/진행) **폐지**. FO / FGI / 백드래프트 / 롤오버.
- 표시 임계값 사용자 설정 `risk.threshold` — 기본 **테두리 ≥100, 주의 ≥70** [가정].
- 병목 = 최솟값 요인(패널 1줄). v8 4.2 "2단계 표시"·`display_v8` 게이트는 **`?ui=legacy` 전용으로만 보존**.
### 4.3 3D 색 (유형별 **동시 중첩**)
FO `#ef4444` · FGI `#a855f7` · 백드래프트 `#facc15` · 롤오버 `#f97316` · 주의 `#9ca3af` · 경계 ±30 ℃ 점선 · 선택 `#42e8ff`. 리본은 연기층 높이 + 유형별 0.14 m 간격, 원래 방 외곽(셀 OR).
### 4.4 **이력 (C-1a 확정)**
- 이력 = 실별·현상별 **전 구간(0~끝) 최대 지수**. 시간바와 무관, 0:00에서도 표시.
- 표시: 이력 ON(기본)이면 최대 ≥100인 현상 전부 **점선** 중첩, 현재 ≥100은 같은 자리에 **실선** 덮음. 주의(70~99) 회색 점선.
- 결과 탭 선택 실 카드에 현상별 최대 지수·최악 시각(예: FO 143 @ 26:30).

### 8.4 경로·호스 (C-3/C-4)
- 차량 위치: 건물 밖 지면 클릭. 기본 = 1F 외부 문 중 면적 최대(동률 ID 순) 바깥 5 m. 3F 기본 D3 (17.5, 34.8).
- 그래프: 전층 CAD 연결 원본 639건 보존, 통행 대상 155(사람용 실내 문·열린 통로·계단, 승강기·창 제외, 문 개폐 무관). Dijkstra. 계단 = 층고×1.5(설정). 실 중심–문–계단 연결점 직선 합(장애물 미고려 — 한계).
- 호스 본 수 = ceil(길이/`hose_m`) + "+1 권장". 3F R2 기본 [사실] 94.4 m · 7본(+1) · 계단 2회.
- 경로선 폭 .4 m + 어두운 외곽, 통과 실 지수 색(≥100 현상색, 70~99 회색, 그 외 `#38bdf8`), 15 m 눈금 번호. 탐색 탭 "경로 위험 요약"표(순서·실·누적 m·호스 번호·현상·지수; <70은 "—").
### 8.5 AI 가연물 배치 (C-7)
- 1차 자동: CAD 라벨 → 용도 → `fire_load_table`. 2차 AI: 건물 탭 "AI 배치" 채팅 → `POST /cfbt/lite/ai/fuel` → 실별 제안 표 → 행 선택 적용 → `fuel-overrides.json` → ① 즉시 재계산, ② "재실행 필요".
- API: `config/ai.json` `{base_url, model, api_key_env}` OpenAI 호환 chat/completions. 키는 환경변수(`PYROCAST_AI_KEY`)만. 미설정 시 안내만. **실제 호출 [미검증]** — 모의 응답으로 흐름 검증.
### 8.6 단독 HTML (C-6)
결과 탭 "HTML 내보내기" → 번들 JS + 건물 + playback(gz·base64, pako 인라인) + 정정·급기 확정·경로·차량. `file://` 재생·탭·이력·경로 동작 [사실, 사용자 확인]. 실행 기능 비활성. S09 8.4 MB, R3 C8 10.6 MB.
