대형 개방 물류창고의 위험 구역 및 구조 손상 평가 검토
2026-10-15 / 조사·방향 정리만 수행. 코드 수정·재계산·설치 없음.

사용자 의도
- 벽 없이 연결된 대형 물류창고에서도 FDS 없이 빠르게 위험 구역을 구분.
- 공식 CFAST 범위 유지. 정밀 화재 재현보다 위험 평가가 목적.
- 철근콘크리트/목조/샌드위치패널/철골에 따른 층별·실별 붕괴 위험 평가 가능성 질문.
- 다음 실제 작업은 다음 주. 예약·자동 실행·새 엔진 도입을 승인한 것으로 해석하지 않는다.

Users Guide 본문31–32쪽(PDF53–54쪽): TARGET은 위치/방향/재질을 지정하며 복사·대류 가열 및 1차원 판/원통 열전도 계산. 대상 위치의 가스온도는 플룸·천장 제트를 포함할 수 있음. 국소 가스온도만 필요하면 임의 재질/방향 지정 가능하다는 설명이 있으나, 열유속·표면온도를 사용할 때는 해당 조건을 제대로 지정해야 함.
Users Guide 본문37–39쪽(PDF59–61쪽): 2D/3D/등온면 출력; 50점/축 기본 시각화 격자, 해상도 증가 시 출력마다 국소 온도/속도 평가로 실행이 느려질 수 있음. 시각화 격자는 CFD 계산 격자가 아니다.
Tech Ref 본문2–3쪽(PDF20–21쪽): 층화가 뚜렷한 구획, 비교적 장애물 없는 평평한 천장에서 개발한 경험식. 면적만으로 정한 절대 적용 한계는 없으며 유사 검증사례로 적합성 판단. 화재성장 HRR은 입력, 점광원 복사는 화원 수 직경 이내 근거리 정확도 제한, 구획 간 복사 교환 미계산.
Users Guide 본문34쪽(PDF56쪽): 최초 작동 스프링클러의 HRR감소만 적용, 후속헤드 추가효과/분무 혼합/설계능력 초과 소화실패 미계산. 대형 랙 창고의 실제 소화 성능으로 일반화하면 안 됨.
Validation 본문8–9쪽은 과거 FAST 등 모델의 격납고 비교를 요약. 이를 최신 CFAST7.7.7의 대형 창고 검증 완료 근거로 쓰지 않는다.

제안: 계산 구획과 위험 관찰 격자를 분리
1. 실제 경계와 방화구획/개구부로 CFAST 구획 정의. 개방 공간은 원칙적으로 연속 공간으로 취급하되 층화/천장/적재 구조가 모델 가정과 부합하는지 먼저 평가. '넓으므로 무조건 불가'도 '입력 가능하므로 유효'도 아니다.
2. 벽 없는 공간을 전폭 개구부로 연결한 가상 방 격자로 분할하는 것은 공식 검증된 일반 해법으로 확인되지 않음. 개구부 유동/복사/열손실이 바뀌므로 기본 자동처리에서 제외. HALL/TALL 옵션을 광대한 창고의 일반 해결책으로 사용하지 않는다.
3. 사람 관찰 높이·랙 상단·천장 근처 등에 위치별 온도/열유속 평가점 배치. 현재 v29 공식 국소온도 후처리를 출발점으로 사용하되, 실제 위험 지표로 확대할 때 native TARGET 값과 대조하고 적용 불확실성 표시.
4. 국소 열노출(온도/복사·대류 열유속/노출시간), 구획 평균 연기층·OD·산소를 별도 표시. 연기 농도의 통로별 전파 전선, 랙 차폐·분무혼합·연속 표면 화염전파를 계산한 것으로 표현하지 않는다.
5. 넓은 공간 평균이 낮아도 화점 부근 고열을 누락하지 않도록 국소 열 표시. 미해석 부분을 안전 녹색으로 처리하지 않는다. 가스온도 적분을 그 자체로 검증된 PPE 화상·인체위험 모델로 표시하지 않는다.
6. 속도는 기존 CFAST 실행+소수 대표 TARGET, 국소공식 후처리 및 캐시부터 측정. 모든 격자에 동적 대상/화원을 추가하거나 3D 출력격자를 무작정 높이지 않는다. 화점이 달라지면 해당 시나리오 재계산 필요. 수초 응답을 아직 보장하지 않는다.
7. 다중 시나리오 격자 위험 빈도는 입력가정하의 조건부 빈도이며 관측으로 검증된 실제 사고 확률이 아니다. 공식 CFAST 지원 입력·적용조건 내에서만 평가. 기본엔진의 한계를 몬테카를로 반복으로 해결한 것으로 해석하지 않는다.

구조 손상/붕괴
- CFAST는 열 환경과 대상 열응답까지 제공하며 구조 내력/좌굴/접합부 파괴/하중재분배/붕괴를 해석하지 않는다.
- 구조 종류만으로 실별 붕괴확률 또는 붕괴시간 계산 불가. 정보 적은 초기 단계에는 열노출과 구조 취약요인의 선별 표시 가능; 숫자 확률/확정 안전 판정과 구분.
- 구조체 종류(철골/RC/목조 등)와 외피/칸막이(샌드위치패널 심재 등)를 별도 변수로 관리. 철골+샌드위치패널 병존 가능. 패널 박리/낙하와 골조/바닥 붕괴를 구분.
- 필요 정보: 기둥·보·슬래브/트러스 위치와 단면, 재료와 강도, 철근/피복, 내화피복 두께·손상, 경간/접합/지지조건, 적재하중, 가열면/지속시간, 구조 연결관계. 열환경→부재온도→온도에 따른 내력/요구하중 검토→영향공간 매핑 순서.
- 실별 표시는 가능하지만 구조 계산단위는 부재/구조경간·연결계통. 한 기둥/보의 영향이 여러 실·상층으로 이어질 수 있으므로 방별 독립 계산 금지.
- 내화 등급시간을 실제 화재에서의 남은 붕괴시간으로 환산하지 않는다. 미확인 구조는 정보부족으로 표시.
- 별도 구조해석 후보 OpenSees for Fire: 열전달·열구조 연동 지원. FDS 없이 CFAST/이상화 화재 열환경과 연결하는 설계 가능하나 별도 모델·검증 필요. 이번에 도입 승인/구현한 것은 아님. 상세 전층 구조해석의 실시간성은 미검증.

다음 주 제안 순서(미착수)
가. 대공간의 공식 국소 열관찰점/높이/출력과 한계 표시 설계.
나. 소규모 대표 예제로 TARGET과 후처리 일치·시간 비용 검증.
다. 구조체/외피 분리 데이터 구조와 구조 손상 우려 표시 설계.
라. 구조자료가 확보된 대표 부재에 한해 내력검토 확장 가능성 검토.
