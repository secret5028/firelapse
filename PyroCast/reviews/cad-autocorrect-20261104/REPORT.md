연결은 개구부 양측 각각 6개 탐침이 중첩 없이 동일 실을 지목할 때만 복구한다. 기존 유효 연결과 충돌하면 보류한다. 빈 탐침을 외기로 해석하지 않는다. 폭은 주 사각형과 분리된 희박한 선 조각이 하나의 외접 폭으로 합산된 경우에만 주 사각형 폭으로 보정한다. 원본 CAD 폴리곤·문짝은 보존한다. 판정 허용치는 `config/cad-autocorrect.json`에 프로젝트 가정으로 기록했다. 현장 치수나 성능 확인을 뜻하지 않는다.

## 남은 미확인

- 고립 71실: 도면 공간은 있으나 유효 문·창 연결이 0개라는 뜻이다. 실제 밀폐실이라는 뜻이 아니다. 연결 3건은 기존에 다른 연결이 있던 실 사이여서 고립 실 수를 줄이지 않았다.
- 앞선 D-3b 증거 분류: 실 폴리곤 중첩 24실, 개구부 없는 설비 공간 라벨 23실, 그 외 개구부 측 실 지정 없음 24실. 이것은 원인 확정이 아닌 기하·라벨 근거 분류다.
- 개구부 연결 검토 54건: 모호한 양측 근거 39건, 서로 다른 방향의 문짝 묶음 15건.
- 용도 추정 106실: 라벨 직접 매핑 대신 기존 층 기본값이 적용됨. 이번 작업에서 새 용도를 만들어 넣지 않았다.
- B1 R9: 면적 0.9512 m², 기존 EV5 폭 1.719 m와 등가 실 폭 불일치. 하나의 복합 도형이라 안전하게 치수를 분리할 근거가 없어 그대로 보류했다.
- 추정/검토 232건은 항목 수이며 고유 실 수가 아니다. 같은 실에 여러 항목이 있을 수 있다. 고립 실을 정상적인 밀폐실로 간주한 전층 계산에는 사용할 수 없다.

## 표시와 적용 범위

공통 건물 탭에 ‘모델 점검’ 목록을 추가했다. 자동보정/용도 추정/검토 필요를 구분하고 층·분류로 필터링한다. 위치 버튼으로 해당 층을 확인할 수 있다. 메타데이터 없는 기존 건물은 ‘미실시’로 표기하며 임의로 ‘문제없음’ 처리하지 않는다.

호텔 검토 3D: `http://127.0.0.1:8840/data/parkmarine-hotel/review.html`. 청록색은 보정, 호박색은 추정/검토, 클릭한 위치는 밝은 청록이다. 화재 결과 화면이 아닌 CAD 입력 검토 화면이다. 정적 서버는 5개 파일만 허용하고 계산 경로는 없다.

`tools/prepare_building_graph.py`에서 자동보정이 기본 적용된다(`--no-auto-correct`로 비활성 가능). 이번에 소급 적용한 건물은 호텔만이다. 기존 CAD 추출기 자체나 모든 업로드 진입점을 교체한 것은 아니다.
