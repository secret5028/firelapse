# r21 배포 검증 보고서

2026-11-12 · FGI 평가 대상을 화점실과 연소 중인 실까지 넓힌 패키지의 검증 결과.

## 달라진 점

- FGI를 연기층이 0.3 m 이상이고 상층 온도가 가스 점화 기준(520 ℃) 미만인 모든 실에서 평가합니다. 이전에는 화점실과, 실 안에서 연소가 계산된 실을 평가 대상에서 뺐습니다(`PyroCast/simulation/pyrocast_cfbt/criteria.py`).
- 연료·산소·온도 기준과 식은 바꾸지 않았습니다. 혼합기 조건 지수이며 실제 점화 발생은 판정하지 않습니다(`occurred`는 비워 두고 조건 충족 여부만 기록).
- 조건 버전이 `physics_p0_v3+fgi_layer_potential_v1`이 되어, 이전 정의로 저장된 결과에는 "구버전 지수" 안내가 붙습니다.
- 수록 결과 32건은 CFAST를 다시 돌리지 않고 FGI만 재평가했습니다(`PyroCast/tools/reassess_fgi.py`). 새 계산은 추가하지 않았습니다.

## 수록 결과 재평가

각 결과에 저장된 연료 항·산소 항(전체 정밀도)에 새 평가 대상 조건만 적용했습니다. 도구는 다음을 모두 만족하지 않으면 그 결과를 거부합니다.

- 이전에 점수가 있던 실·시각의 값이 그대로일 것
- 재평가 결과가 저장된 온도·산소·연료 시계열에 평가식을 직접 적용한 값과 같을 것(평가 대상 일치, 점수 차 0.0002 이하 — 재생 파일의 소수 5자리 반올림 범위)
- FGI 기록을 뺀 재생 파일의 나머지 값이 바이트 단위로 같을 것
- 저장된 요약의 FO·BD 항목과 원격점화 상태가 저장 자료에서 그대로 재현될 것
