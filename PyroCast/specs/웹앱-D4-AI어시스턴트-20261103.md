# D-4 AI 어시스턴트 구현·검증

2026-11-03. 계산 엔진·조건표·전이 규칙은 변경하지 않았다. 실제 AI API 호출은 키 미설정으로 **미검증**이다. 전술 JSON은 사용자 제공 초안이며 CFBT 검수가 필요하다.

## 구현

1. 도구 서버: 지정된 12개 도구를 두 운영 서버의 `POST /cfbt/lite/ai/tools/<name>`에 연결했다. 현재 등록 건물은 기존 CAD 건물과 완도 저온창고 2건이다. 저장 데이터만 읽으며 경로·순위는 기존 모듈을 재사용한다. 없는 값은 null/미평가, 다중 셀 방의 온도 평균은 만들지 않는다.
2. 패널: 기본 우측 아래 접힘, 표시 탭에서 좌측/우측/떠 있는 창·폭 선택. 근거 버튼으로 실·층·시각을 이동한다. 문·연료 변경 및 실행은 적용 대기 영역의 사용자 버튼으로만 처리한다. 기존 C-7 연료 제안은 유지했다.
3. 브리핑: 순위 → 사례 → 경로 → 현상별 최고 4회 → 규칙표, 총 8회. 서버가 같은 셀·같은 시각의 값으로 규칙을 판정한다. 알 수 없는 조건은 충족으로 처리하지 않는다. 규칙 문구는 JSON 원문을 사용하며 현장 지휘관 판단 우선 문구를 붙인다. 저장 버튼으로 사례 옆 MD/JSON에 첨부하고 단독 HTML에도 포함한다.
4. 대화: LLM은 제한된 JSON 도구 계획만 반환한다. 화면에 표시하는 실명·수치·시각은 서버가 도구 결과에서 조립하며 LLM의 자유 서술은 표시하지 않는다. 세션 이력과 현재 건물·사례를 전달한다. 저장 사례 화점과 질문의 경로 목적지를 구분해서 표시한다. 규칙 밖 응답은 “규칙표에 없음”이다.

모의 응답은 테스트 코드에만 있다. 모의 배연 제안의 적용은 임시 설정 파일로 검증했다. 실제 배연 전후 계산이나 실제 AI 연료 적용에 의한 순위 변화는 이번 검증에 포함하지 않았다. API 키가 없으므로 실제 모델의 도구 선택 품질·실제 API 합격 대화는 별도 검증이 필요하다. 키를 저장하거나 응답에 넣지 않으며 무작위 테스트 키의 응답 노출도 검사했다.

file:// 시험 때 운영 서버를 종료하지는 않았다. 대신 내보낸 파일에서 HTTP 요청이 **전혀 없었음**을 기록했다. 브라우저 시험 두 번의 명시적 저장으로 S09에 검증 브리핑 2건이 남아 있다. 시뮬레이션 재계산은 없다.
