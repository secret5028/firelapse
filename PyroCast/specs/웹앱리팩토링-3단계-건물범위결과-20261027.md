# 건물 레이어 범위 수정 결과 — 2026-10-27

상태: 범위·색상 일치 확인, 화면 비교 불합격으로 중단. 운영 화면 전환 및 push 없음.

## 변경 범위

- `app/web/adapters/legacy_building.js`: 직접 자식 일부 선택을 층 전체 traverse로 바꿨다. 기존 install의 이름 접두사 → 기존 재질색 → CAD 외곽선 덮어쓰기 분기 순서를 그대로 적용한다. 이름이 `층_`로 시작하면 `#aab7c0`, 그렇지 않고 기존 색이 `0x8a8a8a/0x8b5a2b/0x93acb5`이면 `#b8c3cb`, CAD 외곽선은 최종 `#bdcbd5`·opacity .42다.
- `app/web/layers/building.js`: 새로 포함된 창 유리·계단 디딤판의 부모 변환과 가시성을 보존한다. 원본 geometry는 빌리고 material만 소유한다. 창 userData의 순환 참조는 JSON 복제하지 않고 얕게 보존한다.
- `app/web/controller.js`: 이전 평면 배열 인덱스 연결을 원본-복제 매핑으로 대체한다. 원본 가림/복원 방식 자체는 유지한다.
- 피킹 평면, 위험 게이트, 엔진, 서버, 캐시, 셰이더는 변경하지 않았다.
