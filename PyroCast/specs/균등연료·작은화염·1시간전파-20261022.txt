2026-10-22 진행 기록 — 균등 연료 배치 / 작은 화염 / 3F 전파 시나리오

사용자 요청
- 거대한 화염 대신 작은 표시를 제공한다.
- 문 앞뿐 아니라 실 규모에 따라 실 안에 연료를 균등 배치한다. 개구부 앞도 포함한다.
- 3F 절반 이상(목표16실)의 연소 전이를 볼 수 있도록 조건을 정해 1시간 계산한다.

표시와 계산
- 기본 화염은 연소 위치 기호: 지름0.35~0.8m, 높이0.45~1.2m. 실 경계와 반자 제한 유지.
- 실제 native 고체 발열이1kW를 넘을 때만 기호를 표시한다. 크기는 물리적 화염 크기가 아니다.
- 계산 크기 보기도 유지. 표시 선택은 HRR/온도/산소/연기에 영향을 주지 않는다.
- 회색 연기 전 분포, 위험 조건 테두리, 가스 화염 OFF를 유지한다.

균등 연료
- CAD 실 형상을4m 격자로 자르고 잘린 각 셀 안에 대표 큐브를 배치한다.
- 큰 실은 격자 셀 최대64개를 목표로 간격을 조절한다. 개구부 안쪽 앵커는 별도로 보강한다.
- 큐브의 네 모서리까지 실 폴리곤 안인지 검사한다. 외곽·내부 구멍·테라스 밖에 놓지 않는다.
- 큐브는 실 바닥과 연료 예산의 대표 표본이다. 실제 가구나 적재물의 부피를 뜻하지 않는다.
- 셀 면적에 따라 실 전체 연료를 배분한다. 문 앞 표본도 같은 예산을 나눠 받으며 연료를 더하지 않는다.
- 새3F 입력: 실내30실, 연료군23개, 연료 표본185개, 판정 표본174개. 코어에는 자동 고체 연료를 추가하지 않는다.
- 각 표본에 같은 기존1D 열응답·369℃ 기준을 적용한다. 최초로 조건에 도달한 표본이 실 대표 화원 위치를 정한다.
- 실당 CFAST 대표 화원 하나를 유지한다. 개별 큐브의 독립 발열·물리적 화염 전면·분산 플룸은 계산하지 않는다.
- FO 이후 실 연료 통합을 유지하고, 보충 직접 복사는 연료 표본의 면적 가중 대표점으로 배분한다. 총 복사 HRR을 늘리지 않는다.
- 저장된 이전 결과는 균등 연료 기호만 추가해 볼 수 있다. 새 위치로 재계산한 것처럼 표시하지 않는다.

1시간 강한 전파 시나리오 — r4_uniform
- 테라스R27 제외, 실내30실. 최초 화점 R4(통로, 외기 창 W2가 있는 실). 계단 화점 아님.
- 기존 일반실 연료 에너지3배, 연료 점유면적2배(바닥65%상한).
- R4/R15 통로는 적치 연료가 있다는 별도 강한 시나리오:1200MJ/㎡, 바닥 점유50%.
- R4 공급 상한20MW, 면적에 따른 실제 설계 정점16.580414MW.
- 큰 실R1/R2 공급 상한 각각50MW, 나머지 최대8MW. 실제 정점은 연료 면적과 HRRPUA로 추가 제한된다.
- 성장계수0.1875kW/s², HRRPUA400kW/㎡. 조사된 적재물 값이 아닌 사용자 요청 비교용 가정.
- 실내 문 개방, 계단문D1/D3 닫힘. 확인된 문 없는 통로는 개방을 유지한다.
- 외기 창 초기50%개방. W0(R2),W2(R4)는 초기닫힘. 모든 평가 대상 일반 창은450℃ 대용 타깃 기준 파괴 시100%개방.
- 착화369℃, FO600℃, 가스 임계값·산소 제한·혼합물 반응식은 그대로다. 강제 추가 착화 시각은 넣지 않는다.
- 3600초, 5초 출력, max timestep1초. 원본/확장 엔진 실행파일 변경 없음.

검증과 달성 기준
- 80개 단위 검사 통과. 오목한 실·내부 구멍·개구부 앵커·복사 가중합 보존 검사를 포함한다.
- 실제 도면 큐브 경계 검사: 실 밖 큐브0개. 실별 연료 분배 총합 보존 확인.
- 목표는 등록한 화원 수로 세지 않는다. 최종 native 실제 고체 HRR>1kW인 실을 집계한다.
- 누적 연소 실 수, 최대 동시 연소 실 수,100kW 초과 실 수·지속시간을 따로 기록한다.
- 적분3600초 완료와 착화 일정의 조건 재확인 완료를 구분한다.
- 목표16실은 입력으로 강제하지 않는다. 달성 여부는 fire-spread-audit.json으로 확인한다.

진행 상태
- R1 30MW:1시간 완료, 추가 착화0건. R1 50MW:1시간 완료, 실제 연소3실. 목표미달.
- 기존 문 앞 배치의 r4_loaded는 새 균등 배치 작업으로 대체하면서 중단. 부분 결과는 완료 사례로 게시하지 않는다.
- 새 r4_uniform은 계산 중. 이 문서 작성 시16실 달성은 아직 확인하지 않았다.

추가 보완 / 최종 계산 입력 r4_uniform_bounded
- 표시 큐브 높이를 곧바로 플룸 기부 높이로 쓰지 않는다. 열응답 표본 높이와 화원 기부를 분리한다.
- 이번 사례는 바닥에 분포한 연료를 가정하여 화원 기부0.02m를 명시한다. 열응답 표본/369℃ 착화 기준은 유지한다.
- NIST 원본fire.f90는 기부와 층 경계에 따라 하층/상층 산소를 사용한다. 기존 높은 기부에서R3/R13이 상층의 저산소를 쓰던 현상을 진단했다. 일반적인 실제 가구 높이를 확정한 것이 아니다.
- 작은 실의 설계 공급 상한은1MW로 제한한다. R1/R2 각50MW, R4 cap20MW(실효16.58), R15 cap8MW(실효5.45)를 유지한다.
- 저장 연료 총량은 줄이지 않는다. 공급 상한은 연료가 타는 속도를 제한하며 공급 지속시간이 길어질 수 있다.
- 초기 native 입력/sidecar가 동일함을 확인해 완료된run00을 재사용했다. 변경된 추가 화원 입력은0~3600초를 다시 적분한다. 상태 체크포인트 재시작을 구현한 것이 아니다.
- r4_uniform_floor의 미완료run01과r4_uniform의 미완료run02는 취소 상태로 보존했다. 완료1시간 결과로 게시하지 않는다.
- 활성 결과 폴더: simulation/results/floor_spread_20261022/r4_uniform_bounded. 목표16실 달성은 아직 확인 중이다.
