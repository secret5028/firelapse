최종 시험 후보 r3b
- 기준 아래 0, 기준 위 전환 구간에서 x*x*(3-2*x), 전환 구간 위 1인 C1 계수.
- 산소 전환 폭 .01 체적분율(1%p), 온도10℃, 연료 .0001 질량분율. 사용자 설정 가능.
- 임계값 자체는 원래 값 유지. 전환 폭은 NIST 범용 상수가 아닌 프로젝트 근사.
- 자동 온도 경로/가정 점화원 경로는 각각 계수 계산 후 최대값. 강제 점화 시간창은 기존대로 유지.
- gate = 점화경로계수 * 산소계수 * 혼합물연료농도계수.
- 기존 원천항이 이미 소비/반출한 재고를 제외한 mf, mc, mo를 사용.
- demand = mf * (연료 1kg당 O2 요구량) + mc * (CO 1kg당 O2 요구량).
- r = k * gate * min(1, mo/demand). 기존 잔여 재고/시간간격 상한도 최종 적용.
- 연료 소비 r*mf, CO 소비 r*mc, 산소 소비 r*demand, 열 발생 r*(mf*hoc+mc*CO잔여열).
- 연료부 연소가 생성한 CO를 같은 평가에서 다시 소비하지 않는다. 잠재 fuel_co와 실제 CO는 기존 분리 유지.
- 솔버 내부의 미분식 평가에서 영구 상태를 변경하지 않는다.
- 모든 값을 같은 진행률로 계산하여 열/산소/연료의 중복 사용 방지.
- 기존 고체 착화 기준, FO 기준/연료 예산, 순정 플룸/산소 제한, 개구부 연소식은 변경하지 않음.

배제한 시험안 r3a
- (1-exp(-k*dt))/dt를 미분식에 직접 넣은 첫 후보는 소형180초사례가120초실행에도75초까지만진행.
- 수지 검사는 통과했으나 성능 불합격으로 채택하지 않음. build/mixture_r3 및 results/mixture_r3_20261023에 보존.
- r3b는 solver dt에 직접 의존하는 평균 반응률 대신 혼합제한 순간 반응률을 사용한다.

검증 범위
- 실제 빌드에 연결한 원천항8사례: 질량/원소/공통진행률/원래소비산소및연료예약/열일치/재진입불변 검사.
- 경계 연속/하한 아래0/단조성/산소비례반응률 검사.
- 순정의 전역 성분 재정규화에 따른 오차까지 제거한 것은 아니다.
- 소형 사례에서 같은 새 실행파일의 옵션OFF 결과는 기존 엔진과 일치해야 함.
- 새 방식의 최대시간간격 절반 시험 합격기준: 상하층 온도차<=5℃, 상층O2차<=.5%p.
- 전환폭 절반 시험은 모델가정 민감도이며 수치오차 시험과 구분.
- 실제 정체 사례가3600초까지완료된 경우에만 run_mixture_r3_floor.py로3F16실목표1시간전파탐색.
- 미완료/미수렴/목표미달은 완료로 표시하지 않음. 새로운 계산을 보기 전 기존3D결과 유지.
