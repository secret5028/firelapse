상태: 검토 의견. 기존 최종 명세를 자동으로 대체하거나 구현 승인을 뜻하지 않는다.
수행 범위: 문서·기존 코드·공식 CFAST 소스 대조. 원본 코드 수정, 입력 변경, 시뮬레이션 재실행 없음.

1. 결론

채택할 수 있는 방향이다. 문 너머 열노출로 대표 가연물의 착화 조건을 평가하고, 추가 화원을 CFAST에 반영하여 이후 온도·유동을 다시 계산하는 구조는 프로젝트 목적에 맞는다. 가장 이른 착화부터 반영하는 순서도 타당하다.

다만 이 문서는 주로 ‘고체 가연물의 추가 착화·인접실 확산’을 다룬다. 앞서 확정한 ‘축적된 미연소 가스가 온도·산소·점화 조건에 따라 추가 연소하는 계산’까지 이 외부 루프 하나로 구현되는 것은 아니다. 두 경로를 연결해야 한다.

권장 전체 구조:
  CFAST 기본 수송·산소 제한 연소·문 분출 연소
  + 필요한 가스 연소 조건·반응 경로 보완
  → 문 너머 열노출 및 대표 가연물 표면온도
  → 고체 추가 착화 이벤트
  → 해당 이벤트를 반영한 재실행
  → 최종 온도·복사·유동과 연소 원인에 따른 CFBT 현상 분류

χ_r=0.30, 거리 기준, 대표 재료, 착화 온도, 성장률 같은 값은 사용자 조절 가능한 탐색 가정으로 채택할 수 있다. 이번 수정 의견의 핵심은 그 수치가 임의적이라는 문제가 아니라 실행 결과와 이벤트가 일치하고, 연료·발열을 중복 사용하지 않도록 하는 것이다.

2. 그대로 살릴 부분

- 기존 해석을 보존하고 확산 계산을 선택 기능으로 제공한다.
- 열노출 후보를 실행 전에 선언한다. 결과를 보고 유리한 지점을 고르지 않는다.
- 문 너머 연기·벽 복사, 화원 직접 복사, 문 분출 연소 관련 복사를 구분해 기록한다.
- 개구부 복사 보정은 부호를 유지한다. 음의 보정을 일괄 0으로 자르면 배경 복사 교체라는 의미가 달라진다.
- 대표 판의 열응답으로 착화 조건을 평가하고, 작은 화원에서 설정 성장곡선을 시작한다.
- 새로운 화원을 반영한 뒤 후속 착화를 다시 평가한다. 이전 회차의 더 늦은 착화를 그대로 모두 확정하지 않는다.
- 계산 실패·미완료를 미착화로 처리하지 않는다.
- 대체 재료, 점화원 가정, 분출화염 복사 근사와 실제 적용한 설정을 결과에 남긴다.
- 착화 이후의 미연소 가정 표면온도를 계속 보고하지 않는다.

3. 구현 전에 바로잡을 핵심 사항

3.1 ‘원본 엔진 수정 없음’의 적용 범위

외부 루프에서 고체 화원을 예약하여 CFAST를 다시 실행하는 부분은 원본 엔진으로 구성할 수 있다. 실제 추가 고체 연소 이후의 온도 변화도 CFAST가 계산한다.

하지만 순정 CFAST 내부의 가스 연소 조건을 UI 설정으로 모두 바꿀 수 있는 것은 아니다. 7.7.7에는 문 분출 연소의 온도 조건 등 내부 조건이 있고, 실 안에 축적된 가스의 독립적인 재점화도 별도 검토 대상이다. 앞선 최종 명세의 사용자 설정을 물리 계산에 적용하려면 해당 경로와 연결해야 한다.

따라서 문서 첫 문장은 ‘고체 확산 루프는 엔진 외부에서 구성한다. 가스 추가연소는 CFAST 기본 기능을 우선 사용하고, 부족한 조건·경로만 확장한다’로 정리하는 것이 맞다. 보충 복사는 수동 판정면 노출이라는 현재 근사를 유지할 수 있다. 이를 기체 상태까지 양방향으로 보정한 복사 계산이라고 표현하지 않는다.

3.2 마지막 화원이 계산되지 않는 반복문 오류

현재 의사코드는 마지막 반복에서도 fires와 ignited에 이벤트를 추가한 뒤, 그 화원을 포함하지 않은 run을 final로 반환할 수 있다.

권장 규칙:
- 최초 실행을 기준 실행으로 둔다.
- 추가 이벤트 상한과 CFAST 실행 횟수를 별도로 센다.
- 후보 선택 → 임시 덱 생성 → CFAST 성공 및 결과 검사 → 이벤트 확정 순서로 처리한다.
- final과 확정 ignitions는 항상 같은 덱에 대응한다.
- 상한 때문에 실행하지 못한 후보는 pending으로 남기고 종료 사유를 표시한다.
- 상한 도달은 ‘확산이 끝남’이나 ‘추가 착화 없음’을 뜻하지 않는다.

추가 착화를 최대 10건 실제 반영한다면 기준 실행을 포함해 최대 11회 실행이 필요하다. 실행 횟수를 10회로 제한한다면 실제 반영 가능한 추가 착화는 최대 9건이다.

3.3 착화 순서·동시 이벤트 처리

t_last의 초기값을 명시한다. 현재의 ‘t_ign > t_last’ 필터는 이전 시각 후보를 먼저 버리기 때문에, 그 뒤 설명한 역전 오류를 검출하지 못한다. 이전 시각 후보가 나왔는지를 필터 전에 검사한다.

같은 시각 또는 시간 해상도 내에서 일치하는 두 후보도 엄격한 > 조건 때문에 누락될 수 있다. 시간 허용오차와 동시 이벤트 정책을 선언한다. 한 건씩 처리하려면 이미 반영한 이벤트 ID를 제외하면서 같은 시각의 다른 이벤트를 허용해야 한다. 재실행 후 생존한 후보만 확정한다.

이전 착화 전 결과 비교는 같은 출력 시각에 정렬하고 온도[℃], 층 높이[m], 발열[W 또는 kW]별 절대·상대 허용오차를 사용한다. 모든 물리량에 같은 0.01을 적용하지 않는다. 정상 종료 표식 외에도 요청 시간까지의 결과, 유한한 수치, 필수 출력 존재를 확인한다.

3.4 DJET_room을 개구부마다 재사용하면 발열이 복제됨

CFAST 7.7.7 vent_jets는 각 개구부 방향의 연소 기여를 계산한 뒤 수신실의 qdot_doorjet에 합산한다. 따라서 DJET_room은 해당 실의 여러 문 기여가 합쳐진 값이다.

문이 3개인 실에서 각 문에 χ_r × DJET_room을 배치하면 전체 복사원 세기는 3 × χ_r × DJET_room이 된다. 이는 설정값 선택과 다른 중복 계산 문제다.

필요한 변경:
- 문별·방향별 기여를 확보할 수 있으면 그 값을 사용한다.
- 확보하지 못하면 명시한 가중치로 실 합계를 문들에 배분하는 근사를 사용한다.
- 같은 실·시각의 배분된 연소열 합은 실 합계와 일치해야 한다.
- 문별 기여 미확보 또는 배분 근사 사용 사실을 기록한다.
- CFAST가 이미 반영한 DJET 발열을 별도 화원으로 다시 더하지 않는다. 외부 계산은 판정면 노출 근사이며, 발열을 새로 생성하는 과정과 구분한다.

χ_r, r_min, r_near는 설정값으로 유지할 수 있다. 거리만으로 정한 near_flame은 실제 화염 길이나 접촉을 계산한 결과가 아니라 근접 가능성 표시다.

3.5 문 좌표를 현재 덱에서 읽는 것만으로는 부족함

현재 cad_cfast_multifloor.py는 등가 직사각형 구획을 만들고 ORIGIN을 i*60,0,z로 배치한다. 벽 개구부도 FACE='FRONT', OFFSET=0으로 작성한다. 이 덱에는 실제 CAD 문 위치·방향이 그대로 보존되어 있지 않다.

필요한 것은 CAD 문 ID를 기준으로 한 양쪽 실의 개구부 위치·법선·높이와 좌표 변환이다. 복사 경로와 후보 생성에는 이 기하 정보를 사용하고, CFAST 등가 구획과의 대응을 명시한다. 실이 병합되거나 변형된 경우의 매핑도 필요하다.

개방률 > 0이라는 조건만으로 문 전체 면적을 적분하지 않는다. 부분 개방 시 유효 개구 영역을 어떻게 정할지 가정한다. 문 여러 개를 합할 때 같은 화원의 동일 가시 경로를 중복 계산하지 않도록 한다.

바닥 face==0을 bounds의 하한으로 일반화하는 수정 방향은 맞다. 회전 좌표, 층 기준 높이, 법선도 함께 일치시켜야 한다.

3.6 [t_exit, t_local]은 보장된 착화 시각 구간이 아님

두 입력은 ‘문 유출 기체에 노출된다고 가정’과 ‘CFAST 해당 위치의 층 평균 기체에 노출된다고 가정’이라는 별도 노출 가정이다. exit가 항상 고온이고 항상 먼저 착화한다는 보장은 없다. 따라서 보수 모드·오차 범위로 단정하지 않는다.

두 시각을 exposure_case별 결과로 저장한다. 하나만 도달하면 다른 값은 미도달로 남긴다. 구간처럼 요약하더라도 ‘두 노출 가정의 결과 범위’라고 표시한다.

exit 가정으로 먼저 추가한 화원은 이후 환경을 바꾼다. 그 실행 결과에서 local 판만 계속 계산해 얻은 늦은 시각을 독립적인 local 확산 시나리오의 결과로 취급하면 안 된다. 경량 기본값은 선택한 노출 가정 하나로 루프를 진행하고, 나머지는 해당 이벤트 직전까지의 참고 민감도로 제공하는 방식이다. 두 확산 시나리오를 비교하려면 각각 별도 루프가 필요하다.

유출 영역은 실제 유동 방향·슬랩으로 판별한다. 중성대가 없는 단방향 유출도 있으므로 항상 [z_N, 문 상단]으로 한정하지 않는다.

3.7 연료 총량과 기존 휴면 화원 중복 방지

기존 덱에 이미 실별 조건부 화원이 있으면 이를 유지한 채 같은 실에 TIME 화원을 추가하지 않는다. 기존 대표 화원을 재설정하거나, 이 확산 모드에서 해당 기존 자동 점화를 비활성화하는 등 단일 관리 경로가 필요하다.

초기 화원, 추가 고체 화원, 열분해되어 미연소 상태로 남은 가스가 같은 연료 재고를 중복 사용하면 안 된다.

CFAST의 설계 HRR은 열분해 공급량과 연결되며 실제 HRR은 산소 부족으로 작아질 수 있다. 따라서 실제 발생 열량의 적분만으로 고체 연료 소비량을 관리하면 이미 가스로 나온 연료를 고체에 남아 있는 것으로 잘못 셀 수 있다. 고체에서 공급된 열분해 질량·잠재에너지를 기준으로 예산을 차감하고, 미연소 가스의 저장·이동·연소를 별도로 이어서 추적한다.

70% 소진 후 감쇠는 사용자 설정으로 채택할 수 있으나 앞선 최종 CFBT 명세에서 이미 확정한 규칙은 아니다. 감쇠 구간을 포함한 전체 설계곡선의 적분이 배정 연료 예산 이내가 되도록 정의한다. 화원 면적도 이용 가능한 구획·가연물 면적을 넘지 않도록 한다.

3.8 대표 판 하나의 착화를 실 전체 가연물 착화로 해석하지 않음

실별 가장 이른 판정면을 대표 화원 활성화 조건으로 삼는 것은 경량 모델로 가능하다. 바닥 중앙 판 하나가 기준에 도달했다고 모든 가연물이 착화한 것으로 보거나, 그 자체로 플래시오버 원인이 입증된 것으로 분류하지 않는다.

앞선 최종 명세와 연결하려면 ‘열적 플래시오버 조건 도달’과 ‘설정한 대표 고체 연료군들의 추가 착화’ 기록을 구분한다. 초기 발화실도 잔여 고체 연료의 확대 연소를 검토하려면 대표 연료군 또는 기존 화원의 성장과 연료 예산으로 처리해야 한다. 방에 화원 하나가 있다는 이유로 가스 재연소까지 금지해서는 안 된다.

4. 열응답·검증 문구 보완

4.1 흡수율 변경과 native 재현 시험의 조건을 분리

기존 material_exposure_v40.solve는 같은 eps로 입사복사 흡수와 재방사를 계산한다. 제안처럼 흡수율을 1로 바꾸면 동일한 입사 노출에서 흡수되는 열이 달라진다. native 타깃 ε가 0.9인 조건의 1℃ 이내 일치를 그대로 완료 기준으로 삼으면 서로 다른 설정을 비교하게 된다.

- native 동등 조건 시험: 흡수·방사·물성·앞뒤 노출을 같은 조건으로 맞춘다.
- 유효물성/흡수율 1 시나리오: 그 설정의 열수지와 수렴성을 별도로 확인한다.
- 흡수율과 방사율은 개별 필드로 둔다. 1이라는 값 자체를 배제할 필요는 없다.
- 판의 뒷면 노출, 대류 기체온도, 초기온도도 데이터 계약에 포함한다.

dt=0.05s와 49노드는 서류 재료의 시작 설정으로 둘 수 있다. 모든 재료에서 자동으로 안정하다는 뜻은 아니다. 기존 솔버의 전도 안정 조건과 비선형 표면 열손실에 맞춰 시간 간격을 제한한다. 물성 단위도 명시한다: 예시 c=2.092는 kJ/(kg·K)이다.

4.2 파일럿 근거에 미래 사건을 사용하지 않음

착화 시각 ±30초의 DJET를 근거로 그 이전 시각의 점화원이 available이었다고 판정하면 미래 정보를 사용하게 된다. 판정 시각 이전의 설정 시간창으로 바꾼다.

같은 실의 DJET나 기존 화원은 주변 점화원 존재의 대리 지표이지 후보 표면에 화염이 도달했다는 계산은 아니다. ‘점화원 가정’과 ‘동일 실 연소 지표 있음’을 별도 필드로 보관하면 된다. 두 경우 모두 설정된 파일럿 조건으로 화원을 활성화하는 현재 방향은 유지할 수 있다.

4.3 연기층 붕괴를 무조건 금지하는 시험은 수정

큰 고정 화원 면적으로 플룸 인입이 과도해지는 문제를 조사하는 방향은 맞다. 그러나 ‘HGT가 0.1m로 내려가면 실패’라는 완료 기준은 가능한 위험 결과를 미리 금지한다.

시험은 화원 면적·위치·공급 연료·플룸 인입·수치 민감도를 점검하는 기준으로 바꾼다. 그 점검을 통과한 뒤에도 층이 낮아지면 결과로 남긴다.

모든 문을 닫았을 때 ‘문을 통한 보충 복사 0’은 적절하다. 하지만 모든 착화 0은 다른 열전달 경로와 기존 화원을 제거한 격리 시험에서만 기대할 수 있다.

4.4 착화 순간 최대 열유속 항을 원인으로 단정하지 않음

판의 온도는 과거의 흡수열, 대류, 재방사, 내부 전도에 좌우된다. 착화 순간 가장 큰 보충 항은 ‘그 순간 최대 보충 입사 항’이라고 부른다. native 노출이 가장 큰 경우도 포함해야 한다.

왜 착화했는지를 보여주려면 항별 시계열과 착화까지의 누적 흡수 노출을 함께 남긴다. 더 분명한 비교가 필요할 때만 같은 착화 전 환경에서 해당 항을 뺀 수동 판 열응답을 추가 계산할 수 있다. 이는 전체 CFAST를 다시 돌리지 않고도 가능한 제한적 민감도 분석이다.

장비 한계(PPE)에도 판정면 높이·방향과 입사 노출이라는 정의를 붙여 연결한다. 대표 연료판 결과를 사람이나 장비 내부 온도로 바로 바꾸지 않는다.

5. 더 가볍게 가져갈 범위

첫 단계에는 선택한 최초 화점·문 일정 한 시나리오에서, 문 주변 대표 후보와 실별 소수 연료군을 사용한다. 모든 화점·문 상태의 조합으로 확장할 필요가 없다.

- 대형 실 자동 분할은 착화 루프의 일괄 선행 의무에서 빼고, 별도 입력 모델 선택으로 둔다. 가상 경계와 개구부를 추가하는 것은 새로운 혼합·유동 가정도 추가하기 때문이다.
- 벽 재료는 현재 운영 덱과 v43 단열 실험 덱을 구분해 적용한다. 모든 현재 모델이 동일 콘크리트라는 전제로 덮어쓰지 않는다.
- 문 복사 기하·형태계수·가시성은 입력 기하와 개방 상태별로 재사용한다. 판 열응답 캐시는 소스 버전과 모든 노출·물성·설정을 포함한 키로 관리할 수 있다.
- 복수 노출 가정의 전체 루프를 매번 두 벌 돌리지 않고, 기본 가정 하나와 필요한 민감도만 사용한다.
- 추가 착화 건수·전체 실행 횟수·시간 예산을 각각 설정한다. 중단 결과는 ‘해당 깊이까지 계산’으로 표시한다.
- 두 구획 사례의 약 90초를 전건물 회차 시간으로 그대로 적용하지 않는다. 제안 구조의 주된 비용은 판 계산보다 전체 CFAST 재실행 횟수다.
- 1초 간격 흡수계수 출력을 전건물 test.out 전체에 항상 요구할지는 별도 성능 판단이 필요하다. 필요한 위치·시간·항목과 출력량을 먼저 구분한다. PRINT 간격은 솔버 내부 시간 간격과 다르다.

6. 최소 데이터 계약 수정

- runs_count, committed_ignitions_count, terminated, complete_to_requested_horizon.
- 최종 입력 해시와 그 입력에 실제 반영된 이벤트 목록.
- pending_candidates와 마지막 유효 결과. 상한·실패 시 미확정 이벤트 구분.
- 노출 가정별 crossing_time 또는 미도달 상태. 예측 신뢰구간이라는 이름은 사용하지 않는다.
- 후보·문·실의 CAD 좌표와 CFAST 좌표 매핑 버전.
- 문별·방향별 DJET 기여 또는 배분 근사 및 실 합계 검산 정보.
- native, aperture_delta, direct_fire, djet 노출 시계열과 단위.
- 고체 잔여 연료, 열분해 공급, 미연소 가스 저장·배출·연소 예산.
- 판정면 착화 이후의 T_surface는 null 또는 valid_until로 구분한다.
- engine/input 외에 보충 복사·판 솔버·재료·설정의 버전/해시.
- UI 명칭은 ‘모델 추가 착화 조건 도달’ 등으로 통일한다. ‘확산 t=’를 표시하면서 확산 시각이라는 표현을 금지하는 현재 문구 충돌을 제거한다.
