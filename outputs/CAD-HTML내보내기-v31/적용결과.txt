v31 HTML 내보내기 — 2026-10-15

사용자 요청: 웹앱에 HTML 익스포트 기능 추가.
기존 앱 왼쪽 작전 도구 상단에 'HTML 내보내기' 버튼 추가. 다운로드 HTML에 건물 원문 JSON, 계산 결과, 작전 설정, 송수구 계통, 3D 라이브러리 4개, 시점·층·보기 모드·경과 시간·표시 설정을 포함한다. 기존 UI를 재사용하며 새 별도 뷰어로 교체하지 않는다.
내보낸 HTML은 저장된 결과의 재생/보기 조작용. CFAST 엔진과 입력 변경 후 재계산, 원본 평면도 페이지는 포함하지 않는다. 서버 저장을 중단하고 HTML 재저장으로 변경사항 보존을 안내한다. 문/창 표시 변경이 저장된 계산을 재계산한 것으로 해석되지 않도록 기존 계산 모드 잠금 유지.

주요 파일:
- work/cad_html_export.js: 단일 HTML 구성·다운로드·보기 복원.
- work/cad_legacy_bridge.js: 오프라인 작전 저장 및 계통 초기값.
- work/restore_cad_ui.py: 내보내기 소스 결합, 오프라인 계통값이 다른 브라우저 저장값으로 덮이지 않도록 처리.
- work/verify_html_export_v31.py: 내장 데이터 원문 SHA256 일치, 라이브러리 포함·의존성, 결과·보기 상태, 재내보내기 중첩 방지 검사.
- work/install_html_export_v31.py: 앱 model.html 및 설치 템플릿 백업 적용.
- 설치기록.json, 검증결과.json, HTML-내보내기-적용.png.
- 소방-3D-결과.html: 실제 설치 앱에서 내려받은 약11.7MiB 단일 파일, 3F/10분/실감 보기.
- 재저장-검증.html: 내보낸 파일에서 전체층/30분/기본 모드로 바꿔 다시 저장한 검증본.

검증:
1. 기존 앱(8778)에서 버튼 클릭·다운로드 성공. 계산/건물 원문 파일 해시 유지, 브라우저 오류 없음.
2. 단일 HTML을 임시 localhost HTTP로 열어 3F/10분/실감 보기 복원, 156공간·가연물20개, 30분 층별연기 표시0/0/2/15/10/11/32/23/3 확인. 기본 모드 전환 및 재내보내기 성공.
3. Three.js와 addons 모두 data URI 내장, 건물/결과 파일은 내장 원문 응답 사용. 서버 작업은 오프라인 파일에서 비활성화. 재내보내기 시 원본 템플릿을 재사용하여 파일이 반복 중첩되지 않음.
4. 브라우저 도구 정책이 file:// 직접 열기를 거부하여 파일 더블클릭 실행은 직접 검증하지 못했다. 이를 우회하지 않았으며 HTTP에서 단일 파일을 검증했다. 현대 Chrome/Edge의 import map·WebGL·Web Crypto 지원을 전제로 한다.

엔진 재계산 없음. building.json/cfast-demo.json과 v30 수치·건물 모델 그대로 유지. 설치 대상2파일과 백업 경로는 설치기록 참조.
