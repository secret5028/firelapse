공식 플룸 계산 및 화면 표현 v29 — 2026-10-15

사용자 요청: 놓친 공식 계산을 재검토하고 화염/플룸/천장 고온 가스를 구분. 기존 UI 유지. 긴 리본 불꽃 금지.

완료
- 기존 앱 model.html, cfast-demo.json, 설치 integrated_viewer.html 적용. 변경 전 backup 보존.
- 원 CFAST 바이너리/전층 입력/전층 수치 결과/건물 모델 유지. 100구획 전층 재계산 없음.
- 기존 결과에 공식 상관식을 적용하는 후처리. 별도 1구획 진단 모델만 native CFAST로 실행(약0.34초).
- 주황 화염, 보라 상승 플룸, 청록 천장 고온 가스. 회색은 기존 광학밀도 기반 연기. 가스 색은 구분용이며 실제 빛/불꽃 색이 아니다.
- 기존 화염 높이(native FLHGT)와 화원 등가 지름 sqrt(4A/pi)을 사용. 카메라 거리에 따른 32px 최소 높이/22px 폭 강제 확대 제거. 실감 화염 높이의 ±6% 일렁임은 시각 효과. 미세 화염은 위치 고리 유지.
- 긴 리본 메시 없음. 천장 가스를 화염으로 바꾸거나 새 화원을 만들지 않음.

공식 소스 점검 범위와 놓쳤던 연결
1. fire.f90 flame_height: 실제 HRR와 화원 면적으로 평균 높이 계산. 기존 출력에 이미 있었음.
2. get_plume_temp_and_velocity: Heskestad 상관식, 상/하부층을 지날 때 가상 원점 보정, 반경 방향 온도/속도 감쇠, 화염 원뿔 가정. 이번에 JS로 옮겨 연결.
3. get_ceiling_jet_temp_and_velocity: 천장 제트 두께, 반경별 온도/속도. 일반실 계산 연결. 수학 함수는 HALL 보정도 포함하지만 방위 의존 복도 표시용 텍스처는 아직 미지원이며 HALL 입력에는 가스 볼륨을 만들지 않는다. 현재 시나리오 HALL 지정은 없음.
4. get_gas_temp_and_velocity: 층 온도/플룸/천장 제트 온도 중 최댓값 사용, 화원별 속도 기여, 모서리 보정(xf=4). 현 화원은 모두 xf=1. 벽 근처라는 이유만으로 보정을 추가하지 않는다(7.7.7 벽 보정은 1).
5. fire.f90 vent_jet_fire: 개구부 연소는 구획별 가스 연소량이며, 일반 화원 플룸식을 문 불꽃 경로 예측으로 대체할 근거가 없음. 기존 DJET 수치 표시만 유지.
6. target.f90: 점 형태 화원 복사와 대상 주위 가스 온도를 따로 계산. 플룸 표현을 추가했다고 다른 실의 직접 화염 접촉/복사/착화 계산이 추가된 것은 아님.
7. prec/cfast_data/cfast_parameters: g=9.80665, cp=1012 J/kg/K, t_max=900(식에서 온도 상승 제한으로 사용), Kelvin 변환 확인. 임의 상수 9.81/1000/섭씨 대입 대신 버전 상수 사용.
8. 추가 기록 정정: input_namelist에서 온도 조건부 착화의 시간간격 1초 제한을 확인. v27 최대시간간격 변경은 해당 조건에서 1.0→0.25초로 해석. 행렬 병목은 함수 계측 전 미확정.

입력 연결
- cfast_plume_metadata.py가 실제 사용한 multifloor.in에서 화원별 AREA/HEIGHT/RADIATIVE_FRACTION/LOCATION/구획 높이/모서리 보정을 읽는다.
- 현재 시나리오는 AREA5.95㎡, base0m, 복사분율0.33, 높이5.5m로 확인. 임의로 반자고를 새로 넣지 않았다.
- 기존 시계열(5초 간격)에서 HRR/상부·하부 온도/경계높이를 가져와 후처리. 시간별 AREA/HEIGHT 입력은 현재 수출기가 감지 시 중단한다. 조용히 고정값으로 바꾸지 않는다.
- 반경×높이 96×96 프로필을 화원별로 작성, CAD 실 다각형 안에 마스킹. 가스 볼륨 48샘플 레이마치. 온도 초과분을 표시 강도로 매핑하며 이는 가스 농도나 위험 기준이 아님. 화원 간 투명도 중첩은 시각 효과이며 온도 합산이 아님.
- 천장 확산의 진행 무늬는 계산 속도를 사용한 시각 효과. 상관식은 순간 준정상 분포이며 선단 도달 시간을 해석한 CFD가 아니다.
- 이 후처리는 원 엔진에 열/연기/착화를 되먹임하지 않는다.

검증
- check_plume_v29.js: 기존 화원 평균 높이 최대 차 0.00000977m, 기존 대상 가스 온도 1,444점 최대 차 0.0000641°C.
- run_plume_probe_v29.py: 1MW, 2㎡, 높이5m 단일실, 반경0/0.5/1/2/4m, 높이0.5/2/4/4.6/4.9/4.99m에서 native CFAST 출력 210점 대조. 최대 차0.000553°C. 천장·중심축·축외 지점 포함.
- 무화원/반경 감쇠/천장 제트 아래쪽 속도0/화원 높이=천장 예외 검사.
- 위 검증은 포팅의 수치 일치 확인이며 현장 화재 물리 검증이 아님. 기존 출력은 반올림되어 작은 차이가 발생한다.
- verify_plume_v29.py: 기존 수치 JSON 및 레거시 UI prefix 불변 확인. 변경은 plume 입력 메타데이터와 표현 코드.
- 브라우저: 0초 화염/가스 0, 10분 화원3개·가스3개, 기본 모드에서 가스0, 표시 해제 시 화염/가스0, 30분까지 재생 정상, 오류/경고 없음.
- 10분 화면: 최초 화염 평균2.220875m, 천장 중심 가스310.0228°C, 해당 중심 상승속도7.0973m/s. UI에 범례와 표시 성격 명시.
