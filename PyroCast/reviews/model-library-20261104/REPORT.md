## 스캔 실행 차단
- 스캔 2건은 개구부 미검증으로 버튼 비활성. 루프백 모델 서버는 모든 POST/PUT/DELETE를 403으로 거부한다.
- 공통 계산 서버에도 출처/등록 파일 가드를 추가했다. 이 가드는 다음 서버 기동부터 로드된다. 현재 스캔 모델은 이미 실행 경로가 없는 8841 서버에서만 제공한다.
- 복사·이름 변경한 스캔도 내장 출처로 거부한다. 알 수 없는 출처는 열람 전용.
