# FireLapse · UI 개발 안내

FireLapse 첫 공개 배포의 브라우저 UI 소스입니다. 사용자 실행 안내는 프로젝트 루트의 `README.md`를 참고하세요.

## 구성

| 경로 | 역할 |
|---|---|
| `web/entry.js` | 저장 결과를 읽고 운영 UI 시작 |
| `web/controller.js` | 선택한 건물·층·실과 계산 결과 연결 |
| `web/panels/` | 헤더, 설정·탐색, 결과, 표시, AI 대화 패널 |
| `web/adapters/` | 저장된 건물·결과를 UI 데이터로 변환 |
| `web/state/` | 선택·재생 등 화면 상태 |
| `model-library/` | 건물 목록, 새 CAD 입력, AI 연결, 운영 페이지 |
| `tests/` | 계약·회귀·브라우저 시험 |

## 수정과 빌드

프로젝트 루트에서 실행합니다.

```powershell
python tools/build_ui_bundle.py
```

생성물은 `simulation/viewer/overlay.js`입니다. 생성된 번들을 직접 수정하지 말고 `app/web/` 원본을 수정한 뒤 다시 만드세요. 색 토큰은 `simulation/viewer/theme.css`에서 관리합니다.

UI는 계산 결과를 읽고 표시합니다. 화면의 색·강조·반올림 변경을 계산식이나 저장 시계열 변경과 혼합하지 않습니다.

## 화면과 데이터 원칙

- 선택한 실과 실제 계산 결과의 층·화점을 구분합니다.
- 결과 목록을 선택하면 해당 층·화점실·결과를 함께 선택합니다.
- 미평가 값은 `—`, 실제 계산된 영 값은 `0`으로 표시합니다.
- FO·FGI·BD는 세 지수로 표시하고 롤오버는 FGI의 부속 상태로 다룹니다.
- 계산 대상 시간은 30분·60분이며 기본 60분, 최대 1시간입니다.
- 단독 HTML은 저장 결과를 재생하며 API 연결·새 계산은 제공하지 않습니다.
- 내부 `pyrocast_*` 스키마·이벤트·저장 키는 기존 자료와의 호환 계약입니다. 제품명 치환만을 목적으로 바꾸지 않습니다.

## 확인 방법

`app/`에서 의존성을 준비한 뒤 `npm test`로 계약 시험을 실행합니다. 브라우저 시험은 Playwright·Chrome 및 시험별 로컬 모델/서버가 필요합니다. `package.json`과 개별 시험의 실행 조건을 확인하세요.

UI 수정 시 관련 시험과 실제 운영 화면에서 건물 전환, 결과 선택, 재생, HTML 내보내기를 확인합니다. 계산을 실행하는 시험은 결과 열람 시험과 구분해 명시적으로 실행합니다.

## 범위

이 문서는 첫 배포의 UI 구조 안내입니다. 개별 시험의 통과를 모든 건물의 형상·물리 모델 검증으로 해석하지 않습니다. 세부 검토 기록과 명세는 프로젝트의 `reviews/`, `specs/`에 보존됩니다.
