## 실제 화면 검증

- 완료 직후에도 기존 `S09 / CAD_3F_R2_C0 / 00:00` 그대로였다. 완료 전후 실제 3D 스크린샷 영역(0,50)-(595,826)의 **변경 픽셀 0**. 자동 사례·카메라 전환 없음.
- 탐색 탭 ‘결과 보기’를 클릭하여 결과 탭 **집계 완료 2/2표본** 확인.
- 이어 새 사례를 각각 수동 선택해 `CAD_3F_R3 / 00:00~60:00` 로딩을 확인한 후 S09로 복원했다. 이 수동 검증은 완료 시 자동 전환과 별개다.
- 무작위 표본이 없으므로 비율은 0/0, 무작위 최고 지수는 미평가로 표시된다. 필수 표본을 발생확률 분모에 넣지 않는다. 필수 표본의 현상별 도달 실 수는 표시된다.
- 새 MC 저장 결과도 완전한 캐시 동등성 증거가 없으므로 다시 열 때 ‘과거 결과 재사용’ 라벨을 사용한다. 이는 방금 계산이 실패했다는 뜻이 아니라, 현재 요청과의 재실행 동등성 보증을 하지 않는다는 의미다.
