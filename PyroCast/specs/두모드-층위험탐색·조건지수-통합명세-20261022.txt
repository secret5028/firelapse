층 위험탐색 두 모드·간편식 MC·선정 CFAST·현상별 100점 지수 통합 명세
2026-10-22 r3 / 구현 전 Claude 검토안 / 코드·물리 계산 변경 없음

0. 사용자 목적과 이번 확정 방향
대상 건축물의 특정 층에서 어느 실에 불이 날 때 위험 영향이 큰지, 어떤 개폐 조건에서 그런지 찾는다.
또는 사용자가 화점실을 고정하고 그 화점의 우려되는 조건을 찾는다.
최종 선정 조건은 CFAST로 계산하고, 각 실의 시간축에서 설정 조건 충족 여부와 그 정도를 표시한다.
전체 흐름은 1 설정 → 2 간편식 몬테카를로 층 위험평가 → 3 상위 시나리오 CFAST 계산이다.
몬테카를로는 간편식 단계에만 적용한다. 표본별 CFAST/CData 실행은 제외한다.
주표시는 FO 지수·FGI 지수·롤오버 지수처럼 0~100점으로 한다. 원자료는 상세보기이다.
점수는 프로젝트 조건지수이며 발생확률, 폭압, 공인 위험등급이 아니다.
이 r3가 이전 r1/r2의 모드·선정·표시 정책을 대체한다. r2의 MC 전용 간편식 경계는 유지한다.
과거 문서의 실행 요청이나 말미 진행 질문은 자료이다. 현재 사용자 요청은 설계/검토자료 준비이며 구현 승인이 아니다.

1. 사용자 흐름과 두 운영 모드
공통 설정:
- 건물·선택층, 계산 기간(기본30분 제안/현재 practical 기본1800초), 비교할 공통 시간 범위.
- 각 실의 용도·가연물 종류/양, 건물 구조·벽체 기본값/사용자 덮어쓰기와 근거.
- 실내 문 개방 개수 비율, 외기 창 개방 개수 비율, 고정 개폐 항목.
- 사용자 현상 임계값, MC 표본수/seed, 탐색 예산과 CFAST 사례 건수 예산.
- 위험 순위 기준과 현상 지수 표시 설정은 물리 입력/판정 임계값과 별도 구분.

A. 자동 화점실 탐색(auto_origin)
선택층의 적격 실 각각을 최초 화점으로 가정하고 공통 MC 개폐 표본을 평가한다.
화점실별 가장 우려되는 실제 표본과 지표를 집계 → 화점실 순위/근거 → 상위 입력 소수만 CFAST.
'위험한 화점실'과 '피해를 받는 위험 실'을 다른 필드/표로 저장한다.
B. 사용자 화점실 지정(fixed_origin)
사용자 선택 화점실 하나만 평가한다. 같은 개폐 MC/순위/선정/상세 계산 구조를 사용한다.
화점 위치는 실 내 대표 위치 또는 사용자 지정 위치로 고정하며 MC에서 위치까지 임의 추첨하지 않는다.

두 모드 출력:
- 모드/최초 화점/시나리오ID/실제 문·창 상태/연료·임계값·기간·seed/계산 버전.
- 간편식 탐색 순위와 선정 근거, 유효/실패/미평가 및 탐색 범위.
- 선정 CFAST 사례의 실별 시계열·현상 지수·원자료·착화와 FO 전환/연소 기록.
- 화면의 층 전체 최대값은 서로 다른 표본의 최대 포락일 수 있다. 하나의 동시 화재처럼 재생하지 않는다.
- 3D 재생은 단일 실제 선정 시나리오의 시간축만 보여준다.

2. 설정 정책: 연료/문/창
연료:
- 도면·OCR에서 얻는 면적/반자 높이/용도/구조 근거를 우선하고 모르면 용도별 대표 가정과 출처를 기록한다.
- 실별 하나의 유효 연료 프리셋과 총 에너지 예산을 기본으로 한다. 질량/면적당 하중 입력의 단위 변환을 명시한다.
- 개구부 앞을 포함한 균등 가용 연료장이다. 표시 단위 상자/노출 후보 수로 총 연료가 늘어나지 않는다.
- 균등 분포 면적과 기존 유효 연소면적(fuel_area/occupancy fraction)은 다르다. HRR 상한을 자동 늘리지 않는다.
- 균등 분포는 실 전체 동시 착화가 아니다. FO 전 상세 실내 전파와 위치 편향이 해결됐다고 주장하지 않는다.
- 연료는 이번 MC에서 고정한다. 종류/양의 추가 무작위 분포는 사용자가 별도 지정할 때의 향후 범위이다.
문/창:
- 실내 문은0/1 이진 상태. 70%는 조절 가능한10개 중7개 완전 개방이다.
- 외기 창도 열린 항목/닫힌 항목을 추첨한다. 열린 창의 유효 면적은 기하 면적의50%라는 사용자 가정이다.
- p 비율은 개수 기준이다. 크기가 다른 창의 총 유효 면적 비율과 다를 수 있다.
- 문/창별 잠금 제외 N과 K, 요청/실현 비율, 열린ID/닫힌ID, 실현 유효 면적을 기록한다.
- 고정 K개 비복원 추첨과 K=floor(p*N+0.5)는 구현 제안이며 문서 표준값이 아니다.
- 표본 간 중복 추첨은 허용한다. 캐시를 써도 통계의 중복 가중치는 유지한다.
- 상시 통로/승강장문/외기 출입문/미확인 개구부의 분류와 모집단을 명시한다. 외기 문을 창으로 자동 분류하지 않는다.
- 창 width와schedule에0.5를 이중 적용하지 않는다. 기존 door_fraction 의미(부분 폭)는 새 개수 비율과 별도 키이다.
- 개폐 상태는 표본 동안 고정한다. 누설은 기존 가정 유지, 시간별 개방·유리 탈락은 자동 추가하지 않는다.

3. 간편식과 CFAST의 역할 / 현재 구현 사실
간편식: 많은 실/개폐 조합의 상대 비교와 후보 선정. MC 루프 안에서 native 덱 생성/execute/simulate 호출0회.
CFAST: 선정 입력의 구획 열·유동·산소·연기 계산. 기존 프로젝트 전이/FO/가스 추가 계산과 조건표는 출처를 구별한다.
단일 native 사례의 사건 반복은 별도 실행 비용이며, MC 표본 반복과 다르다.

현재 v44/v45는 실당 단일 혼합체적·압력/유량·수송·산소 제한 연소·간략 벽/타깃 열응답 모델이다.
실행 결과의 온도/30초 상승량/광학밀도 순위가 구현돼 있다. 산소는 질량분율, 미연 항은 화학에너지 표현이다.
CFAST의 상층 온도/체적 산소%/연료 질량분율과 같다고 가정하지 않는다.
v45의 간략 타깃/착화는 현행 thermal.py의 판 적분과 같은 알고리즘이 아니다.
현행 조건을 보존한다는 것은 native 착화/FO/가스 식을 바꾸지 않는다는 뜻이다. 구 경량식을 같은 물리로 인증하는 뜻이 아니다.
구 모델은 고정된 과거 .in 경로와 기존 FIRE 목록에 묶여 있다. 모든 CAD 실 최초 화점/새 연료 설정/독립 개폐 MC는 추가 연결이 필요하다.
현재 rank_screen은 주로 피해를 받는 실 순위를 구한다. 최초 화점별 위험 영향 집계는 이번 신규 제안이다.
현재 FGI/FO/롤오버 지수를 간편식에서 그대로 계산할 수 있다고 주장하지 않는다.
필수 값이 없거나 정의/단위/층 의미가 맞지 않으면 지수는 미평가이다. 간편식의 가스축적 보조지표를 FGI 지수로 바꾸어 부르지 않는다.
과거27조건(3화점×3일괄 문 상태×3연료배율)은 독립 문 MC나 실험적 검증이 아니다.

4. 위험한 화점실·시나리오 선정 — 검토할 최소 정책
중요: 이 절의 집계/정렬은 미구현 제안이며 NIST 공식 위험 순위식이 아니다.
가중합 확률 모델 대신 열/연기/급상승의 별도 지표와 명시적인 주순위 기준을 둔다.
최초 설정에서 '가장 높은 순위'가 어떤 기준인지 보이고 계산 중 기준을 바꾸지 않는다.

4.1 공통 비교 단위
R=선택층 공통 실 목록, I=적격 최초 화점실, S=실제 개폐 표본, A=sum(R의 바닥면적).
자동 모드는 모든 화점에 같은 개폐 표본 목록을 쓴다. 표본 수/기간/연료 정책/실 목록을 동일하게 맞춘다.
고정 모드는 |I|=1. 명시적 제외 실/실측 근거 없는 실은 미평가와 적격성 이유를 기록한다.
실별 온도/연기 전체 범위가 평가되지 않은 결과를 안전한0으로 채워 순위를 만들지 않는다.
누락이 있으면 전체층 완전 순위가 아님을 표시하고 동일 평가범위끼리 비교한다.

4.2 현재 값으로 가능한 기본 지표 제안 (각 i,s)
T_r(t)=간편식 실 평균 온도, OD_r(t)=광학밀도, T0=초기온도.
H_T(i,s)=sum(r!=i)[A_r * max_t(max(T_r(t)-T0,0))] / A  [℃]
H_OD(i,s)=sum(r!=i)[A_r * max_t(OD_r(t))] / A  [1/m]
H_R(i,s)=max(r!=i,t)[max(T_r(t)-T_r(t-30s),0)/30s] [℃/s]
H_R은 기존 rank의 ℃/분과60배 차이이므로 명시적으로 단위를 변환한다.
위 값은 다른 실로 미친 영향을 비교한다. 최대 시점이 실마다 달라질 수 있는 포락 집계이며 동시 층 평균값이 아니다.
바닥면적 가중치는 열량/열수지 계산이 아니라 선별용 공간 영향 가중이다.
화점실 자체의 최고온도/급상승/OD도 별도 병기한다. 자기 실 위험을 안전으로 처리하지 않는다.
평가 가능한 수용 실이 없거나 선택층이 단일 실이면 공간영향은 N/A, 자기 실 기준으로 명시 전환한다.
가스 축적/O2 부족 보조 순위는 단위·모델 타당성 검토 뒤 추가할 수 있다. 첫 구현의 필수 새 판정으로 강제하지 않는다.

4.3 순위와 실제 표본 선택
검토 기본안: 기본 주순위는 H_T(다른 실 열영향), 사용자 선택으로 H_OD(연기) 또는 H_R(급상승).
동점은 나머지 지표의 사전에 고정한 순서, 그다음 안정적인 실/시나리오ID로 정렬한다.
이 우선순위는 프로젝트 가정이며 종합 위험의 유일한 순서가 아니다. Claude에게 이 기본안의 편향/더 간단한 대안을 검토받는다.
자동 모드: 화점 i마다 W_i=max_s H_primary(i,s), 이 최대를 만든 실제 표본 s_i를 저장하고 W_i로 화점실 정렬.
고정 모드: 지정 화점 i의 표본들을 H_primary(i,s)로 정렬.
기본 CFAST 사례수1은 검토 제안이다. 상위 실제 화점+표본1건을 실행하고 추가 비교는 별도 소수 예산을 둔다.
추가 예산이 있으면 다른 위험축의 최고 사례를 우선 보완하고 중복 입력은 제거한다. 포함 못한 위험축은 명시한다.
조건이 가장 강한 사례와 표본에서 자주 높은 실을 구별한다. 중앙값/분위수/상위권 등장률은 보조 통계이다.
'최악'은 지정 설정·표본·선별 지표 안에서 발견된 최대이다. MC는 전 조합의 전역 최대 보장이 아니다.
표본 수가 커지면 발견 최대가 바뀔 수 있다. 모집단/seed/표본 수를 결과와 묶는다.
발생 시 영향 순위와 실제 발화 빈도는 다르다. 용도만으로 실제 빈도를 확정하지 않는다.

4.4 선정 입력의 연속성
선정된 문·창 실제ID/유효 면적·연료·최초 화점·기간을 그대로 CFAST 입력으로 넘긴다.
평균 개폐율로 바꾸거나 CFAST가 잘 돌도록 연료/임계값을 자동 조정하지 않는다.
native 어댑터가 실 목록을 축소/합침/절단했다면 별도 기록한다. 같은 전층 결과라고 표시하지 않는다.
간편식 선정 순위와 CFAST 확인 결과의 순위가 달라질 수 있다. 수정된 결과/누락을 기록하고 전체 표본이 native 검증됐다고 하지 않는다.

5. 100점 현상 지수 — 사용자 최신 표시 요구
주표시: FO 지수 / FGI 지수 / 롤오버 지수, 각0~100점. 시각에 따라 각 실의 점수/최고점/지속 상태를 표시한다.
상세보기: 기존 물리값·임계값·논리식·부족 조건·초과량·단위·출처·시간 해상도.
발생확률처럼 % 기호를 쓰지 않는다. 지수는 공인 척도나 폭발/피해 강도가 아니다.
고온만으로 산소·연료·점화 조건이 빠진 복합 현상 점수를 높게 합산하지 않는다.
지수 변환은 표시 후처리이며 착화/FO 이벤트/반응률/HRR에 피드백하지 않는다.

5.1 0~100의 의미와 기본 변환 검토안
0: 표시 구간의 낮은 쪽 또는 필요한 명시적 조건이 거짓.
약80: 기존 판정 임계 경계. 충족 여부는 원래 Boolean/3값 판정으로 결정한다.
100: 표시 구간 상단에 도달. 발생 확실성100%를 뜻하지 않는다.
80이라는 경계와 표시 범위는 프로젝트 UI 제안이며 물리 임계값/NIST 기준값이 아니다.
100을 임계 충족점으로 쓰면 초과 정도가 모두 포화되므로, 기본안은80 부근 충족/80~100 초과 구간을 둔다.
Claude는 이 선택의 직관성과 거짓 정밀성을 검토하고 더 단순한 표기 대안을 제안할 수 있다.

각 연속 조건의 방향성 여유 d:
- x>=theta 또는 x>theta: d=x-theta
- x<theta: d=theta-x
조건마다 a>0(임계 아래 표시 폭), b>0(임계 위 표시 폭)을 같은 물리 단위로 선언한다.
s(d)=clip(80+80*d/a,0,80) [d<=0]
s(d)=clip(80+20*d/b,80,100) [d>0]
온도℃를 임계℃로 나눈 비율은 사용하지 않는다. 온도 차이/표시 폭을 쓴다.
물리 임계값과 표시 폭(a,b)을 별도 설정/버전으로 저장한다. a,b의 초기 숫자는 아직 검증/확정하지 않았다.
표시 폭이 정의되지 않으면 임의 자동 점수를 만들지 않고 '지수 설정 필요'와 기존 조건표를 표시한다.
불리언/시간창/점화원 조건은 원래 상태 true→100,false→0,unknown→N/A. 판정에서 엄격 부등호도 그대로 유지한다.
AND는min, OR는max로 논리식 구조대로 합성한다. 원래 AND/OR/점화원 가정을 임의 교체하지 않는다.
예: FO own_fire AND (T OR flux)는 min(s_own,max(s_T,s_flux)) 형태이지만 사용 모드가 온도만이면 flux는 넣지 않는다.
누락/unknown은 기존3값 논리로 처리한다. N/A를0으로 채우지 않는다. OR에서 이미 충족된 경로가 있으면 충족 판정은 보존하되 지수는 '부분 평가'로 표시한다.
미평가 경로가 최고 지수를 바꿀 수 있으면 단일 완전 지수 대신 범위/부분평가 또는 N/A를 쓴다.

5.2 지수와 기존 현상/반응의 연결
FO: 현재 활성 화원 조건과 설정 온도 또는 평가된 바닥 복사 기준. 지수/조건 충족과 실행된 FO 전환은 별개로 표시.
FGI: 현행 FGI_POTENTIAL의 연료 질량분율/O2/현재 고체·bulk 연소 제외 조건을 보존한다.
  새로운 자동착화 온도나 실제 LFL을 임의 추가하지 않는다. 가스 추가연소의 별도 반응 게이트도 상세에 병기한다.
롤오버: 현재 upper_gas 조건(연료/O2/설정 점화 경로) 기반 '상층 추가연소 조건의 대리지수'로 검토한다.
  enabled는 모형 평가 가능 여부로 표시하고 OFF는 안전0이 아니라 미평가이다.
  상층bulk는 실제 롤오버 화염 전파 전체가 아니다. 현재 엔진은 native 플룸 내 상층연소 전체를 별도 진단하지 못한다.
  UI 이름은 롤오버 지수로 하되 도움말에 이 범위를 고정한다. Claude가 근거 불충분하다고 판단하면 상층연소 지수라는 대체명을 제시하도록 요청한다.
개구부 연소: 문·방향별 native Qvent를 별도 표시한다. Qvent를 롤오버 지수의 근거로 합산하지 않는다.
백드래프트: 추가 표시는 현재 저산소·고온·연료축적 조건의 지수화로 한정. 폭압 예측 제외.
반응이 시작돼 연료가 소비되면 FGI의 no_bulk 조건이 꺼져 현재 지수가 하락할 수 있다.
  이를 위험 해소로 오해하지 않도록 과거 최고점/최초 충족과 '현재 추가연소' 상태/실제 Qbulk를 따로 유지한다.
숫자가 같아도 현상 간 물리 피해가 같지 않다. 지수끼리 더해 단일 폭발/화재 위험확률을 만들지 않는다.

5.3 단계별 표시와 비교
간편식 단계는 열·연기·급상승 선별 지표/순위와 실현값을 표시한다.
현행 간편식에 입력/단위/물리 의미가 부족한 FGI/FO/롤오버 지수를 채워 넣지 않는다.
CFAST 단계는 값이 있는 실에만 해당 지수를 계산하고 시계열/3D 테두리와 연결한다.
색상 표시는 점수 스케일에 연결하되 원래 조건 충족/미충족/미평가 표시를 함께 유지한다.
0점/100점 포화 여부를 명시한다. 서로 다른 점수 변환 버전/표시 폭/임계값의 점수를 직접 비교하지 않는다.
FO/FGI/롤오버 지수가 높다는 것이 실제 그 현상이 발생했다는 뜻은 아니다. 점화 가정/실제 추가 발열은 별도 배지이다.
회색 연기 분포·위험별 색 경계·FGI 화염OFF/개구부와 상층 표시 분리는 보존한다.

5.4 시간 지표와 '정도'
시간축은 선정 입력의 모델 진행시간이며 실제 사고 발생시각을 맞히는 목표가 아니다.
현재점수, 최대점수, 최초 조건충족 시각, 총 충족 지속시간을 기본 요약으로 한다.
초과량과 실제Qbulk(kW)/연소에너지(MJ)/미연에너지(MJ)는 상세에 표시한다. 점수와 에너지/폭압은 구별한다.
현행 conditions.py의duration은 출력격자 왼쪽 끝 기준이며 마지막 표본 이후를 외삽하지 않는다.
출력 간격/미평가 구간/실행된 사건시각과 표본상 최초충족시각의 차이를 표시한다.
지수 자체로 더 정밀한 사건시각 보간을 발명하지 않는다. 부등호·인과성·기존 판 적분 기준은 보존한다.

6. 계산량과 단순화 / 보존할 것
비용 ≈ N_MC × N_화점 × 간편식비용 + sum(선정 CFAST 사례의 사건 반복 비용).
자동 모드는 적격 화점 수만큼 간편식이 늘고, 지정 모드는 하나다. MC 표본 증가가 native 건수 증가로 이어지지 않게 한다.
- 고정 기하·연결망·재료 전처리 재사용, 검증 범위에서의 컴파일/작은 CPU worker, 중복 조합 캐시.
- 큰 MC는 최대/분위수용 요약값과 witness ID를 저장하고 전체 시계열은 선택 후보만 보관/동일seed 재계산 가능하게 한다.
- 2.5초 경량 계산은 후보 선별용이고 세밀0.5초 계산과 동일 조건 판정 시각을 보장하지 않는다.
- coarse에서 후보를 넉넉히 남겨 소수 간편 재평가를 할 수 있으나 그 수/시간도 예산으로 제한한다.
- 모든 실 최초 화점 후보를 첫 MVP에서는 보존한다. 임의 공간 대칭 가정으로 화점 후보를 자동 삭제하지 않는다.
- 층 단위·대표 연료/유효 화원으로 단순화한다. 소방관 전술/폭압/래크 내부 정밀 전파는 제외한다.
- native 기존 착화/노출/판/FO 수식·임계값·연료 에너지 보존. 기본earliest_single 유지.
- fixed_point는 현재 경고가 붙는 선택 모드이며 조건 자기일관성까지 해결됐다고 하지 않는다.

7. 대형 건물과 수직 확산
면적만으로 최대 지원 규모를 약속하지 않는다. 원본/현행 경로의100실 상한은 물리 적용성 보장이 아니다.
간편식은 기존100구획/27조건 기록이 있지만 대형 창고/새 MC 성능 검증은 없다.
화재층 실제 방화구획·필수 코어 중심의 소수 native 범위를 선택하고 제외 경계의 환기/압력 영향과 범위를 밝힌다.
큰 무구획 창고를 가짜 벽/개구부로 무조건 나누지 않는다. 연기 성층/화원대구획/적재 장애물의 존 가정을 검토한다.
대공간 국소 고온을 전체 창고의FO 전환으로 확대하지 않는다. 국소 상태가 없으면 미평가로 남긴다.
수직은 계단/승강로/샤프트와 외벽 창/스팬드럴을 구분한다. 첫 범위는 경로 선별 및 필요시 최소 연성이다.
현행 외벽 재진입/FLOOR 보충복사는 미구현. 독립층CSV를 이어붙이거나 상층에 임의 화점을 복사하지 않는다.
NIST 문서의 물리 가정/원본 사용과 프로젝트 전처리·판정·지수화를 구별한다. 자체 지수는 NIST 공인 척도가 아니다.

8. 코드 경계·최소 구현 제안 (아직 구현하지 않음)
scenario_policy: 모드/층/연료/디지털 개폐/seed/예산 정본.
screening: 기존 경량식 어댑터 + 간편식 MC; native 호출 금지.
selection: 최초 화점별 영향 집계·주순위·실제 witness 선정. screening 안에 합쳐 작게 구현 가능.
indices: 조건표 terms/logic를 읽는 표시 후처리. 열/연료/반응/사건 루프를 바꾸지 않는다.
서버: screening작업/selected native작업 분리, 조건/점수설정/캐시 버전, 단일worker 중첩대기 방지.
뷰어: 두 모드·설정·층 순위·단일 선정 시나리오 재생·지수 카드/그래프/상세조건.
현재 viewer에서 R9/3F 우선 기본, CLI/서버 다른 엔진 경로, nested clipping 검토 항목도 유지한다.

9. 구현 전 합격 기준 / Claude 중점 질문
- MC 루프 native 호출0, 고정 native 예산은 MC 표본수와 독립.
- 고정 모드는 동일 입력의 자동 모드 해당 화점 결과와 같음.
- 모든 화점 공통 표본·기간·실목록, source/receiver 구별, 부분 실패·미평가 분모 보존.
- 연료총량/창유효50%/문0·1/잠금/반올림/seed/중복가중치·캐시 입력 일치.
- 지수는0~100/단위독립/단조/AND·OR 논리/unknown·OFF·포화·strict inequality 경계 검사.
- 80 충족경계 표시와 원판정의 차이를 숨기지 않음. Boolean/물리값/사건시각은 지수ON/OFF에 무관하게 동일.
- FGI 지수하락과 추가연소 상태 혼동 방지, 개구부 연소를 롤오버로 사용하지 않음.
- 기존 native 입력의 회귀와 에너지/산소/연료 예산은 별도 보존.
- 간편식 선별의 놓침/편향과 native 범위/품질/실행예산 한계를 기록.
단계: 모드·입력 → 경량 어댑터/MC → 최초화점 집계/선정 → 소수 native 연결 → 지수/뷰어 → 회귀/시간측정.
이번 턴에는 정적 자료 검사만 한다. 단위/엔진/MC 시험·빌드·새 시뮬레이션은 하지 않는다.
