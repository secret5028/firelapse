CAD 공간 연결 보강 v4 (2026-10-14)

변경 사항
- 작은 벽 틈의 보강 후보를 실 수뿐 아니라 영역 대응·면적 변화·문 양쪽 이웃으로 비교합니다.
- 기존 CAD 문·창 형상에 대해 3개 횡단선의 판정이 일치할 때만 연결을 복구합니다.
  중간의 벽을 넘어 연결하지 않으며 외기는 실제 바닥 외곽과 접할 때만 인정합니다.
- 연결이 없는 공간도 3D와 해석기에 유지합니다. 연결 미확정 상태로 표시하며 문을 임의 생성하지 않습니다.
- 3D 변환 후의 층별 simulation_graph와 해석기는 같은 연결·개구부 치수 생성 함수를 사용합니다.
  평면 단계의 그래프는 기본 높이를 사용한 예비 입력입니다. 층고·창대·문 높이가 적용된 building.json의 그래프가 최종 입력입니다.
- 개방 상태는 0·50·100%, 유효 개구 면적 비율입니다. 문짝 각도가 아닙니다.
  기본 단위는 percent이며 fraction 입력은 opening_unit='fraction' 명시 시에만 0·0.5·1을 받습니다.
  0.5를 기본 입력으로 넣으면 오류를 내어 50%와 0.5%의 혼동을 막습니다.
- 인접한 층의 같은 종류 코어를 중첩 형상과 공간 ID로 대응시킵니다.
  대응된 승강로·계단은 별도 일반실로 중복 생성하지 않습니다. 가까운 방으로 임의 연결하던 승강기 누기 연결도 제거했습니다.
  인접층 누락 또는 대응 불명확은 미확정으로 남깁니다. 층 이름은 이 검증에서 4F·5F 형식을 사용했습니다.

실행 예 (필요 패키지: numpy, opencv-python, shapely, ezdxf, scipy)
  python cad_pipeline.py input.dxf result --floor 1F
  python cad_build3d.py result/building result/plan.json --names 1F
  python fire_zone.py result/building.json --floor 1F --fire R0 --door 50 --win 50 --t 60 -o simulation.json
  python cad_build3d.py combined result4/plan.json result5/plan.json --names 4F,5F
  python -m unittest discover -p "test_cad*.py"
DWG 입력은 --dwg2dxf에 별도 변환기 실행 파일 경로가 필요합니다.
코드 ZIP의 CAD3D 폴더에서 실행합니다. 기존의 v2·v3 문서는 이전 변경 이력이며 이번 설명을 우선합니다.

검증
- 43개 단위 테스트 통과.
- 기존 CAD 5개 층 재추출: 실 128개 전부 3D와 해석기에 포함. 이전에 빠졌던 14개 공간 포함.
- 기존 정상 문 연결 보존. 호텔 1층 W6·W7의 외기 연결 복구. 기존 26개 미확정/같은 공간 연결 중 24개 남음.
- 5개 층 × 0·50·100% = 15개 조건, 각 60초 계산 완료. 동일 층에서는 같은 발화실·화재 설정 사용.
  이 검사는 문과 창의 기본 개방률을 동시에 바꾼 실행 검사입니다. 배연 최적화나 독립 효과 비교 시험이 아닙니다.
- 업무시설 1층 R18(약 14.3㎡): 연결 미확정 상태로 유지하고 해당 공간 발화 10초 계산 성공.
- 호텔 5층 추가 추출. 4·5층의 계단 2곳·승강로 2곳 대응 확인. 각 대상층 + 수직 존 모델 30초 계산 완료.

범위와 남은 사항
- 연결 미확정 14개 공간은 임의 연결 없이 고립된 공간으로 해석됩니다. 실 누락은 해소했으나 실제 문 연결을 모두 복원한 것은 아닙니다.
- 층간 검사는 해당 층 + 공용 수직 존 모델입니다. 모든 층의 일반실을 동시에 푸는 전 건물 해석은 아닙니다.
- 반자 위 공간은 별도 모델링하지 않습니다. 층고·창대·개구부 높이에 기본값이 포함됩니다.
- 기존 해석기의 수직 존 상부 환기·다른 층 누기 근사는 유지됩니다. 실제 개구부 확인에 기반한 전 건물 경계조건은 별도 보강 대상입니다.
- 소방 근거는 기존 호텔 소방 심볼 정렬 결과를 재사용했습니다. 다른 표본에 소방 자료를 새로 추출한 것은 아닙니다.
- 계산 완료는 소프트웨어 실행 검증이며 화재 실험 또는 공인 해석기와의 정확도 검증이 아닙니다.
- 연결살수·스프링클러 계통 또는 기존 웹앱 배포는 이번 변경에 포함하지 않았습니다.
