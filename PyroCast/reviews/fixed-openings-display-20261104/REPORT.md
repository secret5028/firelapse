# 확정 급기 상태 3D 표시

확정된 다음 실행 입력을 표시하며, 현재 재생 사례의 개폐 상태를 바꾸지 않는다.

- 표시 탭 `확정 급기 보기`: 기본 ON, 해당 건물에 확정 데이터가 없으면 비활성.
- 열림: 녹색 사각형. 닫힘: 회색 사각형 + ×. 닫힘은 누설 면적이 있을 수 있다.
- 범례에 `확정 급기 · S00 · 다음 실행 입력` 표시.
- 건물 SHA가 일치하는 상태만 표시. 문/창 위치 토글과 별개이며 OFF이면 기존 위치 표시로 돌아간다.
- 외부 창 크기/테라스 제외 규칙과 카메라 방향 판정 유지. 문·창 위로 연장되는 선을 다시 만들지 않는다.
- 기존 내보내기의 openings 상태 및 /cfbt/lite/doors 응답 포함 경로를 그대로 사용한다. 이번에는 HTML 파일 내보내기 재검증을 수행하지 않았다.

## 운영 검증

실제 강화 서버 / S09 / 3F / 1420 s, Edge 별도 검사 세션. 실제 저장 확정 표본 S00(R3)을 읽었다. 테스트 핸들·고정 clock만 주입했다.

- 입력: 69개(열림 29, 닫힘 40).
- CAD 표시 대상으로 대응: 50개. 아래 19개는 기존 창 강조 필터 제외 또는 CAD 문·창에 해당하지 않는 연결 개구부다. 이들을 임의 문으로 만들지 않았다.
- 50개 모두 원본 확정 open 상태와 선 색·× 표시 일치.
- OFF → ON 왕복 시 상태 완전 일치. 기하 재생성 및 자원 수 증가 없음.
- 사례/재생 시각 불변. 다른 건물 해시를 주면 표시 안 됨.
- 완도 이동 시 확정 상태 없음: 토글 비활성. 강화 상태를 완도에 덮어쓰지 않음.
- 브라우저 오류 0, 계산·저장 요청 0. POST는 기존 읽기 전용 AI 보고서 목록 조회만.
- 서버·엔진·계산 입력·저장 결과 수정 없음.
