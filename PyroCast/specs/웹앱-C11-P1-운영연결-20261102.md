# C11 4절 — 완도 P1 운영 화면 연결

P1 저장 CSV만 변환했다. 이 작업의 CFAST·간략 엔진 실행은 0회이며, 원본 CSV·엔진·조건표·셰이더는 수정하지 않았다.

## 구현·확인

| 항목 | 결과 |
|---|---|
| 건물 선택 | 운영 화면 상단 기존 3F ↔ 완도 저온창고 왕복 확인. 기존 목록에 P1 혼입 없음 |
| 운영 주소 | http://127.0.0.1:8832/data/wando-coldstore/model.html |
| 공동 | 안쪽 벽 y=18~18.1 m, 폭 8.75 m·높이 6.405 m의 0.1 m 공동. R5와 별개 선택·시계열·지수 표시 |
| 재생 | 720표본, 5초 간격, 마지막 3,595초(59:55). `simulation_output_complete:false`, “마지막 5 s 미출력” 상시 표시 |
| 값 보존 | 상층 온도·실제 화원 HRR·4지수 전 표본이 저장 P1과 동일. 산소는 체적분율, OD는 zone CSV의 1/m 사용 |
| 절단 | 1,320초부터 1×2 m, 1,800초부터 2×2 m. 녹색 개구 면·라벨 연동. 시간 이동으로 기하 재생성 없음 |
| 검증 | 어댑터 오류 0, 브라우저 콘솔 오류 0. 개구 레이어 dispose 후 구독 0 |

재생 시각은 native 출력의 미세한 부동소수점 편차(최대 0.000047초)를 5초 격자로 표기하며 원래 시각도 보존한다. native WF에는 일정 경계 직전 상태가 출력되어 다음 5초 표본에 반영되지만, **3D 개구 표시는 요청대로 입력 일정의 정확한 시각**부터 열린다. 화재 계산값을 앞당기거나 보간해 바꾸지 않았다.

## 경로

| 항목 | 값 |
|---|---|
| 출입문 | CAD_1F_ENTRY_R5, 중심 (49.375, 0, 0) m |
| 차량 기준점 | (49.375, −5, 0) m, 문 바깥 5 m |
| 화점 앞 도착점 | (46.75, 17.95, 0) m |
| 길이 | 23.1409 m = 외부 5 m + 실내 18.1409 m |
| 호스 | 15 m 기준 2본, UI 예비 1본 권장. 계단 0회 |

경로는 기존 직선 근사다. 장애물·호스 굴곡·여유 길이를 계산하지 않으므로 현장 전개 3본을 재현한 값이 아니다. 최신 명세에 추가된 장애물 회피·다수 차량·대원 표식은 이번 사용자가 지정한 ①~④ 연결 범위에 포함하지 않았다. 기존 4절의 단독 HTML도 이번에는 생성하지 않았으며 완도 페이지는 저장 결과 보기 전용이다.

| R5 시각 | FO | FGI | 백드래프트 | 롤오버 |
|---|---:|---:|---:|---:|
| 1,320초 | 0 | 32.53 | 32.53 | 18.77 |
| 2,100초 | 0 | 98.84 | 96.54 | 82.03 |
| 3,595초 | 0 | 3.98 | 2.12 | 15.68 |

FO 0은 기존 조건표가 ROOM 고체·bulk 발열을 사용하기 때문이다. native 문 분출 발열을 고체 화원으로 재배정하지 않았다. 이력 ON 테두리는 전 구간 최대값이며 현재 지수와 구분된다. 계산하지 않은 다른 방은 기하만 표시하고 안전 판정을 만들지 않는다.
