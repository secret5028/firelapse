# 웹앱 리팩토링 2단계 결과 — 2026-10-26

계약 초안 2·3절에 따라 순수 JS 스토어, 장면 호스트, 빈 레이어 틀을 구현하고 합성 fixture로 검증했다. 실제 건물 렌더러 교체와 3단계는 진행하지 않았다.

## 구현 범위

- `app/web/state/store.js`: 슬라이스별 읽기 전용 스냅샷·구독·액션. 층 변경과 카메라 변경 분리. 요청 seq로 늦은 결과 폐기. 작업 중 중복 실행 거부. legacy 브리지는 dispatch만 제공.
- `app/web/state/series_cache.js`: 결과 메타와 분리된 읽기 전용 시계열 저장. 새 결과 수락 시 이전 값 교체, 프로젝트 종료 시 명시적 clear.
- `app/web/scene/host.js`: 컨테이너당 캔버스·렌더러·루프 하나. start/stop/dispose, 주입 가능한 clock, 리스너·구독·렌더러 해제. clock.now는 밀리초, tick 인수는 초.
- `app/web/layers/empty.js`: 건물·개구부·코어·연기·화염·플룸·위험·선택의 빈 레이어 8개. 개구부는 문/창 그룹 분리. 각 레이어의 소유 자원과 구독을 해제하고 재사용 거부.
- `app/web/scene/render_order.js`: 계약의 렌더 순서·깊이 정책·유형별 색·높이 오프셋 상수. 위험선은 후속 단계에서 실제 방의 전체 폴리곤을 사용해 구현한다. 현재는 선이나 셰이더를 새로 그리지 않는다.
- 화면 용어는 **“상층 연소”**. 기존 정밀 뷰어 설명 문장에 남은 bulk도 이 표현으로 교체했다. 내부 저장 필드명은 변경하지 않았다.

## 동결 및 후속 경계

엔진·시뮬레이션 설정·저장 결과·서버·캐시 키는 변경하지 않았다. 새 시뮬레이션은 0회다. 기존 화면 소스 수정은 위 용어 정리 한 문장뿐이며 새 호스트는 아직 실제 화면에 연결하지 않았다. 셰이더는 복사·변경하지 않았다.

위험 유형별 중첩 동시 표시, 다중 셀 방의 셀 목록 펼침과 “방 평균 없음” 정책은 유지한다. 실제 레이어·패널 연결은 후속 단계다. 캐시 키 변경은 5단계 전 별도 승인을 기다린다. 이번 2단계 검증 후 멈춘다.
