# 설정·탐색 통합 및 층별 단일 화점 MC — 2026-11-04

- 탭: 설정·탐색 / 결과 / 표시. 층 선택 → 연료 설정 → ① 점수 1위 자동 화점 → ② MC → ③ 최악 결과 적용·재생.
- 상위 N 비교와 수동 화점 실행 카드는 화면에서 제외. 기존 실행 경로 자체는 삭제하지 않음.
- MC는 기존 직렬 CLI, 기본 10표본, 30/60분 선택, 표본당 적분 예산 1,200초. 이전 확정 급기를 새 MC 전체에 강제하지 않음.
- 최악 선택 기준: 연소 실 수 내림차순 → 주의≥70 실 수 내림차순 → 최초 FO 빠른 순. 버튼 적용 후 해당 저장 결과와 개폐 상태를 함께 표시.
- 호텔·견본주택은 건물 SHA별 MC/확정 상태 경로. 강화는 기존 MC 경로 사용. 완도 순정 저장 결과는 기존 보기 전용 유지.
- AI 초기 배치는 기존 연결을 사용: 건물·층·실 용도, 위치·인접 정보로 허용된 연료 클래스를 선택하고 동일 fire_load_table 기준량 적용. 수동 실 설정 > 층 설정 > AI 기본값 순서 유지.
- 가연물 기호 기본 ON. AI API 미설정 시 용도별 기준량을 임시 표시하며 AI 완료라고 표시하지 않음. 실제 AI API는 미검증.
