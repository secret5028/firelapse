# D-1 표시 다이어트 — 완료 보고

계산 재실행 0회. 엔진·레이어·셰이더·render_order·서버 소스 74개 SHA256 불변. 표시 기본값, 패널, HUD와 표시 경계만 변경했다. 기존 결과·조건 지수·카메라·화염 크기식은 그대로다.

## 적용

- 기본 ON: 건물, 연기(70%, 온도 무늬 약하게), 화염(hrr), 현재 지수 100 이상 위험 유형, 선택, 경로/차량.
- 기본 OFF: 이력, 주의, 플룸/천장 가스, 셀선, 바닥 틴트, 연기 경계, 연료, 문/창 강조, 코어 투시, ±30℃ 점선, 작전/대원 기호. 개별 토글을 유지했다.
- HUD: 실명 / 최고 현상 한 개 / 상층 온도. 경로 한 줄은 유지. 산소·연기층 높이는 결과 탭 선택 실 카드에서 확인한다. 수동 화점 버튼도 이 카드로 이동했다.
- HUD 옆 `이력 보기`와 표시 탭이 같은 상태를 사용한다. 켜면 기존 전 구간 최대 점선 중첩을 사용한다.
- 범례는 켜진 항목만 한 줄로 표시한다. 플룸 범례는 ON일 때만 DOM에 붙는다. 동결 렌더러가 OFF에서도 쓰는 `cfPlumeNumbers`는 별도의 숨김 요소로 보존한다.
- 셀선·틴트·연기 경계는 패널의 `display_policy.js`에서 그리기 마스크만 바꾼다. 레이어 기하·재질·판정은 변경하지 않는다. 주의 토글은 기존 회색 조건선을 독립적으로 다시 보이게 한다.
- 계단/승강기 라벨은 전체 보기 또는 선택 실 폴리곤 안의 객체만 표시한다. 조작 힌트는 전체 보기에서 표시한다. CUT은 전체 보기 또는 연결 공동(CAVITY) 선택 시 표시한다.
- 완도 대원 ①–⑤는 기본 OFF이며 작전 토글과 동기화된다. 기존 차량 메쉬가 없는 완도는 기존 경로 출발점에 HUD 차량 위치 표식을 사용한다(새 차량 모델을 만들지 않음).

## 전후 확인

1280×720, 시각 고정, 애니메이션 clock 180000 ms. 위험 수는 원래 방 단위다. 전은 이력 ON, 후는 현재 시각이므로 수가 달라지는 것이 의도한 변경이다.

| 장면 | 전 FO/FGI/BD/롤오버/주의 | 후 FO/FGI/BD/롤오버/주의 | draw calls 전→후 |
|---|---|---|---|
| 3F S09 1420초 | 1/0/1/0/5 | 1/0/0/0/0 | 769 → 410 |
| 완도 P1 2100초 | 1/1/2/0/0 | 0/0/1/0/0 | 413 → 377 |

P1 R5의 FGI 지수 99는 HUD에는 나오지만 100 미만이므로 위험 테두리는 나오지 않는다. 이 시각 BD 테두리는 공동(CAVITY) 1실에 표시된다.

### 완도 연기

두 경로는 이미 `legacy_real_bridge.js:displaySmokeDensity()`와 `legacySmokeTexture:true`를 공유한다. 변환 불일치가 없어 변환 함수는 수정하지 않았다. 공통 함수는 양수 OD에 `max(1, OD)`를 적용하는 기존 표시 근사다. 간략 엔진의 입력 농도는 표시용 대용값이므로 실제 광학밀도와 같은 물리량이라고 해석하지 않는다.

- P1 2100초 R5: 상층 OD **8.58794350916 /m**, 표시 uOD **8.58794350916**, 불투명도 **0.7**, 온도 무늬 진폭 **0.4**.
- 연기층 경계 **2.37217635545m**. 기존 표시 여유 1cm 때문에 상층 메쉬 바닥은 **2.38217635545m**, 높이는 **4.02282364455m**. 하층 위끝은 **2.37217635545m**다. 비스듬히 캡처에 상층 범위가 보이며 임의로 높이를 바꾸지 않았다.
- 하층의 극소 OD(2.10e-10/m)도 기존 공통 표시 함수에서 1로 올라간다. 따라서 완전히 투명한 하층은 아니며 이 표시 근사를 이번 작업에서 바꾸지 않았다.

## 검수

- 3F 표시 체크박스 **24개**, 완도 **27개** 모두 반전 후 원복: 초기 상태와 일치.
- HUD 이력 버튼 → 표시 탭 체크 동기화 확인. 플룸 OFF 범례 0개 / ON 1개 / OFF 0개.
- CUT: CAVITY 선택 시 표시 / R5 선택 시 숨김. 전체 보기 계단·승강기 라벨 표시 확인.
- `risk_history.test.mjs`, `results.unit.mjs` 통과. 이력 테스트의 초기값만 OFF로 갱신하고 이력/주의 ON은 시험에서 명시했다.
- 운영 완도 페이지 새로 로드 후 콘솔 오류 0. 기존 플룸의 숨김 숫자 DOM 의존 때문에 발견한 초기 오류는 숨김 기록 요소 보존으로 해결했다.
- 계산·조건 판정 변경 및 서버 계산 요청 없음. 기본값 변경이므로 전후 픽셀 0 비교는 생략했다.
