# r20 배포 검증 보고서

2026-11-11 · r19에 DWG·DXF 변환기를 더한 패키지의 검증 결과.

## 달라진 점

- 실행 패키지에 CAD 가져오기 구성요소를 넣었습니다: 도면 판독기(저장소 `work/cad-web/cad_engine`의 17개 모듈), LibreDWG `dwg2dxf` 0.14, ezdxf 1.4.4, OpenCV 4.14.0.94와 그 의존 라이브러리.
- `config/cad-import.local.json`이 없으면 패키지에 든 변환기를 씁니다(`PyroCast/tools/cad_import.py`). 설정 파일이 있으면 그 설정이 우선합니다.
- 판독기가 점 3개 미만으로 붕괴한 윤곽에서 예외로 멈추던 문제를 고쳤습니다(`cad_evidence.py`). 해당 윤곽은 검사 기록에 남기고 제외합니다.
- 수록 결과(CFAST 32건)와 실행 환경은 r19와 같습니다. 새 계산은 추가하지 않았습니다.

## 수록되지 않은 건물로 확인한 새 건물 생성

### 공리 검토를 API 없이 수행한 경우

API AI가 받을 요청(후보 99개와 원본 도면 이미지)을 그대로 추출해, 후보 실 48개를 원본 CAD 선 위에 확대한 이미지로 직접 판독하고 결정을 가져오기 폴더의 `codex-review.json`에 기록한 뒤 앱의 재검토를 실행했습니다. 아이엔테크놀로지 모델을 만들 때 쓴 것과 같은 기록 방식입니다.

- 채택 6건: 계단 3곳(B1 R23, 2F R5, 2F R16 — 계단 단선·난간·절단선·방향 표시 확인), 문 3개(1F R19↔홀, 2F 화장실 칸 2개). 6건 모두 앱의 기하 검증을 통과해 반영되었습니다.
- 미확인 93건: 화장실·사무실·방풍실·벽체 공동 등 계단·승강기 표현이 없는 실. 승강기 옆 샤프트(B1 R27, 1F R18, 2F R28)는 판별이 애매해 남겼습니다.
- 반영 후: 고립 실 25개, 검토 항목 245건, AI 상태 `codex_source_review,not_connected;validation=not_connected`. 보정 후 검증 단계는 기록 방식으로 넣을 수 없어 미완료로 남습니다.
