# PyroCast 확정 명세 — 2026-10-25 기준 (수정 이력 없음, 현재 상태만)

> 대상: Codex. 이 문서가 `Claude지시-실단위규칙r8-동결`, `Claude지시-간략엔진L1`(1.1~1.5절 포함)을 **대체**한다. 이전 문서는 이력 참고용으로만 둔다.
> 원칙: CFAST 엔진·솔버 무수정. 결과를 맞추려는 임계값 변경 금지. 미평가는 미평가로 표시.
> 표기: **[사실]** 확인됨, **[가정]** 프로젝트 설정(사용자 변경 가능), **[미검증]**

## 1. 구조

| 모드 | 엔진 | 용도 | 실행 시간(3F 30실·1 h) |
|---|---|---|---|
| **탐색(간략)** | `pyrocast_lite` (fire_zone.py 기반 2존, scipy BDF) | 화점·개구부 조합 몬테카를로, 최악 조건 탐색, 3D 시간축 표시 | 약 2~4분 |
| **확인(정밀)** | 순정 CFAST 7.7.7 + 입력 덱 전이 규칙(r8) | 탐색 상위 사례 확인, 공식 결과 | 약 9~30분 |

두 모드는 **같은 전이 규칙, 같은 설정값, 같은 조건표**를 쓴다. 판정량만 다르다(정밀: 판 센서, 간략: 상층 온도).

## 2. 전이 규칙 (두 모드 공통)

- 최초 화재실: 사용자 입력 HRR 곡선 그대로.
- 다른 실·셀: 바닥(z=0)에 대기 화원 1개. 공급은 `item_peak`(입력 연료 peak, 상승 60 s, 외기 우선 상한 k=1.0, 연료 예산 적분 일치).
- **실간 착화:** 출발실(부모) 상층이 `temperature_C`를 넘으면, 경로 지연 뒤 착화.
  - 정밀: 천장 아래 0.5 m 이상·모서리·벽 향·저방사율 0.1 mm 판(T4b) 온도.
  - 간략: 상층 평균 온도.
- **셀 간 착화:** 부모 셀이 `cell_temperature_C`를 넘으면, 셀 중심 거리 / `spread_speed` 뒤 착화.
  - 정밀: 화원 위 1 mm 판. 간략: 상층 온도.
- **부모 선택:** 최초 화재실에서 출발하는 최단 지연 경로(Dijkstra) 단일 부모. 다중 경로 미반영(한계 기록).
- **경로 지연:** 열린 문 `open_delay_s` / 닫힌 일반문 `closed_delay_s` / 방화문 전이 없음 / 셀 경계 거리·속도 / 수직 개구부 위층 방향만 `vertical_delay_s`.
- **통과 공간**(연료 하중 < 50 MJ/m²): 화원 없음, 센서(또는 상층 온도)만. 건너뛰지 않음.
- **셀 분할:** 바닥면적 > 150 m² 또는 장단변비 > 3 → 8~12 m 격자. 셀 경계는 전체 크기 가상 개구부. 최초 실 연료는 셀 면적 비율로 분배.
- 전이 이벤트는 FO 판정이 아니다. 결과에 `trigger_basis`(`plate_sensor` / `upper_layer_temperature`)를 기록한다.

### 3.0 실 단위 산소 재고 — 시험 결과 **옵션 OFF로 보관** (2026-10-25 22:00)

**[사실]** 구현·시험 완료(`oxygen_inventory_mode`). 3F 적분 151 → 139 s(−8 %), 수락 스텝 1,225 → 1,337(증가). B1~B3 결과는 거의 같고, 3F에서 R17이 추가로 연소. **산소 게이트는 느림의 주원인이 아니었다.** 층별 산소 정보를 잃는 대가에 비해 이득이 없으므로 기본 OFF로 둔다. 코드는 보관.

### 3.0a 속도: 원인은 스텝당 비용 (다음 1단계)

**[사실]** 3F: 139 s / 1,337 스텝 ≈ **104 ms/스텝**, 상태 401개. 평균 dt 2.7 s로 스텝 수는 적다. 비용은 강성이 아니라 **스텝 하나의 계산(RHS 평가 + 유한차분 야코비안)**이다. 3실(31 상태)은 스텝당 약 1 ms였다 → 상태 13배에 비용 100배 **[추론: 야코비안 열 수 × RHS 비용]**.

지시(측정 먼저, 수정은 1종류씩):
1. **프로파일 1회(3F 표준):** RHS 호출 횟수, RHS 1회 평균 시간, 야코비안 재계산 횟수, 이벤트 재시작 횟수, 함수별 시간 상위 5개. 실행 없이 기존 결과를 쓸 수 없으므로 3F 1회 재실행(결과는 같아야 함).
2. **프로파일 결과 [사실, 2026-10-25 22:10]:** 적분 170 s 중 수치 야코비안 96 %. 야코비안 325회, 1회당 RHS 452회(상태 441개 → 열 묶음 441개, 묶음 효과 0). 원인: **누적 에너지 상태 E의 희소 행·열이 전부 True**라 어느 열도 함께 교란할 수 없음. RHS 1회는 1.1 ms로 싸다.

3. **적용할 변경 1종류 (수식 변경 없음):** 누적량 상태(E, 그 외 적분기 안의 모든 "합계" 변수)를 **상태 벡터에서 제거**한다. 누적 에너지는 출력 시각마다 RHS 진단값을 사다리꼴 적분해 후처리로 만든다. 그 뒤 `jac_sparsity`를 실제 의존 관계대로 다시 만든다(실·셀은 자기 자신과 개구부로 연결된 이웃·벽 노드만 True). 열 묶음 수가 수십 개로 내려와야 한다.
   - 합격: 상태 배열이 기존 결과와 반올림 수준으로 같고(최대 상대 차이 ≤ 1e-6), 연소 실 집합·이벤트 시각 동일. 야코비안 1회당 RHS 횟수와 적분 시간을 전후로 보고.
   - 예상 **[추정]**: 야코비안 비용 1/10 이하 → 3F 적분 15~30 s.
4. 3이 끝난 뒤에만, 남는 비용에 따라 다음 1종류: 야코비안 재사용 간격, 이벤트 재시작 시 야코비안 재사용, numba. 각각 3F 1회·동일성·시간 보고.

### 3.1 문 분출 연소 (L1e 결과 반영, 구현 지시)

**[사실]** L1e: 상층 연소 ξ_u는 모든 표본·검증 사례에서 0이었다. 상층은 뜨거우면 산소가 없고(LOL 게이트 0), 산소가 있으면 연료가 없기 때문이다. CFAST는 같은 상황을 **문 분출(door jet)**로 처리한다: 미연 연료가 문을 통해 받는 실로 나가면서 **받는 실의 하층 공기**를 끌어들여 탄다(`fire.f90` door jet, 점화 조건 T_source,upper > 외기 + 200 K).

구현(상층 ξ_u는 유지, 아래를 추가):
```
문 j (실 a 상층 → 실 b): ṁ_f,j = 문 상층 유량 × Y_f,u(a)
ξ_dj = min( ṁ_f,j,  m_O2(b) / (s·τ_O2) ) · gate(T_u(a) > T_amb + 200 K)     # 3.0절 간략 산소 사용
발열 Hc·ξ_dj → b 상층,  O₂ 소비 s·ξ_dj ← m_O2(b),  연료 ξ_dj ← 문 통과 연료
```
- 같은 연료를 ξ_u와 ξ_dj에서 두 번 쓰지 않는다(문 통과 전 상층 재고, 통과 후 분출 순).
- **검증 참조 [사실]:** CFAST r5 B3 결과의 `DJET_2` 최고 1,907 kW, `DJET_3` 443 kW(`room_rule_r5_20261025` 저장값). B3 단독·전이 실행에서 간략 ξ_dj·Hc 최고값을 이 값과 나란히 보고한다. 합격 조건은 두지 않고 차이를 보고한다.
- 3F 표준 L3 관문과 MC 20표본을 다시 돌려 백드래프트·FGI·롤오버 집계 변화를 보고한다.
- 알려진 편차 **[사실]**: 단독 화원 후반 상층 온도 CFAST 대비 −14~−20 %. 전이는 CFAST 표준보다 공격적, CFAST 공격 프리셋보다 늦음. **탐색용이며 최종 확인은 정밀.**
- 채택 관문: 3F 표준에서 `CFAST 표준 ⊆ 간략 ⊆ CFAST 공격`, 착화 순서 동일. **상한 집합은 CFAST 공격에서 '전이 조건 통과' 이벤트가 있는 실 전체**(실제 HRR 0인 경계 실 포함, 예: R17). 산소 부족으로 CFAST에서 타지 않은 실을 간략이 태우는 것은 집합 위반이 아니라 경계 차이로 기록.
- 보존 검사: 10 s 출력 재구성 **에너지 잔차 ≤ 0.1 %** 합격. 질량 잔차는 보고만.

## 4. 조건표 (두 모드 공통, conditions.py)

### 4.1 요인 지수
현상마다 온도 `r_T`·연료 `r_F`·산소 `r_O` = 현재값/기준값(낮아야 충족되는 요인은 뒤집음). 충족 = 셋 다 ≥ 1. **정도(점수) = min**, 병목 = 최솟값 요인, 우세 = 최댓값 요인. 입력 없는 요인은 `unknown`, 하나라도 unknown이면 총점 unknown. 산소 기준은 기존 값을 유지한다(FO·상층 반응 12 vol%, FGI·백드래프트 10 vol%). 통일하지 않는다.
MC 집계의 점수 요약은 **최대값**과 **충족(≥1) 시간 비율**로 낸다. 전 시점 중앙값은 쓰지 않는다(미충족 시점이 지배해 0이 됨).

| 현상 | 온도 | 연료 | 산소 |
|---|---|---|---|
| FO | `T_u/T_fo`(600) | `Q_actual/Q_fo`, Q_fo = 7.8·A_T + 378·A_o√H_o (Thomas) | `X_O2,lower/0.12` (gas LOC) |
| 롤오버 | 기존 식 | 기존 식 | 기존 식 (+ ξ_u > 0이면 "진행 중") |
| FGI | `T_u/hot_C`(300) | `Y_f,u/LFL(T_u)` | `X_O2,u/0.10` (기존 FGI 기준 10 vol%) |
| 백드래프트 | `T_u/hot_C` | `Y_f,u/0.10` | `0.10/X_O2,u` (기존 10 vol%) |
| 피난한계 | 연기층 ≤ 1.8 m & ≥ 60 ℃ | — | — |

### 4.2 2단계 표시
- **1단계 연기 위험(공통 3요인):** 뜨거움(T_u ≥ hot_C), 연료(Y_f ≥ LFL), 축적(층 두께 ≥ 0.3 m 또는 경계 ≤ 1.8 m). 1~2개 = 주의, 3개 = 위험 → 2단계.
- **2단계 산소 분기:** O₂ ≥ LOC & (T ≥ T_ai 또는 ξ_u > 0) → 롤오버 진행 / O₂ ≥ LOC → FGI 가능 / O₂ < LOC → 백드래프트 잠재. FO는 별도 독립 판정.
- 출력 필드: `smoke_stage`(0/1/2), `smoke_factors_met`, `phenomenon`, 현상별 지수·점수·병목·우세.

### 4.3 3D 색 (실·셀별, 시각별 1색, 우선순위)

| 우선 | 상태 | 색 |
|---|---|---|
| 1 | FO 충족 | 빨강 |
| 2 | FGI 가능 | 보라 (롤오버 진행 시 주황 띠) |
| 3 | 백드래프트 잠재 | 노랑 |
| 4 | 연기 활성(1단계 1~2개) | 회색(기본 연기색) |
| 5 | 없음 | 투명 |

경계(기준 ±30 ℃) 실은 점선 테두리. 숫자는 클릭 시만. 범례에 "조건 충족 단계이며 발생 예측 아님" 고정.
"연소 중"은 실제 HRR > 0인 실만. 트리거만 있고 HRR 0인 실은 "조건 충족, 산소 부족 미연소"로 구분.

**열린 방화문 처리:** MC에서 방화문이 열림으로 추출된 표본에서는 **전이 그래프에서도 열린 문 간선**으로 둔다(고임목 시나리오). 간략 엔진에 적용. 정밀 r8은 동결 상태이므로 같은 변경은 사용자 승인 후.

## 6. 몬테카를로

- 고정: 화점실, 연료 프리셋, 전이 설정, 시간. seed 기록. 종류별 독립 열림 확률 **[가정]**: 방화문 확정 0.2 / 추정 0.35 / 일반문 0.5 / 개폐창 0.3 / 고정창 0. `fixed_count` 옵션.
- 필수 표본 2: 모든 방화문 열림, 모든 개구부 닫힘(누설만).
- 창 열림 유효면적 0.5. 통로는 항상 열림. 재실자 개폐는 확률로 대체(한계 문구).
- 출력: 연기 위험 도달 실 수(먼저), 현상별 충족 표본 비율·정도 중앙값/최대·최악 표본과 개구부 조합, 경계 실 수, 닫힌 표본의 "개방 시 위험 구간"(조건 교집합 구간, 개방 결과 계산 아님).
- 실패 표본은 제외하지 않고 보고(편향 방지). 관문: 20표본 중 실패 ≤ 1(예산 1,200 s 기준).
- 화점실 비교 모드: 같은 seed·표본을 각 화점실에 적용.

## 7. 결과 필수 기록

`engine_kind`, 엔진 SHA256, 규칙 revision, 설정값·출처, manifest 해시, seed, 생략 기능 목록, `trigger_basis`, `door_class` 근거, 실·셀별 시계열(상층 온도·산소·미연 연료·실제 HRR·ξ_u), 전이 이벤트, 조건표 전 항목, 보존 잔차, 실행 시간 분해, 한계 문구.

**한계 문구(고정):** "계산은 순정 CFAST 7.7.7(정밀) 또는 CFAST 구역 모델 개념을 참고한 프로젝트 간략 엔진(탐색)이다. 전이는 프로젝트 규칙(상층 온도 기준 + 경로 지연)에 따른 가정이며 FO 발생 예측이 아니다. 조건 충족 비율은 설정한 입력 분포 안의 비율이며 실제 발생 확률이 아니다."
