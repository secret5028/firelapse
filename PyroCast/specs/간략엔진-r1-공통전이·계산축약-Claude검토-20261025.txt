0. 사용자 목적과 권고

목적은 화재의 정확한 발생 시각이나 확률 예측이 아니라, 같은 건물·설정에서 위험 조건이 얼마나 충족되고 어디로 전파되는지 빠르게 비교하는 것이다. 간편식 몬테카를로로 화점실·초기 개폐 조합을 탐색하고, 선택 사례의 시간축과 3D를 제공한다. 정밀 모드는 r8 상태로 동결한다.

권고: 별도 '상층·하층 2층 실 네트워크 엔진'을 만든다. 전이 규칙과 사용자 설정은 r8 생성 결과를 공유하고, 온도·산소·연기·센서 열응답을 계산하는 방법만 축약한다. 한 번의 시간 진행 안에서 모든 전이를 처리한다.

쉬운 설명:
  ① 도면의 실·셀·문·창과 r8 설정을 읽는다.
  ② 각 실의 위쪽 연기층과 아래쪽 공기에 대해 열·산소·연료가스·연기를 갱신한다.
  ③ 계산한 열로 기존 위치의 판 센서가 얼마나 뜨거워지는지 근사한다.
  ④ 같은 부모 센서·기준·지연을 넘으면 다음 화원의 같은 공급곡선을 시작한다.
  ⑤ 이 과정을 30분 또는 1시간까지 한 번 진행한다. 처음부터 다시 계산하지 않는다.
  ⑥ 문·창 조합을 바꾼 여러 사례를 이 엔진으로 탐색한다.

같은 규칙은 같은 수치 결과를 뜻하지 않는다. 간략 물리 계산에서 센서 온도가 달라지면 착화 여부·시각도 달라진다. 이 차이를 숨기거나 기준 온도를 조절해 맞추지 않는다.

4. 최소 상태와 계산 순서 [제안]

실/셀: 압력, 상·하층 질량·내부에너지·체적(또는 경계 높이), O2, 잔여 가연가스, 연기 soot, 필요 시 CO/CO2/H2O 수율 성분. 벽체 묶음 온도, PC/FC/창 센서 온도, 고체 연료 잔량, 화원 공급 시계, 이벤트 상태.
혼합 가스는 같은 공기와 함께 이동한다. 성분별로 다른 연기 공간을 만들지 않는다. 연료 종류가 여러 개이면 작은 성분 장부 또는 질량+화학에너지+산소요구량 장부를 사용한다. 하나의 임의 발열량으로 섞어 에너지를 바꾸지 않는다.

단계 순서(정확한 분할식은 Claude 검토 대상):
  1) 확정 이벤트와 실제 문·창 개방률로 공급량/연결을 정한다.
  2) 열팽창을 포함한 준정상 압력·개구부 유량을 구한다.
  3) 유량에 따라 질량·성분·에너지를 보존적으로 이동시킨다.
  4) 공급, 플룸 혼합, 제한된 연소, 층간 이동, 벽 열교환을 반암시적으로 갱신한다.
  5) 체적·열팽창 오차를 제한된 보정 반복으로 확인한다.
  6) 센서와 창을 갱신하고 기준 통과가 있으면 구간 안에서 사건을 확정한다.
  7) 수지·수렴·음수 여부를 검사한 확정 상태만 저장한다.

고정 지형·개구부 좌표·행렬의 희소 구조·정적 복사 계수는 시나리오 묶음에서 재사용한다. 다만 온도·밀도·열림 상태가 바뀐 행렬의 수치 인수분해를 무조건 재사용하지 않는다.

5. 압력과 시간 간격: 가장 먼저 검토할 부분

[문헌] NIST TN 1889 v1(2015, CFAST 7.0.0) §2.1은 압력의 빠른 시간 규모 때문에 식이 강성을 띠며, 단순 명시적 적분에 작은 시간 간격이 필요함을 설명한다. 따라서 DASSL을 큰 간격의 Euler로 바꾸는 것만으로 해결됐다고 볼 수 없다.

[제안] 빠른 압력 변동을 상세 시간 적분하지 않고, 각 단계의 압력·유량을 대수적으로 맞추는 저속 유동 근사를 검토한다. 모든 실을 대기압으로 고정하지 않는다. 내부 문을 외기 공급원으로 간주하지 않는다.
검토해야 할 폐쇄 조건:
  - 방 체적 V_i = Σ층 m_l R_l T_l / P_i 와 각 층 질량·에너지식의 양립.
  - 열팽창·유입/유출·연료 공급을 포함한 압력 잔차의 정의.
  - 밀폐 연결 성분의 압력 기준과 열팽창 처리. '외기 연결 없음'을 임의 누설로 해결하지 않음.
  - 상·하층 경계가 문을 지날 때의 유량 연속성, 수직 개구부 처리.
  - 보정이 실패할 때의 중단 기준.
이 식들은 아직 구현·검증하지 않았다. 정확한 압력 잔차와 반암시적 갱신식을 Claude가 먼저 검토해야 한다. 불필요한 솔버 재작성으로 범위를 키우지 않는 대안도 요청한다.

[제안 초기값] 기본 1초 단계, 사건/수지 실패 시 0.5초·0.25초 등 제한된 분할. 출력 5초. 이는 사용자가 정한 전이값이 아니라 검토용 수치 설정이며 아직 확정하지 않는다.
시간 간격을 무한히 줄이거나 수렴 실패 상태를 채택하지 않는다. 예산 초과·미수렴은 해당 구간 미완료로 반환한다. 내부 단계 수, 압력 반복 횟수/잔차, 분할 횟수와 가장 느린 항목을 기록한다.
얇은 판의 짧은 열응답 때문에 전체 단계가 다시 극소로 줄지 않도록 판은 암시적/해석적 열응답을 사용한다. 반응률은 상태 함수로 정의하고, 솔버 시도 간격으로 물리 반응 상수를 바꾸지 않는다.

6. 열·산소·연료 중복 방지 계약

입력 HRR 공급곡선은 '산소가 충분할 때의 잠재 발열 공급'으로 취급한다. 실제 발열과 구분한다. 연료의 유효 연소열 Hc를 쓰면 공급 질량은 Q_supply/Hc다. 이미 공급된 고체 연료는 고체 장부에서 빠지고, 타지 않은 부분은 가연가스 장부에 남는다.

반응량 ξ 하나로 다음을 동시에 계산한다:
  소비 연료 = ξ, 소비 O2 = s·ξ, 발열 = Hc·ξ, 생성물 = 같은 반응의 수율.
ξ는 같은 시점의 혼합 연료와 사용 가능한 산소에 의해 제한된다. 산소 mass fraction과 vol%를 변환 없이 비교하지 않는다. s, Hc, 수율의 질량·에너지 일관성을 확인한다.

기존 화원 → 플룸/상층 → 개구부 혼합 연소는 같은 잔여 재고를 순서대로 배분한다. 앞에서 쓴 산소·연료를 뒤에서 다시 쓰지 않는다. 개구부 양쪽에 같은 발열을 전부 더하지 않는다. 복사와 대류로 나눈 열의 합도 총 발열을 넘지 않는다.

순정 CFAST의 미연 연료 재연소를 통째로 삭제하면 뜨거운 가스/미연 연료 양이 달라진다. 간략 v1에서도 제한된 혼합량에 대한 산소 제한 반응은 남기는 안을 권고한다. 다만 구체적인 혼합량·반응 위치 배분은 검토 전 미확정이다. 장기 Arrhenius bulk 반응 모델이나 별도 CO 재연소 모델은 새로 넣지 않는다.
CO를 수율로 추적하는 경우 이미 유효 연소열에 포함한 에너지를 CO 재연소 명목으로 다시 더하지 않는다. CO 재연소를 실제 계산하려면 처음부터 잔여 화학에너지와 O2 요구량을 분리한 별도 장부가 필요하므로 v1 범위 밖이다.

산소 음수를 0으로 자르고 사라진 양을 숨기는 방법은 금지한다. 보존적인 유출량/반응량 제한 또는 부분 단계로 처리하고 작동량을 기록한다. 온도 상한 잘라내기, 잔여 가스 삭제, 오래 탄 방의 산소를 정상 공기로 돌리기도 금지한다.
공급 상한 k·1500·A√H는 현행 수치 공급 규칙이다. 이것만으로 산소 계산을 대체하지 않는다.

7. 판 센서·창 파괴·이벤트

PC: 현행 T4b 위치, 천장 기준 높이, 물성, 방사율, 방향, fallback을 유지한다. 상층/하층 중 실제 위치한 층과 국부 노출을 사용한다.
FC: 현행 화원 바로 위 판이다. 층 평균만 넣으면 셀 전이가 사라질 수 있다. 간략 플룸·천장 제트와 화염 복사에 대한 국부 열응답을 계산한다.
판의 '면적×열용량×온도 변화 = 대류 + 흡수 복사 − 방출/전도'를 소수 노드로 근사한다. 구체적인 앞·뒷면 경계와 물성 단위는 원본 센서와 대조한다. PC 기준을 상층 T, FC 기준을 HRR>0으로 바꾸는 것은 이번 제안이 아니다.

실제 경계 사례: 표준 r8 PC_R2_C1 최고 589.773℃, 상층 최고 600.042℃. 평균온도로 대체하면 같은 600℃ 기준에서 전이 여부가 바뀐다. 이 사례를 반드시 비교한다.

창: 기존 설정(일반 단판 6mm 대용, 기본 판 기준 450℃, 사용자 변경 가능, 초기/파괴 후 개방률)을 공유한다. 현재 openings.py는 외기 창의 바깥면 외기 경계를 명시한다. 예전 '양면 실내' 검토 문구를 최신 구현에 그대로 적용하지 않는다.
간략 모델은 유리 대용 판을 소수 열노드로 근사한다. 기준 초과 뒤 기존 1초 개방 전환, 비가역 상태를 따른다. 개방률 이력 함수 하나를 유동/조건표/3D가 공유한다. 5초 출력에서는 파괴를 관측 구간+추정으로 표시하며 정확한 파괴 시각이나 실제 유리 탈락을 예측한다고 하지 않는다.

이벤트: 미발동 → 조건 통과 → 지연 중 → 공급 시작 → 연소/소진 상태를 분리한다. 출력격자 사이 센서 통과는 보간·국부 단계 분할로 처리하고 0초부터 재실행하지 않는다. native 장치 플래그와 실제 발열 시작이 지연만큼 다름을 기록한다. 오래 탄 실도 열·산소 장부는 계속 유지한다.

8. FO·FGI·롤오버·표시의 차이

FO: 기존 설정으로 조건 충족을 계산하되 전이 규칙 이벤트와 별도 필드로 둔다. 전이됐다는 이유로 FO 발생을 확정하지 않는다.
FGI/백드래프트: 온도·O2·미연 가스의 조건 조합을 비교한다. 조건 충족은 점화원, 혼합 균일성, 폭압 또는 실제 발생 확률을 의미하지 않는다. 간략 연소 근사가 잔여 가스량에 영향을 주므로 정밀 모드와의 차이를 표시한다.
롤오버: 상층 조건 충족과 실제 계산한 상층 발열을 분리한다. 이 버전에서 계산하지 않은 반응 경로의 실제 발열은 '미평가'다.
개구부 연소: 별도 발열/위치/정도 필드. 상층 롤오버 발열과 합치지 않는다.

conditions.py는 수치 배열뿐 아니라 확장 엔진 tags와 진단값도 사용한다. 간략 결과를 넣으면 자동으로 동일 판정이 된다고 가정하지 않는다. 공통 조건 어댑터에서 각 입력의 의미와 단위를 명시하고, 없는 값은 unknown으로 전달한다. unknown을 0점 또는 안전으로 바꾸지 않는다.
현재 완성된 공통 0~100점 함수가 있는 것으로 전제하지 않는다. 우선 조건과 원값을 유지한다. 점수는 동일 입력에 대한 별도 공통 후처리 규약을 검토 후 정의하며 발생 확률로 표현하지 않는다. 핵심 조건 미평가 시 총점도 미평가다.

3D는 기존 건물과 시간축을 사용하되 결과에 '간략 계산'을 명시한다. 전체 연기 분포는 계산한 층 체적/농도 근사로 표시하고, 해당 조건이 충족될 때만 위험 테두리를 붙인다. 실제 HRR 양수인 화원과 '조건 통과/지연/산소 부족 미연소'를 구분한다. FGI 화염은 사용자 요청대로 표시하지 않는다. 천장 제트 입자는 상관식의 표시 효과이며 실제 유동장으로 부르지 않는다.

9. 몬테카를로와 사용자 설정

두 모드: (A) 적격한 각 최초 화점실 비교, (B) 사용자가 지정한 화점실에서 조건 탐색. 같은 엔진을 사용한다. CFAST를 MC 표본마다 실행하지 않는다.
공유하는 것: 연료 종류/양, 균등 분포 가정, 사용자 고정 문·창, 개폐 정책, 파괴 정책, 전이 설정, 30분/1시간, 재료/외기 설정. 기본값/추출/추론/사용자 입력 출처를 보존한다.

중요한 기존 표현 차이:
  - 사용자 초기 요청 '70% 개방'은 10개 중 7개를 추첨하는 고정 개수 방식이다.
  - r8 미래 계획의 '종류별 열림 확률'은 각 문을 독립 추첨하면 실제 개수가 바뀐다.
[제안] 기본은 기존 사용자 의미의 fixed_count를 유지한다. independent_probability는 별도 옵션으로만 둔다. 두 방식을 같은 % UI로 몰래 바꾸지 않는다. 반올림, 고정 상태 포함 여부, 종류별 모집단을 기록한다. 고정 상태 때문에 목표 개수 불가능하면 오류를 낸다.
열린 창의 50% 유효 면적은 한 번만 적용한다. 파괴하면 공유한 파괴 후 비율로 늘어난다. 초기 문 상태는 진행 중 임의 변경하지 않는다. 문 종류 미확인/방화문 정책을 따로 기록한다.
같은 난수 seed/표본 조합을 여러 최초 화점실에 적용해 비교한다. 온도·습도·기압 분포는 검증 없이 새로 무작위화하지 않는다.

위험 순위는 전파 규모, 현상 조건의 영향 면적·지속, 고립을 분리한다. 선택한 가중/우선순위를 기록한다. 고립은 별도 통행 그래프와 일반 재실자/소방대원 기준이 있어야 평가하며, 현재 미구현·미평가 항목을 0으로 채워 순위를 만들지 않는다. 점수와 겹쳐보기는 후처리/UI 단계다.
최악은 '설정한 표본에서 가장 위험한 사례'다. 전역 최악 또는 실제 발생 확률을 찾았다고 하지 않는다. 서로 다른 사례의 실별 최댓값을 모아 한 실제 시나리오처럼 재생하지 않는다.

'개방 시 위험 구간'은 v1에서 현재 상태의 산소 부족·잔여 가스 등 조건 구간 표시까지다. 특정 시점에 문을 여는 개입 결과는 계산하지 않았다. 처음부터 열린 경우/닫힌 경우의 짝지은 MC 비교도 중간 개방 실험과 다르다. 실제 중간 개방 개입 계산은 동결 r8 지원 범위를 넘으므로 후속 기능으로 둔다.

10. 성능 기대와 구현 범위

가속 후보: 압력의 빠른 과도상태 축약, 비싼 결합 반복 축소, 벽 열전도 노드 축소, 필요한 센서만 계산, 형상/희소 구조 사전 계산, 컴파일된 배열 계산, 독립 표본의 제한된 병렬 실행.
1초 단계라면 1시간에 기본 3600회 갱신이다. 하지만 각 단계의 압력 반복·사건 분할이 추가된다. 표준 native 9097단계와 숫자만 나눠 속도 배수로 발표하지 않는다. 초기 컴파일/전처리/계산/후처리/출력을 따로 측정한다.
10~20개 소규모 표본으로 표본당 시간과 실패율을 먼저 측정한 뒤 MC 개수를 정한다. 총예산은 '화점 수×표본 수×측정 시간÷실효 병렬 수 + 전처리/입출력'으로 산정한다. 10배·30초·대형 창고 실시간을 보장하지 않는다.
층 전체를 하나로 합치거나 기존 연소실의 O2를 생략하는 방법은 채택하지 않는다. 새 규칙, 다중 부모, 센서 재배치, 정밀 엔진 재개발도 하지 않는다.

11. 최소 검증과 중단 기준 [제안, 구현 전에 검토]

1) 계약 검사: 같은 준비된 모델/센서 시계열을 두 규칙 처리기에 공급한다. 부모·설정·공급곡선·연료 예산이 같아야 하며 사건 차이는 정한 보간/단계 해상도로 설명되어야 한다. 물리 오차와 규칙 구현 오류를 분리한다.
2) 보존 미니 사례: 두 실 이동, 외기 유출입, 닫힌 연결, 산소 부족 공급, 창 전환. 모든 내부 교환은 같은 질량/에너지를 양쪽에 반대 부호로 기록한다. 열·산소·연료 중복, 음수 재고, 체적 폐쇄 실패가 있으면 중단한다.
3) 기존 B1/B2/B3와 r8 표준 결과를 읽어 비교한다. 공격은 2850초 공통 구간만 비교한다. 표준에서 판589.773℃/가스600.042℃ 사례를 반드시 포함한다.
4) 간략 단계 1초/0.5초 비교: 누적 실제 발열·미연 연료, 온도·O2, 창 개방, PC/FC, 전이 누락/추가와 시각을 보고한다. 제안 초기 문턱은 누적 발열 차이 5% 이내. 경계 통과 여부가 뒤집히면 평균 오차가 작아도 '경계 민감'으로 표시하고 해당 사례의 순위 확정을 보류한다. 허용치는 검토 후 고정하며 결과에 맞춰 바꾸지 않는다.
5) 수지 잔차 제안: 전체 유입/유출·공급·벽/외기 손실까지 포함한 누적 질량·에너지 상대 잔차 각각 0.1% 이하(근접 0의 분모와 절대 허용치는 단위별 별도 정의). 이는 물리 정확도 0.1% 보장이 아니라 장부 검사다.
6) 타당성: 정밀 참조 대비 전이 실 수/순서/시각, 센서 최고값·600/300 기준 충족, 위험 순위를 표로 보고한다. T0나 CFAST도 실제 화재 정답은 아니다. B1 음성 대조에서 원인 없는 추가 착화가 나면 출시 보류. B2/B3 미전이는 원인·모델 한계 검토 후 판단하고 기준을 내려 통과시키지 않는다.
7) MC 순위 품질은 한 3F 사례로 입증할 수 없다. 우선 기존 참조 세트로 확인하고, 필요 시 별도 제한 예산의 독립 사례로 상위 후보 누락률을 검토한다. 정밀 모드 수정이나 무한 추가 시험으로 확대하지 않는다.

성능 측정은 위 검사와 별도로 보고한다. 빨라졌어도 보존·규칙 계약에 실패하면 채택하지 않는다. 위험 순위 검증 전에는 '검증된 위험도 순위'가 아닌 탐색용으로 표시한다.

12. 예정 코드 구조와 산출물 (아직 만들지 않음)

새 simulation/pyrocast_lite/:
  contract.py       r8 prepare 결과/설정/manifest를 읽는 어댑터. native 실행 호출 없음
  network.py        압력·개구부·층간 유동 및 보존적 이동
  balance.py        공급·연료·O2·에너지/생성물 장부
  thermal.py        벽/층/센서의 축약 열응답
  events.py         동일 PC/FC 기준, 지연, 창 전환, 공급 시간축
  runner.py         제한된 단계·수렴·시간 예산과 진단
  result_adapter.py 조건표/3D용 공통 의미·단위·unknown 처리
  sampling.py       fixed_count/확률 옵션, seed, 후보 순위

기존 파일은 가져다 읽거나 호출하되 수정하지 않는다. frozen prepare 의존성을 그대로 호출하기 곤란하면 버전·해시를 고정한 manifest 교환으로 분리한다. 규칙을 복사해 두 군데서 발전시키지 않는다. 원본 CFAST 파일은 실행 참조이며 새 엔진 파일과 분리한다.

결과 필수: engine_kind='pyrocast_lite_experimental', rule revision/settings/hash, scenario/seed, 모델 근사 목록, 완료 시간, 원래 실/셀 매핑, 실제 HRR/공급 HRR/전이 이벤트, PC/FC 값, O2/가스/연기, 수지 잔차, 실패/분할 횟수, 미평가 항목. 기본/사용자 설정 출처와 fallback 품질을 보존한다.

13. Claude에게 요청할 결정

가. 이 범위에서 2층+준정상 압력/반암시적 갱신이 가장 작은 구현인가? 압력 잔차와 체적·질량·에너지 폐쇄식을 구체화해 달라. 실패 시 더 작은 대안은 무엇인가?
나. 산소 부족에서 단계를 무너뜨리지 않으면서 미연 연료를 보존하는 플룸/개구부 혼합 반응의 최소식을 제안해 달라. 계산 순서 편향과 에너지 배분도 검토해 달라.
다. 동일 PC/FC 의미를 유지할 최소 국부 노출·판 응답은 무엇인가? 층 평균 대체, 임의 HRR 트리거, 기준 온도 재조정은 제외한다.
라. 반드시 남길 것과 미뤄도 될 것을 한 가지 권고 구조로 정리해 달라. 새 정밀화로 범위를 키우지 말아 달라.
마. 고정 개수/종류별 확률의 입력 차이와 '개방 시 위험 구간'의 주장 범위가 적절한가?
바. 검증 문턱과 성능 측정 계획을 검토하고, 구현 가능한 최소 단계와 중단 기준을 확정해 달라. 미구현 점수·고립 기능을 있는 것처럼 취급하지 말아 달라.

이번 웹 확인에서 7.7.7 배포 PDF 본문은 열리지 않았다. 7.7.7 세부 동작은 저장소의 해당 버전 Fortran 및 Python 구현을 대조했다. 2015 문서를 7.7.7 문서라고 부르지 않는다.

NIST 문헌은 기존 CFAST 모델의 근거다. 새 간략 엔진 전체의 승인·검증을 뜻하지 않는다. 표기는 'CFAST의 구역 모델 개념을 참고한 프로젝트 간략 엔진'으로 한다. 전이 지연·판 기준·공급 상한·셀 전파와 축약 수치해법은 프로젝트 가정/근사이며 별도 검증 대상이다.
