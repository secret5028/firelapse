**지시**
1. **입력 일치 2건 (튜닝 아님, 참조와 같은 값으로 맞추는 것)**

### 1.3.2 복사 되먹임 추가 (항 2개, 튜닝 없음)
후반 온도 과소의 원인 후보가 복사 교환 누락이므로 다음 두 항을 넣는다. 계수는 CFAST 소스의 값·식을 그대로 가져오고, 결과에 맞춰 조정하지 않는다.

1. **상층 가스의 복사 흡수:** 상층 흡수율 `ε_g = 1 − exp(−κ·L_m)`. `L_m = 3.6·V_u/A_u`(평균 빔 길이, 상층 체적/표면적). κ는 CFAST가 soot 농도 없이 쓰는 기본 흡수계수를 소스(`radiation.f90`/`absorb` 경로)에서 확인해 사용한다 **[미검증: 값과 위치를 보고]**. 화원 복사 `χ_r·Q` 중 `ε_g` 몫은 상층 에너지로, 나머지는 벽으로 간다.
2. **벽↔상층 복사 교환:** 상층과 접한 벽·천장 표면과 상층 가스 사이 `q = ε_g·ε_w·σ·(T_w⁴ − T_u⁴)·A_contact`. 상층이 벽보다 뜨거우면 벽으로, 벽이 더 뜨거우면 상층으로 간다. 에너지는 양쪽 장부에 반대 부호로 기록한다.

- 하층은 광학적으로 얇다고 보고 복사 흡수를 넣지 않는다.
- 형상계수·소실 세분화는 하지 않는다.
- 검증: 단독 화원 B2·B3를 다시 돌려 그래프를 갱신한다. 합격 조건은 두지 않고 **차이 %의 변화만 보고**한다. 후반 차이가 줄지 않거나 초기 과대가 커지면 그 사실을 보고하고 항을 되돌린다(옵션 플래그로 ON/OFF).

### 1.5.1 수치 실패 30 % — 원인 격리 후 솔버 대체
- 실패가 특정 개폐 조합에 몰리면 표본이 편향된다(가장 위험한 조합이 빠질 수 있음). 실패를 "제외"로 두면 안 된다.
- 격리: 실패 5건의 마지막 상태를 저장해 보고한다. 확인 항목: 어느 실에서 `V_u`가 상·하한 clip에 붙었는지, 층 질량이 0 근처인지, `Y_O2`·`Y_f`가 0/음수 clip에 걸렸는지, 그 실의 개구부 상태.
- 유력 원인 **[추론]**: 상태가 clip 경계에 붙어 야코비안 열이 0이 되는 것(연기층이 바닥까지 차거나, 밀폐 실). 해결은 튜닝이 아니라 수치 처리다.
  - clip을 매끄러운 하한(softplus, 폭 = 해당 상태 atol의 10배)으로 바꾼다. 물리 상수는 바꾸지 않는다.
  - 그래도 singular가 나면 그 표본만 `method='Radau'`로 1회 재시도한다. 이것은 결과 맞춤 재시도가 아니라 솔버 대체이며, 결과에 `solver_fallback=True`를 기록한다.
- 합격: 20표본 재실행에서 실패 ≤ 1건.

### 1.5.2 상층 미연 연료 연소 추가 — 백드래프트 과다 판정의 원인
- 간략 엔진은 R2에서 못 탄 연료를 상층으로 내보낸 뒤 **다른 실 상층에서 태우지 않는다.** CFAST는 상층·문 분출에서 태운다(순정 `fire.f90` 395-415, door jet). 그래서 간략에서는 미연 연료가 모든 실에 쌓여 백드래프트 조건(Y_f ≥ 0.10 & O₂ < 12 %)이 13/13 표본, 최대 16실에서 켜진다. 과다 판정이다.
- 추가할 식(검토서 3절 나, 항 1개):
```
ξ_u = min( m_f,u / τ,  m_O2,u / (s·τ) ) · g(T_u)
τ = 20 s [가정],  g = CFAST와 같은 LOL tanh 램프,  T_u > 가스 착화 하한(기존 설정 gas_ignition_C 공유)
발열 Hc·ξ_u → 상층 에너지,  O₂ 소비 s·ξ_u,  연료 소비 ξ_u
```
- 이는 정밀 모드 r8에서 **켜져 있는 순정 상층 연소**에 대응하는 항이다. 프로젝트 bulk(Arrhenius)가 아니다.
- 검증: B3 단독 비교와 3F 표준 1회를 다시 돌려 (a) 연소 실 집합이 L3 관문 안에 남는지, (b) 백드래프트 조건 실 수가 어떻게 바뀌는지 보고.
- 이 항이 들어가기 전까지 **백드래프트·FGI 집계는 "미평가"로 표시**한다. FO·피난한계 집계는 그대로 유효하다.

### 1.5.3 L4 출력 진단 — 에너지만 합격 조건
- 질량 잔차(0.5~2.5 %)는 10 s 출력으로 큰 유출입 유량을 적분한 오차가 지배한다. 온도·조건을 좌우하는 것은 에너지 잔차이고 이는 모두 ≤ 0.01 %다.
- 합격 조건을 **에너지 ≤ 0.1 %**로 둔다. 질량 잔차는 보고만 한다(기준 없음). 수락 스텝 장부는 만들지 않는다.
- 이 기준으로 L1d 완료 14건은 모두 통과한다. 집계를 다시 낸다.

### 1.5.4 입력 결함 (사용자 확인 필요)
- CAD 입력에 **방화문 태그가 0개**다. 방화문 열림 확률(0.2)과 필수 표본 S00이 무의미했다. 실제 3F 도면에 방화문이 있다면 개구부 분류를 입력에 넣어야 한다. 사용자가 방화문 위치를 지정하는 UI 또는 목록 파일로 받는다.
- 통로(AUDIT_PASS) 3개는 항상 열림으로 두는 것이 맞다.

### 1.5.5 롤오버 판정 + 조건 점수화 (정밀 모드 conditions.py 공유)

간략 결과를 **정밀 모드와 같은 `conditions.py`**로 통과시킨다. 간략 엔진 코어의 bool 플래그(flash/backdraft/fgi)는 참고용으로만 남기고, 표시·집계는 공통 조건표가 맡는다. 판정식을 두 군데서 따로 발전시키지 않는다.

**조건표가 현상마다 내는 값(기존 정의 유지, 없으면 아래로 정의):**

| 값 | 정의 |
|---|---|
| 요인 지수 3개 | 온도 `r_T`, 가연물 `r_F`, 산소 `r_O`. 각각 "현재값 / 그 현상의 기준값"으로 1.0이 경계. 산소처럼 **낮아야** 충족되는 요인은 `기준값 / 현재값`으로 뒤집어 같은 방향으로 맞춘다 |
| 충족 | 세 지수 모두 ≥ 1.0 (AND) |
| **정도(점수)** | `min(r_T, r_F, r_O)`. 충족 시 1.0 이상이며 클수록 여유가 큼. 미충족 시 1.0 미만이며 "얼마나 모자란가" |
| **병목(열세) 요인** | 지수가 가장 작은 요인 |
| **우세 요인** | 지수가 가장 큰 요인 |
| 미평가 | 필요한 입력이 없는 요인은 `unknown`. 0이나 안전으로 바꾸지 않음. 하나라도 unknown이면 총점도 unknown |

**누락 기준 보완(2026-10-25 20:00).** 조건표에 FO의 산소·연료 기준과 FGI의 온도 기준이 없다. 아래로 정의해 조건표에 추가한다. 모두 기존 설정값이나 표준 식을 재사용하며, 결과에 `[가정]`으로 표시한다.

| 현상 | 요인 | 지수 정의 | 근거 |
|---|---|---|---|
| FO | 온도 | `T_u / T_fo` (기본 600 ℃, 사용자 설정) | 기존 |
| FO | 연료 | `Q_actual / Q_fo`, `Q_fo = 7.8·A_T + 378·A_o·√H_o` kW (A_T: 개구부 제외 내부 표면적, A_o√H_o: 개구부 합) | Thomas 1981 FO 필요 발열량. "지금 타는 양이 FO를 지탱할 만큼인가" |
| FO | 산소 | `X_O2,lower / LOC` (LOC 0.12 vol, 기존 설정) | 플룸은 하층 공기를 쓰므로 하층 산소가 연소 지속 조건 |
| FGI | 연료 | `Y_f,u / LFL(T_u)` | 기존 |
| FGI | 산소 | `X_O2,u / LOC` | 기존 |
| FGI | 온도 | `T_u / hot_C` (hot_C 300 ℃, 기존 `gas.hot_C` 설정) | "개방 시 위험 구간" 규칙과 같은 값. 점화원에 가까운 고온 연기 조건 |
| 백드래프트 | 온도·연료·산소 | 기존 식(T ≥ hot_C, Y_f ≥ 0.10, X_O2 < LOC → 산소는 `LOC / X_O2`) | 기존 |
| 롤오버 | 온도·연료·산소 | 기존 식 | 기존 |

- `Q_actual`은 그 실의 실제 화원 발열 + 상층 연소(ξ_u·Hc). 1.5.2 전에는 화원 발열만.
- 이 정의를 정밀 모드 conditions.py에도 같은 코드로 넣는다(두 모드 공통).

- 롤오버: 조건표의 기존 롤오버 식을 그대로 쓴다(상층 온도·상층 연료·상층 산소). 1.5.2의 상층 연소 ξ_u를 함께 기록해 "조건 충족"과 "실제 상층 연소 중(ξ_u > 0)"을 구분 표시한다.
- 백드래프트·FGI: 1.5.2 전까지는 `unknown`(연료 지수 신뢰 불가). 1.5.2 이후 평가.
- FO·피난한계: 지금부터 평가.
- 표시 예: `FO 충족 · 정도 1.4 · 열세 산소(1.1) · 우세 온도(2.1)`, `백드래프트 미충족 · 정도 0.6 · 열세 온도(0.6)`.
- 정도·지수는 **발생 확률이 아니다**라는 문구를 유지한다. MC 집계는 "충족 표본 수"와 함께 "정도의 중앙값·최대"를 낸다.
- 조건표 입력 어댑터(`result_adapter.py`)에서 단위·의미(상층 평균 vs 국부, mass vs vol fraction)를 명시한다.

### 1.5.5a 2단계 표시: 연기 위험(공통) → 현상 구분 (사용자 제안, 2026-10-25 20:15)

네 현상(FO·롤오버·FGI·백드래프트)은 모두 "뜨겁고 연료가 많은 연기"가 전제다. 현상을 나누기 전에 공통 전제를 먼저 보여준다.

**1단계 — 연기 위험 (실별, 공통 3요인)**

| 요인 | 조건 | 기준 |
|---|---|---|
| 온도 | 상층 온도 ≥ hot_C | 300 ℃ (기존 설정) |
| 연료 | 상층 미연 연료 ≥ 가연 하한 | `Y_f,u ≥ LFL(T_u)` (기존 식) |
| 축적 | 연기층이 충분히 두껍고 내려옴 | 층 두께 ≥ d_min(0.3 m) 또는 경계 높이 ≤ 1.8 m (기존 설정) |

- 0개: 표시 없음. 1~2개: **주의**(노랑, 충족 요인 표시). 3개: **위험**(빨강) → 2단계로 분기.
- 지수는 1.5.5와 같은 방식(현재값/기준값, 병목 = 최솟값).

**2단계 — 산소로 분기 (1단계 3개 충족 시에만)**

| 상층 산소 | 추가 조건 | 표시 |
|---|---|---|
| ≥ LOC(12 %) | 상층 온도 ≥ 자연발화(T_ai) 또는 상층 연소 ξ_u > 0 | **롤오버 진행** |
| ≥ LOC | 위 미충족(점화원 필요) | **FGI 가능**(점화 시) |
| < LOC | — | **백드래프트 잠재**(개방 시 위험 구간 표시) |
| (별도) | 상층 ≥ T_fo & 하층 O₂ ≥ LOC & Q_actual ≥ Q_fo | **FO** (1단계와 병행 표시; FO는 연기 연소라기보다 복사 되먹임이므로 독립 판정 유지) |

- 피난한계(연기층 ≤ 1.8 m & 60 ℃)는 연기 위험과 별도의 생존 조건으로 계속 표시한다.
- 조건표 출력에 `smoke_stage`(0/1/2), `smoke_factors_met`(목록), `phenomenon`(2단계 결과)을 추가한다. 기존 현상별 지수·점수는 그대로 유지한다(2단계 세부).
- 3D: 1단계 주의=노란 테두리, 위험=빨간 테두리, 2단계 현상명은 테두리 라벨. MC 집계도 "연기 위험 도달 실 수"를 현상별 집계보다 앞에 둔다.

### 1.5.6 방화문 자동 분류 (사용자 요구: 수동 지정 없이 자동)

도면에 방화문 태그가 없는 것이 보통이다. 다음 규칙으로 **자동 분류**하고, 결과에 근거를 남긴다. 사용자는 결과 목록에서 틀린 것만 바꾼다.

| 우선 | 규칙 | 분류 | 근거 |
|---|---|---|---|
| 1 | CAD에 방화문 기호·레이어·블록명(`FD`, `방화문`, `갑종`, `60+`, `60분`, `FIRE DOOR`, `SD-F`) | 방화문 | 도면 명시 |
| 2 | 문이 연결하는 실 중 하나가 **계단실·특별피난계단·피난계단·부속실·승강장·비상용승강기** (실 이름 또는 `core_kind` in `stair`, `elevator_lobby`) | 방화문 | 건축법상 수직 구획 |
| 3 | 연결 실 중 하나가 **전기실·기계실·발전기실·보일러실·창고·EPS·TPS·PS·AD·DS** | 방화문 | 설비·샤프트 구획 |
| 4 | 문이 **복도–복도** 또는 **복도–로비** 사이에 있고, 양쪽 바닥면적 합이 방화구획 기준(1,000 m²; 스프링클러 있으면 3,000 m²)을 넘는 쪽에 걸침 | 방화문(구획선 추정) | 면적 구획 |
| 5 | 외기로 나가는 문 | 해당 없음(외기 개구부) | — |
| 6 | 그 외 | 일반문 | — |

- 실 이름 매칭은 기존 `fire_load_table.json`의 `names` 정규식 방식을 재사용한다. 키워드 목록은 설정 파일로 둔다.
- 결과에 `door_class`, `door_class_basis`(규칙 번호), `door_class_confidence`(규칙 1·2 = 확정, 3·4 = 추정)를 기록한다.
- 추정(3·4)인 방화문은 MC에서 열림 확률을 **방화문과 일반문의 중간값(0.35)**으로 둔다 **[가정]**. 확정은 0.2.
- 3D 화면과 결과 목록에 분류 근거를 표시해, 사용자가 클릭 한 번으로 바꿀 수 있게 한다(수정은 저장되어 재실행 시 우선).
- 3F 입력에 적용한 결과(문 ID, 연결 실, 분류, 근거)를 표로 보고한다. 분류 전·후 MC 집계는 별도로 낸다.

### 1.5.7 순서
1. 1.5.3 집계 재산출 + 1.5.5 조건표 연결(FO·피난한계만, 실행 없음) + 1.5.6 방화문 자동 분류 보고 → 2. 1.5.1 격리·수정 → 3. 1.5.2 상층 연소 추가·검증 → 4. 1.5.5 롤오버·백드래프트·FGI 평가 켬 → 5. 20표본 재실행(같은 seed) → 6. 결과 보고. 그 뒤 표본 수 확대는 사용자 결정.

## 3. 전이 규칙 (r8과 같은 설정값, 판정량만 다름)

| 항목 | 정밀(r8) | 간략 |
|---|---|---|
| 실간 착화 조건 | 부모 실 T4b 판 > T_set | **부모 실 상층 온도 > T_set** (기본 600 ℃, 450~700) |
| 실간 지연 | 열린 문 60 s / 닫힌 일반문 600 s / 방화문 없음 | 같음 |
| 셀 간 착화 조건 | 부모 셀 화원 위 판 > 300 ℃ | **부모 셀 실제 HRR > 0** |
| 셀 간 지연 | 셀 중심 거리 / 0.05 m/s | 같음 |
| 착화 후 공급 | `item_peak` 곡선, 상승 60 s, 외기 상한 k | 같은 곡선을 그대로 사용 |
| 부모 선택 | 정적 Dijkstra 단일 부모 | 같음(r8 manifest의 `parents` 그대로) |
| 통과 공간 | 센서만, 화원 없음 | 상층 온도만 참조, 화원 없음 |

- 구현: `solve_ivp(..., events=[...])`. 각 대기 화원마다 이벤트 함수 `T_u(parent) − T_set`(`direction=+1`, `terminal=True`). 이벤트 발생 시 그 화원의 공급 시작 시각 = t + 지연으로 확정하고, **그 시각부터** 적분을 이어 간다. 0초 재실행 없음.
- 이벤트는 1회 확정, 비가역.
- 결과에 `trigger_basis="upper_layer_temperature"`를 기록해 정밀 모드(`plate_sensor`)와 구분한다.

- 실행 시간 측정: 전처리·적분·후처리를 나눠 기록한다.

## 5. 몬테카를로 (L3 합격 후)

- **개구부 상태:** 종류별 독립 열림 확률 **[가정]** — 방화문 0.2, 일반문 0.5, 개폐창 0.3, 고정창 0. 사용자 변경 가능. `fixed_count`(N개 중 k개 추첨)는 옵션.
- **고정 입력:** 화점실, 연료 프리셋, 전이 설정, 시간(30분/1시간). seed 기록.
- **필수 포함 표본 2건:** 모든 방화문 열림, 모든 개구부 닫힘(누설만). 확률과 무관하게 항상 실행한다.
- **출력:**
  - 현상별 최악 표본(조건 충족 실 수 최대, 최초 충족 시각 최소)과 그 개구부 조합
  - 조건 충족 비율(표본 분포 내 비율이며 발생 확률이 아님을 표시)
  - 닫힌 상태 표본의 후처리: 실별 "개방 시 위험 구간"(미연 연료 ≥ 기준 & 산소 < LOC & 상층 온도 ≥ 기준인 시간 구간)
- 첫 실행은 **20표본**으로 표본당 시간·실패율을 측정한 뒤 표본 수를 정한다.
- 재실자 개폐 행동은 모델에 넣지 않는다. 한계 문구: "재실자의 개폐는 열림 확률로 대체".
