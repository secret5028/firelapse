0. 확정할 계산 구조
몬테카를로는 간편식 선별에만 적용한다. 몬테카를로 표본마다 CFAST를 실행하지 않는다.
많은 문·창 개폐 조합과 화점 후보를 간편식으로 비교한 뒤, 소수의 대표 화점실과 실제 개폐 조합만 골라 CFAST로 계산한다.
앞선 r1의 표본별 CFAST 실행·대표실 사전 고정 설명은 이 r2로 대체한다.
2026-10-20 선별계산 명세2의 CData/CFAST 표본별 실행도 이번 범위에서 채택하지 않는다.
이는 계산 구조의 정정이다. 기존 착화·노출·판 열응답·FO·가스 판정 수식과 임계값 변경을 뜻하지 않는다.
현재는 문서만 수정한다. 앱 코드 수정, 엔진 빌드, 새 간편식/Monte Carlo/CFAST 계산은 하지 않는다.

1. 처리 흐름
① 도면/OCR로 층·실·체적·용도·개구부를 추출하고, 미확인 항목은 용도/구조별 기본값과 출처로 보충한다.
② 실별 연료 종류·총량·균등 분포와 문/창 개방 개수 비율을 설정한다.
③ 문·창의 실제 이진 개폐 조합을 난수 추첨한다. 연료는 지정값으로 고정하며 임의의 새 분포로 추첨하지 않는다.
④ 각 조합에 대해 해당 층의 적격 화점실들을 간편식으로 선별한다. 이 단계에는 CFAST 호출·덱 생성·전이 반복이 없다.
⑤ 간편식 지표와 순위의 변동, 미평가, 연결 경로를 집계한다.
⑥ 대표 화점실과 그 실에 대응하는 실제 개폐 조합을 소수 선정한다. CFAST 실행 건수 예산은 MC 표본 수와 독립이다.
⑦ 선택된 입력에만 기존 CFAST+프로젝트 전이 계산을 실행한다. 각 건은 확정 입력을 쓰는 계산이다.
⑧ 간편식 표본 통계와 선택 사례의 CFAST 온도·산소·연기·착화/FO 결과를 구분하여 표시한다.
예시: 1,000개 개폐 표본 × 30개 화점 후보를 간편식으로 평가해도 CFAST는 선택 예산이 2건이면 2개 시나리오뿐이다.
숫자는 설명용이다. 2개 시나리오 각각의 기존 사건 반복 횟수는 별도로 발생한다.

2. 연료 종류·총량·균등 분포
- 실 용도·건물 용도·구조와 OCR 근거로 기본값을 정하고, 사용자가 실별로 수정할 수 있게 한다.
- 현재 room_defaults의 값은 프로젝트 대표 가정이다. NIST 표준 연료량이나 모든 건물에 검증된 값으로 부르지 않는다.
- 균등 분포는 개구부 앞을 포함한 바닥 면적에 가용 연료 예산이 분포한다는 가정이다.
- 총 에너지 E와 면적당 q=E/A, 체적당 E/V를 구분한다. 질량 입력은 유효 연소열로 변환하고 단위를 기록한다.
- 같은 실의 개구부 후보가 증가해도 연료가 복제되지 않는다. 후보와 표시 상자는 공유 예산을 참조한다.
- 분포 면적과 기존 fuel_area_m2/occupancy_fraction 기반 유효 연소면적은 다르다. 균등 분포라고 HRR 상한을 자동 증대하지 않는다.
- 균등 가용 연료가 곧 동시 착화·동시 연소를 뜻하지 않는다. 현재 FO 전 실내 상세 화염 전파와 위치 편향이 해결된 것으로 표시하지 않는다.
- 현재 FO 후 유한 연료 통합/분산 보충복사는 유지한다. 내부 플룸의 상세 면적 연소를 재현하는 기능은 아니다.
- 새로운 유증기·가스 정밀 연소, 임의 새 반응식·임계값·연료 불확실 분포는 이번 범위에서 추가하지 않는다.

3. 문·창 개방 비율과 추첨
- 실내 문 70% 개방은 적격 문 10개 중 7개가 완전 개방, 나머지는 닫힘이다. 모든 문 폭을 70%로 줄이는 뜻이 아니다.
- 열린 외기 창은 해당 창 기하 면적의 50%를 유효 개구로 계산한다. 닫힌 창은 0이다. 50%는 사용자가 정한 프로젝트 가정이다.
- 문과 창은 각각 별도 모집단에서 K개를 비복원 추첨한다. 표본 간 같은 조합의 재추첨은 허용한다.
- K=floor(p*N+0.5)는 반올림 제안이며 표준 규정이 아니다. 요청 비율과 실현 K/N을 함께 저장한다.
- 잠금 지정/상시 개방 통로/승강장문/분류 미확인 개구부는 구별한다. 조절 가능한 분모 N과 고정 상태 수를 표시한다.
- 항목 ID, N/K, 열린 목록, 닫힌 목록, seed/RNG 방식, 유효 면적을 저장한다. 추첨 결과가 실제 입력 정본이다.
- 개수 비율은 총 면적 비율과 다르다. 창 크기가 다르면 같은 개수여도 유효 환기 면적이 달라진다.
- 창 폭에 0.5를 적용하고 schedule에도 0.5를 적용하여 25%로 줄이는 중복 처리를 막는다.
- 현재 door_fraction/window_fraction은 개별 부분 폭 개방률이다. 새 개수 비율은 별도 키로 두고 기존 의미를 보존한다.
- 닫힌 문과 실의 기존 누설은 구분한다. 폐쇄 상태를 완전 기밀로 임의 변경하지 않는다.
- 이 설정의 개폐는 한 표본 동안 고정한다. 소방 활동/시간별 개방/유리 탈락은 이번 MC의 자동 추가 변수가 아니다.

- CFAST 건수 상한은 표본 수와 별개다. 표본 증가·상위 분위수마다 자동으로 CFAST 작업을 늘리지 않는다.
- 선택 사례의 온도/산소/연기 결과를 전체 MC 표본이 CFAST로 검증된 결과로 외삽하지 않는다.

6. 층 범위와 수직 확산
- 기본은 선택층 단위이다. 도면상 층과 실의 공통 목록을 간편식 전체에서 유지한다.
- 현행 cad.adapt의 개방 도달성 기반 제거는 새 선택 사례의 native 범위와 분모를 검토할 때 수정 후보이다.
- 간편식 MC 표본마다 native 어댑터/덱을 만들지 않는다. 실/개구부 목록과 경량 특징을 재사용한다.
- 수직 경로는 계단·승강로·샤프트 연결과 외벽 창 화염/스팬드럴 경로를 구별한다.
- 간편식은 수직 경로와 우선 검토 위치를 선별한다. 연결돼 있다는 이유로 상층 착화를 확정하지 않는다.
- 필요할 때 선택 사례만 코어와 인접층을 포함해 연성 계산한다. 독립층 CSV를 이어붙이는 것은 연성 계산이 아니다.
- 현행 supplementary는 FLOOR/외기 경로를 건너뛰며 외벽 창 분출화염의 상층 재진입은 미구현이다.
- 외벽 상세 보완은 첫 구현 범위에서 보류한다. 상층에 같은 화재를 임의 복사하지 않는다.
- 100실 제한·합침/절단·미포함 범위는 출력한다. 대형 실과 긴 공간의 존 가정 한계도 남긴다.

8. 변경 위치/모듈 제안
- scenario_policy: 층/연료 설정 검증, 문·창 모집단/잠금/추첨 정본 생성.

- 서버: 간편 MC 작업과 선택 사례 native 실행을 구분한다. MC 표본 루프에서 CFAST 작업 submit 금지.

- CLI/서버의 현재 엔진 경로 차이와 중첩 단일 worker 대기는 선택 사례 실행 경로에서 점검한다.

9. 비용·캐시·결과 품질
총비용 ≈ N_MC × N_적격화점 × 간편평가비용 + Σ(선택 native 사례의 회차별 실행비용).
고정한 native 건수 예산 아래 MC 표본 수는 첫 항만 늘린다. CFAST를 1,000번 돌리는 구조가 아니다.
간편식 시간도 후보 수와 식의 복잡도에 따라 늘므로 실제 측정 전 구체적 소요 시간을 약속하지 않는다.
동일 개폐 조합은 간편 결과를 캐시하되 중복 추첨의 집계 가중치를 보존한다. 조합 열거와 MC는 구별한다.
간편 캐시 키는 도면/연료/간편식 버전·정책/실현값을 포함한다. native 키는 선택 입력·엔진 SHA·sidecar·기간을 별도로 포함한다.
간편 MC: 요청/유효/미평가/오류 표본 및 화점별 분모를 남긴다. 실패를 안전으로 채우지 않는다.
선택 native: 정상 종료/범위/회차·시간 상한/조건 재확인 경고를 개별 표기한다. 간편 표본 실패와 같은 분모로 섞지 않는다.
native 한두 건의 FO/FGI 충족 비율을 전체 MC 발생확률로 표시하지 않는다.
과거 30→60분 비용/일괄 반복 실측은 evidence에 있다. 이 새 간편 MC의 성능 실측이 아니다.

10. 구현 전 검토와 향후 최소 검증
- Claude가 기존 경량 모델 재사용 vs 더 작은 특징량/상관식 선별 중 구현량·목적 적합성을 검토한다.
- 보존해야 할 착화/노출/FO 수식과 간편 선별에서 계산 불가능한 조건을 명시한다.
- 향후 MC 실행 중 CFAST 호출 0회를 mock/call count로 확인한다.
- native 예산 고정 시 MC 표본 수 증가로 native 사례 수가 증가하지 않는지 확인한다.
- p=0/1, 작은 N 반올림, 잠금, 문/창 분모, 실제 유효 면적, seed 재현, 중복 가중치를 확인한다.
- 같은 추첨 입력/연료를 선정 단계와 CFAST 입력까지 보존하고, 창50%를 중복 적용하지 않는지 확인한다.
- 공통 실 목록/미평가 분모와 연료 총 에너지를 보존한다. 기존 확정 입력은 기존 native 결과로 회귀 비교한다.
- 선택 사례와 간편식의 순위/과소 선별을 대조하되 CFAST 역시 실제 화재의 정답은 아니다. 일반 무누락 보장을 선언하지 않는다.
- 가스 정밀 화학·폭압·모든 도면 자동 완벽 해석·임의 조건의 발생시각 맞추기를 MVP 범위로 늘리지 않는다.
