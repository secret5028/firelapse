# 연기 농도·화염 밝기 즉시 갱신 수정

## 원인과 수정

슬라이더는 스토어 값을 바꿨지만 즉시 렌더를 요청하지 않았다. 다음 애니메이션 프레임이 지연되면 숫자만 변하고 GPU uniform은 이전 값에 머물렀다. 기존 시험은 입력 뒤 render를 직접 호출해 이를 가렸다.

컨트롤러에서 realView 변경을 구독해 즉시 렌더하도록 수정했다. dispose 시 구독도 해제한다. 계산·조건표·셰이더는 변경하지 않았다. 운영 번들은 재생성했다.

## 재현 및 검증

완도 P1, 1400 s, R5 확대, clock 180000 ms. 초기 장면 이후 RAF 콜백을 중단하고 DOM input 이벤트만 보냈다. 입력 뒤 시험 코드에서 render/tick을 호출하지 않았다. 표시 탭에서는 실제 Home/End 키 입력도 검증했다.

| 항목 | 수정 전 실제 표시값 | 수정 후 실제 표시값 |
|---|---|---|
| 연기 30% | opacity 0.7 | opacity 0.21 |
| 연기 150% | opacity 0.7 | opacity 1.05 |
| 화염 50% | gain 1 | gain 0.5 |
| 화염 200% | gain 1 | gain 2 |

연기 기본 불투명도 70%에 배율을 적용한다. 1.05는 셰이더 입력 배율이며 물리적 불투명도 105%라는 뜻이 아니다. 공동 벽면 발광도 밝기 배율에 따라 0.6900 → 2.7600으로 변했다.

슬라이더·범례를 제외한 캡처 상단 450 px 영역 비교:

| 비교 | 수정 전 차이 픽셀 | 수정 후 차이 픽셀 |
|---|---:|---:|
| 연기 30% ↔ 150% | 0 | 105233 |
| 화염 50% ↔ 200% | 0 | 22152 |

기본 화면 수정 전/후 전체 픽셀 차이 0. 조작 후 100% 복귀 전체 픽셀 차이 0. 브라우저 오류 0. dispose 및 pagehide 후 남은 스토어 구독 0. 두 위치의 슬라이더 값 연동 확인.
