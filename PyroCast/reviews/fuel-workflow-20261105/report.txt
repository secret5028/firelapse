가연물 층/실 설정과 후보 순위 연동 — 2026-11-05

적용
- 층 전체는 양 슬라이더만 표시. 기존 층 종류 값은 보존.
- 3D 클릭/터치한 실만 개별 설정 표시. 14px 들여쓰기.
- 기존 용도별 연료표를 한글 검색하여 실 기준 하나를 변경, 개별 양 조절.
- AI 유사 기준 검색: 기존 표 id만 허용, 표의 수치/출처를 서버가 결합. 추천만으로 저장하지 않음. 미연결이면 비활성. 결과 없음은 자료 없음.
- AI 전층 기본 배치: 연결된 경우 층 선택 전에도 미설정 실 전층 자동 처리. 수량만 변경한 실도 AI 종류 배치 대상, 명시한 종류/수량은 보존. 실제 API 키 미설정: 실제 호출 미검증, 모의 응답은 시험 코드에만.
- 승인받은 호텔 5F 20실의 과거 개별 110%를 층 상속으로 변경. 변경 전 JSON과 해시 보관. 6F 90% 유지.
- 층 변경에서 개별 실 제외 수 표기. 작은 공간의 기호 크기 상한을 부드럽게 처리해 제한에 걸린 실도 양 변화 표시. 경계 밖으로 나가지 않음. 기호이며 실제 가구 형상 아님.
- 변경 저장 후 후보 점수/순위 재조회는 기존 연결 유지. 저장 전 순위에 '변경 저장 후 순위 갱신' 표시. 시뮬레이션 자동 실행 없음.

검증
- Python 연료 통합 11건 통과. 호텔 13개 층 입력 검사, 기존 B1 CAD_B1_R9 개구부 폭 오류는 별개로 유지.
- 독립 시험 데이터: 5F R8 library 기준 300% 저장 → 후보 점수 1.0 → 1.6953895671309134, 순위 20 → 17. 운영 연료값 변경 아님, 계산 엔진 실행 없음.
- JS/브라우저 시험 통과: 경계/구멍, 상속, 개별 100% 보호, 초기화, 검색 후 사용자 선택, 저장 실패/취소, 전층 자동 AI 모의, dispose.
- 운영 호텔: 5F 20실 모두 100→200% 기호 크기 변경. R20 120% 개별 설정 후 층 300% 변경에도 R20 크기 유지. 취소 후 모두 원복. 콘솔 오류 0.
- 운영 검증 POST는 읽기용 /cfbt/lite/ai/reports/list 1회뿐. 연료 저장/시뮬레이션 요청 0회.
- 엔진/물리식/결과 playback 수정 없음. 셰이더·render_order 코드 변경 없음. 운영/체크아웃의 기존 줄바꿈 차이는 유지.

범위 구분
이번 구현은 사용자가 답변으로 확정한 '실별 기준 하나만 검색·변경' 범위.
후속 제안인 자연어 kg/L 여러 항목 추가와 AI 재료 조합 계산은 아직 구현하지 않음.
현재 연료표는 재료 DB가 아닌 EN 용도별 기준 및 사용자 승인 가정. CFAST 문서의 물성 표로 표기하지 않음.
CFAST 입력은 사용자 지정 HRR·연소열 등을 요구: https://github.com/firemodels/cfast/blob/master/Manuals/CFAST_Users_Guide/Input_File_Chapter.tex
실제 물질 추가에는 질량/밀도/연소열뿐 아니라 연소속도·면적·성장·혼합 화원 입력 규칙도 필요. 근거 없는 수치/혼합 규칙은 추가하지 않음.
