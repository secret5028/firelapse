# 소방차 배치·건물 정면 기본 뷰

- 기본 위치: 등록된 주출입구의 실 중심 반대쪽 법선 방향. 전체 층 건물 외곽과 8×2.6m 차량 외접원 사이 거리 ≥10m. 기본 방향을 별도 도면 사실로 추정하지 않음.
- 보수적 차체 이격 하한: 호텔 10.243m (CAD_1F_D18), 완도 10.000m (CAD_1F_ENTRY_R5), 강화 10.297m (CAD_1F_D3).
- 이동: 차량 클릭 → 이동 → 반투명 미리보기 → 첫 클릭 위치 고정 → 커서로 방향 설정 → 두 번째 클릭 확정. Esc/취소는 기존 위치·방향 보존.
- 표시 그리드 내 지상만 허용. 회전된 차체를 검사하고 불가 위치는 붉은 미리보기. 이동/회전 중 카메라 궤도 조작 일시 중지.
- 확정 전에는 호스 경로 불변. 확정 후 기존 경로 계산으로 갱신. 위치·방향은 건물별 화면 상태에 저장하여 새로고침 때 복원.
- 최초/새로고침 카메라: 주출입구 바깥 방향, 약간 내려다보는 정면. 선택 층·실·결과·시간 복원 정책은 유지.
- 순정 엔진·간략 엔진·계산 입력·결과 파일 수정 및 시뮬레이션 실행 없음.

검증: route_selection.test.mjs, scale_reference.test.mjs, route.test.mjs(강화), vehicle_placement_ui.mjs(실제 호텔 UI) 통과. 브라우저 오류 0, 서버 변경/계산 요청 0. UI 자동화는 별도 브라우저에서만 테스트용 참조를 노출했고 운영 코드에 진단 전역을 추가하지 않았다.
UI 첫 시도는 카메라 조정 직후 렌더 전 좌표로 클릭하여 팝업 대기 실패. 두 프레임 렌더 후 클릭하도록 시험을 정정해 통과.
