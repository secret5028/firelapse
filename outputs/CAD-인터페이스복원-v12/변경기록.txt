기존 웹앱 기능 복원 · CAD 모델 보완 v12 — 2026-10-14

적용 위치
실제 바탕화면 ‘소방 크로키 업-로컬웹앱’을 업데이트하고 8778 포트에서 재실행했다.
기존 히스토리를 보존했다. 해당 9층 CAD 작업의 building.json/model.html만 갱신했고, 1단계 추출은 다시 실행하지 않았다.
설치기록.json에 실행 파일 해시·백업·적용 모델 ID를 기록했다.

복원한 인터페이스와 도구
층 버튼, 벽/개구부/바닥/계단/승강기/램프/이름 표시, 벽 투명도.
드래그 회전, Shift+드래그 이동, 휠 확대/축소, 시점 복원, 위에서 보기, 터치 한 손가락 회전/두 손가락 이동·확대 설정.
지표면은 1F 바닥 기준. 1m 격자 및 원래 소방차 8m·사람 1.75m 크기 기준 모델을 재사용했다.
기존 구조 청회색/문·수직이동 금색/창 하늘색/소방 설비 적색 분류를 적용하고 실별 무작위 바닥색을 제거했다.
기존 승강기 표식 코드를 재사용했다. 계단/승강기 이름표와 인접 승강기 묶음 표시를 추가했다. 위층만 볼 때 아래층 연결 계단도 표시한다.
기존 operations-ui.js, auto-route.js, hydraulic-core/ui/view.js를 재사용했다. CAD Z-up 좌표를 기존 X/높이Y/평면Z 좌표로 변환하는 어댑터를 넣었다.
차량 배치/이동/삭제, 복수 화점 시각 표식, 자동/직접 경로, 길이, 15m당 수관 본수 올림, 사람 배치/삭제, 건물별 저장/가져오기를 연결했다.
화점은 기존 작전 표식이다. 화재 물리 시뮬레이션은 실행하거나 구현하지 않았다.
기존 송수구 선택·연결 배관/말단 및 구역 표시 코드를 가져왔다. 현 CAD 건축 모델에는 소방시설 기호가 0개이므로 실제 배관·방수 구역을 자동 추출했다고 주장하지 않는다. 다른 건물의 검토 설비를 복사하지 않았다.
기존 도면 검토 화면과 보정 기능은 작업 단계 화면의 ‘기존 도면 검토’ 링크로 유지한다.

모델 보완
계단·승강기 원본 위치와 기존 35개 수직 연결은 그대로 유지했다.
B1 램프: 이전 코드는 내외측 벽 공통 구간만 취해 약 106°/중심선 17.61m를 표시했다. 해당 사용자 검토 원본 해시에만 180° 반원을 적용했다. CAD 벽 반경 6.15/12.85m, 폭 6.7m는 유지한다.
사용자 해석 B1↔1F를 적용해 바닥 높이차 5.10m, 중심선 길이 29.845m, 경사 17.088%가 되도록 했다. 임시 10% 조절은 이 연결 램프에서 비활성화했다.
180° 범위와 북측을 상단으로 두는 방향은 단순화 모델 해석이다. 상세 접속부/완화구간/실제 경사를 실측 검증한 결과가 아니다.
구조 슬래브를 반자와 분리했다. 위층 바닥은 아래층 구조 천장과 같은 높이이며 중복 두께를 만들지 않는다. 옥탑실 외부 옥상 면과 최상부 지붕면을 추가했다. 표시 두께 0.2m는 기본값이다.
기본 단층 보기에서는 내부를 보기 위해 상부 구조 천장을 숨긴다. ‘선택 층 구조 슬래브 천장’으로 확인할 수 있다. 숨김이 구조 슬래브의 부재를 뜻하지 않는다.
계단·승강기·램프를 movement_connections에 함께 기록한다. 램프 연결 1개를 더해 36개다.

확인한 사항
- 기존 실 폴리곤, 벽 밴드, 개구부, 계단/승강기 위치·형상 및 35개 연결 유지.
- 램프 180°·121점 양측 경계·높이차 5.10m·경사 계산 확인.
- 7F 상부 슬래브와 PH 바닥/옥상 면적·높이 일치 확인.
- 브라우저 WebGL 오류 없이 렌더링, 층 전환, 확대·시점 복원, 벽/계단 레이어 유지 확인.
- 테스트 복사본에서 차량·화점·사람 배치, 1F 자동 경로 75.5m/수관 6본, 저장·새로고침 복원 확인.
- 같은 출발점에서 2F R0까지 계단을 이용한 약 90.44m 경로 생성 확인. 모델 경로 검사이며 현장 통행·전술 안전성 검증은 아니다.
- 격리 테스트 계통 A/B 송수구 선택에 따라 연결 말단이 바뀌고 층 변경 후 선택 유지 확인. 시험 설비/작전은 실제 사용자 히스토리에 배포하지 않았다.
- 최종 실행 파일의 legacy-context 조회 및 CAD 작전 저장 확인. 다른 CAD 작업 ID의 설정 저장 거부 확인.
- 실제 설치 후 1F/B1/PH 화면 확인 및 캡처 저장.
터치 제스처는 기존 방식에 맞춰 설정했으며 실제 태블릿에서의 터치 입력 검증은 하지 않았다.
