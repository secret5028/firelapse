FireLapse · 계산 구성 안내
-compartment fire timeline-

첫 공개 배포는 저장 결과 재생과 계산 가능한 CAD 건물의 재계산을 제공합니다.
일반 사용자는 상위 README의 실행 패키지 안내를 따르세요.

계산 흐름
1. 사용자 선택 층의 가연물 설정
2. 간단 선별식으로 화점 후보 확인·선택
3. MC로 급기·개구부 상태 조합 탐색
4. 선택한 상태를 모델에 적용
5. 간략 엔진 또는 순정 CFAST 선택 후 계산

대상 시간은 30분 또는 최대 60분(1시간), 기본 60분입니다.
대상 시간과 실제 PC 실행 시간은 다릅니다. MC는 여러 조합을 탐색하는
방법이며 엔진 이름이 아닙니다. 스캔 기반 모델은 계산 대상이 아닙니다.
완도는 일반 CAD 경로와 구분된 전용 CFAST 입력·결과를 사용합니다.

폴더
pyrocast_lite/     간략 엔진
pyrocast_cfbt/     CFAST 입력·실행·확장 관련 모듈
extensions/cfbt/   프로젝트가 추가한 확장 코드
vendor/           출처·버전이 고정된 외부 원본
build/            기준/확장 실행 파일과 빌드 자료
config/           가연물·급기 등 계산 설정
viewer/           공통 뷰어·생성 UI 번들·색 토큰
results/          저장 결과와 새 계산 산출물
tests/            계산·입출력 검증 코드

원본과 확장 구분
순정 CFAST, FireLapse 간략 엔진, 프로젝트의 CFAST 확장은 구분됩니다.
확장 결과를 순정 CFAST 결과라고 표시하지 않습니다. 원본 출처와 변경
경계는 SOURCE_BOUNDARIES.txt 및 vendor의 고지를 참고하세요.

결과와 저장
실행 패키지는 최종 재생 자료·요약과 재계산에 필요한 설정을 제공합니다.
원본 CSV·중간 행렬·개발 로그 전체를 배포하는 것은 아닙니다.
새 계산에서는 별도의 과정 파일과 결과가 생성되어 용량이 증가합니다.
앱과 결과 저장 공간의 자동 분리·자동 삭제는 제공하지 않습니다.

표시 해석
FO·FGI·BD는 정의된 조건의 충족 지수이며 발생 확률이 아닙니다.
100은 기준 도달이며 실제 현상 발생 확정을 뜻하지 않습니다.
미평가 값은 —로 구분하고, 롤오버는 FGI의 부속 상태로 표시합니다.

검증 범위
일반 CAD 계산은 층별 구획 입력을 사용합니다. 전 건물의 수직 연기 전파,
모든 도면의 자동 보정, 모든 조건의 물리 정확도를 검증한 제품은 아닙니다.
실제 입력·엔진·완료 상태·추정 연결을 함께 확인하세요.
실행 패키지 확인을 위한 입력 준비·재생 시험과 새 엔진 실행은 별개입니다.

내부 pyrocast_* 모듈명은 저장 자료 및 도구 호환성을 위해 유지합니다.
사용자에게 표시하는 제품명은 FireLapse입니다.
