- 저장 요약 103개 무결성 검사. MC 7개 작업의 표본 순위가 원본과 동일.
- 호텔 5F·견본주택 2F·아이엔테크 1F 입력 준비 및 순정 CFAST 덱 생성 확인. 새 계산 완료를 검증한 것은 아님.
- portable_result_index.test.py: 5/5 통과. 변조·누락 거부, 원본 결과 우선 검증.
- 직접 캡처: 호텔 층별 결과·평면·전체 건물, 완도 CFAST R5 35분.
- 배포 후보의 JSON 인증정보 필드 검사: 발견 0. API 키·로컬 AI 설정 제외.

- 새 CAD 외부 추출 도구 별도 설정. API AI 자동 보정 전체 통합 검증 미완료.
- 완도 일반 계산 상태 API 미지원 404, 전용 화면 HTML 내보내기 비활성.
- 스캔 모델 열람 전용. 모든 건물·화재 조건의 물리 정확도 검증을 의미하지 않음.
- 앱과 새 계산 결과 저장 폴더 자동 분리·자동 정리 미지원.
- 압축 무결성, 다른 폴더 실행 검사와 최종 파일 크기·해시는 GitHub Release 안내/첨부 SHA256SUMS에 기록.
