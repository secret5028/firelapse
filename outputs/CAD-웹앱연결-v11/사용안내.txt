기존 소방 크로키 업 · CAD 업로드 연결 v11

사용 순서
1. 기존 바탕화면 폴더의 “소방 크로키 업.exe”를 실행합니다.
2. 한 건물의 DWG/DXF를 함께 선택합니다. 층은 CAD 문자로 자동 판독합니다.
   층 표시가 없으면 파일 목록에서 해당 층을 지정합니다.
3. “평면 추출·3D 모델 만들기”를 누릅니다.
4. 처리 완료 후 히스토리에서 “평면도·3D 열기”를 누릅니다.
5. “1. 평면도 추출”에서 층별 결과·원본 레이어를 보고,
   “2. 3D 모델”에서 층 선택·계단·승강기·램프를 확인합니다.

이 버전에 연결한 기능
- 기존 업로드·히스토리·진행률에 CAD 추출 및 v10 3D 모델 생성 연결.
- 같은 층의 CAD를 묶고 건축 평면을 기준 도면으로 선택. 관련 도면 목록 보존.
- CAD 직접 문자에서 층·높이·축척 후보 추출. 입면/레벨표 판독 코드 연결.
- 이미 검토한 도면의 보정과 높이는 원본 해시가 정확히 일치할 때만 재사용.
- 계단·승강기 기준 정렬·층간 연결과 차량 램프 표현.
- Three.js를 앱 내부에 포함. 3D 보기에 인터넷·API 키 불필요.
- PDF·이미지와 기존 도면 검토 경로 유지. 기존 data 폴더와 히스토리 보존.

입력 범위
- 한 건물씩 처리하며 최대 50개 파일, 파일당 50MB.
- 한 파일에 여러 층 평면이 배치되어 있으면 층별 파일로 분리합니다.
- 같은 층 건축 후보가 여러 개면 선 객체가 많은 도면을 선택하고 결과에 선택 기록을 남깁니다.
- 보조 도면은 같은 층 목록으로 묶지만 서로 다른 좌표의 소방/설비 도면을 자동 융합하지는 않습니다.
- CAD에서 읽을 수 없는 특수 DWG 객체는 DXF로 저장하여 다시 입력할 수 있습니다.
- 높이가 판독되지 않고 기존 검토 기록도 없으면 용도별 기본값을 쓰며 화면에 출처를 표시합니다.
- 램프 경사·상승 방향은 v10과 같은 표시용 가정입니다.

검증
- 실제 B1·1F DXF 업로드: 공간 67개, 개구부 159개, 인접 층 코어 연결 5개.
- 실제 호텔 5F DWG: 변환 → 평면 추출 → 3D 모델 생성 통과.
- 기존 이미지 입력과 기존 도면 검토 화면 유지 확인.
- 브라우저에서 평면/3D 전환, B1/1F 층 전환 및 3D 렌더링 확인.
- 여러 층을 한 층으로 임의 덮어쓰지 않는 입력 분기 등 4개 검사 통과.
- 경로 이탈 요청 거부 확인. 위 검증은 연결·실행 검사이며 도면 정답률이나 화재 물리 검증이 아닙니다.

3단계 시뮬레이션 버튼은 아직 비활성 상태입니다.
설치 경로·이전 앱 백업은 설치기록.json, 재배포 가능한 실행 파일은 배포본 폴더에 있습니다.
