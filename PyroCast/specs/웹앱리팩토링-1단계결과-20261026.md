## 계약 초안의 빈 부분과 처리

1. **다중 폴리곤:** R2_C1은 형상 조각이 두 개다. 단일 polygon만 유지하면 일부 형상이 사라지므로 `polygons_m` 배열을 추가했다. 구멍도 그대로 보존한다. 이후 렌더러는 이 전체 배열을 사용해야 한다.
2. **방 단위 연속값(사용자 승인 반영):** R1·R2·R10은 여러 셀로 구성돼 있다. 셀 원값은 전부 유지하고, 방 합성 시계열은 null, `aggregation: "none"`으로 기록한다. 단일 셀 방은 원값 그대로이며 `aggregation: "single"`이다. 기존의 ‘일부 셀 조건 충족 → 방 표시’ 판정은 유지한다. 이후 실 상세 UI에서는 다중 셀 방의 셀 목록을 펼쳐 보여주고 **“방 평균 없음”**을 표시한다. 새 집계 규칙은 별도 안건으로 승인 후 추가한다. 이번에는 UI 작업을 시작하지 않았다.
3. **저장 부속 파일:** 공급 발열량, 당시 설정, seed는 재생 파일만으로 복원할 수 없어 같은 실행의 result/input 파일을 함께 읽었다. 현재 기본값으로 대체하지 않았다.
4. **표시색과 조건:** 기존 대표색·rollover_band는 `legacy_color`에 보존했다. 공통 조건표 판정과 기존 화면의 대표색 게이트가 완전히 같지는 않다. 이번에는 화면을 바꾸지 않았으며, 이후 위험 레이어 연결 시 이 차이를 숨기지 말아야 한다. 사용자 확정 정책은 유형별 테두리 중첩·동시 표시다.
5. **미확인 메타데이터:** 저장 자료에 없는 fallback 센서 목록이나 결과 연결 ID는 null로 남긴다. 빈 목록이나 가짜 ID를 만들지 않는다. building은 저장 시나리오의 3F 범위이며 전 건물 모델이라고 표시하지 않는다.
