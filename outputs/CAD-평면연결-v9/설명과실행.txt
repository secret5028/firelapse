1단계 평면 추출 — CAD-평면연결-v9

범위: 업무시설 28-200-2026-00000010, B1·1~7F·PH 총 9층 CAD 재추출.
기존 v7/v8 결과는 보존했다. 3D 표현 개선이나 시뮬레이션 엔진 변경은 하지 않았다.

변경
- 주차장 이름이 붙은 주 공간의 면적 근거를 층 용도 판정에 우선 적용한다. 작은 창고 이름 빈도 때문에 B1 전체가 창고가 되는 문제를 수정했다.
- 주차장 맥락과 서로 동심인 차량 폭 곡선들의 근거로 램프를 별도 객체로 저장하고, 해당 선을 계단 정렬 후보에서 제외한다. 특정 건물 좌표·층·개구부 ID를 규칙에 넣지 않았다.
- 램프 경계에 있는 문짝·벽 지지 근거 없는 호 후보는 제거한다. 이번 B1 D0가 해당한다.
- 계단 기호의 반복 단선으로 전층의 동일한 기준 영역을 만들고, 계단실 영역과 구별한다. 다른 CAD 표현에서는 기존 계단실 추출 근거를 보존한다.
- stair_inside/elev_inside와 stair/elev의 의미를 코어-실 대응에 반영한다. 넓은 주차장·홀 내부의 코어는 접근 공간 관계로 기록하고 실 전체를 승강로로 바꾸지 않는다.
- B1 및 PH 층명을 인접 층 판정에 반영한다. 층고 연속·같은 코어 종류·기하 겹침을 검사한다. 겹침 기준 0.6은 낮추지 않았다.
- 정렬은 계단·승강기 기준이다. 기둥은 코어 정렬의 보강·미세 보정에 사용한다. 벽 모양으로 대체하는 fallback은 제거했다.

결과
- 계단 1: B1~PH, 계단 2: B1~7F.
- 승강기 2개: B1~7F, 승강기 1개: B1~6F. 원본 후보가 없는 층으로 연장하지 않았다.
- 코어 5개 계통, 인접 층 연결 35개.
- 램프 1개, B1 용도 parking. 램프 곡선 부분의 평면 형상을 보존했다.
- 76개 단위 테스트와 9층 형상 일관성 검사. 다른 건물 3개 층의 기존 코어 수와 개구부 목록 유지 확인.
- 자동 검사 통과는 원본 정답이나 화재 물리 검증을 의미하지 않는다. 시뮬레이션을 실행하지 않았다.

남은 범위
- 램프 상하단의 정확한 위치·표고 및 외기 연결은 미확정이다. 차량 통로라는 분류와 계단 제외를 먼저 반영했다.
- B1과 1F 각각 계단 후보 1개는 대응 층 근거가 없어 단독 후보로 남겼다. 주요 두 계단 연결과 구분된다.
- 3F R27 실내외 판정은 이번 변경 대상에서 제외했으며 이전 미확정 상태다.
- 스캔 소방 PDF는 기존 검토 목록을 이어받았으며 CAD에 자동 정합·융합하지 않았다. CAD 텍스트는 직접 추출하여 floor_metadata.json에 보존했다.
- 브라우저 실제 클릭 검증은 수행하지 않았다. JavaScript 구문과 정적 미리보기를 검사했다.

파일
index.html: 전층 목록 및 연결 요약.
office-층/코어검토.html: 원본 벡터 또는 추출 평면 위에 계단·승강기·램프 표시.
office-층/index.html: 기존 벽·문·창 검토 UI.
office-층/floor_metadata.json: CAD 문자 기반 용도·표고·축척 후보와 채택한 층고.
층별도면묶음.json: 같은 층 관련 도면·검토자료 그룹.
층간연결.json: 정렬 변환, 코어 노드, 접근 공간, 인접 층 연결, 근거 겹침률.
building.json: 기존 연결 형식과 호환되는 정렬 결과. 현재 단계에서는 연결 데이터의 저장 형식으로 사용.
code/: 적용 코드 사본. 원본 작업 코드는 C:\Users\예방\Documents\Codex\2026-09-07\2\CAD3D.
