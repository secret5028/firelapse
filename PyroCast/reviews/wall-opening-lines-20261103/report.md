# 공통 문·창 개구부의 벽 선 정리

벽 투시, 벽 면의 기하·재질, 문틀·창틀, 위험·선택 테두리, 호스 경로는 유지했다. 공통 BuildingLayer에서 CAD 벽 윤곽 LineSegments만 문·창 개구부 내부와 교차하는 부분을 제외한 선 조각으로 표시한다. 다른 건물도 같은 코드 경로를 사용한다. 원본 CAD 기하는 수정하지 않으며 잘린 표시용 기하만 소유·해제한다.

개구부의 방향·폭·높이·두께 범위를 사용한다. 문 양끝 기둥과 상인방, 창 상하 프레임은 남긴다. 별도 openings 레이어는 변경하지 않는다. 형상이 없는 개구부는 임의로 추정해 잘라내지 않는다. 문 형상에 깊이 정보가 없는 경우 표시용 중심선 양쪽 0.075m 범위 및 0.015m 여유를 사용한다. 계산·연결망·문 개방 조건은 변경하지 않았다.

완도 CUT은 display_schedule에 맞춰 닫힘/반개방/전체 개방 범위를 적용한다. 정적 개구부는 최초 로드 때만 처리하고, 같은 개방률에서는 기하를 다시 만들지 않는다.

## 검증

- 단위 시험: 문·창, 대각선 개구부, 층 변환, 주변 평행 벽 보존, 프레임 보존, 시간 가변 개방, 원본 기하 보존, 동일 개방률에서 재생성 없음 통과.
- 기존 건물 재질 복원 시험 50회 통과. 원본 기하·재질 dispose 0, 남은 구독 0.
- Edge 완도 0/1325/2100 s 전후 캡처: 벽 선 객체 8개 잘림. 벽 Mesh들의 기하 종류·투명도·불투명도 전후 동일. 잘린 선의 양옆 조각이 생기므로 정점 합계는 912→944로 증가한다. 오류0, dispose 후 구독0.
- 기존 CAD building.json/model.html 실제 생성 코드로 추가 검증: 전체 9개 층의 벽 선 객체 15개 잘림, 생성·잘라내기 195ms(단일 측정). 3F 전후 캡처 저장. 오류0.
