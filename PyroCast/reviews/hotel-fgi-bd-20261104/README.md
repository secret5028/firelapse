# 호텔 FGI·BD 0 원인 검수 — 2026-11-04

## 결론

**호텔에서 지수 계산이 꺼진 것이 아니다.** 현재 저장 사례는 R16 문 1개 완전 개방, 창 2개 50% 개방이다. 이 입력에서 간략 엔진은 공급 연료 전량이 화원에서 연소한다고 계산한다. 미연 연료 항이 0이므로 동일 조건표의 FGI·BD 최솟값도 0이다. 닫힌 개구부 대조에서는 같은 엔진이 미연 연료와 두 지수를 생성했다.

이것은 **모델 내부의 원인 확인**이며 실제 호텔에서 FGI·BD가 없다는 검증은 아니다. 순정 CFAST 동일 입력 대조는 아직 하지 않았다. 사용자가 앞서 퇴근 후 실행을 요청했으므로 지금 대조할지 별도로 질문했다. 지수를 높이기 위한 임계값·연료·산소값 수정은 하지 않았다.

## 앞선 설명의 정정

원 입력의 화원 높이는 바닥+0.76 m이나, `simulation/pyrocast_cfbt/rule_cells.py` 초기 화원 분할은 z를 바닥으로 바꾼다. 실제 간략 솔버의 화원 높이는 **0 m**였다. "화원이 경계 위에 잠겼는데 하층 공기를 썼다"는 첫 진단은 이 사례에 맞지 않았다. 입력 원본만 보고 실제 컴파일된 좌표를 놓친 설명을 철회한다.

하층 유입 우회 max 항은 9월 원본 `fire_zone.py:318`부터 있었다. 제거 시험에서 호텔의 FGI·BD 0은 유지됐다. 이 항 제거를 호텔 해결책으로 배포하지 않고 원래 코드로 돌렸다. 원본·순정 CFAST 엔진, 조건표, 전이 기준, 저장 사례를 수정하지 않았다.

화원 높이 강제 변경, 고정 500 kW/m²로 계산하는 플룸 지름, 가상 원점 없는 근사 등은 실제 CFAST 대조에서 확인할 모델 차이다. 이번에 결과를 맞추려고 변경하지 않았다.
