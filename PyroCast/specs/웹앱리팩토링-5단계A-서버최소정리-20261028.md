## 실행 계약
- 화점: 현재 승인된 3F 적격 실. 문 정정과 연료 기준을 입력 스냅샷으로 저장한다.
- 표본 수: 필수 2표본 포함 2~1000. 기존 추출기, seed20261025 기본. 30분/1시간은 현재 결과 시간에서 전달.
- 한 번에 한 작업, 표본 직렬. 1,200초는 **표본당 적분 예산**이며 기존 BDF→수치 실패 시 Radau 1회도 남은 예산을 공유한다. 전·후처리 시간은 기존처럼 별도다.
- 새 결과를 목록에 추가하되 현재 3D 장면은 자동 교체하지 않는다. 실패·미완료는 명시하고 완주 playback만 선택 가능하다.
- 서버 재시작 시 남은 CLI 프로세스를 확인한다. 중단 작업을 자동 재실행하지 않는다. 취소 API는 이번 범위에 없다.
- 현재는 기존 3F 입력에 연결한 서버 래퍼다. 임의 건물에 대한 새로운 입력 생성기를 구현한 것은 아니다.
