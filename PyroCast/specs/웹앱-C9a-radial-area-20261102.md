# C-9a — legacy 도면 셀 면적에 맞춘 radial_area

`cell_mode: radial_area` 추가. **기본 legacy 유지**, S09 R2 동일 개폐·연료·물성으로 3600초 실제 적분 **1회**, BDF, 10초 출력, 실행 예산 1200초. 임계값·전이 규칙·솔버 조정이나 결과를 맞추기 위한 재실행 없음. 참조 집합 관문은 불통과다.

## 면적과 반경

사용자가 지칭한 legacy 104㎡는 저장된 초기 셀 `R2_C0`의 **도면 교집합 면적 104.11701㎡**다. 계산용 사각 셀 면적 108.35793㎡와 구분해 도면 면적을 사용했다.

화점 `[57.67, 53.34536796564403]` 중심 24각 원을 사용한다. 원∩방 폴리곤 면적이 A, 2A가 되는 반경을 각각 **기하 이분법 60회**로 구한다. 화재 결과를 이분법에 사용하지 않는다.

| 항목 | 값 |
|---|---:|
| 목표 A | 104.117010㎡ |
| r1 | 10.150159 m |
| r2 | 14.082501 m |
| 화점 / 중간 / 외곽 면적 | 104.117010 / 104.117010 / 116.839780㎡ |
| 최초 화원 peak | 13,014.626 kW |

R2 총 면적 325.0738㎡, 총 연료 예산은 그대로다. 원래 곡선에 셀 면적 비율을 적용하는 규칙을 유지했으므로 최초 peak는 legacy의 13,544.742 kW와 소폭 다르다. 이번 변경은 도면 면적을 맞춘 것이며, 계산용 사각 면적까지 같은 것으로 간주하지 않는다.

조건 시각은 실제 HRR 발생 시각과 다르다. 기존 규칙은 부모의 **상층 온도**를 보므로, 부모의 고체 공급이 시작되기 전에도 유입 열로 조건이 충족될 수 있다. R2 중간 셀은 자신의 공급 시작 전 300℃를 넘어 외곽 전이를 예약했고, R1_C6도 자체 착화 이벤트 없이 가열되어 다른 셀의 트리거가 되었다. 이번에 이 규칙을 바꾸지 않았다. 실제 연소 실 집계는 HRR > 0 출력 기준이다.

## 참조 집합 관문

- CFAST 표준: `{R2}`.
- lite radial_area: `{R1, R2, R7, R10}`.
- CFAST 공격 부분 결과: `{R1, R2, R6, R7, R8, R9, R11, R23}`.
- 표준 포함은 통과, 공격 집합 안에 들어가는 조건은 **R10 때문에 불통과**. 기존 순서 관문도 R1/R7의 동시성 차이로 불통과.

기존 관문과 같이 비교 구간은 0~2850초다. CFAST 공격은 미완료 참조이고 S09와 개폐 입력이 다르므로, 이 관문은 동일 입력의 1시간 검증이 아니다. 기본 모드 전환은 하지 않는다.

## 구현·검증·한계

- 변경: `radial_cells.py`의 면적 기반 반경 결정·모드·캐시 식별, playback의 모드 메타데이터, 전용 실행/검사/보고 도구. 레이어 변경 없음.
- 새로운 대용 박스에서 기존 창 오프셋이 범위 밖이 되는 입력 오류를 **실행 전** 발견했다. radial_area에서만 컴파일용 창 타깃 중심을 대용 박스 중앙에 둔다. CAD 창 중심·폭·높이·스케줄, lite 유동 입력은 보존한다. lite에서 판 센서·창 파괴는 여전히 계산하지 않는다.
- 셀 중심 선택, 개구부 중심에 따른 셀 배정, 경계 길이 가상 개구부, 거리/0.05 지연, 20㎡ 미만 병합은 C-9와 동일하다. 도심이 폴리곤 밖이면 내부 대표점을 사용하므로 중간 셀 중심이 화점과 상당히 떨어질 수 있다. 이번 중간→외곽 지연은 498.377초다.
- 기하가 달라지므로 열 교환 경계·벽 둘레·창 소속도 달라진다. 기존의 가상 경계를 포함하는 벽 열손실 근사는 유지된다. 목표 면적 일치만으로 legacy와 같은 온도·전파를 보장하지 않는다.
- 기본 legacy 모델·manifest·contract는 수정 전과 동일. 기존 고정 반경 radial manifest도 C-9 저장본과 동일. 면적 목표, 비중첩·합집합, 구멍, 체적·연료·원 개구부 폭 보존 검사 통과.
- 캐시 키는 모드·입력·계산 소스 SHA뿐 아니라 **산출 목표 면적·r1/r2를 포함한 분할 기하**도 포함한다. 동일 명령 재조회는 CACHE HIT, 추가 적분 0회. 기존 저장 결과는 덮어쓰지 않았다.
- 계산 중 소스 불변, S09 원본 입력에 `cell_mode`만 추가. 코어·조건·전이 규칙·레이어·셰이더·서버 등 확인 대상 27파일 SHA 불변.
- legacy 1420초 3D 재캡처는 C-9 기준 대비 차이 픽셀 0. C-9a 캡처는 같은 카메라·clock 180000 ms·1420초·C8 표시 기본값을 사용한다.
