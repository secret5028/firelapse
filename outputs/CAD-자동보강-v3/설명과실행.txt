CAD 자동 보강 v3 — 2026-10-14

목표: 작은 형상 오차를 허용하면서 3D와 구획 기반 시뮬레이션의 입력을 자동 생성.
사람의 전수 확인을 실행 조건으로 삼지 않는다. 물리 해석 정확도 검증은 별도다.
실행 명령과 의존성 설치는 CAD-추출-사용법.txt와 같다.

이번 변경
1. 픽셀 해상도는 20mm 유지. 벽 틈 보강 후보를 80/160mm 범위로 비교한다.
   문·창 구역은 보강에서 보호한다. 기존 문 구분이 유지되고 실 수가 안정적인
   두 보강 크기가 발견되면 작은 쪽을 채택한다. 안정 조건 불충족 시 기존 결과 유지.
2. 반복 동심 원호의 일정 간격과 같은 영역의 반복 블록을 함께 확인해
   객석 단차 후보를 구획 경계에서 제외한다. 원본 선과 제외 근거는 보존한다.
   INSERT 기준점이 그림에서 떨어진 경우 실제 변환된 블록 형상의 중심을 사용한다.
3. 승강기 블록의 영역이 일반 실에 섞여 있으면 승강로를 분리한다.
   모델용 경계 두께 기본값 120mm, 카 블록 외접 영역 기반의 근사다.
   이미 독립된 승강로와 문이 있으면 기존 구획을 사용한다.
   기존 CAD의 인접 틈 근거가 있는 경우에만 승강기문 연결을 생성한다.
4. 생성된 실과 확정 가능한 연결을 simulation_graph.json으로 내보낸다.
   같은 실끼리 연결되거나 연결 대상을 모르는 개구부는 연결표에서 제외하고 목록에 남긴다.
   개방 상태 0/50/100%를 입력 가능한 상태 목록으로 기록한다. 제어 UI/해석 실행은 별도.
5. 추정·보정 근거 및 연결표는 building.json의 해당 층에도 전달된다.
   기존 시제품 엔진 fire_zone.py는 미확인 None을 외기로 바꾸지 않도록 수정했다.

실제 도면 확인
호텔 4층: 실 22→25, 승강기문 0→3. 승강로 3개와 일반 실의 면적 중첩 0.
업무시설 1층: 객석 단차 원호 7개 / 반복 좌석 블록 90개 근거.
다목적실의 기존 9개 영역을 약 161㎡의 한 공간으로 정리.
나머지 실 개수 변화에는 승강로 분리가 함께 포함된다.
3개 건물 5개 층의 기존 정상 문 연결을 공간 대응으로 비교하고 3D 전달 검사 통과.
29개 단위 시험 통과. 검증결과.json에 층별 변경과 남은 미확인 연결 기록.

범위와 한계
이 버전은 화재·연기 해석 자체를 실행하거나 그 결과 정확도를 검증하지 않았다.
승강로 경계는 도면 블록에 근거한 모델링 근사이며 실제 벽 위치·두께의 정답은 아니다.
반복 단차선 판정은 복수 근거를 사용하는 추정이며 모든 도면 작성 방식을 포괄하지 않는다.
계단실은 기존 코어/벽 근거를 유지한다. 개방 계단에 임의의 벽을 만들어 폐합하지 않는다.
미확인 연결 제외에 따른 결과 영향은 해석 시나리오에서 고려해야 한다.
기존 출력은 보존했으며 v3 결과를 새 폴더에 저장한다.
