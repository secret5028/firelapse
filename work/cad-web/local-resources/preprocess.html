부분 판독 · 기본 사용

미리보기에서 좌상단과 우하단을 차례로 클릭하세요. 또는 후보 버튼을 선택하세요. 좌표는 회전 후 이미지 기준입니다. 잘라낸 부분만 전송하며 전체 모델 판독 완료로 처리하지 않습니다.

실행 시 선택한 이미지가 해당 제공자에게 전송됩니다. API 비용이 발생할 수 있습니다. 키는 저장하지 않습니다.

2. 판독 데이터로 모델 생성

모델에 포함할 층 평면도를 체크하세요(한 번에 최대 20개). 도면 전체 이미지를 넣지 않고 구조화된 데이터로 생성합니다. 미확정 페이지는 건너뛰고 사유를 표시합니다. 생성 후에도 3D 초안과 원본 대조가 필요합니다.
