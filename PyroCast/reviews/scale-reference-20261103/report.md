# 공동 발광 제거 및 크기 비교 모형 복원

- 주황색 공동 발광 메쉬·알파맵·갱신 코드를 제거했다. cavity_wall_glow 화원은 내부 불꽃으로 되돌리지 않으며, 저장 발열량과 분출 화염은 유지한다.
- 기존 CAD 참조 모형의 소방차·사람 기하를 복원했다. 원본: Documents/Codex/2026-09-07/2/CAD3D/out/28-200-2018-00000088/croquis.html의 크기 비교 모형.
- 완도 경로 시작점에만 연결한다. 다른 건물의 사람 표시는 변경하지 않는다. 기존 차량 표시 설정으로 두 모형을 함께 끄고 켠다. 실제 사고 당시 인원·차량 배치가 아닌 크기 비교용이다.
- 조명 없는 완도 부트스트랩에서도 보이도록 원본 색을 유지한 MeshBasicMaterial을 사용했다. 길이·비율은 변경하지 않았다.

## 검증

완도 P1 1325/1400/2100 s: 공동 발광 메쉬 0, 보이는 분출 화염 2. 분출 HRR·길이 등 진단 객체는 이전과 완전 동일. 시뮬레이션 재실행 및 결과 데이터 수정 없음.

장면에서 측정: 소방차 길이 8m, 사람 높이 1.75m. 차량 표시 OFF/ON 왕복 통과. 브라우저 오류 0, dispose/pagehide 후 스토어 구독 0.
