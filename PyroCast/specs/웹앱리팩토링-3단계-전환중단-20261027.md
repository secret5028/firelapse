## 저장한 전환 초안

- `app/web/entry.js`: 기본 새 호스트 / ?ui=legacy 분기, 같은 canvas 중복 attach 방지. 간략 결과가 없는 기존 CFAST 화면은 기존 경로 보존.
- `app/web/controller.js`: 기존 패널과 스토어 연결, 기존 fitFloor·실/연소점 확대 수식, 기존 CAD 캔버스 인계, 사례 읽기·전환.
- `app/web/panels/legacy_lite_panel.js`: 기존 패널 HTML·문구와 상세 출력·검토 메뉴를 추출. 패널 재설계 없음.
- 호스트는 기존 renderer·패널의 cfMeaning을 명시적으로 인계받을 수 있게 확장. 기존 CAD 프레임 루프가 호스트를 구동하며 별도 루프/캔버스를 만들지 않는다.
- store에 camera/fit fire 모드와 기존 개별 문·창/연료 표시 상태 추가. 실감보기 래퍼에 기존 균등 연료 기호 연결, 셰이더 불변.
- `tools/build_ui_bundle.py`: 프런트엔드 모듈만 기존 overlay.js URL용으로 묶는다. 서버 경로 수정 불필요. 검증용 산출물은 `simulation/results/ui_refactor_stage3_switchover_20261027/overlay.js`에만 생성했다.

실제 `simulation/viewer/overlay.js`는 이전 파일 그대로다. 이 초안의 전체 UI 상호작용·회귀 검증은 아직 완료하지 않았다. 운영 반영 전에 픽셀 차이 원인 해결, 전체 보기 비교, 사례 전환·카메라·표시 토글·해제 회귀 확인이 남았다.
