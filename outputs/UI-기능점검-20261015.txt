판단 기준
3단계 흐름은 평면도 추출 → 3D 모델링 → 시뮬레이션이다. CAD 추출은 현재 수준으로 마무리됐다. 기존 시점 조작·색상 분류·1m 격자·계단/승강기 표시를 유지한다. 목표는 화점과 현장 조건을 입력하여 시간별 공간 위험과 소방시설의 기여를 시각화하는 것이다. 진입경로·설비 위치는 이를 지원한다. 대원 행동 시계열 입력을 중심 기능으로 되돌리지 않는다. 현재 자연어 기반 시뮬레이션은 구현되지 않았다.

실제 화면에서 확인한 정리 필요점
1. 홈 맨 위에 예전 '큰 도면 · 2단계 처리' PDF 전처리가 CAD 업로드보다 먼저 나온다. MVP 중심 입력과 화면 우선순위가 어긋난다.
2. 작업 열기 후 히스토리 바, 단계 바, 모델 내부 층 바가 세 줄을 차지한다. 평면도 이동 링크도 반복된다. 양쪽 패널은 항상 열려 있고 별도 스크롤을 갖는다.
3. 왼쪽 '작전 설정'은 차량 추가가 첫 항목이다. 화점 지정은 아래에 있고 문·창 개방은 오른쪽 상세 설정 깊숙이 있다.
4. 상세 설정에는 추가 층 체크박스, 두 번째 벽 투명도, 수직 공간 전체 표시가 있다. 층 단독 선택과 층별 포함 선택의 의미가 구분되지 않는다.
5. 저장이 모델 JSON, OBJ, 천장, 문, 창, 작전, 계통으로 나뉜다. 작전 자동 저장은 operations만 저장하므로 '모든 설정이 저장된다'고 표시하면 안 된다.
6. 현재 경로 추가는 차량이 있어야 활성화된다. 화점 배치 시 자동 경로를 생성한다. 코드상 기준용 차량도 자동 경로 출발점에 사용될 수 있다. 화점 지정과 경로 생성을 분리하고 차량 없는 진입점 출발도 지원하는 방향이 적합하다.
7. 화염 크기 소/중/대는 표시 제어다. 이를 화재하중·열방출률·계산 위험도 입력처럼 보이게 두지 않는다.
8. 소방설비 패널은 '송수구 연결 · 필요 송수압' 중심이다. 현재 CAD 작업에는 계산용 계통이 미등록이라고 실제 화면에 표시된다. 기능 존재와 실제 도면의 설비 데이터 확보를 구분한다.
9. 상세 설정의 공리 검사는 보정 전 판단·보정 이력까지 길게 나열한다. 현재 결함 목록으로 읽히지 않도록 추출 단계의 검토 기록으로 옮긴다. 작은 샤프트 등 합의된 생략 사항을 새 필수 오류로 제시하지 않는다.

유지
- CAD 업로드/층 판독과 보정 선택, 처리 상태, 작업 히스토리, 기존 결과 재열기.
- 평면 추출/3D/시뮬레이션의 단계 구조. 시뮬레이션은 '준비 중' 상태를 명시.
- 원본 도면 및 레이어 대조. 1단계의 보조 화면으로 접근 유지.
- 층/전체 보기, 회전·이동·확대, 위/비스듬히/시점 복원, 터치 조작.
- 1m 지표면 격자, 구조/문/창/설비 색상, 계단·승강기 선명도 완화 방식, 램프·테라스·구조 슬래브 표현.
- 화점 위치, 개별 문·창 개방 상태. 현재 합의는 닫힘/50%/열림이며 단순 버튼으로 제공하는 방향.
- 진입경로·거리·수관 수, 차량·사람 배치, 송수구·연결설비·구역 확인. 보조 도구로 정리하되 기능 제거 금지.

합칠 것
- 반복된 상단 이동 메뉴를 공통 작업 헤더와 단계 메뉴로 통일. 층 선택은 하나의 기준으로 동기화.
- 표시 레이어/벽 투명도/수직공간 표시를 '보기 설정' 하나로 통일. 다중 층 표시는 같은 패널의 상세 옵션.
- 문·창 선택과 개방 설정은 '선택 대상 속성'으로 이동. 향후 공간 재료/화재하중도 같은 패널에 연결할 자리 마련. 변수 목록을 이번에 확정하지 않음.
- 저장은 사용자에게 '작업 저장/불러오기·내보내기' 하나로 제공하되, 모델/개구부/작전/계통의 저장 범위를 먼저 실제로 통합해야 함. 버튼만 삭제해서는 안 됨.
- 소방설비는 위치·계통·연결구역을 앞에 두고 압력 계산/제원 편집을 상세 영역으로 통합.

기본 화면에서 숨길 것
- PDF·스캔 전처리 및 과거 AI 도면 판독: '다른 형식/기존 작업'으로 이동. 구현·원본·기록 보존.
- 차량/사람 배치 상세 버튼: '현장 도구'를 열 때 표시. 진입경로와 설비는 접근성 유지.
- 반자 높이 편집, 층 띄우기, 원본 대조 경계, 공리 로그: 모델 검토/고급 설정으로 이동.
- OBJ/JSON 개별 내보내기와 원시 층별 도면 목록: 내보내기/상세 정보로 이동.
- 과거 시험 작업: 일반 건물 목록과 구분해 보관함/시험 작업 필터로 표시. 삭제하지 않음.

삭제 또는 대체할 UI 후보
- 통합 후 중복 평면 링크, 중복 투명도/층 제어, 중복 저장 진입 버튼.
- '화점 지정 시 자동 경로 생성' 기본 동작은 해제하고 필요할 때 경로 도구에서 실행. 자동 경로 기능은 유지.
- 소/중/대 '화염 크기'는 기본 조건 입력에서 제거하고 필요하면 '표식 크기'로만 유지. 물리 입력으로 전용하지 않음.
- 현재 검토된 램프에서 비활성인 경사/방향 조절기는 읽기 전용 연결 정보로 대체. 다른 건물에 필요한 램프 모델 기능까지 삭제하지 않음.
- 기본 패널의 반복 설명문은 도움말로 이동. 필요한 범례·단위·자료 상태는 유지.

권장 화면 구성
상단: 건물 이름/작업 목록, 1 평면도 · 2 3D · 3 시뮬레이션, 저장 상태.

향후 3단계: 자연어 조건 입력, 적용된 조건 확인, 시간/위험 결과 표시. 현재 동작하는 기능처럼 전시하지 않음.

1. 홈 CAD 우선 정리, 상단/양옆 패널 및 중복 보기 제어 통합.
