# 공간별 기본 입력 수정 — 2026-11-08

닫힌 외부 창이 열린 실내 문을 가려 후속 화원 곡선을 0으로 만들던 문제를 수정했다. 유효 면적이 양수인 개구부를 선택하며, 최소 누기 가정은 연료 공급 상한으로 사용하지 않는다. 유효 개구부가 없을 때도 지정 연료 곡선은 유지하고 실제 연소의 산소 제한은 CFAST가 계산한다. 압력·산소 값을 강제로 보정하지 않는다.

CAD에 여러 용도 키워드가 섞이면 첫 정규식 일치로 화장실 등으로 단정하지 않는다. 기존 `default` 기준량을 **임시로** 적용하고 분류 확인 필요를 기록한다. 단일 화장실 분류 및 사용자 지정·기존 승인 분류는 유지한다. DA는 설비 샤프트 분류에 포함하며 실제 연료량은 여전히 확인 대상이다. 도면 추출과 공간 형상은 변경하지 않는다.

초기 화원의 공통 `alpha=0.047` 덮어쓰기를 제거하고 `fire_load_table.json`의 용도별 `t_alpha`로 `alpha=1000/t_alpha²`를 적용한다. 호텔·사무실은 300초 기준이다. 표에 출처가 없는 값은 프로젝트 임시값으로 표시한다. 총 연료 에너지의 곡선 적분과 분할 예산 보존은 유지한다. 피복률·개구부 공급 계수 등은 `config/physics_defaults.json`의 `source_input`에 기록한다.

단일 계산·MC·확정 급기 계산의 공통 CFAST 실행 경로에 입력 근거를 저장한다. 결과 화면에 성장 기준, 기계 급배기 미입력, 용도·연료량 확인 대상 수를 표시한다. 환기 미입력과 사용자가 명시한 0 ACH를 구분한다. 기존 결과에는 새 입력 적용 전 저장 결과임을 표시하며 저장 파일은 재작성하지 않는다.

입력 및 규칙 리비전을 올리고 실행 증거에 분류 코드·연료표·입력 생성 코드를 포함했다. 기존 결과를 새 기본값으로 계산된 캐시로 재사용하지 않는다. 위험 지수 공식 자체를 바꾼 작업은 아니다.

## 확인

- 25개 층 557개 공간 입력 재생성: 새 화원 곡선 413개, 양의 연료가 0 곡선으로 사라지는 사례 0건, 곡선 에너지 불일치 0건. 강화 3층의 기존 승인 용도는 보존.
- 호텔 5층 R6/R11: 닫힌 창 대신 열린 D7/D15 선택, 후속 화원 공급 곡선 최대 1.947/2.051 MW. 해당 실의 실제 착화 여부와 구분한다.
- 신규 Python 회귀검사 10개 통과: 열린 문·닫힌 창, 밀폐 입력, 에너지 보존, 혼합 용도, 사용자 지정 보존, 용도 성장률, MC 전달, 환기 미입력 구분, 실제 호텔 입력 연결.
- 전체 simulation: 332개 중 306 통과, 기존 자료 누락 오류 8, 제외 18. app: 112개 중 92 통과, 기존 자료 누락 오류 12개와 setUpClass 오류 1, 제외 8. 새 실패 0.
- UI 함수 검사 및 별도 브라우저의 결과 응답 대체 검사: 적용 성장률·총량·환기 근거 표시, 페이지 오류 0. 서버 결과 파일 수정·계산 시작 없음.
- 대표 CFAST 실행과 설치·보존 확인은 작업 산출물에 별도로 기록한다. 수치 검사 통과를 실제 가연물·설비 입력 검증 완료로 간주하지 않는다.

## 남는 입력 확인

혼합 공간의 실제 용도, 공장 적재량·재료, 물품별 발열 곡선, 설비 풍량 자료는 코드만으로 확정할 수 없다. 미확인 값은 임시값으로 남으며 실제 자료로 대조해야 한다. 높은 미연소 연료 축적 경고는 제거하지 않았다. 기존 CFAST 물리 타당성 검사와 자동 전술 제한도 유지한다.
