가스 점화 실감 보기와 계단실 예시 정정 — 2026-10-21

정정 이유
R25는 도면 OCR상 휴게실이다. 이전 점화 대상 R21은 이름이 비어 있어도
stair_inside 태그와 dedicated_room 코어 C3가 있는 계단실이다. 단일층 옵션에서
코어 분류를 생략해 일반실 고체 연료를 배정했던 것은 오류다. 이전 R21 점화 비교를
일반실 시연으로 사용하지 않는다. 이전 결과 파일은 추적용으로 보존한다.

입력 처리
cad.py는 수직 연결 실행 여부와 독립적으로 태그/실 이름/전용 core_nodes로 코어를
식별한다. ELEV.홀은 승강로로 분류하지 않는다. 코어에는 자동 2차 고체 연료군을
배정하지 않는다. 코어를 명시적으로 초기 화점으로 택하면 낮은 코어 연료 대용값을
사용한다(10 MJ/m2, 점유율1%, 100 kW/m2; 조사값/표준값 아님).
단일층 코어는 기존 단일층 존 근사를 사용하며 층간 흐름은 닫힌 경계로 제외한다。

시연 범위
R25 휴게실 → R15 ELEV.홀2 → R4 ELEV.홀3. 실제 CAD 문 연결 D5/D0를 유지한다.
R21 계단실을 제외하고 나머지 연결도 닫힌 절단 경계로 근사한 국부 시연이다.
R25 연료/공급 가산, 창/문 개방 시나리오는 기존의 명시적 가산 가정이다.
건물 실태 조사값이나 계단실 FGI의 불가능성을 뜻하지 않는다.

표시 계약
playback.Qbulk_kW는 실 상층 bulk_HRR_W만 사용한다. 문 제트 발열과 고체 HRR을
합친 Qgas나 위험 색으로 가스 화염을 켜지 않는다. 이전 Qbulk 없는 결과에는
가스 화염을 꾸며 넣지 않는다. 실감보기의 회색 연기/층 높이/OD를 유지한다.
위험 색은 연기층의 CAD 윤곽(상·하 경계선)과 바닥·텍스트에 남긴다.
연기 본체의 무늬·회색·불투명도 식은 기존 것을 그대로 유지한다. 연기 전체의 75% 보라/빨강 착색을 제거했다.
추가 가스 화염은 기존 CAD polygon과 구멍 마스크로 실 상층에 제한한다.
별도 바닥 화원/고체 착화 사건을 만들지 않는다. 저장된 bulk 발열이 없으면 꺼진다.
점화 가정 시각 이전으로 다음 출력의 불꽃을 보간하지 않는다. 자발 반응 시작 시각이
출력 사이에서 미확정이면 첫 양의 저장 시각 전에는 표시하지 않는다.
불꽃 무늬·밝기·흔들림·층 안의 분포는 표시용이다. 실제 점화점, 화염 전면,
전파 속도, 국부 온도, 폭압·폭연 강도를 계산하거나 입증하는 것이 아니다.
화염은 내부 관찰을 위한 겹침 표시이므로 벽/연기를 투과해 보일 수 있다.
화염 효과는 native 에너지·산소·그을음 계산에 되먹임하지 않는다.
온도·산소·연기 차이는 같은 시각의 기준/점화 가정 실제 계산 출력에서 읽는다.
화염을 보이게 하려고 연기 농도를 인위적으로 낮추지 않는다. 연기 투명도 옵션은
관찰용 표시만 바꾸고 계산 OD는 유지한다. 연기는 점화 후 증가/감소 모두 가능하다.

조작
저장된 예시 점화 비교 → FGI 가정 점화 재생(1배속, 3초 전 시작).
가스 점화 직전 / 가스 점화 5초 후 / 기준 계산·점화 가정 토글을 지원한다.
고체 화원 수와 가스 연소 실 수를 별도로 표시한다. 실 선택에 OCR 실 용도를 표시한다.
추가 GPU 부하는 실제 가스가 타는 실에만 기존 32단계 볼륨 메시 한 개이다.
NIST 원본 및 프로젝트 Fortran 확장을 변경하거나 엔진을 재빌드하지 않는다.
