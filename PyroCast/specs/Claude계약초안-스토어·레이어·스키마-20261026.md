## 1. 데이터 계약 (JSON Schema 초안, `app/contracts/`)

버전 필드 `schema: "pyrocast.<name>/1"`. 모든 ID는 문자열. 단위는 필드명에 고정(`_m`, `_C`, `_kW`, `_s`, `_massfrac`, `_volfrac`).

### 1.1 `building/1`
```json
{
  "schema": "pyrocast.building/1",
  "building_id": "str", "source_hash": "sha256",
  "units": {"length": "m", "origin": [0,0,0], "up": "z"},
  "floors": [{
    "floor_id": "str", "name": "str", "elevation_m": 0, "height_m": 0,
    "rooms": [{
      "room_id": "str", "name": "str", "usage": "str|null",
      "core_kind": "stair|elevator|shaft|lobby|corridor|null",
      "polygon_m": [[x,y],...], "holes_m": [[[x,y],...]],
      "floor_z_m": 0, "ceiling_z_m": 0,
      "cells": [{"cell_id": "str", "polygon_m": [[x,y],...]}]
    }],
    "openings": [{
      "opening_id": "str", "kind": "door|window|passage|vertical",
      "door_class": "fire_confirmed|fire_estimated|ordinary|fixed|null",
      "door_class_basis": "str|null", "user_override": "bool",
      "a": "room_id|OUTSIDE", "b": "room_id|OUTSIDE",
      "center_m": [x,y,z], "width_m": 0, "sill_m": 0, "soffit_m": 0,
      "exterior": "bool", "initial_fraction": 0
    }]
  }],
  "errors": [{"code": "UNMAPPED_CELL|DUPLICATE_ID|...", "ref": "str", "msg": "str"}]
}
```
- 셀→실은 `rooms[].cells[]`로만 표현. 실 수 = `rooms.length`, 셀 수는 별도.
- 매핑 실패는 **`errors`에 적고 데이터에서 뺀다**. 가까운 실로 붙이지 않는다.

### 1.2 `result/1` (재생용)
```json
{
  "schema": "pyrocast.result/1",
  "result_id": "str", "engine": {"kind": "lite|cfast", "version": "str", "sha256": "str"},
  "scenario": {"building_id": "str", "floor_id": "str", "origin_room_id": "str",
               "settings_snapshot": {}, "settings_hash": "sha256", "seed": "int|null",
               "opening_state": {"opening_id": 0.0}},
  "status": "complete|partial|failed", "t_end_s": 3600, "dt_out_s": 10,
  "limits_text": ["str"],
  "time_s": [0,10,...],
  "rooms": {"room_id": {
     "T_upper_C": [], "T_lower_C": [], "interface_m": [],
     "O2_upper_volfrac": [], "O2_lower_volfrac": [], "O2_basis": "layered|room_proxy",
     "fuel_upper_massfrac": [], "HRR_actual_kW": [], "HRR_supply_kW": [],
     "HRR_doorjet_kW": [], "HRR_upperburn_kW": [],
     "aggregation": "none|single"
  }},
  "cells": {"cell_id": {"room_id": "str", "...같은 필드..."}},
  "events": [{"t_s": 0, "kind": "ignition|supply_start|window_break|rule_trigger",
              "room_id": "str", "cell_id": "str|null", "parent_room_id": "str|null", "basis": "str"}],
  "conditions": {"room_id": {"t_index": {
     "smoke_stage": 0, "smoke_factors": ["hot","fuel","deep"],
     "FO": {"met": "bool|null", "degree": 0.0, "r_T": 0.0, "r_F": 0.0, "r_O": 0.0, "bottleneck": "T|F|O|null", "dominant": "T|F|O|null"},
     "FGI": {}, "backdraft": {}, "rollover": {"...": "", "burning_upper": "bool"},
     "untenable": {"met": "bool|null"}
  }}},
  "opening_risk": {"room_id": [[t0_s, t1_s], ...]},
  "boundary_rooms": ["room_id"], "fallback_sensors": ["room_id"]
}
```
- `met: null` = 미평가. 0이나 false로 채우지 않는다.
- 새 대표색을 계산하지 않는다. 기존 `color`·`rollover_band`는 `legacy_color`로 보존하고, 위험 레이어는 이를 포함한 **display_v8 호환 게이트**를 사용한다. `conditions.*.met`는 상세 패널용이며 표시 게이트를 대체하지 않는다(3단계 사용자 정정).
- 55 MB 파일 대비: `rooms`/`cells` 시계열은 지연 로드 가능하게 **메타(`time_s`, `events`, `conditions`)와 시계열을 분리된 파일로도** 허용(`result-meta.json` + `result-series.json`).

## 2. 스토어 (`app/web/state/store.js`, 순수 JS)

```js
// 단일 스토어. 슬라이스는 독립. 변경은 action으로만. 구독은 슬라이스 단위.
const state = {
  building: null,              // building/1
  result:   null,              // result/1 (meta); series는 별도 캐시
  screening: null,             // screening/1
  camera:   { mode: 'floor|all|top|room', target: null, pose: null },   // 층 변경이 바꾸지 않음
  selection:{ room_id: null, cell_id: null, source: 'list|click|touch' },
  floor:    { floor_id: null },                                           // 가시성만
  playback: { t_s: 0, playing: false, speed: 1, t_end_s: 0 },
  realView: { enabled: true, smokeOpacity: 1, temperatureSmoke: true },    // 3단계 실감보기 표시 설정
  layers:   { building: true, openings: true, core: true, smoke: true, flame: true,
              plume: true, risk: true, selection: true },                 // 서로 독립
  risk:     { show: { FO: true, FGI: true, backdraft: true, rollover: true, smoke: true } },
  jobs:     { active: null, queue: [], lastError: null },                 // 중복 실행 방지
  request:  { seq: 0 }                                                    // 늦은 응답 폐기
};
export const store = {
  get(slice),                      // 읽기 전용 스냅샷
  dispatch(action, payload),       // 'selection/set', 'playback/seek', 'floor/set', 'layers/toggle', ...
  subscribe(slice, fn) → unsubscribe,
};
```
규칙
- `floor/set`은 `floor`만 바꾼다. 카메라는 `camera/fit` 명시 액션만 움직인다.
- `result/load`는 `request.seq`를 올리고, 응답 도착 시 seq가 다르면 폐기.
- `jobs/start`는 `active`가 있으면 거부(순차 정책).
- 표시 액션(`layers/*`, `risk/*`)은 서버 호출을 일으키지 않는다(lint로 검사).
- legacy → 스토어 브리지는 `dispatch`만 호출, `get`은 금지(단방향).

## 3. 장면 호스트·레이어 (`app/web/scene/`, `app/web/layers/`)

### 3.1 레이어 계약
```js
export class Layer {
  static id = 'smoke';           // 고유
  mount(scene, store) {}         // 객체 생성·구독 등록. DOM 생성 금지
  setData(frame) {}              // frame = {building, resultMeta, series(t), t_s, selection, floor}
  setVisible(bool) {}
  tick(dt_s, clock_s) {}         // 선택. 호스트 루프만 호출
  dispose() {}                   // 구독 해제·GPU 해제. 호출 후 재사용 불가
}
```
- 레이어는 **다른 레이어를 참조하지 않는다.** 필요한 값은 frame으로 받는다.
- 레이어는 조건을 **재계산하지 않는다.** `conditions`를 읽어 표시만 한다.
- 셰이더·재질은 `legacy_real_view.js`에서 import. 복사·수정 금지.

3단계 smoke/flame/plume 이식 보충(2026-10-27): `realView/set`으로 enabled·smokeOpacity(0~1)·temperatureSmoke를 갱신한다. 호스트 frame은 layers·realView 및 prefers-reduced-motion 값을 제공한다. 원 playback은 별도 읽기 capability이며 result 어댑터로 다시 만들지 않는다. 세 레이어는 서로 참조하지 않고 단일 legacy 렌더 세션을 공유하며 smoke tick이 한 번만 update/animate한다. 호스트가 `#cfMeaning`을 제공하고 회수한다. 기존 모듈이 만드는 범례 DOM은 원본을 유지한다.

### 3.3 위험 레이어 — 사용자 정책 (유형별 중첩)
- FO·FGI·백드래프트·롤오버 **독립 리본 Mesh 4장**. 실 외곽(전체 폴리곤)을 사용하며 셀 내부 선을 만들지 않는다. 회색 주의·셀 외곽 점선·바닥 틴트·연기 경계면은 기존 코드의 별도 표시를 유지한다.
- 리본 높이: 활성 셀 중 최소 h를 사용해 `base=max(.16,min(height-.5,...activeHeights))`, `z=z_m+min(height-.04,base+i*.14)`. i는 FO·FGI·BD·롤오버 순. 리본 폭은 기존 .055/.04. **바닥+.02/.015 규칙은 폐기**.
- 표시 게이트: FO는 기존 color 빨강, FGI는 stage 2 및 Ou ≥ LOC, BD는 stage 2 및 Ou < LOC, 롤오버는 rollover_band. 기존 색 복원 경로도 보존하며 멤버 셀 OR로 방에 적용한다. 상세 조건표와 다를 수 있으며 이를 숨기지 않는다.
- 경계 점선은 기존 셀 외곽 표시의 boundary/gapSize 정책을 유지한다. 위험 리본이 켜진 방의 셀 점선은 숨긴다. 이 문서의 과거 '위험 리본도 모두 점선' 추정은 폐기한다.

### 3.4 호스트
- 캔버스·렌더러·루프 **하나**. `host.start()/stop()/dispose()`.
- 루프는 `clock` 객체를 받는다: 기본 `performance.now`, 시험 시 `{now(): fixed}` 주입 → 캡처 위상 고정.
- 리스너는 호스트가 등록·해제. `dispose()` 후 `window` 리스너 수 = mount 전과 동일(검사 항목).

## 4. 1·2단계 합격 검사 (실행 없음)

| 검사 | 방법 |
