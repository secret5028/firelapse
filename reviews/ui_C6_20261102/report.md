# C-6 단독 HTML 내보내기

구현 완료. 원 서버 종료 후 Chrome 정적 HTTP 자동 검증 통과. **file:// 직접 실행은 사용자가 Chrome에서 열어 정상 동작을 확인했다.** 자동 도구의 file:// 접근은 정책상 차단되어 두 검증의 주체를 구분한다. C-7은 진행하지 않는다.

## 기능과 포함 범위

- 결과 탭 `HTML 내보내기` → `GET /cfbt/lite/export/<case>`.
- 기존 운영 HTML/번들, Three.js 및 외부 표시 모듈 16개를 내장한다. import 경로만 Blob 모듈로 연결하며 셰이더 원본은 변경하지 않는다.
- 건물 JSON, 선택 playback, 실 용도 연료표, 문 분류 정정, 확정 급기, 경로 결과, 차량 위치, 선택 실·층·시각·표시·이력·카메라 상태를 gzip/base64로 내장한다. pako 2.1.0 inflate와 라이선스를 인라인 포함한다.
- S09만 포함한 결과 목록을 제공한다. 다른 MC 표본 전체, 원본 평면도 페이지, 새 계산은 포함하지 않는다. 이미 저장된 선별표·규칙 설정은 조회할 수 있다.
- 실행·문 정정·최악 적용/해제는 `보기 전용`으로 비활성화한다. 로컬 자료 조회만 허용하는 fetch 경계와 CSP `connect-src 'none'`을 함께 적용한다. 원 서버로 대체 요청하지 않는다.
- 경로·호스·이력·시간·표시 변경은 파일 안에서 작동한다. 서버 저장이나 시뮬레이션 실행은 없다.

**급기 확정은 ② 두 극단 설정보다 우선하므로, 모든 개구부를 확정하면 두 입력이 같아질 수 있다.**

이번 파일의 급기 스냅샷은 C-5에서 확정한 R3 MC S00의 69개구부이고, playback은 저장된 R2 S09 그대로다. 현재 설정을 S09에 소급 적용하거나 재계산한 결과로 표시하지 않는다.

50 MiB를 넘는 다운로드에서는 20초 선택 항목을 보여준다. 기본은 10초이며 자동 축소하지 않는다. 20초는 시계열만 간추리고 형상·이벤트·마지막 시각은 보존한다. 중간 최고값·짧은 조건 충족은 빠질 수 있음을 파일의 가정과 한계에 기록한다. 시각 1430초에서 직전 저장 표본 1420초를 읽는 것도 확인했다.
