# B-2 — 연기 색 램프 옵션

2026-10-28. B-2만 구현. 기준 커밋 `5d6df72`. 시뮬레이션 재계산 없음.

## 동작

표시 탭에 **연기 색: 현재 / 중성**을 추가했다. 기본값 현재.
- 현재: `uRampMode=0`, 기존 회색→노랑→빨강 계산식 그대로.
- 중성: `uRampMode=1`, 연기 RGB 세 채널을 같은 값으로 만든다. 표시 기준점은 20℃에서 밝기 0.70, 600℃ 이상에서 0.035이며 사이를 선형 보간한다. 이는 시각화용 색 매핑으로 물리적 연기 색 예측이 아니다.
- 중성의 온도 무늬는 회색 명암 변화다. ‘약하게’는 명암 무늬 진폭만 줄이고, ‘끔’은 온도에 따른 기본 회색 램프를 유지하면서 명암 무늬를 끈다.
- 온도·광학밀도·불투명도·층 높이·화염·플룸·위험 테두리 계산은 변경하지 않았다. 새 uniform은 `uRampMode` 하나뿐이다.
