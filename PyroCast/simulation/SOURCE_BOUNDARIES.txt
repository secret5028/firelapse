시뮬레이션 코드의 출처와 경계
2026-10-21

1. 원본 CFAST — vendor/cfast-7.7.7/
Source/*.f90는 공식 CFAST-7.7.7에서 고정한28개 원본 파일이다.
sources.json에 원본 URL과SHA256을 보관한다. 이 목록 자체의 해시도 tools/engine_sources.py에서 고정한다.
원본과 목록은 일반 기능 개발 중 수정하지 않는다. 버전 변경은 별도 명시적 작업으로 진행한다.
다운로드 도구는 누락 파일만 복구하며, 받은 바이트가 고정 해시와 다르면 저장하지 않는다.
이미 있는 원본이 수정돼 있으면 덮어쓰지 않고 중단한다.

2. 우리가 작성한 엔진 내부 확장 — extensions/cfbt/
fortran/declarations.inc : 추가 상태·게이트·파라미터 선언.
fortran/routines.inc     : 축적 미연가스 bulk 연소, 산소/연료 제한, 게이트와 별도 진단 출력.
hooks.py                : 원본의 어느 위치에 무엇을 연결하는지13개 연결점의ID·목적·문자열을 정의한다.
여기에는 CFAST 모듈 전체의 수동 복사본을 두지 않는다.
추가 수식/진단은 fortran/에서, 연결 위치 변경은 hooks.py에서 편집한다.

3. 우리가 작성한 외부 모델과 실행 연결 — pyrocast_cfbt/
아래 Python 파일은 전부 프로젝트 코드이며 원본 CFAST에 포함된 코드가 아니다.
native.py     : 실행 파일 호출, 완료 캐시, native CSV 읽기. 이름의native는 원본 코드라는 뜻이 아니다.
deck.py       : CFAST 입력 생성, 대표 화원과 유한 에너지의 설계 공급곡선.
model.py      : 사용자 설정·임계값·유효성 검사.
flashover.py  : FO 임계값 후 실 단위 연료 통합·공급 확대.
exposure.py   : 문 너머 기체/벽 복사 보완, 직접 화염 및 문 가스 연소 복사.
thermal.py    : 외부 대표 가연물 판의 열응답.
spread.py     : 고체 착화/FO 사건 선택·재실행·인과성 검사·연료 장부·현상 분류.
cad.py        : 기존 CAD 모델을 기체 구획과 가연물 후보에 연결.
playback.py   : 계산 결과를 기존3D에 전달할 데이터 생성.
viewer/       : 프로젝트의 표시·조작 코드. 계산 엔진 원본과 분리한다.
현재 Python 후처리는 확장 엔진의 진단 출력을 요구한다. 순정 바이너리만 넣으면 같은 전체 기능이 된다는 뜻은 아니다.

4. 생성물 — build/generated/cfbt/
tools/prepare_engine.py가 원본을 검증한 뒤28개 빌드 입력을 생성한다.
5개는 명시된 연결점이 들어간 원본 사본이고, 나머지23개는 원본 바이트와 같다.
생성물은 직접 편집하지 않는다. 다음 생성 때 원본과 확장 정의에서 다시 만든다.
MANIFEST.json : 원본 해시, 추가 코드 해시, 생성 파일별 역할과 연결점 목록.
CFAST_DIFF.patch : 원본과 합성본의 전체 차이.
이 폴더는 소스의 별도 진실 원천이 아니다. Git 제외 대상인 빌드 산출물이다.

5. 빌드 경로
python tools/build_engine.py baseline
  vendor 원본28개만 컴파일 → build/baseline/cfast-baseline.exe
python tools/build_engine.py cfbt
  원본 검증 → 합성 소스 자동 생성 → build/cfbt/cfast-cfbt.exe
baseline은 원본 비교용 빌드다. 프로젝트 전체 Python 기능의 순정 호환성까지 보장하는 명령은 아니다.
build.json에 실제 컴파일 파일·역할·해시·추가 코드와 실행 파일 해시를 기록한다.
원본 수정/해시 목록 변경/연결점 누락·중복이면 빌드를 중단한다.
예전 engine/의 임의 파일을 발견해 자동으로 override하던 선택 방식은 제거했다.

6. 기능 책임 구분
CFAST 원본: 두 층 기체의 질량·에너지·종 수지, 산소 제한 연소, 플룸 상관식,
             문/창/층간 유동, 원본 벽·기체층·화원 복사와 벽 열전도.
엔진 확장: 축적 미연가스 추가연소와 온도 게이트, 방향별 가스 연소/층별 유동 진단.
외부 확장: 설계 공급곡선, 가연물 후보·열응답·실간 복사 보완, 추가 착화/FO 전환과 사건 재실행.
사용자 임계값, FO 이후 공급 램프·HRRPUA 등은 프로젝트 설정이며 NIST 원본 상수로 표기하지 않는다.

7. 검증 명령
python tools/verify_engine_boundary.py
python -m unittest discover -s tests -p test_*.py -v

기존 실행 파일을 덮어쓰지 않는 별도 빌드/비교:
python tools/build_engine.py baseline --output-root build/engine-boundary-check
python tools/build_engine.py cfbt --output-root build/engine-boundary-check
python tools/verify_engine_boundary.py --build-root build/engine-boundary-check
python tests/check_engine_boundary.py

이번 정리는 모델 수식이나 입력 가정을 바꾸지 않았다.
이전 engine/의5개 생성본이 새 생성본과 바이트 단위로 같은 것을 확인하고 중복 파일을 제거했다.
기존 native/의 두 파일은 내용 변경 없이 fortran/으로 옮겼다.
별도 원본/확장 빌드와 기존 작은 FO 시험의 native 출력 비교를 확인한다.
기존 build/baseline, build/cfbt 바이너리와 그 과거 build.json은 당시 산출물로 보존했다.
따라서 그 과거 build.json의engine/ 경로는 역사 기록이며, 다음 재빌드부터 새 경계를 기록한다.
기존 CAD30분 결과·과거 검토ZIP·운영3D를 새 결과로 덮어쓰지 않는다.
