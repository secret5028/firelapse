# B3 발열량 기준 불꽃 구현 및 검증

2026-11-02. B-3 구현 완료. 기본은 `growth`를 유지하며 표시 탭에서 `hrr`를 선택한다. 계산 엔진과 저장 결과는 변경하지 않았다. 한 커밋으로 보관하고 다음 단계는 진행하지 않는다.

## 구현

- HRRPUA는 `GET /cfbt/lite/fire-load-table`로 `simulation/pyrocast_lite/fire_load_table.json` 원본을 직접 읽는다. 별도 상수표 없음. 승인 용도 키 또는 승인 용도 표시명으로 원본 `classes`를 찾고 `rhrf`를 사용한다. 용도를 찾지 못하거나 유효한 값이 없을 때만 500 kW/m²를 적용한다. HTTP 실패를 500 기본값으로 숨기지 않는다.
- 서버 변경은 승인된 GET 3줄뿐이다. 요청 IP가 127.0.0.1인지 검사하고 파일 바이트를 그대로 반환한다. 계산·캐시·저장 로직 불변. JSON 자체도 변경하지 않았다.
- `A=min(셀 면적,Q/HRRPUA)`, `D=2√(A/π)`. HRR 모드에는 기존 65% 피복 규칙을 적용하지 않는다.
- 높이는 기존 플룸의 `CfastPlumeMath.flame`을 그대로 공유한다. 식을 복제하지 않았다. 0.1 m 하한, 천장 아래 0.1 m 상한, 기존 ±6% 맥동을 적용한다.
- HRR 모드의 배열은 화원 ID 해시로 간격 0.5~1.1W, 위치 흔들림 ±0.4 간격을 결정한다. 같은 입력과 clock이면 같은 모양이다. CAD 마스크와 renderOrder 20 유지.
- 색·성장 단계는 해당 화원의 실제 HRR/자기 최고값 비율을 유지한다. HRR 모드에서는 기존 조명 3개를 매 프레임 실제 HRR 상위 3화원에 배정한다. 밝기식 유지.
- 기본 픽셀 동일성을 위해 새로운 배열·조명 배정은 HRR 모드에만 적용한다. growth로 돌아오면 기존 표시로 복귀한다.
- 불꽃 면적·높이·맥동은 표시용 근사이며 실제 연소 전선이나 추가 착화 계산으로 되먹임하지 않는다. 모양이 실제 화염 형상을 재현한다는 뜻은 아니다.
