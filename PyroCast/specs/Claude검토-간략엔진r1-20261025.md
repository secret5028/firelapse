## 3. 보존식·수치 갱신 (질문 가·나·다)

**가. 압력** — 새 식 불필요. fire_zone.py의 `dP/dt = (γ−1)/V·(h_u+h_l)`을 그대로 두고 BDF가 적분한다. 밀폐 성분은 r8 덱과 같은 `LEAK_AREA_RATIO`(이미 CFAST 입력에 있음, 0.00017·0.000052)를 **공유 입력**으로 쓴다. "임의 누설"이 아니라 정밀 모드와 같은 값이다. 외기 연결이 전혀 없는 성분이 생기면 입력 오류로 거부한다.

**나. 산소 부족 반응 최소식** — 재고 하나를 순서대로 배분한다. 각 단계에서:
```
ξ_fire = min( ṁ_supply,  ṁ_ent·Y_O2,lower / s )           # 화원: 하층 공기만 사용
잉여   = ṁ_supply − ξ_fire  → 상층 연료 장부
ξ_upper = min( m_f,u / τ,  m_O2,u / (s·τ) ) · g(T_u)        # 상층: τ = 20 s [가정], g = tanh 램프(LOL 0.12~0.15)
개구부로 나간 연료 → 받는 실 상층 장부에 추가, 그 실에서 같은 식 적용
```
- 발열 = Hc·ξ, O₂ 소비 = s·ξ, 수율은 같은 ξ에 비례. 한 ξ로 질량·산소·에너지를 함께 움직이므로 중복이 없다.
- 상층 반응을 상태 함수(장부/τ)로 정의하므로 솔버 시도 간격과 무관하다. Arrhenius·CO 재연소는 넣지 않는다(설계안과 같음).
- 음수 재고 방지는 ξ의 min 구조가 보장한다. 자르기(clip) 금지는 그대로 유효하다.

**다. 판 센서 최소식** — 판 1개를 열용량 노드 1개로 둔다.
```
ρcδ · dT_p/dt = h(T_g,local − T_p) + ε(q_in − σT_p⁴)        # 앞면
T_g,local: PC = 판이 놓인 층의 온도(r6a 배치가 천장 제트 밖이므로 층 평균이 맞음 [사실, A시험 차이 5.5 ℃])
           FC = max(층 평균, Alpert 천장 제트 T_cj) ; q_in에 점원 복사 χ_r·Q/(4πr²) 추가
```
- 시간상수: 1 mm 강판 ≈ 20~30 s, 0.1 mm 저방사율 판 ≈ 15 s **[추론]**. 1 s 이하 단계가 필요한 강성은 아니지만, BDF 안의 상태 변수로 넣으면 별도 처리가 필요 없다.
- 기준 통과는 `events`로 잡는다. 엄격한 초과(>)는 이벤트 방향(`direction=+1`)으로 표현한다.

## 5. 최소 구현·합격 기준

| 단계 | 내용 | 합격 | 중단 |
|---|---|---|---|
| L0 | fire_zone.py를 `pyrocast_lite/core.py`로 복사(원본 불변). 자체 열분해 전이 OFF 옵션. 기존 입력으로 1회 실행 | 이전 기록과 같은 결과·시간(5~12 s) | 실행 실패 |
| L1 | `contract.py`: r8 `prepare()` manifest(실·셀·개구부·화원·센서·설정)를 읽어 모델 생성. 수치 복사 없음 | B1~B3·3F manifest 로드, 부모·지연·공급 곡선이 r8과 바이트 동일 | 불일치 |
| L2 | `sensors.py`+`events.py`: PC·FC 상태, 기준 이벤트, 지연 후 공급 시작, 셀 간 300 ℃ 규칙 | B1 전이 없음. B2·B3 전이 실에서 실제 HRR>0 60 s 이상 | B1 추가 착화 |
| L3 | 상층 τ 반응 최소식 | 질량·에너지 누적 잔차 ≤ 0.1 %(장부 검사) | 초과 |
| L4 | 3F 표준 1회. r8 표준(`room_rule_r8_20261025`)과 비교 | **연소 실 집합 일치**, 착화 순서 일치, 시각 차이 보고. 경계 사례(PC_R2_C1 589.8 ℃)의 통과 여부 보고. 실행 시간 보고 | 집합 불일치 시 원인 보고 후 정지(기준 조정 금지) |
| L5 | `sampling.py`: 종류별 열림 확률(기본) / `fixed_count`(옵션), seed 고정. 3F 20표본 | 표본당 시간·실패율 보고 | 실패율 > 10 % |

- L4가 **간략 엔진을 탐색에 쓸 수 있는지 판정하는 관문**이다. 여기서 연소 실 집합이 다르면 그 차이의 원인(온도 근사, 유동, 반응)을 보고하고 사용자가 판단한다.
- 설계안 11절의 1 s/0.5 s 비교는 BDF 사용 시 `rtol` 1e-4/1e-5 비교로 대체한다.
- 성능은 L4·L5에서 전처리·적분·후처리를 따로 측정한다. 배수 약속 없음(설계안과 같음).

## 6. 질문 마·바 답

- **마.** 기본은 종류별 열림 확률로 바꾼다(2절 #4). 두 방식을 같은 % UI에 섞지 않는다는 설계안 지적은 맞다. "개방 시 위험 구간"의 주장 범위(조건 구간 표시, 중간 개방 개입은 미계산)는 적절하다.
- **바.** 검증 문턱(누적 발열 5 %, 잔차 0.1 %)은 적절하다. 다만 결정적인 문턱은 **L4의 연소 실 집합 일치**다. 평균 오차가 작아도 집합이 다르면 탐색에 쓸 수 없다. 점수·고립은 미구현으로 표시한다(설계안과 같음).
