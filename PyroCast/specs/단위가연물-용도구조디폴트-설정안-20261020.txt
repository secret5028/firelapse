단위 가연물·용도/구조별 디폴트 설정안
2026-10-20 / 상태: 검토 제안, 미적용

이번 작업 범위
- 사용자 요청에 따라 값과 구현 방향만 정리한다. 실행 코드·시나리오·기존 결과·현재3D 화면은 수정하지 않았고 화재 계산도 실행하지 않았다.
- CAD/OCR로 추출·추론할 수 있는 정보 외에는 건물 용도, 실 용도, 구조 형식별 대표 디폴트를 사용한다. 추가 실측자료 제공을 필수 조건으로 두지 않는다.
- 전 구획 최초 화점 탐색은 기존 간편 계산식으로 유지한다. 이 제안은 연료 배분·착화/확산과 선택 조건의 CFBT/CFAST 연결에 관한 것이다.

1. 권장안
일정한 크기와 에너지의 가정 연료 단위를 공간에 분산하고, 용도에 따라 단위 수와 간격을 바꾼다.
단위별로 미착화/가열/착화/연료 방출/잔량을 관리한다. 한 단위가 착화했다고 실 전체 연료의 성장 곡선을 시작시키지 않는다.
가스 계산 구획은 기존 실 단위를 유지한다. 가연물 단위마다 가스 구획을 만들지 않는다.
CFAST 전달용 대표 화원과 단위별 연료 장부를 구분한다. 가까운 연소 단위를 묶을 수 있지만 총HRR만 합쳤다고 플룸·복사·유동까지 동일해지는 것은 아니다.
균등 배치는 기본 대리 배치다. 실제 배치를 복원했다는 뜻으로 표시하지 않는다.

2. 정보 적용 순서와 근거 표기
우선순위: 명시적 CAD/DXF 문자·OCR/객체 → 여러 단서가 일치하는 용도/구조 추론 → 대표 디폴트 → 사용자 수정.
각 값에 value/unit/source/evidence_status/confidence/override를 둔다.
evidence_status: drawing_explicit / inferred / default_assumed / user_override / conflicting.
상위 근거가 들어오면 해당 항목만 교체한다. 근거가 약한 한 항목 때문에 전체 건물을 덮어쓰지 않는다.
OCR의 '화','갑' 같은 문/방화 표기는 실 용도나 가연물 종류로 해석하지 않는다.
철골 기둥이라는 정보만으로 외벽·칸막이·천장 재료를 확정하지 않는다. 골조/벽체/마감은 별도 속성이다.

현재 자료의 주의점
- 현행 건물 데이터는 전체 office,2~4층 factory 등으로 분류돼 있으나 분류의 근거 수준을 따로 관리해야 한다.
- R2(약325㎡) 안에 'ELEV.홀 1', 'Assembly Line', '우레탄/W' 등의 표기가 함께 있다. 전체를 빈 홀로 낮추면 안 된다.
- R1은 'RF생산라인', R8은 'A/S실', R9는 '공작실/설비보관실', R23은 '우레탄/W/교육장' 등 혼합·충돌 표기가 있다.
- 원본 DXF 텍스트 확인에서 실내재료마감표/상세도 참조 주기는 찾았으나 이번 자료에서 실제 벽체 적층 구성은 확인하지 못했다. 캐노피 철골 부재 주기는 건물 전체 철골 구조의 증거로 쓰지 않는다.
- R2/R23은 가스 구획을 곧바로 쪼개기보다 내부 연료 용도 영역을 먼저 나눈다. 문자 위치·공간 연결·작업대/기계 블록·통행 영역을 이용한 추정 영역이다. 영역이 결정되지 않으면 혼합/미확인으로 표시하고 용도별 대안을 비교한다.

3. 단위 가연물의 시작 값 — 프로젝트 탐색 디폴트
아래 단위 크기·에너지·HRR 값은 특정 NIST 실험체나 법정 표준의 복제가 아니다. 사용자 조절이 가능한 최초 비교용 설정이다.
- 평면 크기:1.0m×1.0m.
- 표시 높이:0.76m. 빈 공간이 있는 가구/적재물의 대리 외형이며 통나무1㎥로 취급하지 않는다.
- 단위 총에너지:1000MJ(1GJ).
- 현재 유효 발열량18.1MJ/kg을 쓰면 약55kg의 열량 상당량이다. 실물 중량이나 목재100%라는 뜻은 아니다.
- 단위 HRR 상한의 시작 값:500kW. 중간 성장률 alpha=0.0111kW/s², 에너지70%까지 성장/유지 후 나머지30% 선형 감쇠를 비교용 곡선으로 사용한다.
- 한 단위의 설계 HRR 시간적분은 해당 단위 에너지와 일치시킨다. 피크·성장률·총량은 서로 다른 설정이다.
- 단위의 상면0.76m와 노출되는 측면 중앙0.38m를 가열 후보로 삼을 수 있다. 동일 단위의 여러 면이 조건을 넘어도 연료는 한 번만 활성화한다.
- 착화 면 좌표·화원 기부·3D 표시를 같은 좌표/높이로 연결한다.
- 재질은 목재/서류 혼합, 플라스틱/수지, 포장재 등의 라이브러리를 분리한다. 단위 외형이 같다고 착화 열특성·그을음·유효 조성을 동일하다고 가정하지 않는다.
- 가스 온도·산소·고체 착화 임계값은 별도의 사용자 설정이다. 배치 비교 중 이 값까지 동시에 바꾸지 않는다. 기존45℃ 조건은 기능 시험 이름으로 보존한다.

4. 용도별 에너지 밀도 시작 값
아래에서420MJ/㎡의 사무실 평균은 문헌값이다. 나머지 낮은/높은 탐색값은 현장 미확인 상태에서 쓰는 프로젝트 디폴트이며 표준에서 정한 수치라고 표시하지 않는다.

도면에서 실 용도가 갈리는 경우 하나의 평균값으로 조용히 덮어쓰지 않는다. 예: R23의 교육장과 수지 작업장은 다른 경우다.
세부 내용물이 확인되면 Q=sum(m_i*H_i) 또는 문헌/실험 패키지 총에너지로 위 면적 디폴트를 대체한다. 기존 면적 예산에 다시 더하지 않는다.
건물 전체 용도는 실 용도가 없을 때만 하위 근거로 쓴다.

5. 균등 배치 및 문 앞/실 내부 구분
- Q_zone=q_zone*A_reference. 에너지 밀도가 어떤 바닥면적을 기준으로 한 값인지 명시한다.
- 목표 단위 수는 Q_zone/1000MJ. 정수 단위 뒤의 잔여 에너지는 마지막 부분 충전 단위에 배정한다. 반올림으로 에너지를 추가하지 않는다.
- 단순 정사각 배치의 간격 시작값 d=sqrt(1000/q) m.
  20MJ/㎡→약7.1m,100→3.2m,150→2.6m,420→1.5m,500→1.4m.
- 실제 배치는 해당 CAD 연료 영역 안으로 제한하고, 벽·기둥·구멍·문 회전 영역·도면상 통행 경로를 제외한다.
- 도면에서 통행 폭을 못 읽으면 문 앞1m의 비적재 띠를 배치용 가정으로 둔다. 법정 피난 폭 판정을 대신하지 않는다. 문 회전 형상이 있으면 그 형상을 우선한다.
- 문 앞 연료는 별도의 고정 비율이나 추가 예산이 아니다. 배치된 단위 중 문 앞 비적재 띠 바깥, 개구부와 보이는 가까운 영역(시작 범위0.5~2.5m)에 있는 단위를 분류한 것이다.
- 문 가까이에 가연물이 없으면 문 앞 착화 후보도 만들지 않는다. 먼 실 내부 단위는 가열 조건을 따로 본다.
- 문 앞 영역끼리 겹치면 단위 ID를 공유한다. 두 문이 같은 연료를 각각 소비하지 않는다.
- 통로 제외 때문에 목표 수량이 안 들어가면 중복/겹침 배치하거나 총량을 몰래 줄이지 않는다. 배치 불가를 알리고 별도 적재/단위 크기/용도 설정으로 해결한다.
- 다른 배치끼리 비교할 때 총에너지·재질·성장 곡선은 고정한다.
- 가볍게 비교할 배치3개: 균등 / 격자 반칸 이동 / 동일 수량을 통행 경로 바깥의 문 근처·벽쪽에 편중.
  반칸 이동은 문과 격자의 우연한 맞물림을 확인하고, 편중은 배치 민감도를 본다. 세 경우로 전역 최악을 보장하지 않는다.

6. 계산 편의성과 공간 유사성의 절충
권장: 단위별 연료 장부 + 가까운 단위의 소수 대표 화원.
- 가스 공간은 기존 실/상하층을 유지한다. 단위 개수만큼 기체 구획을 만들지 않는다.
- 배치는 여러 단위로 표현하되 native 대표 화원은 실당2~4개 군집을 시작 목표로 한다. 문 앞/실 내부 구역이 기본이고 서로 먼 군집은 분리한다.
- Q_group(t)=sum(Q_unit(t-t_ign,unit)). 아직 착화하지 않은 단위는 합산하지 않는다. 대표 화원 하나의 활성화가 군집 전량의 동시 착화를 뜻하지 않게 한다.
- 각 단위의 열노출/재질/잔량은 외부 모듈이 관리하고, native에는 활성 단위의 합산 연료 공급·HRR·면적을 전달하는 설계가 필요하다. 현재 코드에는 이 단위 모델이 구현돼 있지 않다.
- 군집 좌표를 미래의 연소 상태에 맞춰 과거까지 소급 이동하면 착화 전 결과가 달라진다. 대표 위치는 사전 고정하거나 첫 활성 단위에 고정하며 변경이 필요한 원거리 단위는 별도 군집으로 둔다.
- 대표 화원 집계는 전체 HRR/연료 수지 보존을 목표로 한 공간 근사다. 독립 플룸의 유동·복사가 정확히 같아지는 것은 아니다. CFAST도 다중 플룸 상호작용을 상세하게 풀지 않는다.
- 지금의 '단위 하나 추가할 때마다0초부터 재실행'을 수백 단위에 그대로 적용하면 느려진다. 화원 수 축소만으로 이 문제가 해결되지는 않는다.
- 가벼운 첫 구현은 문 앞/실내의 작은 군집 수준에서 사건을 확정하고, 그보다 세밀한 단위 순차 연소는 별도의 연료 상태/결합 방식으로 단계적으로 추가한다. 단위 수만 늘린 재실행 루프는 권장하지 않는다.
- 실행 횟수를 줄이려고 가까운 시각의 사건을 임의로 동시에 확정하지 않는다. 후속 발열이 더 이른 착화를 만드는지 원인 일관성 확인이 필요하다.
- 속도나 실제 유사성이 확보됐다고 미리 선언하지 않는다. 같은 총량의2군집/4군집 결과 차이와 기존14실 조건의 실행 시간을 나중에 확인한다.

7. 벽체 디폴트 선택 규칙
구조와 용도별로 '바닥/천장,외벽,실내 칸막이'를 따로 정한다. 도면의 단면·마감 주기·재료명·두께가 있으면 그 값이 우선이다.
아래 두께/구성은 프로젝트 대표 구성이다. 법규가 정한 단일 표준값이나 해당 건물에서 확인한 구성으로 표시하지 않는다.

골조별 기본값은 선택용 규칙이다. 예: 철골 건물에도 콘크리트 외벽이 있을 수 있고 RC 건물에도 경량 칸막이가 있을 수 있다.
실제 슬래브/천장 높이·플리넘/마감 두께는 CAD/OCR 정보가 있을 때 따로 적용한다. 현재3F의ceil_rule.ceiling=false는 모델 표시/분류 정보이며, 그 자체로 재료가 불연 또는 노출 콘크리트라는 증거로 쓰지 않는다.

8. 열물성 대표값과 다층 벽체 취급
콘크리트 기준 프로필(기존 CFAST 예제와 동일):
  k=1.75W/(m K),rho=2200kg/㎥,cp=1.0kJ/(kg K),두께0.15m,방사율0.94.
석고보드 비교 프로필(공식 CFAST ATF 검증 입력의 특정 재료):
  k=0.13W/(m K),rho=930kg/㎥,cp=1.09kJ/(kg K),두께0.017m,방사율0.90.
  이17mm는 표면 보드 재료 예제다. 스터드·공기층을 포함한 실제 칸막이 전체와 동일하지 않다.
철골 단열패널 대표 구성의 출발점:
  강판0.5mm/단열심재100mm/강판0.5mm. 구성 두께는 프로젝트 가정이다.
  강판 물성 예제 k=48,rho=7854,cp=0.559; 유리섬유 단열 물성 예제 k=0.036,rho=105,cp=0.795(단위는 위와 동일).
  위 심재는 열조건을 위한 불연 단열 대표재다. 실제 심재가 미확인인데 EPS/PUR가 없다고 확정하지 않는다. 가연성 심재/마감이 식별되면 연료·연기 속성도 별도 처리한다.

CFAST 현행 연결은 단층 WALL 재료 하나를 모든 면에 넣는다. 재료 표면별 선택과 실제 면적에 맞는 공유벽 연결이 추가돼야 위 구분을 반영할 수 있다.
등가 단층으로 줄일 때 최소한 R=sum(L/k), C_A=sum(rho*cp*L)를 함께 맞춘다. 열저항만 맞추거나 k만 산술평균하지 않는다.
R/C가 같아도 층 순서와 초기 표면 열흡수까지 일치하지는 않는다. 다층 응답을 검증하기 전에는 '다층 벽체 재현'이라고 표시하지 않는다. 30분 탐색용 등가 프로필로 분리한다.
가능하면 기존 native의1차원 전도 해법/공유벽 연결을 이용하고, 다층 열모델을 무조건 새로 크게 만들지는 않는다.
모델 안에 있는 인접실 사이 벽은 상대 실의 열환경에 연결한다. 모든 내부 벽 뒤를 외기20℃로 간주하지 않는다. 미계산 인접 공간은 온도 경계 가정임을 남긴다.
완전 단열은 기본값에서 제외하고 열손실0의 별도 한계 비교 조건으로만 둔다.
