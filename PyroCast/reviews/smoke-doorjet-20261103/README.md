## 수정

- 완도 외장 Mesh/Line 렌더 순서 11/12 → 8/9. 연기 10보다 먼저 합성한다. 외장 불투명도와 연기 기본값은 유지했다.
- 기존 HRR 불꽃 볼륨·Heskestad 함수를 재사용해 개구부에서 수신 실 방향으로 회전시킨 분출 화염을 추가했다. 수평 길이는 Heskestad 길이에 기존 ±6% 맥동을 적용한다. 수신 실 폴리곤 마스크로 잘라 다른 실로 넘어가지 않게 한다. 색은 기존 성장 단계 색을 사용한다.
- CAVITY의 PU 화원은 일반 불꽃·연료 기호·플룸 대신 공동 폴리곤 수직 벽의 주황 emissive 표시로 바꿨다. 실제 PU HRR이 0이면 꺼진다.
- 화염 토글은 기존 불꽃·분출 화염·공동 발광을 함께 제어한다. 계산·조건표·전이·물리 시계열은 변경하지 않았다.

### 분출 발열량 연결

3F는 저장된 방향별 개구부 HRR을 그대로 사용한다. 완도 순정 CSV는 수신 실 DJET 합계만 제공하므로, 저장된 상층 유출 유량 비율로 개구부에 나눈 **표시용 배분**이다. 상층 유출이 없으면 전체 유출 비율을 쓴다. 개구부별 실제 연소량 예측으로 표시하지 않는다. 양의 DJET에 대응하는 유출 경로가 없으면 내보내기를 실패시켜 임의 배분을 막는다.

수평 Heskestad 적용, 개구부 중심 배치 및 HRR 기반 단면은 표시용 근사다. 실제 분출 속도·화염 궤적 계산은 아니다. 완도 개구부별 배분값은 엔진 열·산소 장부에 되먹이지 않는다.
