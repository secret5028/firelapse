# C-9 — radial 옵션 및 S09 1시간 단일 실행

완료 범위: radial 입력 분할, 캐시 키, S09 R2 3600초 **실제 적분 1회**, 비교 캡처·시계열. 기본값은 **legacy 유지**. 추가 시나리오·재실행·기준 조정 없음. Push 없음.

## 결과

| 항목 | legacy S09 저장 결과 | radial 6 / 12 m |
|---|---:|---:|
| 적분 시간 | 557.20 s | 10.76 s |
| 전처리 | 과거 기록 분리 불가 | 0.084 s |
| 후처리 | 과거 기록 분리 불가 | 3.858 s |
| 총 기록 시간 | 564.07 s | 16.17 s |
| 계산 종료 시각 | 3600 s | 3600 s |
| 연소한 원래 방 | R1, R2, R7, R9, R23 — 5실 | R2 — 1실 |
| 추가 착화 | 있음 | 0건 |
| 전체 계산 셀 수 | 38 | 38 |

적분 기준 약 51.76배 차이다. **저장된 과거 시간과 이번 1회 시간의 비교이며 같은 결과를 유지한 성능 개선이 아니다.** 재실행으로 legacy 시간을 새로 측정하지 않았다. radial은 추가 착화가 없어 연소 부하가 훨씬 작다. 총 시간은 결과 저장·요약까지이며, 별도 playback 내보내기·캡처 시간은 제외한다.

## 실 집합 관문

기존 관문 `tools/run_lite_l1c.py:gate()`의 저장 CFAST 결과 사용. 공통 관찰 구간은 **0~2850 s**다.

| 집합 | 원래 방 |
|---|---|
| CFAST 표준 | R2 |
| lite radial | R2 |
| CFAST 공격, 2850 s까지 부분 결과 | R1, R2, R6, R7, R8, R9, R11, R23 |

`표준 ⊆ radial ⊆ 공격` **참조 집합 포함관계 통과**. radial의 3600 s 전체도 R2뿐이다. 다만 공격 CFAST가 미완료이고, 저장 CFAST 입력과 S09 MC 개폐 조합은 다르다. **동일 입력의 1시간 CFAST 비교 합격으로 확대 해석할 수 없다.** 새 CFAST는 실행하지 않았다.

## 셀과 전이 정지

| 셀 | 면적 m² | 최고 상층 ℃ | 최고 시각 s | 1420 s 상층 ℃ |

| 화점 R2_RAD0 | 34.739 | 294.23 | 940 | 208.90 |
| 중간 R2_RAD1 | 116.477 | 243.82 | 950 | 182.87 |

화점 셀이 300℃를 넘지 않아 중간 셀 착화 이벤트가 없었다. 최초 화원 peak는 원래 40,634.225 kW 곡선에 면적 비율 0.106864를 적용한 **4,342.341 kW**다(legacy 초기 셀은 1/3인 13,544.742 kW). 전체 R2 연료 예산은 보존되고 나머지 연료는 대기 셀에 남는다.

화점의 CAD 위치는 `[57.67,53.34536796564403]`이다. 해당 위치 주변 방 형상이 좁아 r1 원 전체보다 실제 교집합이 작다. 분할로 초기 공급 몫·열 교환 경계·개구부의 소속 셀이 달라진다. 낮아진 온도의 기여 요인을 별도 실행으로 분리하지 않았으며, 기준·반경을 결과에 맞춰 조정하지 않았다.

가상 경계 폭: 화점–중간 10.166 m, 중간–외곽 27.111 m, 높이 각 3 m. 기존 거리/0.05 규칙 지연은 각각 167.491 s, 143.314 s다. 조건 자체가 미충족하므로 이 지연 이후의 공급은 시작하지 않았다.

## 구현·가정

- `pyrocast_lite/radial_cells.py`가 실제 CAD 폴리곤과 24각 원을 교차한다. 구멍 보존, 20㎡ 미만 외곽→중간→화점 병합. 초기 대공간만 적용.
- `room_rule_r7/r8.prepare()`에 선택적 partitioner 인자만 추가했다. 기본 호출 경로의 모델·manifest·contract는 수정 전과 구조적으로 동일함을 확인했다.
- 공통 입력 컴파일에는 면적이 같은 사각 대용 박스를 사용하고, lite 체적·벽/누설 면적 입력은 실제 셀 면적·둘레를 사용한다. 연소·산소·유동·열손실의 식, 조건표, 전이 임계값과 속도는 변경하지 않았다.
- 화점 셀 중심은 화점, 나머지는 도심이 내부이면 도심, 아니면 내부 대표점이다. 이 좌표로 기존 셀 간 거리 규칙을 적용한다. 고리가 여러 조각으로 나뉘어도 한 존으로 취급한다.
- 실제 문·창은 CAD 중심점에 가장 가까운 셀에 전체 폭을 배정한다. 개구부가 셀 경계를 걸치는 경우의 분산 유입은 해석하지 않는다. 전체 폭은 보존한다.
- 기존 벽 열손실 모델에 폴리곤 둘레를 넣으므로 가상 경계도 벽 면적에 포함하는 기존 근사가 남는다. 원형 분할의 둘레 증가가 손실에 영향을 줄 수 있다. 별도 물리 모델 개선은 하지 않았다.
- playback만 실제 radial 폴리곤을 넘긴다. 레이어·셰이더·서버 수정 없음. 승인 용도 메타데이터는 기존 게시 방식대로 전달해 불꽃 HRRPUA가 같은 용도표를 읽게 했다.
- `cell_mode`, `radial_r1_m`, `radial_r2_m`과 전체 입력·파라미터·계산 소스 해시가 캐시 키에 포함된다. legacy 저장 파일은 덮어쓰지 않는다. 새 UI 선택기는 이번 범위에 없다.

## 검증과 산출물

- legacy 기본 prepare의 모델·manifest·contract 일치, 비화점실 셀 일치.
- 체적 5832.000635㎥, 연료 에너지 보존, 실제 개구부 69개의 원래 폭 보존. 폴리곤 합집합·비중첩·구멍·작은 셀 병합 검사 통과.
- mode/r1/r2 변경 시 키 구분. 동일 명령 재호출은 `CACHE HIT 237010a6…`이며 추가 적분 0회.
- 실제 적분 BDF 1회, 537 accepted steps, 1507 RHS 평가, 실패 없음. 임계값·솔버·출력 간격 변경 없음.
- 온도·산소 원시값을 변경하지 않고 승인 용도 표기만 추가한 뒤 최종 캡처했다. 두 캡처는 카메라 동일, clock 180000 ms, 시각 1420 s, 캔버스 595×700, C8 기본 옵션 동일. 브라우저 오류 0.
- 코어 적분·조건·전이 그래프·레이어·셰이더·서버 등 확인 대상 23파일 SHA 불변. 변경된 공통 파일은 입력 분할 인자 전달 2파일, 간략 어댑터·누설 기하 입력·playback 어댑터다.
