## 경로·이력·오프라인

- 기본 차량: 외부 문 `CAD_1F_D3` 중심 `[17.5,39.803,5.1]`에서 바깥쪽 5m, 차량 `[17.5,34.803,5.1]`. R3 경로 57.960678 m, 계단 계수 1.5, 호스 15m.
- R3 전 구간 최악: FO 141 @05:50, FGI 51 @09:00, 백드래프트 143 @06:50, 롤오버 40 @08:30. 실선은 현재, 점선은 전 구간 최대라는 기존 정의 유지.
- 내보낸 파일은 새 R3 확정 급기 결과 `case-2f22eacb07e6e588bdd2`다. 건물·번들·playback·문 정정·확정 급기·차량·경로와 현재 표시 설정을 포함한다.
- 운영 8780 포트를 닫은 상태에서 8823 정적 서버로 열었다. `file://` 검증으로 표현하지 않는다. 이후 임시 정적 서버는 종료하고 운영 서버를 복원했다.
