CAD 벽·문·창·실 추출 + 소방도면 보조 판정 (2026-10-14 v2)

진입점
  단일층: cad_pipeline.py
  건물 전체: run_building.py
  최종 평면 → 3D: cad_build3d.py

환경
  Python 3.12에서 확인.
  python -m pip install -r requirements-extraction.txt
  DWG는 별도의 dwg2dxf 변환기가 필요. DXF는 직접 입력 가능.

단일층 실행
  python cad_pipeline.py "층.dxf" "새출력폴더" --floor 4F
  python cad_pipeline.py "층.dwg" "새출력폴더" --floor 4F --dwg2dxf "변환기경로"

기존 소방도면 추출물을 함께 쓰는 실행
  python cad_pipeline.py "층.dxf" "새출력폴더" --floor 4F --fire-json "기존/4F_fire.json" --fire-reference-plan "기존/4F.json"
  --fire-json의 symbols는 건축 도면 좌표계(m)로 이미 정렬된 심볼이어야 함.
  동일 층의 기준 평면과 기존 정렬 근거를 비교. 미확인 시 표시만 하고 자동 재분류하지 않음.
  소방 원본에서 새 심볼을 추출하려면 기존 fire_symbols.py / fire_building.py 흐름을 사용.
  이번 실증은 Claude가 추출·정렬했던 소방 심볼 좌표를 재사용하고 최신 평면에 다시 대조함.

전체 건물 실행
  python run_building.py "도면폴더" --out "새출력폴더" --fire-dir "기존소방추출폴더"
  소방 폴더는 <층>_fire.json과 기준 <층>.json을 함께 포함해야 함.
  --fire-dir과 출력폴더를 같게 지정하면 중단하여 기준 평면을 보호함.
  소방도면이 없으면 --fire-dir 생략. 각 층 검사와 3D 생성은 계속 수행.

단일층 3D 검증
  python cad_build3d.py "새출력폴더/building" "새출력폴더/plan.json" --names 4F --use lodging
  이 명령의 층고는 기본값을 사용할 수 있음. 실제 높이는 --levels 또는 건물 일괄처리에서 도면값 사용.

생성물
  architecture.json / architecture_plan.png: 건축 CAD 기반 형상 추출
  plan.json: 최종 판정, 원본 벡터, 보정 근거, 실·문 연결, 소방 근거, 검사, 소스 해시
  fire_evidence.json: 심볼 실 소속, 개구부 후보별 거리·차폐·경합, 판정 근거
  source.svg: CAD 원본 벡터(선·문 원호) 확인
  fused.png / index.html: 건축·소방 통합 결과와 원본 전환 보기
  quality.json: 유효하지 않은 면, 실 겹침, 미확인 연결 등 검사
  종료 코드 0: 형상 검사 오류 없음(도면 판독 정확도 승인 아님)
  종료 코드 2: 형상 검사 오류. 결과 파일은 진단용으로 남김.

주요 처리
  블록·반복 삽입·대칭 형상 전개와 누락 진단.
  CAD 원래 선을 소스 레이어·블록·형상과 함께 보존. 자동 보정 기록은 별도.
  실의 내부 제외 영역(기둥·샤프트 등)을 보존하고 3D로 전달.
  윤곽 자기 교차는 make_valid로 면 분리하고 변화를 기록. 삭제된 비면 성분도 검토 기록.
  알려진 문 형상은 작은 틈 봉합으로 막지 않음.
  문틀 지지가 불명확한 임시 연결은 검토 대상으로 남김.
  실내창을 폭만으로 미닫이문으로 확정하지 않음.
  감지기는 실 존재·분할 검증의 보조 자료. 없다는 이유로 실을 삭제하지 않음.
  피난구유도등은 정렬·실 소속·고유 후보·중간 벽·실 연결을 검사.
  근거가 충분한 기존 창 개구부만 문으로 보정. 문 여닫이 방식은 unknown으로 유지.
  미닫이문 방식과 지하 환기구 분류는 유도등 근접만으로 변경하지 않음.
  문·창 종류 보정과 실별 소방 근거는 최종 JSON 및 3D JSON에 전달.

허용오차와 범위
  기본 실·벽 면은 20mm 래스터 기반. --res 값은 미터(예: 0.01 = 10mm).
  원본 LINE 좌표는 1µm 자리로 기록하지만 이는 도면 자체의 측량 정확도를 뜻하지 않음.
  문 원호는 해석형 중심·반지름·각도 보존. 다른 곡선은 기존 곡선 분할 근사 포함.
  레이어 분류는 layer_map.json에 근거. 지원하지 않는 작성 방식은 검토가 필요.
  심볼 연결 거리 1.5m, 후보 경합 0.25m는 매칭 허용오차이며 법규 기준이 아님.
  복잡한 벽 틈·동일 공간 연결·누락 개구부는 검토 표시로 남김. 정확도 100%를 보장하지 않음.
  방화문 속성, 개방률 0/50/100%, 소화설비 배관 연결, 화재 엔진 검증은 별도 범위.
