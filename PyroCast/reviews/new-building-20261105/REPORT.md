## 현재 한계 / 미검증

- **현재 AI API 설정이 없어 실제 스캔 이미지의 자동 판독은 미검증이며 사용 불가.** 기존 `config/ai.json`과 지정 환경변수의 API 키, 이미지 입력을 지원하는 모델을 연결해야 한다. 연결이 없으면 판독 버튼을 비활성화하고 `판독 연결 필요`를 표시한다. 없는 벽을 임의 생성하지 않는다.
- 결측 검사는 선언된 층 범위와 판독 결과를 검사한다. 제출되지 않은 층의 존재나 AI가 놓친 벽을 자동으로 완전히 보증할 수 없어 원본 겹침 확인을 필수로 둔다.
- 현재 한 층당 대표 평면도 한 페이지, B20~100F 범위. PH 및 한 페이지 여러 층은 자동 생성 범위 밖이다. 벽 높이는 확인된 층고를 사용하며, 스캔 문·창은 높이 미확정 평면 표식이다.
- 업로드 렌더링 의존성은 `tools/requirements-model-import.txt`. 저장된 설정만 읽고 키는 저장·응답·로그로 출력하지 않는다.
