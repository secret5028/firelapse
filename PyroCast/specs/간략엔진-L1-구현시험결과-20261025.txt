간략 엔진 L1 구현·관문 시험 결과 — 2026-10-25

결론: 별도 간략 엔진을 구현했으나 L2의 양성 사례 B2·B3에서 전이가 없어 관문 불합격.
기준을 바꾸지 않았으며 3F(L3), 보존 합격검사(L4), 몬테카를로와 운영 3D 반영은 보류했다.
계산이 빠른 것과 탐색에 사용 가능한 것은 구분한다. 정밀 모드 r8과 원본 fire_zone.py는 그대로다.

1. 구현

simulation/pyrocast_lite/core.py
  지정된 fire_zone.py를 복사했다. 기존 scipy BDF, 희소 Jacobian, 슬랩 양방향 유동,
  산소 제한, 미연 연료 이월, 벽 kρc 열손실, FO·BD·FGI·피난 판정을 보존했다.
  한 화원의 기여를 계산하던 구간을 실/셀별 화원 기여 루프로 확장했다.
  새 압력 솔버·자체 시간 스텝퍼·판 센서는 추가하지 않았다.

simulation/pyrocast_lite/adapter.py
  r8 prepare/resolve를 읽기 전용으로 호출한다. 원래 셀 분할·정적 부모·지연·공급곡선을 사용한다.
  실간은 부모 상층 > 설정 온도, 셀 간은 부모 실제 HRR>0이다.
  r8 manifest에 참고용 판 정보가 포함되지만 간략 상태에는 판이 없고 판 가열 계산도 없다.
  cell_temperature_C는 수치 범위 검증에는 남되 간략식에서 사용하지 않음을 표시한다.
  초기 창 비율을 그대로 사용하고 파괴는 OFF. 층간 FLOOR vent는 조용히 대체하지 않고 오류로 거부한다.

simulation/pyrocast_lite/runner.py
  solve_ivp의 양방향 중 양의 방향 이벤트(direction=+1, terminal=True)를 사용한다.
  이미 기준을 넘은 상태도 확인한다. 이벤트 확정 후 같은 상태·시각에서 적분을 잇는다.
  공급 시작까지의 지연 구간도 계속 적분한다. 사건 시각에서 공급 시각으로 시간을 건너뛰지 않는다.
  기존 r8 곡선에 지연이 들어 있으므로 조건 시각을 기준으로 곡선을 평가해 지연 중복을 막는다.
  입력 곡선 절점에서도 BDF를 이어 시작한다. 이것은 0초 전체 재실행이 아니다.
  10초 출력, 실제/공급 HRR 분리, 조건·지연·연소 상태 및 모델 한계 저장.

tools/run_lite_l1.py / simulation/tests/test_lite_l1.py
  단계별 실행 및 결과 저장. 이미 시도한 물리 사례는 자동 재실행하지 않는다.
  이벤트 연속성, 지연 중복 방지, 한 번 확정, 무발열 셀 미착화, 설정 범위, 연료 예산/개방률 검사 6건 통과.

2. L0 — 원본 호환 확인

기존 호텔 4F 객실 R0, 문/창 닫힘, 파괴 OFF, 1200초/10초 출력이라는 같은 입력으로 비교했다.
과거 '5~12초'의 동일 환경 원시 기록은 확보하지 못했으므로 그 시간을 재현했다고 주장하지 않는다.
대신 현재 PC에서 원본과 복사본을 직접 비교했다.

구분                     적분 시간       최고 HRR       최고 상층 온도
원본                     3.371초         640.0 kW       274.6℃
복사본 원본 호환 ON      3.354초         640.0 kW       274.6℃
복사본 열분해 피드백 OFF 5.433초         640.0 kW       274.3℃

호환 ON의 전체 상태 배열은 원본과 정확히 일치했다(최대 차이 0).
OFF에서는 미연 공급·누적 에너지가 달라지므로 '원본과 같은 결과'는 아니다.
원본 T_pyro0/T_pyro_span은 다른 실 착화가 아니라 최초 화원의 미연 공급 피드백이다.
L1에서는 지시 취지대로 이를 OFF로 하여 잠재 공급량 Qp=Q_supply를 따른다.
L0의 기존 수직 존 구성은 원본 비교용으로만 유지했고, L1 어댑터는 단일층이다.

3. L1 — 입력 계약

B1·B2·B3·현재 3F를 모두 로드했다. 3F는 30개 원래 실 → 40개 계산 셀이다.
각 입력을 독립적으로 r8 prepare한 manifest 해시, 부모 관계와 모든 공급곡선 해시가 일치했다.
열린 창 비율은 이미 입력된 비율을 그대로 적용하며 50%를 다시 곱하지 않는다.
이것은 물리 계산 일치가 아니라 전이 입력 계약 일치 검사다. 3F 시뮬레이션은 하지 않았다.

4. L2 — B1·B2·B3 (각 1200초)

모두 r8 표준 설정, 기본 item_peak, 출력10초, 원본 kρc 열손실 모델/값을 유지했다.

사례  전처리       적분          후처리       R1 상층 최고  추가 실제 연소실  판정
B1    약0.004초    0.911초       약0.07초     331.7℃       없음             음성 대조 통과
B2    0.004초      0.867초       0.073초      406.4℃       없음             양성 관문 불합격
B3    약0.004초    0.999초       약0.07초     523.8℃       없음             양성 관문 불합격

정확한 전처리/후처리 값은 각 summary.json에 저장했다.
최초 R1 실제 최고 HRR은 B1=1500, B2=2000, B3=2000 kW. 모든 경우 공급 상한까지 실제 발열했다.
R2·R3 실제 HRR은 0, 전이 이벤트도 0이다. 센서 판정량의 사소한 경계 오차가 아니라
부모 상층이 600℃에 도달하지 못해 규칙이 발동하지 않은 결과다.
B1은 원래 미전이 사례다. B2·B3는 실제 연소 60초 조건을 만족하지 못했다.
추가 임계값 조정, 창/연료 변경, 재시도는 하지 않았다.

5. 원인과 검증 한계

[확인] 부모·지연·공급 곡선은 r8 생성 결과와 같다. 기준 초과가 없어서 전이가 없다.
[확인] 현재 fire_zone 기본 벽 열관성 kρc는 1,350,000이다.
       CFAST B 입력 물성 곱은 0.12 W/(mK) × 800 kg/m³ × 1000 J/(kgK) = 96,000이다.
       약14.1배 차이다. CFAST는 유한두께 20mm 경계이고, 간략 쪽은 기존 축약 열손실식이다.
       지시서의 '기존 kρc 모델 유지'를 따라 값을 바꾸지 않았다.
[추론] 다른 벽 열손실과 유동·플룸·복사 처리의 차이가 낮은 상층 온도에 기여한다.
       벽 차이 하나가 전부라고 확정할 수 없으며 파라미터 스윕으로 결론을 맞추지 않았다.

기존 r7 저장 결과를 읽은 진단(새 native 실행 없음):
  B2: R2 조건 시각 약881초. 그 직전 native R1 상층606.8℃, 같은 시각 간략397.5℃.
  B3: R2 조건 시각 약311초. 그 직전 native R1 상층632.4℃, 같은 시각 간략452.9℃.
이 저장 결과의 대기 화원 공급 방식은 room_involvement이고 이번은 r8 기본 item_peak다.
따라서 전체 실행을 동등 조건의 속도/정확도 비교라고 부르지 않는다. 첫 추가 착화 전
부모 온도가 이미 다른 것을 보여주는 참고다. L3의 동일 r8 표준 비교는 아직 하지 않았다.

추가로 확인한 원본의 범위:
  - 미연 연료 수송은 있지만 이미 생성된 가스의 추가연소/CO 재연소는 없다.
  - 롤오버 판정과 soot/광학농도 수송은 없다. 미평가로 표시했다.
  - 원본 복사 분율0.30과 native 덱0.35가 다르다.
  - 원본 누설 문0.02m²/창0.003m² 가정은 native 닫힌 VENT와 동일하지 않다.
  - 원본 FO 상수873K는599.85℃다. 조건식을 유지하고 전이 기준600℃와 구분했다.
  - r8 미래 창 개방 기준 공급 상한은 공유하지만 간략 창 파괴는 OFF다. 한계를 기록했다.
  - P0 기준 밀도와 원본 경계 clipping이 남는다. 이를 보존검증 합격으로 볼 수 없다.

6. 중단 범위

L2 양성 관문 불합격으로 이번 구현은 실험 상태에 둔다.
L3 3F 1회 / L4 누적 잔차0.1% / MC20표본 / 위험 순위 / 기존 3D 교체는 진행하지 않았다.
MC 코드도 아직 추가하지 않았다. 해당 기능을 완료했다고 표시하지 않는다.
질량·열·산소 보존 검사는 미평가이며 '중복 없음 검증 완료'로 보고하지 않는다.
사용자가 제시한 L3 '집합 일치'와 '경계 차이는 오류 아님'은 동시에 관문 합격을 뜻하지 않는다.
이후 L3에서 경계 차이로 집합이 달라도 사유를 기록한 뒤 중단하는 기준을 유지한다.

다음 검토에서 필요한 결정은 온도 임계값 변경이 아니라 경계조건의 대응이다.
원본 kρc 값을 고정한 탐색 모델로 볼지, 기존 열손실 식은 유지하되 r8 재료 입력을 대응시킬지
명시해야 한다. 대응시키는 경우에도 두 열손실 모델의 동등 정확성이 보장되는 것은 아니다.
그 결정 전에는 값을 바꾸거나 계산을 더 돌리지 않는다.
