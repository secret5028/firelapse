CFBT 조건부 화재 거동·위험 탐색 최종 명세
작성일: 2026-10-20 (Asia/Seoul)
상태: 요구·설계 명세. 구현 완료를 뜻하지 않음.
이번 작업: 명세 파일 신규 작성만 수행. 프로젝트 코드·엔진·계산 입력·기존 결과 변경 및 재계산 없음.

1. 목적

사용자가 정한 임계조건 아래에서 연기·미연소 연료·산소의 이동과 추가 연소를 계산하고, 그에 따른 온도·열유속·압력·유동 변화를 3D에서 확인한다. 계산에 나타난 연소 과정과 원인에 따라 백드래프트형, 롤오버형, 플래시오버형, FGI형 현상을 분류한다.

임계값은 탐색 가정으로 허용한다. 범용 임계값이나 실제 사건 재현 정확도를 먼저 확보해야만 기능을 개발할 수 있다는 전제는 두지 않는다. 대신 어떤 가정을 사용했고 어떤 연료·산소·발열 계산으로 결과가 나왔는지 추적한다.

하나의 시나리오는 최초 화점, 대표 연료, 문·창·배연 상태 및 변경 시각, 초기환경, 재료, 연소모델, 임계값 묶음으로 정의한다. 첫 제품 범위는 선택한 시나리오의 계산·비교이다. 모든 화점과 독립 문 상태의 전수 탐색은 포함하지 않는다.

2. 전체 계산 흐름

CAD/실·문 연결망 + 연료·화재곡선 + 개방 일정
  → CFAST 열·압력·유량·성분 수지
  → 온도·산소·연료·점화 조건 평가
  → 해당 반응 경로의 연소 허용
  → 연료·산소 소모, 생성물·발열 계산
  → 복사·대류·벽 열전달과 이후 온도·유동 계산
  → 계산 과정의 원인·현상 분류
  → 실별 시계열·이벤트·3D 표시

현상 이름 자체가 별도 열원을 생성하지 않는다. 한 연소 과정이 여러 현상 조건과 관련되어도 연료·산소·에너지는 한 번만 계산한다.

3. 공간·성분·기류의 기본량

3.1 실/층별
- 상층·하층 온도, 층 경계, 층 체적·질량, 압력.
- 산소 질량 및 농도, 미연소 연료 질량·농도·잠재에너지.
- 그을음 질량·광학밀도, 기존 화원 발열과 가스 추가연소 발열.
- 바닥 및 설정한 관찰 위치의 열유속, 대표 타깃 표면온도.
- 단일층으로 계산하는 계단·승강로에는 단일층 규칙을 적용한다. 존재하지 않는 하층 값을 만들어 넣지 않는다.

3.2 문/연결부별
- 각 방향·층 사이 기체 질량유량[kg/s], 체적유량[m3/s], 평균 유속[m/s].
- 유입 산소량 = 해당 유동의 상류 산소 질량분율 × 기체 질량유량.
- 유입 미연소 연료량과 그을음량도 같은 방식으로 계산.
- 양방향 유동의 유입·유출을 각각 보존한다. 순유량 하나로 대체하지 않는다.
- 유속은 해당 흐름이 사용하는 유효 면적과 밀도로 환산한다. 닫힌 문 누설도 수지에는 반영한다.

3.3 중성대
- 같은 절대높이에서 양쪽 압력차가 0이 되는 높이를 구한다.
- 층 경계와 개구부 구간을 나누며, 여러 근이 있으면 모두 보관한다.
- 흐름 방향은 실제 압력차/기존 유동 결과를 사용한다. 항상 위가 유출이라고 고정하지 않는다.
- 단방향, 무유동, 근 계산 불가를 구분한다.
- 중성대는 기류·환기 상태 설명 지표다. 높이 하나만으로 연료지배/환기지배를 결정하지 않는다.

연기 양은 연기층 체적·그을음 질량/광학밀도·미연소 연료량을 구분해 표시한다. 전체 고온 가스 체적이나 그을음량을 곧바로 가연성 연료량으로 사용하지 않는다.

3.4 연료 농도 지수
- 기준은 연료 질량분율 Y_f를 설정한 연소하한 질량분율 Y_LFL로 나눈 값이다.
- Y_f는 가능한 한 엔진의 실제 미연소 연료 질량과 층 질량으로 구한다.
- Y_LFL은 사용자 고정값 또는 선택한 상관식 프로파일로 정의하고 계산식·온도·연소열 단위·유효 범위를 기록한다.
- 기존 제안의 온도 보정 상관식은 탐색용 선택지로 둘 수 있다. 지수1은 그 설정 하한 도달을 뜻한다.
- 범위를 벗어나거나 값이 없으면 자료 없음으로 처리한다. 미연소 연료0으로 바꾸지 않는다.

4. 사용자 설정

4.1 기본 탐색 임계값
- T_FO_warn=500℃, T_FO=600℃, q_FO=20kW/m2.
- T_AI=520℃, T_HOT=300℃.
- O2_DEF=10vol%, O2_SUF=12vol%.
- 연료 농도 지수 기준=1.0, 과농 연료 질량분율 Y_RICH=0.10.
- 연기 관련 조건의 최소 층 두께 dz_min=0.3m.
- 급격한 온도 상승 기준 dTdt_rapid=5℃/s, 기본 평가창=30s.
- 관찰 높이 기본=1.5m.
이 값은 사용자 제안의 초기 탐색 설정이다. 변경·저장·불러오기·초기화를 지원한다.

4.2 적용 조건
- 지표별 켜기/끄기, 대상 실·층, 최초 발화실/비발화실 구분.
- 점화원: 없음/존재 가정/지정 시각에 작용. 고온 자발반응과 파일럿 점화를 구분한다.
- 개방 상태: 실제 개방률·누설·유입량으로 처리. BD 대기 상태를 완전 밀폐실에만 제한하지 않는다.
- 최소 연기층 두께는 지표별 선택이다. 얇은 층이라는 이유로 모든 연소·열환경 계산을 중단하지 않는다.
- 접근 범위·상태 지속시간·재활성화 조건은 설정 가능하게 한다.
- 고체 착화는 재료군의 대표 타깃과 표면 착화온도를 사용한다. 기체 온도를 표면온도로 바꾸어 읽지 않는다.

4.3 계산 설정과 표시 설정
- 연소 허용 임계조건·반응모델·문 상태·연료가 바뀌면 물리 계산을 다시 수행한다.
- 표시 색·경고 기준·시계열 평가창만 바뀌면 저장 결과에서 다시 판정한다.
- 각 값에 단위, 사용자 가정/문헌 모델/엔진 기본값 구분, 설정 이유, 선택적 출처를 보관한다.
- UI의vol%와 엔진 산소 질량분율을 명시적으로 변환한다. 15mass%와15vol%를 동일시하지 않는다.
- 임계값 변경이 실제 반응 게이트에 전달되어야 한다. 화면 설정만 바뀌고 숨은 엔진 기준이 그대로 작동하는 상태를 허용하지 않는다.

5. 연료지배·환기지배 구분

반응 경로마다 연료 공급으로 가능한 발열 Q_f와 혼합된 산소로 가능한 발열 Q_o를 구한다.
- 연소가 허용된 상태에서 Q_f가 제한하면 연료지배.
- Q_o가 제한하면 산소/환기지배.
- 차이가 설정한 전환 범위 안이면 혼합/전환 상태.
- 화원이 비활성, 공급이0, 점화 미충족 등은 별도 상태. 무발열을 일괄 환기지배로 판정하지 않는다.
- Q_actual/Q_input은 보조지표로 표시한다. 입력 정의·연소 경로를 함께 기록한다.
- 한 실의 고체 화원과 개구부 가스연소가 서로 다른 지배 상태를 가질 수 있다. 경로별 상태를 보관하고 실 요약은 선택한 집계 규칙을 표시한다.

6. 추가 연소율과 온도 변화

6.1 기본 경로: CFAST 활용
- 기존 연료 공급률, 플룸/개구부 혼합 유량, 산소 제한, 반응 생성물·발열 계산을 활용한다.
- 기본 관계: Q_actual=min(연료 공급률×유효연소열, 혼합유량×산소질량분율×저산소보정×산소소모당발열량).
- 문을 통해 이동하는 연료와 공기 혼합에 따른 연소율은 기존 유동 계산에서 구한다.
- '축적 연료를 N초에 전부 태움'을 필수 사용자 설정으로 만들지 않는다.
- 저장량[kg]을 공급률[kg/s] 인수에 그대로 넣지 않는다.

6.2 추가 경로: 같은 구획에 축적된 가스의 재착화
- 기본 개구부 연소/기존 화원 플룸과 별도로 필요한 구획내 반응을 추가한다.
- 사용자 조건은 반응의 허용을 결정하고, 활성화 후 연소율은 선택한 반응모델로 구한다.
- 2006년 연구의 온도·연료·산소 농도 기반 유한반응 모델을 설계 후보로 사용한다.
- 반응계수·대상 연료·혼합 가정은 프로파일로 기록한다. 현재 문헌 계수를 모든 연기의 확정 상수로 채택하지 않는다.
- NIST FDS의 혼합/반응 시간 모델은 참고할 수 있으나, 격자·국소 난류량을 실 크기로 단순 치환해 공식 FDS 계산이라고 부르지 않는다.
- 반응모델의 정확한 식·단위·시간적분·계수 프로파일은 구현 전 기술 설계에서 고정한다. 새 전층 열·유동 솔버는 만들지 않는다.

6.3 공통 수지
- 연료·산소 소모, 생성물, 대류/복사 발열을 동일한 상태와 시간 진행에 반영한다.
- 내장 연소와 확장 반응은 하나의 연료/산소 예산을 공유한다.
- 연료 소진·산소 부족 시 반응이 제한되거나 중지된다. 재축적·재공급 시 설정에 따라 다시 활성화할 수 있다.
- 발열 이후의 온도·층 높이·압력·기류·벽 열전달은 CFAST 계산에 반영한다.
- 구획 가스온도를 임의로 점프시키거나, 가스 잔량을 남긴 채 새 고체 FIRE로 같은 에너지를 더하지 않는다.

6.4 복사열
- CFAST의 화원·가스층·벽·타깃 복사와 대류·벽 전도를 활용한다.
- 외부 열이 유입돼 뜨거워진 경우와 실내 연료가 추가 연소해 뜨거워진 경우를 구분한다.
- 문 너머 국소 복사 보완 v41은 별도 검수 경로로 보관한다. 채택할 때는 기존 복사항 교체/중복 여부와 구획 에너지 연결을 명시한다.

7. 현상별 조건·작동·분류

각 현상에는 (A) 위험 조건 형성, (B) 반응 진행, (C) 급격한 열환경 변화의 세 상태를 구분한다.
급변이 없더라도 위험 조건이나 가스 연소 상태는 표시한다. 이름이 붙었다는 이유로 온도를 높이지 않는다.

7.1 BD: 백드래프트형 급격 연소
위험 조건:
- 미연소 연료 축적 기준, 산소 부족 기준, 고온 유지 기준 충족.
- 완전 밀폐 여부보다 실제 저환기/산소 제한 상태를 사용한다.
반응:
- 개방·공기 유입 재개/증가 또는 산소 공급의 누적으로 혼합·점화 조건이 충족되면 가스 연소.
- 유입 산소가 즉시 소모될 수 있으므로 산소 농도 상승만 필수 증거로 요구하지 않는다. 산소 유입·소모량도 사용한다.
분류:
- 이전 저산소·연료 축적 이력 + 산소 공급/혼합 회복 + 축적 가스 발열 증가 + 설정 급변 기준 충족.
- 모델 내 원인=산소 공급/혼합 회복에 따른 축적 가스 연소.

7.2 RO: 롤오버형 연기층 연소
위험 조건:
- 상층 연료 농도와 고온 기준, 산소/점화 조건 충족.
반응:
- 상층 또는 개구부를 통해 연결된 상층의 가스 연소를 계산.
분류:
- 상층 가스연소·연결 경로 및 발열의 진행을 기준으로 분류한다.
- 급변 기준을 넘으면 '급격한 온도 상승 동반'을 추가한다.
- 산소 유입 증가만으로 BD와 RO를 구분하지 않는다. 기존 축적/저산소 이력과 연소 위치·경로를 함께 쓴다.
- 존 모델에서 판정하는 것은 상층·연결 공간 단위의 연소다. 해상되지 않는 실내 화염전면 위치를 생성하지 않는다.

7.3 FGI: 이동·축적 연기의 착화
위험 조건:
- 다른 공간으로 이동하거나 현 위치에 축적된 연료가 농도·산소 조건 충족.
- 고온 자발반응 또는 사용자가 설정한 점화원이 작용할 수 있음.
반응:
- 해당 공간의 가스를 소모하고 추가 발열을 반영.
분류:
- 연료가스 이동/축적 이력 + 점화 조건 + 해당 공간 가스연소.
- 초기 T_AI 미만에서 파일럿으로 시작한 경우도 기록.
- BD/RO와 중첩 가능. 실제 압력파·폭발에너지를 계산한 것으로 해석하지 않는다.

7.4 FO: 플래시오버형 전이
위험 조건:
- T_FO_warn 또는 설정한 열환경 접근 기준.
- 상층 T_FO, 바닥 q_FO는 열환경 지표로 각각 기록.
반응:
- 대표 가연물의 표면 착화조건 도달 시, 아직 연소에 참여하지 않은 고체연료의 화재곡선/열분해 공급을 활성화한다.
- 화재곡선은 기존 연료 예산과 연결한다. 이미 계산 중인 전체 연료를 다시 추가하지 않는다.
분류:
- 대표 가연물의 연소 참여 확대 + 그 발열 기여 + 설정 급변 기준 충족을 '플래시오버형 전이'로 분류.
- 전실 연소 참여의 범위는 사용자 설정의 대표 재료군 전체/참여 비율로 정의한다.
- 온도·열유속만 도달하면 '플래시오버 열환경 조건'으로 기록해 고체 착화 원인 분류와 구분한다.
기존 구현에서 추가할 사항:
- 실당 대표화원1개는 실 안의 전체 가연물 착화 순서를 표현하지 않는다.
- 상세 가구 배치 대신 대표 재료군의 수동 타깃과 미참여 고체연료 예산을 연결한다.
- 최초 화원과 추가 참여 고체연료를 같은 총재고 안에서 나누고, 고체→가스 공급→연소 소모를 추적한다.
- 이 구분이 없는 실에서는 '모든 가연물 착화'를 판정했다고 하지 않는다. 열환경 지표와 대표 타깃의 도달 상태를 보여준다.

7.5 RAPID 및 열환경 초과
- 상층/하층/관찰높이별 온도 상승률을 구분한다.
- 기본은 현재 시각까지의 설정 시간창에서 변화율을 계산한다. 미래 값을 사용한 평활로 사건 시점을 앞당기지 않는다.
- 복사 열유속의 급증도 별도 시계열·이벤트로 보관한다.
- 온도 상승 원인이 유입 고온가스/복사·대류 가열이면 그 원인을 표시한다. 실내 가스연소로 오분류하지 않는다.
- 보호장비 관련 기준은 사용자 설정의 열환경 지표로 사용한다. 자동으로 개인 방호시간으로 환산하지 않는다.

8. 원인 구분과 중첩 처리

반응 경로별 기록:
- 연료 공급/잔량, 산소 유입/소모, 점화 조건, 지배 상태.
- 기존 고체 화원 발열, 새로 활성화된 고체연료 발열, 구획내 가스 발열, 개구부 가스 발열.
- 유입 고온가스의 엔탈피, 벽/가스/화원 복사·대류 열전달.
- 설정 조건 충족 시각, 연소 시작·종료·재개 시각, 급변 구간.

분류는 이 반응 기록과 이력에 근거한다. 온도와 산소가 같은 시각에 변했다는 상관만으로 원인을 확정하지 않는다.
복합 원인이면 복수 태그와 기여 항을 함께 제시한다. 단일 원인으로 강제하지 않는다.
개입 효과를 별도로 확인할 필요가 있을 때는 선택한 시나리오의 문 개방 유지/변경 등 짝 비교를 수행한다. 모든 후보에 추가 전수계산을 요구하지 않는다.
열원 기여량은 기록하되, 비선형 피드백을 무시해 각 현상의 독립 온도 상승분으로 단순 분해하지 않는다.

9. CFAST 기본 기능과 추가 범위

[기존 CFAST 활용]
구획·층의 질량/성분/에너지 수지, 문/누설/수직연결/기계유동, 온도·압력·층높이, 산소 제한 연소, 미연소 연료 수송, 기존 화원 상층 연소, 개구부 가스연소, 화원·가스층·벽 열전달, 타깃 열응답·시간/온도/열유속 착화, 입력 화재곡선.

[입력·후처리·UI 확장]
사용자 설정과 단위변환, 대표 문/배연 일정, 중성대·방향별 성분유량 표시, 지배 상태·현상·원인 이벤트, 발열/잔량 시계열, 설정별·시나리오별 결과 비교, 3D 레이어, 엔진·설정별 캐시 식별.

[기존 계산부 연결 확장]
사용자 복합조건을 개구부 등 선택한 가스연소 경로에 연결. 기본 발열률·화학량론·수지를 재사용. 기존 숨은 온도게이트 및 저산소 설정과의 적용 관계를 명시. 원본 기본 계산 모드도 유지.

[새 계산이 필요한 부분]
같은 구획의 축적 가스 재착화 반응항, 그 반응의 속도/혼합 모델과 수지 연결. 대표 재료군의 미참여 고체연료와 추가 착화·열분해 공급 연결. 둘 다 기존 연료 예산을 공유하며 새 연료를 중복 생성하지 않는다.

[이번 범위에서 제외/보관]
새 전층 솔버, v44/v45 이중 엔진 확대, 모든 독립 문 조합 탐색, 가구별 상세 배치·열분해, 상세 화염전파·폭압·압력파, 복잡한 볼륨 렌더링. v41은 별도 검수 대상으로 보관하며 자동 전층 이식하지 않는다.

원본 CFAST 실행파일·운영앱·기존 결과는 비교 기준으로 보관한다. 확장 계산이 필요하면 별도 엔진/모드/출력 경로로 구분한다. 구현은 아직 시작하지 않는다.

10. 결과 계약과 화면

결과마다 보관:
- 시나리오 ID, 엔진 버전/해시, 연소모델 ID, 설정 묶음/해시, 입력 가정.
- 실/층 기본 시계열, 개구부 방향별 유량·성분유량·중성대.
- 현상별 조건 상태와 연소 상태, 최초 충족/반응/급변 시각, 지속시간.
- 원인 태그와 관련 연료·산소·발열 기록.
- 데이터 없음·모델 적용 불가·계산 미완료를 정상 미충족과 구분.

조건 상태: 미충족/접근/충족/이전 충족/자료 없음.
연소 상태: 비활성/점화 대기/산소·혼합 대기/진행/공급 제한/소진/중지.
현상 분류는 별도 필드이며 복수 값을 허용한다.

3D:
- 온도/산소/미연소 연료 색 모드, 상층·하층·관찰높이 구분.
- 문별 중성대·유동 방향·산소 및 연료 전달.
- 위험 조건 형성 배지와 실제 모델 반응 진행 표시를 구분.
- 실 선택 시 설정값 대비 현재값, 원인, 발열·온도·열유속 그래프.
- 이벤트 타임라인과 해당 실·시각 이동.
- 표시 문구는 '모델 분류: 백드래프트형 급격 연소' 등으로 통일하고, 설정과 계산 근거를 바로 확인하게 한다.
- 서로 다른 시나리오의 실별 최대를 한 실제 화재의 시간 재생처럼 합성하지 않는다.

시간 해상도:
내부 적분과 파일 저장 간격을 구분한다. 급변 사건을 기존5초 출력의 단순 보간만으로 만들어내지 않는다. 필요한 이벤트 주변 원시값을 보관하고, 표시의 매끄러움과 계산 해상도를 구분한다.

11. 구현 순서와 완료 기준

1) 발화실-홀-계단 등 소형 연결망에서 기존 기본 연소의 상태·발열·유량을 읽는 연결부를 확인.
2) 사용자 조건 게이트를 기존 추가연소 경로에 연결하고 온도·유동 피드백 확인.
3) 구획내 축적 가스 재착화 반응을 동일 수지에 연결.
4) 대표 고체연료의 추가 참여와 FO 원인 분류 연결.
5) 3D·이벤트·원인 설명 및 선택 시나리오 비교.
6) 기존 건물에 적용. 전수 조합 탐색으로 확대하지 않음.

최소 확인:
- 확장OFF시 기본 계산 복원.
- 연료/가용산소가 없으면 해당 반응 발열0.
- 총연료·잠재에너지 소모 일관성 및 native/확장 중복 소모 없음.
- 임계값 변경이 지정한 반응 게이트와 결과에 실제 반영.
- 산소 공급 변화·가스 연소·고체 착화·외부 열유입의 원인 기록 구분.
- 시간간격을 줄여 주요 사건·순위가 어떻게 변하는지 확인.
- 조건 형성만 있는 경우와 추가 연소·급변이 동반되는 경우를 구분.
완료 기준은 구현된 수지·조건·피드백·설명이 일관되는 것이다. 특정 문헌의 착화시각에 맞추기 위한 튜닝이나 모든 실의 현상 발생을 요구하지 않는다.

12. 설계 근거와 남은 기술 결정

- 2011년 Access design: 대표 개방·환기 시나리오에서 발화실 밖 열위험을 비교하는 구성에 참고.
- 2006년 Kudo 등: 자기소화 후 연료·산소·온도와 재착화 발열을 연결하는 반응 구조에 참고.
- CFAST7.7.7 기술문서와 버전 고정 소스: 기존 공급/혼합·산소 제한 연소 및 수지 재사용.
- NIST FDS 기술문서: 혼합 제한/유한 반응속도 모델의 참고. 존 모델의 적용 가정은 별도 명시.

구현 전 고정할 기술 항목:
구획내 재착화의 정확한 반응식·계수 프로파일·혼합 근사, 대표 고체연료의 초기/추가 참여 예산, 게이트의 적용 경로, 수치 적분·출력 해상도. 이는 추가 코드 구현을 위한 기술 결정이며, 위험 가능성 탐색이라는 목적과 사용자 임계값의 채택을 다시 논의하는 전제조건이 아니다.
