전체 프로그램 사용 시나리오 — 최신 수정 반영 r8
2026-10-22 / 구현할 기능의 흐름을 정리한 명세 / 구현 완료 보고가 아님
배연 대안 비교는 MVP 이후 기능으로 확정한다. 지금은 코드·엔진·결과를 수정하지 않는다.
기본 흐름: 도면 → 건물/3D → 조건 설정 → 간편식 MC 탐색 → 상위 CFAST → 결과 보기/비교.

1. 도면 처리
가. OCR 추출
- 층 이름, 방 이름, 건물 용도·구조, 치수·높이, 문·창 표시를 읽는다.
- 글자와 주석 테두리를 벽체 등 도면 형상과 분리하여 별도 레이어로 만든다.
- 창고·주방·기계실·위험물 등 가연물 관련 문자정보를 따로 저장한다.
나. 평면도 구성
- 같은 층을 나타내는 중복 도면을 묶는다.
- 크기와 방향을 맞추고 중첩되는 공통 부분으로 기본 평면도를 만든다.
- 서로 다른 부분은 따로 보관해 확인·보완할 수 있게 한다.
다. 벽·문·창 추출
- 벽·문·창을 찾아 각각 별도 레이어로 구분한다.
- 위치·크기·연결 실과 외기 연결 여부를 정리한다.
라. 소방시설 추출
- 도면의 스프링클러·연결살수·연결송수·배연설비 등을 읽는다.
- 송수구별 담당 구역, 배관, 펌프·수조 등 연결 자료를 만든다.
- MVP에서는 위치와 연결 표시까지 한다. 소화·배연 효과의 화재 계산 연동은 이후 기능이다.

2. 건물과 실 구성
가. 공간 정보
- 층별 방·복도·홀·계단 등 공간과 이름·용도를 연결한다.
- 실의 면적·반자 높이·층고·체적을 정리한다.
나. 연결 정보
- 문으로 연결된 실과 지상 안전한 외부 출구까지의 경로를 정리한다.
- 사람이 사용하는 실내 문은 환기상 닫혀 있어도 통행 가능으로 둔다.
- 사람이 사용하지 않는 공간의 점검구·EPS 문은 피난 경로에서 제외한다.
- 잠김·장애물에 따른 통행 불가는 고려하지 않는다.
- 계단·승강로·샤프트의 열·연기 연결과 외벽 창을 통한 상층 전파 경로는 구분한다.
- 피난 경로 제외가 열·연기 모델에서 해당 공간을 삭제한다는 뜻은 아니다.
다. 미확인 정보
- 불확실한 항목은 기본값으로 진행하고 추정·미확인 상태를 남긴다.
- 사용자가 이름·경계·높이·연결을 수정할 수 있게 한다.

3. 3D 건물 생성과 소방시설 보기
가. 건물 보기
- 벽·바닥·문·창·반자·계단·승강로 등 공간을 만든다.
- 층별 보기·위에서 보기·실 선택·실감보기를 제공한다.
- 잘못된 부분을 확인·수정하고 모델을 저장한다.
나. 설비 보기
- 설비 종류별로 표시를 켜고 끈다.
- 송수구를 선택하면 연결된 배관·설비·담당 구역을 강조한다.
- 여러 층에 걸친 배관·펌프·수조는 투시해서 연결을 볼 수 있게 한다.
- 기존 표시 기능을 우선 재사용하고 추정 위치·연결은 구분한다.
- 표시용 연결·화살표를 실제 방수량·유속·소화 성능으로 표현하지 않는다.

4. 화재 조건 설정
가. 실별 연료
- 도면 문자와 실·건물 용도로 가연물의 종류·양을 기본 설정한다.
- 랙·화물 정보가 있으면 LLM이 근거를 묶어 적재량·연료량을 추정한다.
- 정보가 부족한 부분은 기본값을 적용하고 사용자가 수정한다.
- 연료는 개구부 앞을 포함해 실 안에 균등하게 있다고 가정한다.
- 총 연료량은 유지하며 표시 상자·착화 후보가 많아진다고 연료를 늘리지 않는다.
나. 문·창
- 문은 열림/닫힘으로 설정하고 전체 중 열린 개수 비율을 지정한다.
- 예를 들어70%는10개 중7개 완전 개방이다.
- 외기 창도 열린 개수 비율을 지정하고 열린 창은 기하 면적의50%를 유효 개방으로 계산한다.
- 특정 문·창은 상태를 고정할 수 있다.
- 사용자가 정한 초기 개폐 상태는 유지한다. 화재 도중 사람이 여닫는 행동은 입력하지 않는다.
- 예외로 화재에 의한 창 파괴를 반영한다. 설정 기준에 도달하면 창이 파괴되고 지정한 최종 개방률로 증가한다.
- 일반 단판 판유리 6 mm 대용의 기본 기준은 대표 타깃 표면온도 450℃ 초과로 두며 사용자가 변경한다.
- 기본 물성은 밀도2500 kg/m³, 비열0.82 kJ/(kg·K), 열전도율0.95 W/(m·K), 방사율0.90이다.
- 열유속 방식과 파괴 후 최종 개방률도 사용자가 설정한다. 450℃는 문헌 참고 근사이며 NIST 공인 파괴온도가 아니다.
- 출력은5초 간격을 유지하고 파괴는 개방 변화 관측 구간으로 표시한다. 원본 내부 개방 판정은 기록 간격과 별개다.
- 균열·열응력·조각 낙하 과정은 생략하고 파괴 이벤트와 개방 면적 변화만 계산한다.
- 초기 열린 창50%와 파괴 후 개방률은 별도 값이다. 파괴 후 개방률은 창 전체 기하 면적 기준의 최종값이다.
다. 환경과 기준
- 외기온·기압·습도는 고정값 또는 MC 추첨 범위·분포로 정한다.
- 벽체·천장 재료, 계산할 층, 현상 판정 임계값을 설정한다.
- 계산 기간은30분(1800초) / 1시간(3600초) 중 선택한다. 기본은30분으로 둔다.
- 동일 탐색·선정·상세 비교에는 선택한 공통 기간을 적용하고 결과와 함께 저장한다.
- 추출값·LLM 추정값·기본값·사용자 지정값을 구분한다.
- MC 탐색량과 CFAST 상세 계산 사례 수를 별도로 설정한다.

5. 탐색 모드 선택
가. 자동 화점실 탐색
- 이 층의 어느 실에서 화재가 나면 영향이 큰지 찾는다.
- 적격한 각 실을 최초 화점으로 비교한다.
나. 사용자 화점실 지정
- 사용자가 최초 화점실과 위치를 지정한다.
- 이 화점에서 어떤 개폐·환경 조건이 가장 위험한지 찾는다.

6. 간편식 몬테카를로 위험 탐색
가. 조건 추첨
- 설정한 비율로 실제 문·창의 개폐 조합을 만들고 환경 조건을 추첨한다.
- 고정한 항목과 연료 설정은 유지한다.
- 자동 모드에서는 화점들 사이에 공통 표본을 사용한다.
나. 간편 평가
- 많은 조합을 간편식으로 계산한다. 이 단계에서 CFAST를 반복 실행하지 않는다.
- 현상 영향, 화재 전파, 고립을 구분해 평가한다.
- 현상 영향은 조건 충족 정도와 영향 면적을 본다.
- 화재 전파는 연소 중인 실의 면적과 개수를 본다.
- 고립은 처음 있던 외부 출구 경로가 위험 때문에 모두 사라지는 경우를 본다.
- 간편식이 평가할 수 없는 조건은 미평가로 남긴다.
다. 후보 제시
- 위험한 최초 화점실과 실제 조건 조합을 순위로 보여준다.
- 기본은 고립 우선으로 두고 현상·전파별 후보도 확인할 수 있게 한다.
- 선정 이유와 실제 열린 문·창, 환경 조건을 보여준다.
- 탐색한 범위에서 발견한 최대이며 모든 경우의 전역 최악을 보장하지 않는다.

7. 상위 시나리오 CFAST 계산
- 가장 높은 순위 또는 사용자가 고른 소수 사례만 상세 계산한다.
- 선정된 실제 초기 문·창·환경·연료 조건과 창 파괴 정책을 그대로 사용한다.
- CFAST로 온도·산소·연기와 개구부 유동을 계산하고 기존 추가 모델로 착화·FO 전환·가스 추가연소 등을 계산한다.
- 원본 계산과 프로젝트 추가 계산을 구분한다.
- 창 파괴는 순정 CFAST 조건부 개방을 활용하는 안을 우선 검토하고, 파괴만으로 외부 전체 재실행을 추가하지 않는다.
- 실제 창 개방률 시계열을 유동·추가 열전달·후속 착화·3D에서 함께 사용한다.
- 전층 전이 탐색에서는 추가 착화6건이라는 고정 제한을 없애고 선택층의 적격 미착화 연료군 전체를 평가할 수 있게 한다.
- 실제 착화는 기존 조건을 만족한 경우에만 확정한다. 전층 탐색이 모든 실을 강제로 태운다는 뜻은 아니다.
- 착화/FO 대상 수에 맞춰 반복·재실행 예산을 함께 산정하고 시간/수렴 제한은 별도로 유지한다.
- 30분·1시간까지의 계산 완료, 전층 전이 탐색 완료, 실제 연소확대 범위를 각각 표시한다.
- 예산 초과/미평가/수렴 실패로 중단되면 마지막 성공 결과와 미평가 범위를 남기고 전층 탐색 완료로 표시하지 않는다.
- MVP에서는 소방시설 성능의 화재 계산 연동을 새로 구현하지 않는다.

8. 시간에 따른 결과 보기
가. 전체 보기
- 시간에 따라 온도·연기·화재 전파를 보여준다.
- 회색 연기는 전체 분포를 유지하고 위험 조건은 색 테두리로 표현한다.
- 추가 착화·FO 전환·창 파괴의 위치와 시점, 창 개방 면적 변화를 표시한다.
나. 세 위험 레이어
- 현상 영향 / 화재 전파 / 고립을 각각 켜고 끈다.
- 한 가지·임의의 두 가지·세 가지 모두를 겹쳐 볼 수 있게 한다.
- 범례와 점수·면적을 구분하고 서로 다른 위험을 발생확률 하나로 합치지 않는다.
다. 현상별 지수
- FO·FGI·롤오버·백드래프트 등의 지수를0~100점으로 보여준다.
- 실을 클릭하지 않아도 가장 높은 현상 지수 또는 표시 기준 이상을 경계로 표시한다.
- 상세보기에서는 실제 계산값·임계값·최고점·최초 충족·지속시간·판정 근거를 확인한다.
- 개구부 연소와 상층 추가연소를 구분한다. FGI 표시용 화염OFF 방침은 유지한다.
라. 통행 기준 선택
- 일반 재실자 / 보호장비·SCBA 착용 소방대원 중 선택한다.
- 같은 화재 계산 결과에 각 기준을 적용해 통행 위험·출구 연결·고립을 보여준다.
- 소방대원 열환경은 NIST 자료의 온도·복사열·노출시간을 함께 참고하되 구체적 수치는 검토한다.
- 보기 기준·레이어 전환만으로 CFAST를 다시 돌리지 않는다. 필요한 자료가 없으면 미평가를 표시한다.

9. 초기 조건 변경과 비교
- 사용자가 문·창·연료 등 초기 설정을 바꾸면 별도 시나리오로 저장한다.
- 고정한 항목을 유지하고 간편식 MC로 나머지 조건의 최악 조합을 다시 찾는다.
- 선정된 변경 사례만 CFAST로 계산하고 기존 결과와 같은 시간축에서 비교한다.
- 어느 실의 온도·연기·착화·현상지수·고립이 커지거나 줄었는지 보여준다.
- 실제 물리 입력이 바뀐 사례는 현재 실행 구조에서0초부터 재계산한다. MC 전체 CFAST 실행은 하지 않는다.
- 시나리오 중간의 인위적 문·창 개폐 행동은 포함하지 않는다. 화재에 의한 창 파괴는 예외이다.

10. 저장과 결과 출력
- 도면·3D·설비 연결·설정·추정 근거·MC 표본/seed·선정 사례·계산 결과를 저장한다.
- 같은 조건을 다시 불러와 확인할 수 있게 한다.
- 위험 지도·현상 지수·두 통행 기준·변경 전후 비교를 보고서로 출력한다.
- 기본값·가정·평가 범위·미평가·모델 한계를 함께 기록한다.

11. MVP 이후 기능
가. 소방시설 성능 연동
- 스프링클러·연결살수·배연설비 등의 작동 조건과 효과를 화재 계산에 연결한다.
- NIST 계산으로 가능한 범위와 별도 성능·수리 모델이 필요한 부분을 나눠 구현한다.
나. 배연 대안 비교
- 층별 또는 여러 층의 배연 위치·급기 경로·방법·유효 풍량을 비교한다.
- 배연 후보를 간편식으로 선별하고 상위 소수만 CFAST로 비교한다.
- 연기 감소와 함께 고립 개선·현상 조건 변화·화재 전파의 개선/악화를 평가한다.
- 일반 재실자·소방대원 기준으로 결과를 볼 수 있게 한다.
- 여러 층의 배연은 계단·샤프트 연결 영향을 포함해 검토한다.
