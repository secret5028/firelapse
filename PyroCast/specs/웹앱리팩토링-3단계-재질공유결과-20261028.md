# 건물 레이어 재질 공유 결과 — 2026-10-28

요청 범위 완료. 네 장면 모두 픽셀 차이 0. 운영 번들 배포와 push는 하지 않았다.

## 구현

- `app/web/layers/building.js`: 복제 Mesh/Line이 원본 `material` 객체를 직접 참조한다. geometry도 기존대로 빌린다.
- 최초 변경 전에 재질별 color 복사본·opacity·transparent를 Map에 한 번만 저장한다. 같은 재질을 여러 객체가 공유해도 이미 바뀐 값을 원래 값으로 덮어 저장하지 않는다.
- 색과 외곽선 opacity는 기존 install 분기를 담은 어댑터의 순서대로 적용한다.
- 재질은 소유 자원에 넣지 않는다. 재구성 또는 dispose 때 저장한 값을 복원하고, transparent가 달라지면 needsUpdate를 설정한다. 원본 material/geometry는 dispose하지 않는다.
- 기존 객체 선택 범위, 피킹 평면, 엔진, 서버, 캐시 키, 셰이더는 바꾸지 않았다.
