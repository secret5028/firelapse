PyroCast 실용 탐색 모드 / 2026-10-21

사용자 최신 결정: 세밀한 현상 재현을 더 늘리지 않는다. 도면 연결·실행 안정성과
가벼운 위험 탐색을 우선한다. 20261021 구현지시 개정2의 전체 구현을 뜻하지 않는다.

기본 실행
- CLI --profile practical, CAD 연결도 practical 기본. --profile legacy는 기존 가정을 유지한다.
- 30분 관찰, 5초 저장, 최대 시간간격 1초(해석기가 더 줄일 수 있음).
- 가스 추가연소는 기존 확장의 재고/산소 제한을 유지한다. 실용 모드 기본 Ea=0,
  k_ref=0.1/s. 산소 비례 인자를 포함한 대표 반응률이며 상세 화염 전파 속도가 아니다.
  native 문 연소 게이트 변경은 OFF. 온도·산소·대표 반응률은 사용자 설정.
- FO 600℃(조절 가능) 도달 시 유한 연료 공급을 30초에 걸쳐 확대한다.
  기본 연료 면적 기준. CFAST가 실제 발열·산소·연기·온도를 계산한다.
- FO 후 전달 복사만 최대4개 격자 대표점으로 분배, 30초 동안 비중 전환.
  엔진 화원/플룸은 추가하지 않는다. 격자점이 실제 연료 위치라는 뜻이 아니다.
- 최대6회 실행(사용자 설정해도 실용 상한8회), 총600초(상한900초),
  개별180초(상한300초). 숫자는 프로젝트 실행 정책이다. 수렴/출력 실패 때만
  1회 dt를 절반으로 재시도하며 같은 실행·시간 예산에서 차감한다.
- 고체 응답17노드, 최대0.2초(안정조건에 따라 더 줄어듦), 개구부 적분4격자.
  작은 시간간격을 건물 전체에 반응속도로 강제하지 않는다.

입력 경계
- building.json 파일, cad-output 폴더, 기존 프로젝트에서 건물을 찾는다.
  여러 건물이면 --building 경로를 지정한다. 특정 job/3F/R9는 필수가 아니다.
- 예전 v35 연료 파일 없이 용도 문구로 대표 연료를 생성한다.
  통로30MJ/m2·점유5%·150kW/m2, 보통실400MJ/m2·31%·250kW/m2,
  숙박 문구/건물용도310MJ/m2·31%·250kW/m2,
  공정/창고600MJ/m2·40%·250kW/m2. 모두 프로젝트 탐색 기본값이다.
  혼합 문구(홀+공정 등)는 저연료 통로로 단정하지 않는다.
- 철골/목조 문구: 저항을 가진 대표 경량 내장재. 그 외/미확인: 콘크리트 대용.
  실제 벽체 적층/구조 추정의 검증값이 아니다. 경계 구성은 사용자가 덮어쓸 수 있다.
- 100구획을 넘고 기존 병합이 불가능하면 화점 연결망부터 범위를 제한한다.
  제외 구역을 표시하고 절단 경계는 닫힘 근사. 전건물 결과로 해석하지 않는다.
- 개구부 위치 없는 연결은 임의 생성하지 않고 오류를 설명한다.
  외곽선·축척·층·개구부 연결 추출은 별도 CAD/OCR 파이프라인의 책임이다.
  모든 DWG/PDF/사진을 무조건 자동 처리하는 제품은 아직 아니다.

한계와 표시
- 한계 목록과 입력 경고를 result.json/playback.json/3D의 '계산의 간략화·한계'에 표시.
- 잘못된 열유속 후보는 제외하고 다른 후보는 계속 계산. 전부 미평가인 연료군은
  incomplete_exposure로 표시. 상한 종료도 전이 완료나 안전을 뜻하지 않는다.
- 첫 계산 실패 시 성공 결과를 만들지 않는다. 추가 계산 실패 시 이전 유효 상태 보존.
- 기존 결과는 덮어쓰거나 새 실용 모드 결과로 소급 표시하지 않는다.
- FGI/RO/BD는 층 평균 상태·반응 이력의 탐색 표시이다. 점화원별 래치, 상세 LFL
  고온 보정, FGI 펄스/PPE 선량, 폭연 압력, 1000회 무작위 점화 실험은 이번에 추가하지 않는다.
- NIST 원본과 Fortran 확장은 이번 변경에서 수정하지 않았다.

실행 예시 (simulation 폴더)
python -m pyrocast_cfbt examples/three_rooms.json --output results/my_practical
python tools/connect_cad.py C:/path/to/project --building C:/path/to/building.json --output results/new_building
python tools/connect_cad.py C:/path/to/cad-output --build-only --output results/preflight

3D: 기존 3D 생성 결과(model.html/로컬 CAD 자산)가 있는 폴더를 viewer 서버에 전달한다.
새 도면을 자동 업로드/OCR/3D로 생성하는 웹앱 전체를 이 연결 서버로 교체한 것은 아니다.
