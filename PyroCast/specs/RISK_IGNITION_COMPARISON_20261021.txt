위험 색상·선택 시점 가스 점화 비교 / 2026-10-21

사용자 요청
위험 유형 색상, 실·시점 선택 점화 가정의 온도/산소/연기/인접 고체 착화 비교,
현재 CAD에서 외기에 면한 화점실의 연료를 늘린 FO/RO/FGI 탐색 사례.
발생 확률을 임의 조절하는 기능이나 상세 폭연 해석은 구현하지 않는다.

위험 보기
- 위험 유형 보기: 보라색 FGI 가능 조건/가정 점화, 붉은색 BD 가능 조건,
  주황색 롤오버·가스연소 지표, 노란색 FO 열적 기준/공급 전환.
- 실 바닥/윤곽과 상층 연기에 같은 위험 색을 사용한다. 위험이 겹치면
  BD→가정 점화→FGI 조건→RO→FO 순으로 색을 정하고 상태 설명에는 함께 표시.
- 기본 온도/연기/산소 보기도 유지한다. 위험 보기에서는 구분용 보라색 플룸
  표시를 끈다(위험 색과 혼동 방지). 실제 화원 불꽃은 유지한다.
- 위험 플래그는 출력 시점 단위로 표시한다. 보간한 참/거짓으로 조기 점등하지 않는다.
- FGI 기본 선별: 연료 질량분율0.5% 이상, O2 체적10% 이상, bulk 반응이 없고
  실제 고체 화원이 타고 있지 않은 실. 모두 사용자 탐색 임계값이며 LFL/확률이 아님.
  이전 1.4/HoC 식을 질량분율 LFL로 취급하지 않는다.

점화 가정 비교
- 선택 실·현재 시각, 기본30초 점화 보조 창, 반응률0.2/s(0.01~1 설정).
- 지정된 실·시간에만 기존 상층 연료와 산소로 추가 반응. 온도 점화게이트만 우회.
  기본 O2 한계는 FGI 선별 O2값(10vol%). chemistry·재고 예약·산소 수지와
  상층 에너지 반영은 기존 확장 경로를 유지한다. 연료/발열을 임의로 새로 넣지 않는다.
- Fortran 확장에 force_room/time/duration/rate/o2_min 설정, 시간 경계 hook1개 추가.
  원본 vendor 소스는 무수정. 새 바이너리 build/ignition/cfbt/cfast-cfbt.exe.
  이전 실행파일은 보존한다. hook14개, 합성 원본 파일5개에 연결.
- 점화 후 약300초까지만 재계산하고 이후 고체 착화와 FO를 다시 판정한다.
  미래 고체 사건을 기준 결과에 고정하지 않는다. 앞선 시각 불변 검사도 수행.
  기준 재생은 동일 비교 시간까지 잘라서 비교한다(도면/개구부 일정은 자르지 않음).
- 기본 전체6회/600초 예산. 한도/실패의 경우 마지막 유효 결과·미완료 표시 유지.
- 기준/점화 토글, 실별 현재 온도/O2/OD 차이, 온도 점선, 고체 착화 시각 차이.
- 동일 기준 입력·엔진 해시·모듈 해시·실·시간·반응률의 비교는 재사용한다.
  예전 실패 결과나 코드/엔진이 다른 결과는 성공 캐시로 취급하지 않는다.
- API: POST /cfbt/ignite {case,room,time_s,duration_s,rate_s_inv};
  GET /cfbt/status, /cfbt/comparison.json, /cfbt/comparison-demo.json.
  서버에서 허용한 저장 사례/현재 결과만 참조하고 임의 파일 경로를 받지 않는다.

현재 CAD의 외기면 시연
- 3F R25: 외부 창 W1 및 통로 R15와 문 D5. 외기면 선택은 실제 CAD 연결정보 근거.
- 경량 국부 범위 R25/R15/R21 세 실,30분. 나머지 연결은 닫힌 절단 경계 근사이며
  전체 건물 전파 결과가 아니다. 전체3D는 유지하고 다른 구역은 미계산 표시.
- R25 입력 에너지4배, 최대 공급8배, 연료 면적 전체 바닥, HRRPUA750kW/m2,
  t2 alpha0.1875kW/s2. 실제 연료 조사나 NIST 기본값이 아니라 사용자 요청 가산 시연.
- 외부창10%→450초80%, 실내문15%→300초100% 가정. 단순 연료 증가 외에
  성장/연료면적/환기도 변경한 복합 시연이며 개별 변수 인과 효과로 해석하지 않는다.
- results/cad_exterior_risk_demo_v2: 실제3회 엔진 정상종료. FO600℃ 공급전환314.779s,
  R15 RO 지표95s/FGI 선별245s, R21 FGI 선별320s, R15 고체 착화506.039s.
- results/cad_exterior_ignition_demo: R21 380초 점화,680초까지 비교, 추가 반응 관측.
  R21 온도 기준 대비 최대 약296.31℃ 증가, O2 차이 최대약2.60%p,
  OD 차이 최대약1.345/m. 각 최대는 같은 시점이라는 뜻이 아니다.
  R15 고체 착화506.039→491.192초(약14.85초 앞당김). 둘 다 전이 탐색 완료.
- 이 시연은 실제 해당 건물에서 FO/FGI가 발생한다는 검증이 아니다.

한계
- 2층 평균·단방향 보충 복사·대표 연료/면적·시간간격 의존 근사는 유지한다.
- 점화 보조는 유한 시간 창 가정이다. 상세 화염 전파/폭압/열분해/혼합층 해석이 아니다.
- RO/BD는 유동·가스 반응과 이력의 지표이며 화염 전면/압력파의 관측 결과가 아니다.
