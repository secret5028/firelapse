# 4단계 항목 2 완료 — 표시 탭·HUD·범례

이번 범위는 표시 탭 ↔ 스토어, 범례 칩, HUD, 임계값, 보기/카메라 버튼 이동이다. 결과·탐색·건물 탭 재설계는 진행하지 않았다. 계산·재계산·서버 수정·push 없음.

## 변경

- 표시 탭: 레이어 9개, 위험 유형 4개와 주의, 임계값 2개, 불투명도 100/40/15%, 온도 무늬 현재/끔. 작전 기호는 기본 OFF. 기존 체크박스는 복제하지 않고 이동했고 결과 탭의 중복 입력은 0개다.
- 모든 입력은 스토어 액션으로 연결한다. 작전 기호는 경계 컨트롤러에서 CAD의 차량·인원/작전 그룹을 표시한다. 계산 조건은 바뀌지 않는다.
- HUD: 선택 실/셀 이름, 해당 셀의 최고 현상 지수 pill, 상층 온도·상층 산소·바닥에서 연기층 경계까지 높이. 기존 설명 5줄 삭제. 여러 셀의 새 평균은 만들지 않는다.
- 좌하 `#cfMeaning`에 현상 4종·주의·경계 점선·선택 칩. 원래 렌더러가 삽입하는 플룸 범례 의존을 유지한다.
- 위에서/비스듬히는 상단 보기로 이동. 3D 우상에는 ⟲/+/-/실 확대/연소점만 남긴다. 기존 카메라 동작을 실행한 뒤 스토어에 기록한다.

## 온도 무늬 — 사용자 확정 반영

옵션은 **현재 / 끔** 두 개이며 기본은 현재다. ‘약하게’ 옵션·툴팁·표시용 온도 보정식을 제거했다. 스토어도 weak 값을 거부한다.

기존 렌더러의 `temperatureSmoke` ON/OFF 입력만 사용한다. 래퍼에서 온도 입력이나 uniform을 직접 변경하지 않는다. 76개 연기 재질에서 끔은 `uTemperatureSmoke`만 변경되고, `uLayerTemp`를 포함한 나머지 uniform은 유지된다. 현재로 돌아오면 전체 uniform이 동일하다. 계산 시계열·HUD·셰이더 소스는 변경하지 않는다.

두 옵션으로 정정한 최종 번들에서 14개 토글·입력·HUD·카메라·dispose 검사를 다시 통과했고 데스크톱/모바일 캡처를 갱신했다. 위 4장면 픽셀 비교 자료는 직전 ‘현재’ 기본값 검사 결과를 보존했다. 이번에는 온도 uniform 불변과 현재 복원 시 전체 uniform 동일성을 추가로 검사했다.
