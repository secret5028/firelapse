# CAD → 3D 공리 적용 마무리

## 적용 결과

| 항목 | 이번 적용 전 | 적용 후 |
|---|---:|---:|
| 층 | 14 | 14 |
| 실 후보 / 공간 | 257 | 251 |
| 실에서 분리한 기둥 | 0 | 6 |
| 미연결 공간 | 47 | 41 |
| 수직 연결 | 6 | 20 |

최초 미연결 71건 중 앞선 문 인식·AI 검토로 24건을 해소했다. 이번 6건은 문 연결 복구가 아니라 기둥 중복 분류 제거다. B3 R5, B2 R12, B1 R13, 1F R8, 2F R7, 3F R7의 동일 위치 기둥을 구조물로 보존했다. 원래 폴리곤·면적·라벨은 보관했다.

계단·승강기 반복 위치와 대응 실 형상을 비교하여 수직 연결 20개를 구성했다. 램프는 형상만 보존하고 모델의 수직 이동·유동 연결에서 제외한다. 복합 복도를 통째로 계단실로 승격하거나 누락 층을 건너 연결하지 않는다.

## 남은 미완 표시

미연결 41건, 불명확 코어 대응, 정렬 문제, 로더 오류는 검토 목록과 도면 위치 표시에 남긴다. 입력 로더는 14층 중 13층 통과. B1은 `Opening wider than usable equivalent room: CAD_B1_R9`가 남아 있다. 이는 모델 열람 완료이지 모든 공간의 계산 적합성 확정이 아니다.

AI 검토 8건은 앞서 원본 CAD를 시각 검토하여 남긴 해시·형상 근거가 있는 결정이다. 공통 처리기는 이를 검증하고 적용한다. 잘못되거나 오래된 결정은 미확인으로 남긴다. 새 CAD마다 원격 AI API를 자동 호출하는 서비스는 이번 구현에 포함하지 않았다.

## 검증

- CAD 관련 단위 시험 44개 통과.
- 같은 입력 재적용 시 추가 보정 없음, 원래 공간 형상 보존 확인.
- 호텔 14층 전환, 보정/미완 필터, 위치 선택, 모바일 확인: 브라우저 오류 0, 변경 요청 0.
- 입력 어댑터 구성만 확인: 74개 계산 공간, 수직 개구부 20개(계단·승강기), 기둥의 계산 공간 혼입 0.
- 화재 시뮬레이션 실행 0회. 기존 저장 시뮬레이션 결과 변경 없음.
- 입력 어댑터에는 수직 연결 정책 검사만 추가했다. 계산 코어·조건표·실감 셰이더는 변경하지 않았다.

## 산출물

- `comparison.json`: 층별 전후·남은 실 ID·로더 결과.
- `building-before.json.gz`: 이번 적용 전 입력 스냅샷.
- `ui-verification.json`, `adapter-verification.json`: 검증 수치.
- `hotel-B2-column.png`: 기둥 분리와 남은 미완 표시.
- `hotel-5F-R17-before.png`, `hotel-5F-R17-after.png`: 문 연결 검토 표시.
- `hotel-review-B1.png`, `hotel-review-mobile.png`: 로더 오류 위치·모바일 표시.

공통 최종 처리 진입점은 `tools/finalize_cad_model.py`다. 과거 호텔 진단용 일회성 스크립트를 다시 실행해 과거 보고서를 덮어쓰지 않는다. 도면 → 3D 작업은 이 기준으로 마무리한다.
