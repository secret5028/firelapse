# C-4 경로 위험 표시 — 2026-11-02

C-4만 구현. C-5 미착수. 화재 계산 0회. 한 커밋, push 없음.

## 변경

- 경로 색상 폭 0.40m. 양쪽 0.08m의 어두운 외곽선(#07131d)을 추가해 총 외곽 폭 0.56m.
- 색상선 renderOrder 38, 외곽선 37, 높이 기존 바닥+0.12m. transparent=true, opacity=1, depthTest/depthWrite=false. 셰이더 변경 없음.
- 통과하는 원래 실의 멤버 셀 × FO/FGI/백드래프트/롤오버 저장 지수 중 최댓값으로 표시한다. 지수 ≥100은 해당 현상 색, 70≤지수<100은 회색, 나머지는 기존 파란색이다.
- 유형별 색은 기존 render_order.js의 RISK_COLORS를 import한다. 계산/판정식이나 해당 파일을 변경하지 않는다.
- 이력 ON: 기존 어댑터의 index_history_max를 사용한다. OFF: index_by_cell의 현재 출력 표본. 출력 사이에는 직전 표본을 쓴다.
- C-4의 100/70 기준은 고정이다. 테두리 유형 필터·표시 임계값과 독립적이며, 표시 필터 때문에 경로 위험이 누락되지 않는다.
- 다중 셀 방의 물리량 평균을 새로 만들지 않는다. 저장된 조건 지수의 최댓값만 경로 표시용으로 사용한다.
- 탐색 탭 ③ MC 카드 바로 아래, 규칙/경로 설정 위에 요약표. 순서·실·누적 거리·호스 번호·현상·지수 6열. 표본 시각과 현재/누적 기준 표시.
- 연속한 같은 실 구간은 한 행으로 합친다. 누적 거리는 구간 끝, 호스 번호는 그 구간에 걸친 본 번호 범위다. 외부 접근도 거리 장부에 포함한다.
- 다른 층 등 저장 평가가 없는 구간은 ‘미평가/—’. 파란색을 안전 판정으로 설명하지 않는다. 일부 지수 누락은 셀 근거 툴팁에 기록한다.
- 시간/이력 변경 시 재질 색과 표만 갱신한다. 경로 Dijkstra·기하 재생성·서버 fetch·엔진 실행 없음.
